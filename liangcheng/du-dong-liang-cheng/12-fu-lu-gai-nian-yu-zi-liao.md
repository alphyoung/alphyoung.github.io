# 12 附录：概念与资料

把反复出现的关键概念集中解释，并给出一张可以直接查对的历代归属总览。

## A.1 九阶段脉络一览

| 阶段      | 跨度                | 一句话主题                             |
| ------- | ----------------- | --------------------------------- |
| 序 地理底座  | —                 | 一个山地环抱的湖盆，加上一个走了千年的名字             |
| Ⅰ 史前湖畔  | 距今约 6700 — 4300 年 | 中原先民北上定居，石城聚落出现，“长城以北无仰韶文化”的旧说被推翻 |
| Ⅱ 边地初开  | 前 12 世纪 — 公元 3 世纪 | 农牧接触带第一次被纳入中原郡县与边塞体系              |
| Ⅲ 拓跋与北魏 | 1 — 6 世纪          | 中原郡县退出，草原政权在此设郡编户，“凉城”之名出现        |
| Ⅳ 隋唐边地  | 6 世纪末 — 10 世纪初    | 帝国重来，但以马邑郡、羁縻府州的方式间接管理            |
| Ⅴ 辽金元州县 | 10 — 14 世纪        | 北方王朝直接设州县，名字三次更改，终成中书省腹里          |
| Ⅵ 明代边墙  | 1368 — 1644 年     | 被推到大同镇边墙之外，成为蒙古土默特部的牧地与互市之口       |
| Ⅶ 清代厅县  | 1644 — 1912 年     | 察哈尔旗地（不设盟）与宁远厅并行，移民把这里重新纳入版图      |
| Ⅷ 战争与县制 | 1912 — 1949 年     | 现代县制确立，县治由田家镇转向新堂                 |
| Ⅸ 人与水   | 1949 年 — 至今       | 以流域为单位重新安排生产与生活                   |

## A.2 关键概念表

| 概念        | 含义                                              | 常见误解                           |
| --------- | ----------------------------------------------- | ------------------------------ |
| 岱海遗址群     | 环岱海的新石器时代遗址，以王墓山、老虎山、园子沟为代表，涵盖仰韶中晚期至龙山早期        | 误以为各遗址属于同一时期，或把“老虎山文化”当成某个古代民族 |
| 凉城郡       | 北魏设置的郡，隶恒州，郡治在岱海北侧；古籍亦作梁城郡                      | 误以为就是今天的凉城县，或以为县名自古连续          |
| 宁远        | 清代宁远厅、民国宁远县的名称，1914 年改为凉城县                      | 误与湖南、辽宁等地的宁远混为一谈               |
| 察哈尔特别区    | 1914 年设立的省级建置，1928 年改置为察哈尔省；凉城当时属其下的兴和道         | 误与清代察哈尔八旗混为一谈，或误以为它与绥远省是同一体系   |
| 内属蒙古      | 清代直接由朝廷任命总管管理的蒙古旗，察哈尔八旗属之；不设盟，也不设世袭扎萨克          | 误以为它们与北面的乌兰察布盟同属一套盟旗体系         |
| 旗与厅       | 清代在内蒙古中南部并行的两套管理安排，蒙旗与民政分掌不同人口与事务，俗称“旗厅并存、蒙汉分治” | 误以为两者职权完全分离、互不相干               |
| 卫所        | 明代以军事编制管理地方的形式，隶于都司、镇等体系                        | 误当作普通府县，忽略其军事性质                |
| 羁縻府州      | 唐朝授予地方首领官职、通过其管理部众的间接治理方式                       | 误以为与内地州县同样是直接派官管理              |
| 边外地       | 明中期以后长城以北、由蒙古诸部控制的地带                            | 误以为边墙两侧长期隔绝、从无往来               |
| 土默特部      | 明代蒙古右翼的一部，16 世纪中叶起由俺答汗统领，驻牧于大同边外与丰州滩一带          | 误与清代归化城土默特旗混为一谈                |
| 考古学文化     | 研究者归纳的一组具有共同特征、分布于一定时空内的遗存                      | 误读成古代国号或现代民族的古称                |
| 农牧兼营      | 种植、饲养与狩猎共同构成生计的经济形态                             | 误用“农耕 vs 游牧”的二分去套每个居民          |
| 岱海        | 凉城县境内的湖泊，湖岸与水面长期变化                              | 误以为旧称“天池”由康熙所赐                 |
| 敕勒川 · 土默川 | 与今呼和浩特、大青山南麓相联系的历史区域名                           | 误等同于岱海盆地，或误当作一个县的历代曾用名         |

## A.3 凉城地区历代归属总览

今天的凉城县在 1914 年定名，古代各郡县的边界与现代县界不同；同一时期，今县境也可能分属不同单位。本表用于查对，不用于推演。

| 时期          | 管辖政权或实际控制者              | 主要行政隶属与变化                                                                         |
| ----------- | ----------------------- | --------------------------------------------------------------------------------- |
| 新石器时代       | 本地聚落人群                  | 岱海遗址群（王墓山、老虎山、园子沟等）见证仰韶至龙山时代；尚无王朝行政单位可考                                           |
| 夏、商、西周至春秋   | 本地人群及其组织                | 尚无足够证据落实到某个王朝直属行政单位                                                               |
| 战国后期        | 赵国                      | 地方志记为赵国雁门郡地                                                                       |
| 秦           | 秦朝                      | 雁门郡                                                                               |
| 西汉          | 汉朝                      | 初年曾属分封的代国；主要涉及雁门郡沃阳等县                                                             |
| 东汉          | 汉朝，末期控制衰退               | 与并州所辖雁门郡相关；《后汉书》所列郡辖县包括疆阴，已不见沃阳                                                   |
| 三国          | 鲜卑等部落首领                 | 拓跋鲜卑势力逐渐发展，不能确认为曹魏稳定直辖县地                                                          |
| 西晋          | 地方部族首领，与晋朝存在归附、册封关系     | 拓跋等首领组织部众，出土晋朝官印反映政治联系                                                            |
| 东晋十六国       | 拓跋代政权，后受前秦支配，再转入北魏      | 376 年前秦灭代；386 年拓跋珪复国并改号魏，不属南方东晋直接管辖                                               |
| 北魏          | 北魏                      | 恒州—凉城郡相关县地；今县南部还涉及善无郡                                                             |
| 东魏、北齐、北周    | 北朝边境政权与北方力量交错           | 旧郡县废置调整，相关地区有紫阿镇记载；全县范围内连续、统一的隶属尚不能确定                                             |
| 隋           | 隋朝                      | 马邑郡；隋末突厥势力介入                                                                      |
| 唐           | 唐朝羁縻体系，控制范围随时期变化        | 主要隶属线索为单于都护府—桑乾都督府，机构后来有迁治                                                        |
| 唐末、五代       | 契丹势力逐步扩展                | 逐渐转入辽朝统治，具体交接过程缺少完整地方记录                                                           |
| 辽（与北宋并立）    | 辽朝                      | 西京道—德州—宣德县，不属北宋                                                                   |
| 金（与南宋并立）    | 金朝，金末转入蒙古统治             | 西京路—大同府—宣宁县；1168 年由宣德县改名                                                          |
| 元           | 元朝                      | 中书省腹里—大同路—宣宁县，不属岭北行省                                                              |
| 明初          | 明朝                      | 大同北部军事卫所体系，地方沿革记有宣德卫                                                              |
| 明中后期        | 岱海一带为蒙古土默特部的驻牧地         | 成为大同边外地，地方沿革记万历十年（1582）属蒙古土默特政权；今县域南缘边墙与明朝大同镇防务相连                                 |
| 清           | 清朝，蒙旗与民政机构并存（旗厅并存、蒙汉分治） | 蒙旗为察哈尔镶红、镶蓝旗（沿革另记正红旗），属内属蒙古、不设盟，归察哈尔都统系统；民政由宁朔卫、怀远所演变为宁远厅，清末属山西省归绥道，1884 年厅治移驻科布尔 |
| 1912 — 1914 | 中华民国政府                  | 宁远厅改宁远县，属山西归绥道，随后随绥东各县改属绥远特别区                                                     |
| 1914 — 1928 | 中华民国政府                  | 改名凉城县；察哈尔特别区（察哈尔省前身）—兴和道—凉城县                                                      |
| 1928 — 1937 | 中华民国政府                  | 察哈尔特别区改置为省、兴和道裁撤，划归绥远省—凉城县                                                        |
| 1937 — 1945 | 日伪占领政权与抗日力量分区控制         | 占领区后来纳入伪蒙疆巴彦塔拉盟体系；山区有抗日根据地                                                        |
| 1945 — 1948 | 国共双方争夺，控制范围反复变化         | 国民政府区划属绥远省；中共县政权隶绥南专署；1948 年后中共县政权在全县确立                                           |
| 1949 — 1954 | 中华人民共和国                 | 绥远省—和林专区，1950 年转入集宁专区                                                             |
| 1954 — 1958 | 中华人民共和国                 | 内蒙古自治区—平地泉行政区—凉城县                                                                 |
| 1958 — 2003 | 中华人民共和国                 | 内蒙古自治区—乌兰察布盟—凉城县                                                                  |
| 2003 年以后    | 中华人民共和国                 | 内蒙古自治区—乌兰察布市—凉城县                                                                  |

## A.4 周边名称速查

| 名称              | 含义                   | 容易混淆之处                |
| --------------- | -------------------- | --------------------- |
| 岱海              | 凉城县境内的湖泊             | 旧称众说纷纭，不必都坐实到同一水域     |
| 阴山 · 蛮汉山        | 大山系与其中的支脉            | 蛮汉山不是独立的另一条山脉         |
| 敕勒川 · 土默川       | 与今呼和浩特、大青山南麓相联系的历史区域 | 与凉城相邻，不能直接等同于岱海盆地     |
| 林胡 · 楼烦         | 先秦北方人群与部落名称          | 不代表现代县域内固定的国家         |
| 匈奴              | 秦汉北方的重要政治力量          | 不能概括此前所有北方人群          |
| 柔然 · 敕勒（高车）     | 北魏时期不同的北方政治力量与人群     | 两者不是同一群体，与北魏或战或和      |
| 突厥 · 沙陀         | 不同时期的北方族群与政治力量       | 东突厥影响隋唐边疆；沙陀在唐末五代代北崛起 |
| 契丹 · 女真 · 蒙古    | 分别与辽、金、元的建立密切相关      | 政权更替并不等于原有居民整体消失      |
| 丰州 · 白塔         | 今呼和浩特赛罕区的古城与佛塔       | 与凉城的德州、宣宁县分别具有行政沿革    |
| 王墓山 · 老虎山 · 园子沟 | 史前遗址及其研究线索           | 不是同一时期的一座城            |
| 参合陂             | 史籍地名及战役名称            | 具体位置存在学术争论            |
| 田家镇 · 新堂        | 旧县治所在地与后来的县城中心       | 同一县名之下行政中心曾转移         |
| 绥远 · 归绥         | 近代省级区域与城市名称          | 不是同一个地理单位             |
