# 02 阶段一·史前湖畔

凉城有人居住的历史，从岱海周边的台地开始。岱海遗址群用成排的房屋、窑洞与石砌围墙，推翻了“长城以北没有仰韶文化”的旧认识——中原的彩陶、东来的纹饰与本地的手艺，在这片湖岸上合成了新的文化。这一阶段的转折点，是聚落从单纯的居住点，走向需要协调大量人力才能修筑的设防村落。

* **约六千年前** 王墓山聚落
* **约四千年前** 老虎山石墙
* **仰韶阶段** 中原先民北上
* **龙山阶段** 窑洞与石城

## 1.1 为什么选择山坡，而不是紧贴水边

_新石器时代_

今天谈环岱海史前遗址，常会遇到**王墓山、老虎山和园子沟**。它们构成**岱海遗址群**的核心，时间跨度约从距今六千七百年到四千三百年，横跨仰韶文化中晚期与龙山文化早期。这批遗址是二十世纪中国北方史前考古最重要的收获之一：它**打破了“长城以北没有仰韶文化”的旧认识**，也让中华文明起源阶段的一次重大变动留下了可以丈量的物证。要注意的是：所谓“环湖”，**不意味着所有房屋都建在同一条岸线上，也不意味着这些聚落同时繁盛。**

这批遗址之所以出现在这里，与气候有关。距今约六千七百年至六千年前，这里比今天温暖湿润，**岱海湖面约是今天的四倍**，湖滨台地宜耕宜渔。中原的先民分两路北上：一支从华北平原沿永定河、桑干河上溯，一支自晋中汾河、关中渭河沿黄河而来，在岱海南岸的丘陵阴坡落脚，垦荒种地，也捕鱼狩猎。考古学家田广金把这次迁徙称为人类历史上最早的\*\*“走西口”\*\*。

落脚点选在**背山面水的山坡**，而不是紧贴湖岸的滩地：山坡排水好，不易受湖水涨落侵袭，又能俯视湖面与河谷，靠近耕地与渔场。发掘所见房址**成排分布**，居住面经过烧烤硬化，说明定居已相当稳定。当时湖面远大于今天，**当年的岸线其实就在聚落近旁**。

以王墓山坡下遗址为例，考古报告把它放在山坡、冲沟、季节性河流与岱海的关系中描述。研究者关心的，不只是它离湖多远，还包括坡度、侵蚀以及水流是否破坏过遗迹。

定居者需要接近水，也需要相对稳定的居住面；要取得食物，也要处理排水、取土和燃料供应。湖泊岸线与地表长期变化，古代聚落与水源的距离也不同于今天——**今天看到的“距湖多远”，不等于当年的取水距离。**

## 1.2 王墓山：陶器里的日常生活

_仰韶阶段_

王墓山一带的发掘，是建立岱海地区仰韶时代文化序列的重要工作。不同地点的地层与器物组合，让研究者能够比较早晚变化，**而不是把“六千年前”当作覆盖全部遗迹的统一标签。**

陶器首先是生活用品。容器的开口、腹部和底足不同，可能与储存、烹饪和搬运有关。制陶与用火技术，参与了湖边居民日常生活的许多环节。**从器形的变化里读出的，是做饭、盛水和搬东西的方式在变。**

王墓山出土的器物里，有一类东西格外有地方特色：**火种炉**。它兼具保存火种、照明与取暖的功能，在岱海地区成批出现——同期的河南孟津、山西芮城也有出土，但数量远不及这里。**在这片湖岸上，火不只是灶里的偶然光亮，而成了需要用专门器物维系的技术。**

仰韶晚期，湖岸上的人群构成更复杂了。一支来自太行山东侧、以**小口双耳罐**为水器的文化，与带来**筒形罐和鱼鳞纹**的红山文化因素先后到达岱海—黄旗海一带，与本地使用**小口尖底瓶**的人群相遇、融合，形成一支具有鲜明地方特征的**海生不浪文化**。陶器上因此同时能看到中原的彩陶纹样、东来的鱼鳞纹，以及本地创新的网格纹与涡纹。

{% hint style="info" %}
**概念辨析｜文化的相遇，不等于人群的替换。海生不浪文化里那几支外来因素，学界更倾向解释为技术、器物与纹样的传播**，而不是大规模的人口迁徙——红山文化的筒形罐到了岱海，纹饰就与辽西本地作品明显不同。考古材料能证实的是人群之间持续的往来；往来的规模与形式，还需要另找证据。
{% endhint %}

## 1.3 老虎山：当一个村落开始修墙

_龙山阶段_

进入龙山时代，**老虎山、园子沟**等地出现了新的聚落形态。老虎山遗址依山势修筑，面积约十三万平方米，四周环绕石砌围墙，南北长约三百七十米、东西宽约三百三十米，是迄今发现的我国古代最早、最完整的石墙防护体系之一。

修筑围墙意味着劳动需要协调：石料从哪里来，谁来搬运，墙线怎样安排，损坏以后由谁维修？\*\*围墙使人看见超出单户家庭的组织能力。\*\*不过，从“有公共工程”到“已经建立王国”，中间仍需要社会分化、权力结构等方面的证据——墙本身证明的是协作，而不是王权。

老虎山文化板城遗址的发掘还发现了窑洞式房屋、陶窑和灰坑。部分房屋保留抹壁痕迹与灶的结构，不同形式的陶窑则展示出制陶技术。这些材料把抽象的“史前文化”还原成一连串具体劳动：**挖掘、抹墙、生火、塑形、烧制。**

园子沟则是目前国内发现的原始社会时期**窑洞式房屋**遗址中规模最大、保存最完好的一处，已发掘房址八十多座。房屋依山成排，多数前有院落；讲究的房址分前后两室——**前室设灶，是做饭、就餐的地方；后室地面与洞壁抹白灰，灶居室中，屋角还有约一米高的白灰墙裙**，用来休息与会客。四千年后再看这种格局，它正是中国古建筑“前堂后室”的原型。

{% hint style="info" %}
\*\*学者评价｜“凉城的老虎山、园子沟文化是高楼大厦”。\*\*实地考察过这批遗址的考古学家苏秉琦这样比较：“现在历史教科书上的半坡文化是土房矮屋，而凉城的老虎山、园子沟文化是高楼大厦，它们是中华民族五千年文明的曙光。”他看重的是石砌城墙、祭祀台、白灰敷壁与规整火塘所体现的组织与技术水准——在这一代学者眼中，这里处在同期文化的领先位置。
{% endhint %}

石城为什么会出现？一种解释指向气候：距今五千五百年前后有一次寒冷期，此后干冷加剧，岱海来水减少、可耕地收缩，聚落之间的资源竞争随之紧张，**设防的高地聚落于是成为主流**。环壕与石城，是同一件事在不同环境下的两种做法——前者围住平地的聚落，后者守住临河的台地。

{% hint style="info" %}
\*\*概念辨析｜“老虎山文化”不是国号，也不是民族名。\*\*考古学文化是研究者用来归纳一组具有共同特征、分布于一定时间和空间内的遗存的概念。它帮助人们比较生活与技术传统，但它既不是古人留下的国号，也不是今天某一民族的古称。把考古学文化直接读成“某个古代民族”，是最常见的越界。
{% endhint %}

{% hint style="info" %}
\*\*人物故事｜考古学家怎样让湖边的房屋重新出现？\*\*田广金等考古工作者在岱海地区开展的调查与发掘，将零散地点逐步放进可以比较的文化序列。考古发现的价值不只在于找到漂亮器物，也在于记录一堵墙压住什么地层、一个灰坑打破哪座房屋。**被认真保存的位置关系，往往比一件脱离出土背景的古物更能说明历史。**
{% endhint %}
