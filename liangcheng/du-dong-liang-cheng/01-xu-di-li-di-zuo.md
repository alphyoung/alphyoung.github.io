# 01 序·地理底座

凉城的全部历史都发生在同一片地形里：一个山地环抱的湖盆。在进入编年之前，先把四件事说清楚——这片湖盆在阴山格局中的位置，湖本身的名字与水位，它向西与“敕勒川”的关系，以及“凉城”这个名字从北魏郡名到现代县名的一千年旅程。

## 0.1 一座湖盆，几个方向

_地理_

凉城县位于内蒙古乌兰察布市南部，与山西北部相邻。中央是岱海及周围盆地，外围是山地与沟谷，道路将这里与晋北、呼和浩特和乌兰察布其他地区连接起来。

湖盆为聚落提供了水土条件；山地影响耕地分布、放牧空间和出行方向；道路则使本地人的生活与更远的市场和政权相连。凉城的历史地位随周边中心的变化而改变：\*\*大同强盛时，这里与大同腹地的联系突出；归绥和集宁的重要性上升后，凉城与这些城市的联系也更加紧密。\*\*同一片湖盆，在不同时代被不同方向“拉”进不同的世界。

## 0.2 阴山伸向岱海：山梁之间的凉城

_地理_

凉城的山川属于更大的阴山地理格局。阴山横亘内蒙古中部，由多段山地构成；凉城西北的**蛮汉山**是其支脉，山地西北面向土默特平原，东南面向岱海盆地。县境北部的蛮汉山、南部的**马头山**与中部的**岱海**，构成山地环抱湖盆的地形。

阴山南北的水热条件、植被和生产方式存在差异，山地又有沟谷可供通行。这使它既影响农业与牧业的分布，也影响军队行进、人员迁徙和贸易路线。凉城处在这一过渡地带，**湖盆中的种植、山坡上的放牧以及山间道路上的往来，可以同时存在。**

从赵、秦汉的北方经营，到北魏的边防，再到明代大同镇的边墙，山口、水源和能够供给粮草的地方，反复成为争夺与经营的对象。阴山并没有几千年不变的政治边界；同一条山道，在不同时期可能连接腹地与边塞，也可能连接两个政权的市场。

## 0.3 岱海向西，是敕勒川的世界

_地理_

“敕勒川，阴山下。”这句北朝歌谣所唤起的原野，通常与今天呼和浩特、土默川及大青山南麓联系起来。土默川东缘抵近蛮汉山，而岱海盆地位于山地另一侧。凉城与这片平原相邻，通过山间道路联系；**两者各有自己的地形和地方历史。**

云中川、敕勒川、白道川、丰州滩、土默川，是认识呼和浩特周边历史时经常遇到的名字。它们有的来自郡城，有的来自部落，有的来自交通孔道，\*\*范围并不完全重合，也不是一个县依次换了五次名字。\*\*把视野从岱海向西展开，才能看清凉城为何不断与云中、盛乐、丰州和归绥发生联系。

{% hint style="info" %}
**疆域 · 别把相邻当成同一** —— “敕勒川”与“岱海盆地”是相邻而不重合的两个地理单元：前者指大青山南麓、今土默川一带的平原，后者是阴山支脉东南侧的一个封闭湖盆。它们在历史叙事中经常一起出现，因为人员、军队和物资正是沿着山间孔道在两者之间来回，而不是因为它们是同一块地方。
{% endhint %}

## 0.4 从凉城郡到凉城县：一个名字的千年旅行

_地名_

凉城县旧称**宁远**，其名称的历史源头可以追溯到北魏**凉城郡**，古籍中也写作**梁城郡**。“凉城”作为现代县名，确立于 1914 年：民国初年的宁远县因与湖南、辽宁等地的宁远县重名，采用北魏旧郡名，更名凉城县。**古老的郡名重新成为地方名称，但北魏郡域与现代县域并不相同。**

关于“梁城”与“凉城”，地方还有在山梁设郡、因气候凉爽而得名的解释。《水经注》保存的说法则是：湖西已有一座俗称凉城的旧城，郡名取自这座城。可以确定的是，**这个名称早于清代，并非始自康熙年间。**

县治的位置也换过。**田家镇**是旧县治所在，与今天的永兴镇相联系；**新堂**则与后来县城的发展相联系。同一个凉城县名之下，行政中心曾发生转移——这条线索会在第八阶段收尾。

{% hint style="warning" %}
\*\*地方传说与可考史实要分开看。\*\*岱海一带流传着把湖泊与康熙巡边联系起来的故事：相传皇帝来到湖边，喜爱这里的凉爽与水色，兴建行宫，为湖题名“天池”，又留下“凉城”的名字。故事寄托着人们对岱海风光的赞美，但赐名、题字与行宫的具体情节，目前缺少可确证的同时代材料；“凉城”之名在北魏已经存在，现代县名则启用于 1914 年。
{% endhint %}

## 0.5 岱海：一片湖的名字，与它的水位

_地理 · 地名_

岱海所在的湖盆，是一个狭长的陷落盆地：北有蛮汉山，南有马头山，水汇在中间的低处。地质研究认为，这一带在较早的地质时期气候湿润、水系发育，湖面高于现在，湖水曾沿着河道向外流；后来气候转干、来水减少，多余的水不再外流，岱海便成为一个依靠周围二十多条河流与地下水补给的内陆湖。\*\*这片水从来不是静止的：它的形状与大小，取决于来水与蒸发之间的长期平衡。\*\*史前大暖期里它曾大幅扩张，据考古研究推算，距今约六千七百至六千年前的湖面约为今天的四倍；此后又几经涨落。

湖在不同时代留下过不同的名字。《汉书·地理志》雁门郡下已记\*\*“盐泽”**（即盐池），是文献中较早的称呼；另有**“诸闻泽”**一名，常被联系到岱海，但《中国历史地图集》把诸闻泽标作黄旗海，两说并存。北魏郦道元《水经注》承《汉志》记**盐池\*\*，并写“沃水又东北流注盐池，池北七里即凉城郡治”（“七里”旧刻讹作“十里”）——沃水就是今天从西南流入岱海的弓坝河，盐池即今天的岱海。北魏在这里设县，县名**旋鸿**，据说取自湖上的水鸟。**湖名与县名一起进入史册，说明这片水一直是本地设治得以成立的理由之一。**

辽、金、元时期，湖名随王朝更迭而变：辽称\*\*“奄遏下水”**，金称**“昂阿下水”**，元称**“下水”**。金代还在湖畔设置了**下水镇\*\*（一般认为在今岱海南岸），元代并置下水站，是丰州通往大都驿路上的节点——镇的建制直接以湖水为名。宋元以来的汉文记载里还有\*\*“鸳鸯泊”\*\*一类说法，湖上水禽成群，是这些名字共同的来源。**名字换了几次，湖作为这片山地与草原之间最重要水源的身份却没有换。**

清代，蒙古语名称进入官方文书，写作**岱噶淖尔**（亦作岱噶津尔）、**岱哈泊**等，光绪初年才固定为今天的**岱海**。民间把康熙巡边、题名“天池”与这片水联系在一起；传说中的行宫后来改称汇祥寺，曾是当地规模最大的寺院之一，时称“绥东第一大刹”，1939 年 11 月被国民党六路军焚毁。传说之外可以确认的是：直到清代，岱海仍是这一带最显眼的地标，宁远厅的治所与周边的村庄、市镇，都围着它安排。

湖也是资源。水、草、鱼和湖边的滩地，支撑过牧群、渔船与农田；湖一变小，靠它生活的人就得跟着调整。二十世纪后半叶以来，岱海明显萎缩，水质一度恶化，人与湖的关系因此成为当代凉城最紧迫的问题——这一段留到第九阶段展开。
