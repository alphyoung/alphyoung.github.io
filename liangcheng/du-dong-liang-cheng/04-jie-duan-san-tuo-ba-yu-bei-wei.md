# 04 阶段三·拓跋与北魏

中原郡县的北边控制衰退时，草原上的整合已经先行一步。二世纪中叶，鲜卑首领檀石槐把各部编成东、中、西三部，其中的拓跋部向西南移动，落脚在参合陂一带——这正是今天岱海的东北。此后代国建立，北魏设凉城郡、隶恒州，郡治就在岱海北侧，“凉城”这个名字由此出现。同一时期，参合陂之战与敕勒部众的迁入，让这里成为草原政治力量进出的通道。这一阶段的转折点，是本地治理方式的反转：此前是朝廷派官、设县、定籍，此后先由部落首领组织部众，再由一个以草原为根基的王朝重新设郡编户。

* **西晋** 鲜卑 · 乌丸归义侯印
* **386** 拓跋珪改号魏

## 3.1 檀石槐与三部鲜卑：草原的一次整合

**1 — 3 世纪**

东汉初年，**乌桓**与**鲜卑**同出被匈奴击破的东胡，长期役属于匈奴；乌桓较早被汉朝迁入上谷、渔阳等五郡塞外。公元 91 年北匈奴西迁之后，鲜卑进据漠北，成为草原上最主要的力量。**“匈奴之后”的草原并没有空下来，只是换了一批组织者。**

二世纪中叶，鲜卑首领**檀石槐**把各部整合起来，立庭于弹汗山，分其地为东、中、西三部，各置大人统领。《后汉书》记他“南抄缘边，北拒丁零，东却夫馀，西击乌孙，尽据匈奴故地”，并特别写到他“网罗山川水泽盐池”。**“盐池”正是岱海在北魏以前的称呼之一：对游牧政权来说，水泽与盐池是必须掌握的资源，而不是风景。**

在这一格局里，鲜卑的西部长驱西南，其中一支——**拓跋部**——越过阴山，落脚到参合陂一带，也就是今天岱海的东北方向。地方志把这一步记作凉城与鲜卑相遇的起点。**换句话说，后来在这里设凉城郡、留下“凉城”之名的那个政权，最初是以草原部众的身份走进这片湖盆的。**

檀石槐死后，三部解体，各自发展。三世纪前期，**轲比能**一度再统一漠南鲜卑，与曹魏时和时战，235 年被刺杀，联盟随之解散。**草原上的整合与解体反复交替，没有哪一次是永久的。**

西晋时期，拓跋部首领受晋朝册封，并与并州方面结盟共抗刘渊，拓跋猗卢被封为代公、代王，代国由此建立。《魏书·序纪》记拓跋猗㐌统领的一部居于代郡参合陂北面，能率十余万骑。**1956 年，凉城县西北的小坝子滩窖藏出土“晋鲜卑归义侯”金印**，同出“晋乌丸归义侯”金印、“晋鲜卑率善中郎将”银印及刻有“猗㐌金”的四兽形金饰牌，正是这类政治关系的实物：朝廷授名号、给印绶，**部众仍由首领自己组织**——这套办法后来被隋唐的羁縻府州沿用。

339 年，代王**拓跋什翼犍**在参合陂会集诸部落首领；371 年，**拓跋珪**出生在参合陂以北。**这片湖盆于是成了拓跋部从草原走近平城、走向北魏之前，最重要的一处落脚地。**

## 3.2 盛乐与平城之间：拓跋兴起与北魏设郡

**三国 — 北魏**

鲜卑各部经过整合又解体之后，这一带的治理方式与内地州县仍然不同。东汉末至三国，汉朝原有的北边郡县控制衰退，今凉城一带主要由部落首领组织部众，**曹魏稳定的县级直辖关系尚难确证**；地方首领与西晋之间有受封、归附与军事合作，但**部众仍由首领自己统领，并不等同于朝廷派官管理。**

到东晋十六国时期，这一地区进入拓跋代政权的活动与控制范围。376 年前秦灭代，代国故地一度受前秦支配；386 年**拓跋珪**重建代国，随后改国号为魏，**北魏**兴起。南方的东晋并不直接管辖凉城。

拓跋鲜卑及北魏的兴起，深刻影响了内蒙古中南部与晋北地区。**盛乐**所在的和林格尔一带与**平城**所在的大同地区，是这一时期的重要政治中心，凉城与岱海处在它们周边的山川和交通网络之中。

北魏设**凉城郡**，隶恒州，郡治在岱海北侧，相关县份有**参合、旋鸿**等。今县南部还涉及**善无郡**辖地，说明\*\*今天的凉城县域并不完全等于当年的凉城郡。\*\*北魏时期的直接上级关系，为“北魏—恒州—凉城郡、善无郡相关辖地”。

政治中心从草原边缘向平城发展，意味着统治者需要同时处理牧业资源、农业人口和更大规模的行政事务。**鲜卑也不是一个始终由同一君主统率的整体**；拓跋部、慕容部等拥有不同的政治经历。

## 3.3 参合陂之战：一场地望未定的胜仗

**395 年**

\*\*395 年，拓跋珪领导的北魏军队在参合陂击败后燕军队。\*\*这场战争是北魏崛起的重要事件，因此经常进入凉城的地方历史叙事。

但是，**参合陂的具体位置存在争议**，主要有三说：一说即今岱海（《辞海》《中国历史地图集》采此说）；一说为今黄旗海东岸一带（丁谦首倡，张文平《燕魏参合陂之战地望新考》申论，并区分不同时期的参合县与参合陂）；《大清一统志》则主张在山西阳高。此外《水经注》把战场系于参合陉（今岱海西南一带）。因此，\*\*这场战役与今日岱海之间的地理对应关系尚无定论。\*\*地方叙事里最响亮的故事，恰恰是地望最不确定的一个。

{% hint style="info" %}
**历史小故事｜柔然南下：北魏身后的对手。**

北魏向中原扩展时，北方还有**柔然**这一强大对手。公元 402 年，北魏道武帝拓跋珪出征后秦，柔然首领社仑乘机南下。《魏书》记其军队进入参合陂，又至善无以北的湖泽地带。这些地名与凉城、晋北的历史地理相联系，但参合陂的具体位置仍有争议。**故事揭示了北魏的难题：向南用兵时，还须防备北方对手切入身后。**

柔然与北魏的关系也曾通过婚姻和使节缓和。434 年，柔然可汗吴提与北魏宗室女子联姻，北魏太武帝也纳吴提之妹。**边地的政治关系在战争、和亲与再次交战之间反复变化，并非始终处于同一种对抗状态。**
{% endhint %}

## 3.4 敕勒迁徙：歌声背后的离乡与定居

**429 — 546 年**

**敕勒**与史书中的**高车**诸部关系密切。429 年，北魏太武帝拓跋焘出击柔然，随后又遣军招降、征服东部高车，**将大量部众迁置漠南**。《魏书》描述他们迁居后继续畜牧，逐渐增加谷物食用与农业生活，向北魏贡献牲畜、毡皮等物资。**史籍的迁置范围很广，不能缩成“十余万人同年全部搬到敕勒川”。**

敕勒川的名字与敕勒人群在阴山南麓的活动、居住相联系。这里既有牧群和毡帐，也有战争造成的强制迁徙，以及迁来者重新安排生活的经历。北魏早在 386 年兴起，398 年迁都平城；**429 年的迁徙，是这一政权发展过程中的人口重组，而非北魏建国的起点。**

{% hint style="info" %}
**历史小故事｜斛律金的一曲乡音。**

546 年，东魏权臣高欢进攻西魏玉壁城，久攻不克，损失严重，自己也病倒了。退兵之后，为回应关于他受伤的传言，高欢勉强坐起会见众人，让敕勒出身的将领**斛律金**唱起《敕勒歌》，自己也跟着和唱，感伤落泪。这一场景记在《北齐书》中，发生于山西方向的战争与退兵背景下。

今天人们常用《敕勒歌》赞美草原。把它放回这段历史，**歌中还有失意者对家园的惦念**：穹庐般的天空、开阔的原野与牛羊，是离乡将士心中熟悉的生活。斛律金的唱歌经历也不等于他独自创作了今天所见的全部诗句；歌谣经过传唱、转译和记录，才成为流传至今的文学作品。
{% endhint %}

## 3.5 北魏之后：旧郡废置与边境的反复调整

**6 世纪**

北魏末年，凉城郡原有建置在动乱中废置。东魏、北齐至北周时期，这一带处在北朝政权与北方力量接触的边境，郡县和军事据点不断调整。

《辽史》追述相关地区曾有北齐设置的**紫阿镇**，但对其具体位置和辖境的记载不足，\*\*无法据此确定今天全县在这一时期始终由同一个机构管辖。\*\*换句话说，郡县的招牌虽然换过，却很难说清哪一年、哪一级机构在管这里——这正是北朝末年边地的常态。

北魏之后，本地档案里“隶某郡”的线索一度中断。这一度中断，本身就是北朝末年边地的实况：政权更迭频繁，郡县的设置跟着军事形势反复调整，等隋朝统一，才重新接上一条明确的隶属线索。
