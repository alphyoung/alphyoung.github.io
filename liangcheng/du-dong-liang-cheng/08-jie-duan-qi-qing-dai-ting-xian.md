# 08 阶段七·清代厅县

清代用移民、旗地与厅制重新组织这里的人口和土地：山西、陕西的家庭沿“走西口”的路线迁入，察哈尔八旗（内属蒙古，不设盟）的旗地与民政厅县同时存在，1734 年设宁朔卫、怀远所，1750 年改置宁远厅，治田家镇。这一阶段的转折点，是行政与生计一起落地——村庄、市镇与衙署同时出现，今天凉城的行政雏形与商业中心由此成形；旗与厅并存、“一地两制”的运作方式，则成为理解当地的钥匙。宗教与曲调的流动，也把这里与晋北连在了一起。

* **18 — 19 世纪** 走西口移民
* **察哈尔** 镶红 · 镶蓝旗 · 不设盟
* **1734** 宁朔卫 · 怀远所
* **1750** 设宁远厅（治田家镇）
* **清末** 山西省归绥道

## 7.1 清代移民带来的，是一个个家庭的生计选择

18 — 19 世纪

清代内蒙古中南部的开发，使蒙地原有社会与进入当地的农业人口产生了更密切的联系。凉城曾存在**旗厅并存**的治理格局。

\*\*“移民”这个词，落到生活里，是找地、筹种、建屋与安排家庭。\*\*迁入者需要适应当地雨水和土壤，也要处理土地使用、租佃以及与原有居民的关系。**这些土地此前已有放牧、通行和其他资源利用活动，农业扩展改变了原有的使用方式。**

这一过程与更大范围的\*\*“走西口”\*\*人口流动相联系。山西、陕西等地迁来的家庭，不仅携带种子和农具，也带来方言、曲调与节俗。**不同家庭的迁居时间、路线和落脚经历各不相同**，农田和村庄的增加也改变了原有土地使用关系。

**二人台**的形成，是文化在迁徙中发生变化的一个例子。它在蒙汉民歌、坐腔与民间歌舞相互影响的基础上发展，有些地方曾用蒙汉语穿插演唱，称为\*\*“风搅雪”\*\*。这一民间小戏后来流传于内蒙古中西部及晋、陕、冀相邻地区，连同晋剧等艺术，构成当地居民熟悉的声音世界。**二人台并非从内地原样搬来的剧种，而是在共同生活中逐渐形成的艺术。**

## 7.2 宁远厅与田家镇：一套治理体系的落地

1734 — 1911

清代，今凉城地区的蒙古部众和旗地主要涉及**察哈尔镶红旗、镶蓝旗**（凉城县政府沿革另记有正红旗），属于察哈尔八旗体系。察哈尔部原是漠南蒙古的重要部众，康熙十四年（1675 年）布尔尼之乱平定后，部众被按满洲八旗建制编为左右两翼、迁驻宣化、大同边外，镶红、镶蓝两旗分驻今县境。与北面设盟的外藩蒙古不同，察哈尔八旗属**内属蒙古**：不设盟，也不设世袭扎萨克，各旗由朝廷任命的总管管理，先隶理藩院典属司，乾隆二十六年（1761 年）起设**察哈尔都统**驻张家口，总理游牧旗务。与此同时，农业移民的民政事务逐步纳入山西方面设置的地方机构。**蒙旗与民政机构同时存在，共同构成当地的治理格局——这也是“旗厅并存”在凉城的具体来历。**

雍正十二年（1734 年），清廷设**宁朔卫、怀远所**，由大朔理事通判统辖，隶山西朔平府；乾隆十五年（1750 年）裁并卫所，设置**宁远厅**——厅名取“宁朔卫”之“宁”与“怀远所”之“远”，治所在今永兴镇一带的**田家镇**（旧籍亦作蒿儿兔、哈尔图）。光绪十年（1884 年），宁远厅改设抚民通判、升为直隶厅，改隶山西省归绥道，厅治也在这一年由后营子移驻科布尔；光绪二十九年（1903 年），又以厅北科布尔巡司地析置陶林厅。清末民政隶属为“清朝—山西省—归绥道—宁远厅”，\*\*蒙旗事务仍另有察哈尔系统管理。\*\*两套系统各管一部分人口与事务，地方沿革把这一格局概括为八个字——**旗厅并存，蒙汉分治**。

**宁朔卫 · 怀远所（1734） → 宁远厅（1750） → 宁远县（1912） → 凉城县（1914）**

{% hint style="info" %}
**概念辨析｜旗与厅，为什么能够同时存在？**

旗制与厅制服务于不同的管理安排，涉及人口、土地和事务的分工。**两套机构的职权存在联系，具体权限随时期和事务而变化**——既不是简单的“两套班子各管一半”，也不是其中的一套形同虚设。理解这一点，才能读懂清代内蒙古中南部“一地两制”的实际运作。
{% endhint %}

**田家镇**作为宁远厅和后来宁远县、凉城县的治所，是近代凉城的重要中心。一个地方成为行政驻地，会集中办事、诉讼与人员往来的需求，也为商业和服务活动提供条件。衙署、街道与周围村庄之间形成了日常往来。**人们到城里办事、交易和歇脚，行政职能与商业活动共同支撑着镇上的生活。**

## 7.3 凉城山中的佛迹与跨省的佛乐

16 — 20 世纪

凉城的宗教生活，与山地、村镇和邻近晋北地区的往来相连。蛮汉山的**佛爷洞、拜佛亭**等名称，保留了当地对佛教活动的记忆。地方介绍还讲述僧人在山中修行的故事，不同材料所记修行年数和人物来历并不一致，这些情节属于地方传述；**山林中的佛教景观，则是今天仍能辨识的一层文化痕迹。**

更清楚的一条线索，藏在声音里。中国非物质文化遗产网记载，山西左云**楞严寺佛乐**流传于左云及内蒙古凉城一带，明代初年已有相关传统，明清时期继续发展。它包含歌赞与器乐两部分，使用管子、笙、鼓和铙钹等乐器，既用于僧侣诵经，也进入民间法事。

这意味着，凉城与晋北的联系还包括僧侣、仪式和曲调的流动。唱诵与器乐在传播中吸收地方音乐特点，使宗教活动与乡村的声音世界相接。**楞严寺位于左云，佛乐却能跨过今天的省界，在凉城流传；行政边界并不等于日常文化的边界。**

{% hint style="info" %}
**周边格局 · 蒙古各部、清廷与归绥**

进入清代以后，这里逐步置于新的帝国治理体系中。北方蒙古社会的组织、山西方向的移民活动，以及归绥方向的行政联系，共同塑造地方。**蒙汉之间的关系不仅发生在抽象的民族层面，也落实在土地、市场和相邻家庭的生活里。**
{% endhint %}
