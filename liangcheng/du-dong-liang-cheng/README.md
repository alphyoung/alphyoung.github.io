# 00 读懂凉城

## 湖盆、山口与边墙 —— 九大历史阶段

> 把视野拉开看，一条主线贯穿全篇：这片湖盆**两次被推到大一统秩序之外**（东汉末、明代），**又两次被拉回来**（北魏隋唐、清代）。边地的历史，往往就是这样来回摆动，而不是单向地“越来越内地”。

一个坐落在阴山南麓、岱海之滨的塞外县份，如何从史前湖岸的房屋与石墙出发，经过农牧之间的接触地带、北魏的郡城、隋唐的羁縻府州、辽金元的州县、明代的边墙、清代的移民与厅县，走到今天这个必须重新与湖泊协商的凉城。岱海的水位、阴山的山口与历代边墙，是这段历史的三个支点；北方各族在这里进出、落脚、设治与互市，则纵贯其间。

## 三个“凉城”：地理的、名称的、建置的

**地理的凉城**：一个被山地环抱的湖盆。北有蛮汉山、南有马头山，中部是岱海与其周围的盆地。它是自然概念，也是全篇所有故事的舞台——湖岸线、山口与山道的位置，长期决定了人们在哪里住、往哪里走。

**名称的凉城**：这个名字并非自古如此。它来自北魏的凉城郡（古籍中也写作梁城郡），中间长期中断，直到 1914 年才重新启用为现代县名；在此之前，这片地方叫宁远。

**建置的凉城**：今天的凉城县，与古代的郡、县、厅、卫所辖境并不重合。同一时期，今县境还可能分属不同单位；而同一个行政中心，也曾从田家镇迁往新堂。把“凉城县”当成一条自古连续、边界不变的行政实体，是理解本地历史最常见的绊脚石。
