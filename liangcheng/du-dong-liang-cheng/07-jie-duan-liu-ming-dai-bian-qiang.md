# 07 阶段六·明代边墙

明朝把这里推到大同镇的边墙之外。明初一度以宣德卫等卫所控制，中期以后防线收缩，岱海一带成为“大同边外地”，主要由蒙古诸部控制，16 世纪中叶起属俺答汗所统的土默特部；1571 年的隆庆和议又打开了封贡互市的口子。这一阶段的转折点，是“墙”的出现：它先是一条现实边界，把两种秩序分开；随后又在互市与日常往来的侵蚀下，慢慢变成一道地景。明代凉城因此不能整体归入明朝某个府县——这正是它作为边地的特点。

* **明初** 宣德卫等卫所
* **15 世纪** 大同镇边墙
* **16 世纪** 土默特部驻牧 · 库库和屯
* **1571** 隆庆和议
* **1580** 归化城大召

## 6.1 长城改变了道路，也改变了生活安排

**明代**

明代凉城一带与**大同边防**紧密相连。地方沿革材料将这里的早明建置与**宣德卫**相联系，此后边防布置和实际控制范围仍经历变化。

明初，这里的主要治理形式由元代县制转为**军事卫所**，处于明朝大同北部防御体系之中。明朝中期以后，防线收缩，岱海一带成为**大同边外地**，主要由蒙古诸部控制；今天县域南缘的边墙和军堡，则与明朝**大同镇**防务相连。因此，**明代凉城不能整体、连续地归入明朝某个府县**：明初的卫所控制与中后期的蒙古部落控制，是两个不同阶段。

岱海南侧的长城遗迹，也把这种边地经验留在地表。王墓山坡下遗址的考古报告甚至以附近明代次边长城作为地理参照：**相距不远的史前聚落与明代边墙，属于相隔数千年的两套生活秩序。**

边墙影响人们从哪里经过，也需要烽燧、堡寨、守军和补给配合。**墙内外的实际接触会随军事形势和政策改变，不能想象成几百年从无往来。**

## 6.2 从丰州滩到土默川：俺答汗与边境互市

**16 世纪**

明代中后期，蒙古**土默特部**在丰州滩一带发展，**土默川**之名与之相联系。土默特首领阿勒坦汗，汉文史籍常称**俺答汗**，在这一地区经营牧业、农业和聚落，推动形成新的政治与商业中心。**库库和屯**，即后来归化城、今天呼和浩特旧城的前身，也在这一过程中兴建。

凉城一带并不在明朝的辖区之内，而是**土默特部**的驻牧地。土默特万户内分多部，牧地由各支台吉分别领有，范围东起宣府边外、西抵黄河，岱海周围正在其中。地方沿革材料据此记为：**万历十年（1582 年），今地属蒙古土默特部政权管辖。**

{% hint style="info" %}
**历史小故事｜一个孙子的出走，打开了议和的门。**

1570 年，俺答汗的孙子**把汉那吉**因家庭纠纷投奔明朝。明朝边臣没有将他处死，而是善加接待；俺答汗最初想用兵索回孙子，得知他受到礼遇后，转而与明方谈判。双方交换人员，继而讨论封贡与互市。**1571 年，俺答汗受封顺义王**，隆庆和议促成了边境关系的重要转折。
{% endhint %}

和议使大同、宣府等方向的**封贡互市**有了较稳定的制度安排。对长城沿线及边外居民而言，马匹、牲畜、布帛与生活物资的交换，直接关系生计。凉城处于大同边外与土默川相联系的区域，**这种贸易环境的变化，也构成其明清地方社会发展的背景。**
