# 00 读懂藏传佛教

## 高原、教派与册封 —— 七个历史阶段

> 把视野拉开看，一条主线贯穿全篇：藏传佛教在这片高原上**先被王室请进来，又随王朝崩溃而中断**（前弘期），**再靠地方领主的供养长出一批各自独立的教派**（后弘期）；此后每一次教派格局的大变动，几乎都伴随一次**来自中原王朝的册封**——元朝独尊萨迦、明朝多封众建、清朝把转世的最终认定权直接收归中央。宗教的传承与政权的承认，在这条线上始终缠在一起。

一片平均海拔四千米以上的高原，如何在几百年里接住一个外来宗教，把它译成自己的语言、长成自己的教派、积累出自己的寺产与政治地位；而中原王朝又如何一步步把这片高原上的宗教秩序纳入自己的版图与行政。藏传佛教的历史，既是信仰史与教理史，也是高原与中原之间往来、册封与治理的历史。

## 三个“藏传佛教”：宗教的、教派的、政教的

**作为宗教的藏传佛教**：以藏文为经典语言、显密兼修的一个佛教传承体系。它有自己的学修次第——先显宗五部大论，后密宗四续部；有自己的僧团、戒律与寺院制度。这是它与其他佛教传统并列时的身份。

**作为教派的藏传佛教**：它内部并不是一个整体。宁玛、噶当、萨迦、噶举、格鲁，各有祖师、各有根本教法、各有传承与寺院系统。“藏传佛教”是一个统称，底下是若干互相竞争又互相学习的教派；把这些教派当成一个统一组织的不同部门，是最常见的错位。

**作为制度的藏传佛教**：13 世纪以后，部分教派与地方政权结合，形成延续数百年的“政教合一”治理形态；同时期起，中原王朝通过册封、设官、定章程把高原纳入管辖。这一层是历史的产物，不是宗教的固有属性——它有一个明确的起点，也有一个明确的终点（1959 年民主改革）。

这三层要分开看，又不能切断看：教派的兴衰受制度影响，制度的形态由中央与地方的权力关系决定，而宗教的传承又反过来为制度提供合法性。下面的七个阶段，讲的就是这三层如何彼此纠缠、又如何在不同的历史条件里重新组合。
