# 03 阶段二·教派林立

吐蕃王朝崩溃之后，卫藏没有统一政权，佛教也没有统一组织。它从两个方向重新传入——西面从阿里、东北面从安多——并与地方领主的供养结合，长出一批各自独立的教派：噶当、萨迦、噶举、宁玛。复兴的动力不是来自中央，而是来自地方——与前一阶段王室自上而下的推行正好相反，这是一次自下而上的重建。这一阶段的转折点，是佛教的组织形态从“王朝的宗教”变成“领主与寺院的宗教”：没有哪个教派统治全藏，也没有哪个教派离得开供养。

* **978 前后** 下路弘法复兴
* **10—11 世纪** 上路弘法 · 阿里译经
* **1042** 阿底峡入藏
* **1073** 萨迦寺创建
* **1121** 塔波拉杰创噶举派
* **12 世纪** 宁玛派伏藏传统成形

## 2.1 上路与下路：佛教从两个方向回来

10 — 11 世纪

吐蕃崩溃后，高原分裂为若干地方势力，谁也没有能力再像王室那样供养一个统一的僧团。佛教的复兴因此不是一次“中央决定的宗教政策”，而是两个方向上的自发接续。

\*\*下路弘法——从安多方向。\*\*吐蕃末年逃到安多一带的僧人没有断绝传承。10 世纪后期，卫藏的求法者翻山到安多受戒、学法，再把戒律与僧团制度带回卫藏。时间一般定在 978 年前后。**它带回的是“戒律”：僧团怎样成立、怎样传戒、怎样组织。**

\*\*上路弘法——从阿里方向。\*\*吐蕃王室的后裔在西部阿里建立了古格等地方政权。10 至 11 世纪，这些政权大规模派人赴印度求法、译经，并迎请印度高僧入藏，其中最重要的一次就是迎请阿底峡。**它带回的是“学理”：中观、因明与密宗的系统传承。**

两条路的共同点是：\*\*它们都在地方政权的支持下完成。\*\*从此，“教派向世俗权力寻求庇护、世俗权力借宗教取得合法性”的供养关系成为常态。这条关系贯穿了此后几百年的全部历史。

{% hint style="info" %}
**辨析 · 从“自上而下”到“自下而上”**—— 前弘期与后弘期的佛教，是两种完全不同的生长方式。**前弘期是自上而下的**：由赞普下令、王室出资、国家设译经院，佛教是王朝工程的一部分，所以王朝一倒它也就断了。**后弘期是自下而上的**：没有统一政权，谁也没有能力再供养一个统一的僧团，佛教只能一个地方一个地方地、由领主与家族出钱出力重新接起来。**“教派林立”不是复兴不彻底，而是这种生长方式的必然结果**——动力来自下面，组织形态就必然是分散的。
{% endhint %}

## 2.2 阿底峡与噶当派：把次第讲清楚

11 世纪

1042 年，印度高僧**阿底峡**（Atiśa，982—1054）受古格王邀请入藏，先在阿里传法，后进入卫藏。他在藏地的时间不算长，留下的影响却很深远。

他的代表作《**菩提道灯论**》把修行组织成一个清晰的次第：从下士道（皈依、明信因果）到中士道（生起出离心），再到上士道（发菩提心），最后才进入密宗。这个“由显入密、循序而上”的框架，纠正了当时一部分人越过显宗直接修密的做法。

他的弟子仲敦巴（1005—1064）在热振建寺，形成**噶当派**（“噶当”意为“佛语教诫”）。

把阿底峡放到整个后弘期的坐标里，他的分量还要更重：**他是“佛教从两个方向回来”之后，把散落的传承重新整理成一套可教、可学、可传的体系的那个人。**《菩提道灯论》确立的“先显后密、循序而上”，后来成了藏传佛教各家共同的次第语言，宗喀巴的《菩提道次第广论》正是沿着这条线写下来的。**1042 年因此是后弘期真正的分水岭。**

{% hint style="info" %}
**概念辨析｜噶当派今天不显眼，但在教理史上位置极重。噶当派后来没有作为一个独立大派延续下来，容易被当成一个次要的角色。事实上，它的“道次第”方法被宗喀巴全盘继承**——格鲁派的《菩提道次第广论》，正是沿着《菩提道灯论》这条线写下来的。“格鲁派”在早期甚至被称为“新噶当派”。**看一个教派的分量，不能只看它今天还有多少寺院。**
{% endhint %}

## 2.3 萨迦、噶举、宁玛：三条传承路径

11 — 12 世纪

这一时期形成的教派，可以顺着三条不同的**组织路径**来理解。路径不同，它们后来与政权打交道的方式也不同。

### 萨迦派｜以家族与寺产为骨架

1073 年，昆·贡却杰布在萨迦地方建寺。萨迦派以“**道果法**”为核心教法，寺主之位由昆氏家族世代承继。**它的组织形态最接近“寺院即领地”**——教权与家族权力合为一体，这也解释了它后来为何能迅速成为与中央王朝对接的一方。

### 噶举派｜以师徒传承为骨架

玛尔巴（1012—1097）三次赴印度求法，传给米拉日巴（1040—1123），米拉日巴传给塔波拉杰（1079—1153）。1121 年塔波拉杰建冈波寺，形成塔波噶举，此后陆续分出“四大八小”诸多支系。噶举派的核心教法是大手印与那若六法。**因为靠师徒相承，它的支系特别多**，后来与元明两代打交道的噶玛噶举，就是其中的一支。

**玛尔巴 → 米拉日巴 → 塔波拉杰 → 塔波噶举 → 四大八小**

### 宁玛派｜以“古旧”与伏藏为骨架

宁玛派自称承继 8 世纪莲花生传下的旧译密法，“宁玛”就是“古旧”的意思。它有一套特殊的经典来源——**伏藏**：相传由莲花生等人埋藏、后世由掘藏师取出的经典。这套传统在 12 世纪以后系统化。**它是唯一跨越前弘期与后弘期的教派**，因此也最强调自己传承的连续性。

{% hint style="info" %}
\*\*概念辨析｜“四大八小”是后世的归纳，不是当时就有一份名录。\*\*教派名称与支系谱系，通常是在其组织成形、并且需要说明自身正统性之后才被整理出来的。宁玛、噶举、萨迦这些称呼也不例外。**把后世的分类表当成当时人的自我认同，会把一个长期分化的过程压缩成一棵树。**
{% endhint %}

## 2.4 寺院经济：教派靠什么活下来

制度

教派要延续，光有教法不够，还得有稳定的物质基础。后弘期的寺院主要靠三样东西：

* \*\*领地与牧场。\*\*施主与地方领主把土地、牧场和依附人口布施给寺院，由寺属农户耕作、牧民放牧，产出归寺院支配。这是大寺院最主要、也最稳定的收入来源。
* \*\*布施与供养。\*\*包括来自地方领主、蒙古贵族与中原王朝的馈赠。来自外部的供养往往数额更大，也因此更能改变一个教派的地位。
* \*\*商业与借贷。\*\*寺院参与长途贸易（茶叶、食盐、毛皮、布帛），也从事放贷。寺院有资本、有信誉、有仓储与驮队，在这些交易中有天然优势。

这套结构还有一个更长的后果：\*\*庄园经济的萌芽。\*\*在分裂割据的局面下，土地、牧场与依附人口的归属不断被重新划分，**谁控制了一座寺院，谁就控制了一份稳定的产业与人口**。教派林立，背后正是这份产业在地方势力之间被反复瓜分——这也是为什么后弘期的寺院从一开始就不只是修行团体，而是有产业、有属民、有管理办法的经济组织。

这套经济结构带来两个后果。第一，大寺院逐渐成为**地方上的权力中心**——它不只是修行场所，还是领地主、债权人、教育机构与纠纷仲裁者。第二，**寺院与世俗领主的利益高度绑定**，教派之间的竞争因此常常是经济与政治地位的竞争，而不只是教义之争。

{% hint style="info" %}
**制度 · “政教合一”的土壤在这里**—— “政教合一”不是在某一刻被某个政权“设立”出来的制度，而是在几百年里一点点长出来的：寺院先有了领地和依附人口，再有了司法与仲裁的功能，最后当某一派取得地方政权时，它手里的宗教权威与经济实力就直接转化为政治权力。**要理解它的坚固，必须先理解它的经济基础。**
{% endhint %}
