# 02 阶段一·佛教入藏

佛教在 7 世纪由印度与汉地两个方向传入吐蕃，最初只是王室供养的“客人”。到 8 世纪后期赤松德赞时期，它才被立为国家支持的宗教：迎请寂护与莲花生，建成桑耶寺，出现第一批本土出家的僧人，译经变成国家工程。推动它的不只是信仰，还有一层政治盘算：赞普需要用一套由王室供养、听命于王权的外来宗教，去压制与旧贵族绑在一起的本土苯教祭司集团。9 世纪中叶，朗达玛灭佛，加上吐蕃王朝自身的崩溃，佛教在卫藏的中心地带一度中断。

这一阶段的转折点，是佛教从外来信仰变成王朝宗教，又随王朝一同崩塌——它的兴与亡都系在王室身上，靠山一倒，前弘期便戛然而止。

* **约 7 世纪** 松赞干布建寺译经
* **约 779** 桑耶寺建成
* **8 世纪后期** 本土僧团出现
* **9 世纪初** 厘定译语
* **838—842** 朗达玛灭佛

## 1.1 松赞干布：文字、两座寺与一个开端

### 吐蕃王朝

松赞干布（约 617—650 年在位）是吐蕃王朝的奠基者之一。传统记载把佛教初传系于他在位的时期：迎娶尼泊尔的尺尊公主与唐朝的**文成公主**（641 年），为安置两位公主带来的佛像而兴建**大昭寺**与**小昭寺**；命人创制**藏文**，并开始翻译佛经。

需要说清楚的是尺度：\*\*这一时期的佛教还说不上是“国家宗教”。\*\*建寺、译经与请僧人的记载中，有相当一部分是后世的追述；松赞干布本人在传统叙事里更常被描述为“护持者”而不是“修行者”。真正让佛教成体系地进入吐蕃的，是下一个世纪的赤松德赞。

但有一个后果是确定的：\*\*藏文的创制。\*\*没有藏文，就没有后来大规模的译经，也就没有以藏文为载体的教派传承。文字是藏传佛教得以成立的技术前提——这一点常被忽略，因为它是“基础设施”而不是“教义”。

还有一层用意不那么显眼，却更能解释这件事为什么值得反复追述：\*\*佛教是一种可以从外部整套引进、并且由王室直接供养与掌握的力量。\*\*在它对面，是世代承担祭祀、占卜与丧葬的苯教祭司集团——他们与旧贵族势力交织在一起，对王权构成实际的分权压力。**请一个在本地没有根基的宗教进来，等于在旧势力旁边，扶起一股听命于王室的新力量。**

{% hint style="info" %}
\*\*历史小故事｜两尊佛像，两种方向。\*\*传说两位公主各自带来一尊释迦牟尼像：尺尊公主带来的是不动金刚像，文成公主带来的是觉卧佛像。大昭寺与小昭寺分别成为这两尊像的居所，而供奉觉卧佛像的大昭寺后来成为拉萨的中心，寺院与八廓街绕着它生长。**一座城围着寺庙长起来，这在藏传佛教的历史上不是孤例。**
{% endhint %}

## 1.2 赤松德赞：寂护、莲花生与桑耶寺

### 8 世纪后期

8 世纪后期，赤松德赞（755—797 年在位）把佛教确立为国家支持的宗教。这一转折由三件事构成。

{% stepper %}
{% step %}
### 迎请寂护（Śāntarakṣita，藏译“静命”）入藏

他是印度那烂陀寺的学僧，来自中观学派，把戒律与中观学理带进吐蕃。传说他初到吐蕃时并不顺利——传法受到本地势力的抵制，于是建议先请一位更有“法力”的人来处理阻力。
{% endstep %}

{% step %}
### 迎请莲花生（Padmasambhava，藏译“白玛迥乃”）入藏

他来自乌仗那（约在今巴基斯坦斯瓦特河谷一带），属于密宗传承。他在史料中的角色，是处理佛教与本地神祇、苯教势力之间的冲突——把原有的地方神灵收编进佛教的护法体系，而不是消灭它们。
{% endstep %}

{% step %}
### 建成桑耶寺

一般认为在 779 年前后。这是一座兼采印度、汉地与吐蕃形制的寺院：中央主殿代表须弥山，四周分列佛塔与殿堂，并有专门的译经场所。
{% endstep %}
{% endstepper %}

这三件事背后有一条更硬的逻辑：\*\*佛教从一开始就是高度政治化的。\*\*迎请寂护与莲花生、修建桑耶寺、供养僧团，花的是王室的财政，用的是王权的意志；而它要压制的对象，是与王室争夺社会支配权的苯教祭司集团与旧贵族。8 世纪王室主持的那场佛苯辩论，苯教落败、经典被埋藏或改写——**与其说是一次教义判决，不如说是一次权力站队。**

桑耶寺之后，出现了**第一批本土出家受戒的僧人**，史称“七觉士”（或称“预试七人”）。这是一件标志性的事：\*\*僧团是本土的，不再是引进的。\*\*只有出现了本土僧团，佛教才可能真正扎下根，而不是随外来僧人的离开而消散。

{% hint style="info" %}
\*\*概念辨析｜“王室请进来”这件事本身，就是政治。\*\*把佛教入藏理解成一次单纯的信仰传播，会看不懂它后来的走势。赞普力推佛教，有信仰的成分，也有治理的算计：\*\*用一套由王室供养、教团不世袭、经典可以翻译的宗教，去平衡苯教祭司与旧贵族的牵制，把合法性资源收拢到王权手里。\*\*理解了这一层，才能解释为什么佛教在吐蕃的起落几乎与王室的强弱同步——也才能解释它在 9 世纪中叶为什么会那样骤然中断。
{% endhint %}

## 1.3 热巴巾与译经：一次大规模的知识搬运

### 9 世纪初

9 世纪初，赤祖德赞（热巴巾，约 815—838 年在位）在位期间，译经规模空前。更重要的是，这一时期进行了**译语的厘定**——统一佛教术语的译法，编成语词对照的工具书，规定新译与旧译的用词标准。

这件事的意义超出宗教。它把印度佛教的义理系统**整体翻译成了藏语**，形成了一套能够自足运转的经典与术语体系。此后的教派不必依赖外来僧侣，也能自己建宗立派、互相辩论。可以说，**后来几百年里所有教派之争的“共同语言”，是在这一步搭起来的。**

同一时期，王室在拉萨修建寺院，并规定僧人由王室供养。教权与王权的位置摆得很近——这既是佛教在吐蕃的黄金期，也是它后来遭遇反噬的原因。

{% hint style="info" %}
\*\*概念辨析｜“译经”不只是翻译，是建立一套可传承的知识体系。\*\*统一术语、编订目录、规范译法，这些工作让佛教从“一批外来的书”变成“一套本地人可以自己读、自己讲、自己争的学问”。中国历史上几次大规模的译经（汉地的译场、吐蕃的译经院）都起了同样的作用。**宗教能不能本地化，很大程度上取决于经典能不能本地化。**
{% endhint %}

## 1.4 朗达玛灭佛与王朝的崩塌

### 9 世纪中叶

838 年前后，朗达玛（赤祖德赞之兄，一说为弟）即位，推行压制佛教的措施：关闭寺院，令僧人还俗，佛经与佛像受到损毁。842 年，他被僧人刺杀，吐蕃王朝随即分崩离析，进入长期的分裂割据。

\*\*佛教在卫藏的中心地带一度中断。\*\*原因不难理解：寺院是供养体系的一部分，僧人的日常由王室与贵族供养支撑；供养体系一断，僧团就散了。\*\*更根本的原因在政治而不在教义：前弘期的佛教是靠王室的财政供养与政治庇护立起来的，靠山一倒，它也就失去了继续存在的前提。\*\*史料把这一段称为“前弘期”的终结，此后的复兴则称“后弘期”。

但“中断”并不等于“消失”。一部分僧人带着经典逃往安多、阿里等边缘地区，在那里把戒律传承与经典保存下来——这正是下一个阶段佛教能够“回来”的前提。

{% hint style="info" %}
**概念辨析｜灭佛不是一个人的宗教好恶。把这场变故归因于“朗达玛一人反佛”，会漏掉背后的政治结构：王室对佛教的重度供养、僧人获得的显赫地位与免役特权，已经引起贵族与苯教祭司集团的强烈不满。灭佛是一次政治清算**，宗教政策的翻转是它的表现形式，而不是全部原因。同样的逻辑，在后来几次教派兴衰中反复出现。
{% endhint %}
