# 06 阶段六·战争与一体化

两次世界大战把欧洲从世界中心推向废墟，冷战又把大陆一分为二。正是在战争的教训与冷战的压力下，欧洲走上了前所未有的道路——以部分主权让渡换取和平与繁荣。1989—1991 年之后，欧洲重新拼合，但新的张力也随之而来。

* **1914** 一战爆发
* **1919** 凡尔赛条约
* **1939** 二战爆发
* **1945** 二战结束
* **1957** 罗马条约
* **1989** 柏林墙倒塌
* **1991** 苏联解体

## 6.1 一战与凡尔赛体系

1914 — 1929

1914—1918 年的**第一次世界大战**是欧洲第一次工业化总体战：堑壕、机枪、毒气与炮火吞噬了整整一代人。四大帝国——德意志、奥匈、俄罗斯、奥斯曼——在战争中或崩溃或解体。

1919 年\*\*《凡尔赛条约》**对战败国德国施加领土割让、军备限制与巨额赔款，并创设**国际联盟\*\*。但和约把战争责任单方面加于德国，又未能建立有效的执行与调解机制。战后的魏玛共和国在通胀与屈辱中挣扎，1929 年**世界经济大萧条**更是雪上加霜。

## 6.2 极权主义与第二次世界大战

1929 — 1945

大萧条摧毁了人们对自由民主的信心。意大利的**法西斯**、德国的**纳粹**与苏联的**斯大林体制**，都以某种形式的极权动员作为答案。1933 年希特勒上台，一步步撕毁凡尔赛安排、吞并奥地利与捷克斯洛伐克。**1939 年德国入侵波兰**，二战全面爆发。

这是一场真正意义上的全球战争，也是人类历史上最惨烈的暴行现场：战场遍及欧洲、北非、亚太，**大屠杀**系统性地屠杀了六百万犹太人以及大量其他群体。1945 年德国无条件投降，欧洲在废墟与道义的震撼中重新出发。

{% hint style="info" %}
\*\*“二战后的欧洲一体化从哪来？”\*\*直接动因之一，就是防止再度发生这样的战争。法德这两个宿敌选择把煤与钢——战争最基本的原料——交由一个共同机构管理，用经济捆绑取代军事对抗。
{% endhint %}

## 6.3 冷战分裂的欧洲

1945 — 1989

战时的同盟很快转为对峙。以美国为首的西方推行**马歇尔计划**（1948 年起）重建西欧经济，1949 年成立**北约**；苏联则在东欧建立势力范围，1955 年组织**华约**。“铁幕”从波罗的海一直拉到亚得里亚海，欧洲被一分为二。

分裂的象征是**柏林墙**（1961 年修建）。同一座城市被高墙与水雷带割开，两面各自运行着不同的制度。东欧在苏联影响下推行计划经济与一党体制，1956 年的匈牙利、1968 年的“布拉格之春”，都是被压制的改革尝试。

## 6.4 欧洲一体化：从煤钢共同体到欧盟

1951 — 2004

1951 年，法、德、意、荷、比、卢六国签署《巴黎条约》，次年正式成立**欧洲煤钢共同体**，把战争资源置于共同管理之下。1957 年六国签署\*\*《罗马条约》\*\*，1958 年欧洲经济共同体正式成立，逐步实现关税同盟与共同市场。此后一体化不断扩展与深化：机构化、单一市场、人员自由流动。

1993 年，**《马斯特里赫特条约》生效，欧洲联盟正式成立；1999 年起欧元作为记账货币启用，2002 年进入流通。2004 年，欧盟迎来最大规模的一次东扩**，十国同时加入（除中东欧八国外，还有马耳他与塞浦路斯），欧洲的分裂线从制度上被缝合。

## 6.5 1989 之后：重新拼合的欧洲

1989 — 至今

1989 年，**柏林墙倒塌**；1990 年两德统一；**1991 年苏联解体**，冷战以和平方式收场。中东欧国家纷纷转向多党制与市场经济，并陆续申请加入欧盟与北约。与此同时，南斯拉夫在解体过程中爆发残酷的战争，提醒人们民族问题并未随冷战一起消失。

今天的欧洲在成就与张力之间前行：一体化带来了长久的和平与繁荣，也让主权、福利、移民与身份认同的争论日益尖锐。理解这些争论，仍需回到前面六个阶段——欧洲从来不是一个凝固的实体，而是一个不断被重新拼接的过程。

{% hint style="info" %}
\*\*一体化是理想还是利益？\*\*两者都在。政治理想提供了方向，经济利益与冷战压力提供了动力。正因为它同时依赖两者，当利益分歧或外部压力变化时，一体化便会出现摇摆与反复。
{% endhint %}
