# 02 阶段二·中世纪

中世纪不是"黑暗的空白"，而是欧洲基本结构成型的时代：封建契约、庄园经济、教会权威、大学与城市都在此期生长。800 年查理曼加冕开启西欧的第一次整合，1054 年东西教会分裂，14 世纪的瘟疫与战争则把这个秩序推向深刻危机。

* **962** 奥托一世加冕
* **1054** 东西教会分裂
* **1096** 第一次十字军
* **1215** 大宪章
* **1347** 黑死病

## 2.1 法兰克与查理曼：西欧的第一次整合

476 — 843

西罗马瓦解后，日耳曼诸部在原帝国土地上建立了一系列王国：西哥特人在伊比利亚、东哥特人在意大利、法兰克人在高卢。其中法兰克王国最具潜力。墨洛温王朝的克洛维皈依天主教，把王权与教会、罗马化的高卢贵族联系起来。

到 8 世纪，加洛林家族取而代之。**800 年，查理曼在罗马由教皇加冕为"罗马人的皇帝"** ——一个意味深长的举动：它既延续了罗马的想象，也让皇权需要教皇的加冕来承认。这是西欧自西罗马灭亡后的第一次大规模整合。

但整合并不牢靠。843 年\*\*《凡尔登条约》\*\* 将查理曼的帝国三分，大致奠定了后来法、德、意三国的雏形——不过，这只是若干可能的走向之一，并非命中注定。

## 2.2 封建制度、庄园与骑士

9 — 13 世纪

中央权力弱小，秩序便由层层的人际契约来维持。这就是通常所说的**封建制度**：封君把土地（采邑）授予封臣，封臣以军事与忠诚回报，封臣又可以再向下分封。它形成了一个松散的等级网络，而非现代意义上的国家。

土地上的经济单位是**庄园**：领主拥有土地与司法权，农奴或农民耕作并缴纳地租与劳役。绝大多数人口生活在乡村，靠天吃饭。与此并存的是**骑士**阶层——以武力换取土地，逐渐形成一套关于荣誉与忠诚的行为规范。

{% hint style="info" %}
\*\*不要把"封建"想象成整齐的金字塔。\*\*同一块地可能同时存在几重权利主张，封臣对多个封君效忠也属常态。中世纪的政治是拼贴式的，靠习惯法与谈判维系，而非清晰的科层结构。
{% endhint %}

## 2.3 教会与皇权的拉锯

1075 — 1250

中世纪欧洲最重要的两条线索，是**教会**与**世俗君主**的关系。教会拥有自己的法律、法庭、税收与广大的地产，它并不仅仅是一个信仰团体，而是一个跨国性的权力机构。

1077 年的**卡诺莎之辱**是这场较量的著名一幕：神圣罗马帝国皇帝亨利四世在与教皇格里高利七世的"叙任权之争"中失势，被迫在雪地里忏悔。1122 年\*\*《沃尔姆斯协定》\*\*达成妥协，皇帝与教会在主教任命上各让一步。

教会内部也不断改革：修道院运动、托钵修会（方济各会、多明我会）兴起，既净化信仰，也扩大影响。到 13 世纪，教皇的权威达到顶峰，却也埋下了与民族君主长期冲突的伏笔。

{% hint style="info" %}
\*\*另一个转折：\*\*1054 年，罗马与君士坦丁堡互相绝罚，**东西教会大分裂**。此后西欧天主教与东欧、东南欧的东正教分道扬镳，欧洲的宗教版图就此一分为二——这一裂缝至今仍在。
{% endhint %}

## 2.4 十字军、商业复兴与城市

1096 — 1300

1095 年，教皇乌尔班二世在克莱蒙号召"收复圣地"，\*\*第一次十字军（1096 起）\*\*由此发动。此后的两百年间，西欧先后发动多次东征，成果有限，影响却深远：它加剧了与伊斯兰世界及东正教世界的对立，也把东方的商品与知识带回西欧。

与此同时，地中海贸易蓬勃发展。**威尼斯、热那亚、比萨**等意大利城市靠转口贸易积累财富；北方的波罗的海—北海区域则出现**汉萨同盟**。城市自治、行会与银行随之兴起，一个不同于庄园的城市经济逐渐成形。

城市需要识字的人。12 世纪起，**大学**在博洛尼亚、巴黎、牛津等地相继出现。古典著作经由阿拉伯世界的翻译重新进入西欧，为后来的文艺复兴悄悄积蓄了条件。

## 2.5 黑死病与中世纪的危机

1347 — 1453

**1347 年，黑死病经黑海与西西里登陆欧洲**，此后数年带走约三分之一甚至更多的人口。劳动力锐减，庄园经济动摇，社会矛盾尖锐，宗教权威也遭到质疑。这场瘟疫对欧洲结构的冲击，远超过一场单纯的疾病。

与瘟疫并行的是战争与分裂：**英法百年战争（1337—1453）持续百年，把两国推向民族意识的觉醒；教会内部出现大分裂**（1378—1417），一度同时有两位甚至三位教皇。中世纪的统一幻象正在消散。

{% hint style="info" %}
\*\*"黑暗的中世纪"这一说法从何而来？\*\*它主要出自文艺复兴时期的人文主义者：为了凸显自己对古典的重光，他们刻意把中间这段贬为"黑暗"。今天的历史学更倾向于把中世纪看作一个有创造力的时代——大学、议会、银行、机械钟都诞生于此。
{% endhint %}
