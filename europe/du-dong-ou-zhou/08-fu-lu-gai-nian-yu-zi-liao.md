# 08 附录：概念与资料

把全篇反复出现的关键概念集中解释，并给出可用于继续深入的线索。历史学的价值，一半在于知道事实，一半在于知道这些概念从何而来、边界在哪。

## A.1 六阶段脉络一览

| 阶段        | 跨度          | 一句话主题               |
| --------- | ----------- | ------------------- |
| Ⅰ 古典地基    | 前 800 — 476 | 希腊、罗马、基督教三大源头在地中海合流 |
| Ⅱ 中世纪     | 476 — 1453  | 基督教世界整合，同时政治长期分散    |
| Ⅲ 统一的破裂   | 1453 — 1648 | 信仰统一破裂，主权国家体系确立     |
| Ⅳ 君主的世纪   | 1648 — 1789 | 绝对权力登峰，科学与启蒙兴起      |
| Ⅴ 革命与民族国家 | 1789 — 1914 | 主权在民 + 工业化，民族国家成型   |
| Ⅵ 战争与一体化  | 1914 — 今    | 两次大战与冷战，走向联盟        |

## A.2 关键概念表

| 概念              | 含义                 | 常见误解                |
| --------------- | ------------------ | ------------------- |
| 城邦（polis）       | 以公民共同体为核心的政治单位     | 误当作现代国家；其公民范围其实极为有限 |
| 共和国             | 以元老院、选举与任期制约束权力的政体 | 误以为罗马共和国是全民民主       |
| 封建制度            | 以土地封授与效忠关系维系的等级网络  | 误当作整齐的科层金字塔         |
| 主权（sovereignty） | 国家在其领土内的最高权力       | 误以为自古就有；它是近代的产物     |
| 民族国家            | 以民族认同为合法性基础的国家     | 误以为“一族一国”是自然状态      |
| 均势              | 以力量平衡防止一方独大、维持秩序   | 误以为平衡必然带来和平         |
| 一体化             | 国家将部分主权交由共同机构行使    | 误以为等于建立一个“欧洲国”      |

## A.3 主要政治体时序总览

| 政治体         | 大致时间              | 关键线索             |
| ----------- | ----------------- | ---------------- |
| 希腊城邦        | 前 800 — 前 146     | 公民政治、哲学与戏剧的源头    |
| 罗马共和国 / 帝国  | 前 509 — 公元 476（西） | 法律、行省与地中海统一      |
| 拜占庭帝国       | 395 — 1453        | 东正教、希腊语、延续千年     |
| 加洛林帝国       | 800 — 843 分裂      | 西欧第一次大规模整合       |
| 神圣罗马帝国      | 962 — 1806        | 多王国的政治框架，非单一民族国家 |
| 奥斯曼帝国（欧洲部分） | 14 世纪 — 1922      | 长期统治巴尔干与东南欧      |
| 欧洲联盟        | 1993 — 今          | 主权让渡型的区域一体化实验    |

## A.4 继续深入的建议

* \*\*先抓主干：\*\*用六个阶段与总时间轴搭起框架，再往里填细节，比零散记忆事件更有效。
* \*\*再分专题：\*\*宗教、经济、战争、思想四条线索各自可以单独梳理，看清它们如何互相牵引。
* \*\*留意视角：\*\*同一事件在不同立场下叙述迥异。对任何“常识性”结论，都值得问一句：这是谁的说法？
