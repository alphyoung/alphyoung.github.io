# 03 阶段三·统一的破裂

中世纪的两大统一在这一阶段同时被打破：拉丁基督教世界的信仰统一，以及以地中海为中心的经济格局。文艺复兴重新发现古典，大航海把争夺推向全球，宗教改革撕裂了信仰；三十年战争之后，《威斯特伐利亚和约》确立了主权国家并立的新秩序。

* **1453** 君士坦丁堡陷落
* **1492** 哥伦布抵达美洲
* **1517** 宗教改革
* **1555** 奥格斯堡和约
* **1648** 威斯特伐利亚和约

## 3.1 文艺复兴与人文主义

**14 — 16 世纪**

转变更早就已在意大利酝酿。富庶的**城市共和国**——佛罗伦萨、威尼斯、米兰——赞助艺术家与学者，美第奇家族是最著名的资助者。学者重新搜集、校勘古希腊罗马的文本，形成**人文主义**：把注意力从神学思辨转向人的尊严、修养与公共生活。

技术放大了这场运动。**约 1450 年，古腾堡改良活字印刷**，书籍从此可以大量复制。思想不再依赖手抄与口传，传播速度与范围被彻底改变——这也为随后宗教改革的迅速扩散提供了条件。

达·芬奇、米开朗基罗、拉斐尔、马基雅维利、伊拉斯谟……他们既继承古典，又以新的眼光观察现实。文艺复兴并非与中世纪一刀两断，而是把中世纪的养分用新的方式重新组织。

与文艺复兴同时，欧洲人的目光从彼岸转向此世，从地中海转向大洋。而 1453 年**君士坦丁堡的陷落**，既终结了拜占庭千年帝国，也宣告了中世纪的落幕——欧洲由此被推向一个新的开端。

## 3.2 大航海与殖民帝国

**1415 — 1600**

奥斯曼在 1453 年攻陷**君士坦丁堡**，此后长期掌控东地中海与欧亚之间的商路。西欧的商人于是更多转向海洋——不过，把海外扩张完全归因于“商路被堵”是一种简化：葡萄牙的远航早在 1415 年就已开始。葡萄牙沿非洲海岸南下，绕过好望角进入印度洋；西班牙则向西押注——**1492 年，哥伦布抵达美洲**。

此后的百年里，西班牙与葡萄牙率先建立横跨大洋的殖民帝国，荷兰、英国、法国随后加入。美洲的白银大量流入欧洲，颠覆了物价与贸易格局；非洲与美洲之间则被强行串联起**跨大西洋奴隶贸易**，约一千二百万人被强行贩运到美洲，另有大量人口死于掳掠与航程。

大航海的深层后果是经济重心的转移：地中海不再是欧洲的中心，大西洋沿岸的里斯本、塞维利亚、阿姆斯特丹、伦敦相继崛起。欧洲内部的力量格局，从此开始向西北倾斜。

{% hint style="warning" %}
\*\*关于“地理大发现”这个说法：\*\*它对欧洲人而言是“发现”，对美洲原住民却是灾难的开端——征服、奴役与疫病使当地人口锐减。今天越来越多的教材改用“大航海时代”或“殖民扩张”，以容纳被书写遮蔽的另一侧。
{% endhint %}

## 3.3 宗教改革：统一信仰的破裂

**1517 — 1555**

**1517 年，马丁·路德发表《九十五条论纲》**，质疑赎罪券与教会权威，主张“因信称义”。《圣经》被译成德语，普通人得以自行阅读。加尔文在日内瓦建立另一套改革传统，英国国王亨利八世则因婚姻问题另立英国国教。西欧延续千年的宗教统一就此破裂。

1555 年\*\*《奥格斯堡宗教和约》\*\*确立“教随国定”：谁统治，就信谁的教。但这并没有带来个人信仰自由，也未纳入加尔文宗，矛盾继续积累——半个世纪后，它以一场更大规模战争的形式爆发。

{% hint style="info" %}
\*\*宗教改革不只是信仰之争。\*\*它同时是政治与社会的冲突：诸侯借改革摆脱教会与皇帝的税收和司法管辖，印刷术放大了争论，1524—1525 年的德意志农民战争则把它推向社会底层。信仰、权力与利益是缠在一起的。
{% endhint %}

## 3.4 三十年战争与威斯特伐利亚体系

**1618 — 1648**

**1618—1648 年的三十年战争**是宗教与王朝矛盾的总爆发：它从波希米亚的一场叛乱开始，逐步卷入西班牙、丹麦、瑞典、法国，几乎把中欧打成废墟，德意志地区人口损失尤为惨重。

1648 年\*\*《威斯特伐利亚和约》\*\*结束了战争。它通常被看作近代国际关系的起点：以主权国家为单位、以条约与均势维持秩序，“主权”这一概念从此有了制度化的依托。

| 和约确立的原则 | 含义               | 后世影响          |
| ------- | ---------------- | ------------- |
| 主权平等    | 各邦国彼此独立，互不隶属     | 现代“主权国家”观念的雏形 |
| 教派归属按领地 | 承认天主教、路德宗、加尔文宗并存 | 宗教多元化在中欧被制度化  |
| 以条约协调冲突 | 用谈判与均势代替宗教战争     | 外交与均势体系的先声    |

这一阶段因此可以这样概括：\*\*信仰的统一破裂了，取而代之的是主权国家的并立。\*\*欧洲此后不再有一个共同的宗教权威，只能在多个国家之间寻找平衡。
