## 阅读之前，先分清四种“欧洲”

**地理的欧洲**：从大西洋到乌拉尔山的一片陆地。它是自然概念，边界本身就带着人为约定。

**文化的欧洲**：常被等同于“基督教世界”或“拉丁—日耳曼传统”。但东南欧长期受东正教与奥斯曼影响，并不共享同一套叙事。

**政治的欧洲**：中世纪的王朝领地、近代的主权国家、现代的欧盟，是不同的政治形态。家族可以统治多国，国家也能让渡部分主权结成联盟。

**欧盟**：成立于 1993 年（《马斯特里赫特条约》），是当代的一个特定组织；它既不等于地理欧洲，也不等于文化欧洲。把三者混为一谈，是理解欧洲最常见的绊脚石。

全篇的分段，依据的是欧洲政治形态的几次根本转折：**古典世界的形成 → 基督教世界的整合 → 统一信仰的破裂 → 主权国家的成熟 → 民族国家的兴起 → 战争之后的联合**。

## 一条时间轴看全史

* **前776**：首届奥林匹亚赛会，希腊城邦时代
* **前509**：罗马共和国建立
* **前27**：奥古斯都，罗马帝国开端
* **313**：米兰敕令，基督教合法化
* **476**：西罗马灭亡
* **800**：查理曼加冕
* **1054**：东西教会大分裂
* **1096**：第一次十字军
* **1347**：黑死病蔓延
* **1453**：君士坦丁堡陷落，中世纪终结
* **1492**：哥伦布抵达美洲
* **1517**：路德《九十五条》，宗教改革
* **1648**：威斯特伐利亚和约
* **1687**：牛顿《原理》，科学革命顶点
* **1789**：法国大革命
* **1815**：维也纳会议
* **1861 / 1871**：意大利、德国相继统一
* **1914**：第一次世界大战
* **1939**：第二次世界大战
* **1957**：罗马条约，欧共体成立
* **1961**：柏林墙修建
* **1989**：柏林墙倒塌
* **1991**：苏联解体
* **2004**：欧盟东扩
