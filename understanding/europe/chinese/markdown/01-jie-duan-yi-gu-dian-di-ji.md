# 01 阶段一·古典地基

欧洲文明的三个源头——希腊的城邦与思想、罗马的法律与统一、基督教的信仰与组织——在地中海沿岸相遇并合流。但这个地基从一开始就不是一块整石：当西部的帝国框架在 476 年瓦解时，东部的罗马又延续了近千年。此后欧洲的历史，始终有两条线并行。

* **前776** 传统纪年中最早有记录的奥林匹亚赛会
* **前509** 罗马共和国
* **前27** 罗马帝国
* **313** 米兰敕令
* **330** 君士坦丁堡建都
* **395** 帝国东西分治
* **476** 西罗马灭亡

## 1.1 希腊：城邦、公民与“欧洲”的起点

前 800 — 前 146

欧洲文明最早的自觉，出现在爱琴海沿岸那些彼此独立的小共同体里。希腊人把它们称作 **polis**（城邦）——不是一片疆域，而是一个由公民共同体构成的政治单位。雅典、斯巴达、科林斯各自为政，语言与神祇相通，政治却互不隶属。

公元前 5 世纪，波斯两次西侵，希腊城邦在**马拉松（前 490）**与**萨拉米斯（前 480）**两役中取胜。这场胜利被后世不断援引，视为“欧洲”与“东方”对立的原型——尽管当时并没有“欧洲”这个政治身份。真正让希腊城邦元气大伤的是自己人之间的**伯罗奔尼撒战争（前 431—前 404）**，雅典战败，斯巴达取得霸权；长期战争也削弱了希腊城邦世界。

雅典留下的遗产不在疆域，而在观念：公民大会、陪审法庭、悲剧与哲学，把“公共事务”变成可以辩论的对象。它同时是有限的——妇女、外邦人和奴隶被排除在公民之外。

### “欧罗巴”这个词从哪来？

Europa 本是希腊神话中的腓尼基公主，后来逐渐被用来指称爱琴海以西的陆地。可见“欧洲”最初是一个地理与文化上的模糊方位，而非一个统一实体。把它当作自古存在的整体，是一种后见之明。

{% hint style="info" %}
**疆域 · 希腊化世界** —— 公元前 336 年，马其顿的亚历山大即位，前 334 年东征，十余年间打到印度河流域。他死后帝国分裂为托勒密、塞琉古、马其顿等希腊化王国，从埃及一直铺到中亚。这时的“希腊”早已不是城邦，而是横跨三洲的文化圈。
{% endhint %}

## 1.2 罗马：从共和国到帝国

前 509 — 公元 284

罗马最初只是台伯河畔的一座城。前 509 年传说中驱逐国王、建立**共和国**，此后以元老院、执政官与公民大会构成一套复杂的权力平衡。它靠军团与同盟体系逐步吞并意大利，又经**布匿战争（前 264—前 146）**击败迦太基，把地中海变成“我们的海”。

扩张也带来失衡。贫富分化、军队私人化让共和国的制衡渐渐失效。恺撒渡卢比孔河（前 49），随后被刺（前 44）；到**前 27 年，屋大维获“奥古斯都”称号**，元首制确立，罗马进入帝国时代。此后两个世纪是所谓**“罗马和平”（Pax Romana）**，地中海世界被道路、法律与贸易连成一体。

| 对比项   | 共和国（前 509 — 前 27） | 帝国（前 27 之后）    |
| ----- | ----------------- | -------------- |
| 权力中心  | 元老院与一年一任的执政官      | 元首（皇帝）掌握军权与行省  |
| 合法性来源 | 公民选举与传统           | 军队拥立 + 元老院授予头衔 |
| 扩张方式  | 同盟与行省并存，持续军事征服      | 以皇帝为核心的直接统治    |
| 遗留影响  | 共和主义的政治语汇         | 罗马法、拉丁语、行省行政   |

罗马最持久的遗产是**法律**。从《十二铜表法》到帝国后期的法学汇编，一套关于财产、契约与身份的制度被反复打磨，后来成为欧洲大陆法系的共同源头。

## 1.3 基督教：从被迫害的教派到国教

公元 30 — 392

基督教诞生于罗马治下的犹地亚，最初只是帝国众多宗教中的一个小教派，曾长期遭到排斥与迫害。转折发生在**313 年《米兰敕令》**：在 311 年伽列里乌斯宽容敕令之后，君士坦丁与李锡尼于 313 年进一步确认宗教宽容，并规定归还基督徒财产。此后它迅速与帝国权力靠拢。

325 年**尼西亚会议**试图解决神学争论，也开了皇帝介入教会事务的先例。380 年**《帖撒罗尼迦敕令》**确立对尼西亚派基督教的支持，而非不加区别地认可所有基督教教派。与此同时，330 年君士坦丁把都城迁往博斯普鲁斯海峡边的**君士坦丁堡**，帝国的重心东移。

{% hint style="info" %}
**一个容易忽略的事实：**基督教的传播范围覆盖亚、欧、非三洲。埃及、叙利亚、小亚细亚在很长时间里比西欧更为“基督教化”。把基督教简单等同于“欧洲的宗教”，遮蔽了它更广阔的地中海背景。
{% endhint %}

## 1.4 两条路：西部的终结与东部的延续

284 — 476

帝国太大，一人难以独治。284 年戴克里先即位，293 年创设“四帝共治”；**395 年狄奥多西逝世后，帝国由两个皇帝分别统治东西两部**，行政分治从此延续。西半部长期财政拮据，军队中大量雇佣日耳曼将领，边境压力持续累积。

**476 年，日耳曼将领奥多亚塞废黜在意大利统治的西部皇帝罗慕路斯·奥古斯都（奥古斯图卢斯）**，西罗马帝国通常以此为终点；但尤利乌斯·尼波斯仍在达尔马提亚保有帝号至 480 年。这一年在当时并不引人注目——真正的变化在于：西半部被一个个日耳曼王国取代，一个“罗马治下的地中海世界”就此解体。

但这只是事情的一半。**东部的罗马帝国并未终结**：它以君士坦丁堡为都，通行希腊语，以《查士丁尼法典》延续罗马法，以正教会延续基督教，1453 年之前一直是地中海东部最强大的政治体。后世称它为**拜占庭帝国**——这个名称是 16 世纪学者的发明，当时人始终自称“罗马人”。

| 对比   | 西部（拉丁）        | 东部（希腊）          |
| ---- | ------------- | --------------- |
| 语言   | 拉丁语，后分化出各罗曼语  | 希腊语，长期保持官方地位    |
| 教会   | 罗马主教，逐渐演变为教皇制度 | 君士坦丁堡宗主教，与皇权紧密结合 |
| 政治   | 日耳曼王国林立，权力分散 | 皇权集中，官僚与税收体系延续  |
| 命运   | 476 年帝位中断     | 延续至 1453 年      |

{% hint style="warning" %}
**请不要把 476 年读成“文明灭亡”。**更准确的说法是：西部的帝国行政框架瓦解，东部的帝国继续存在近千年；与此同时，日耳曼诸部、罗马旧贵族与基督教会三种力量，正在重新组合成拉丁西欧的中世纪。而东半部则走上另一条路——拜占庭、东正教、斯拉夫世界的线，会在后面每一章里继续出现。
{% endhint %}
