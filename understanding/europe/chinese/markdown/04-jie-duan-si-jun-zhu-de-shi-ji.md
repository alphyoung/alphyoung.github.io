# 04 阶段四·君主的世纪

三十年战争后，欧洲不同政治体继续调整秩序，加强财政与军事能力是若干君主国的重要方向：绝对君主把行政、税收与常备军制度化。与此同时，欧洲东部发生着更剧烈的变动——三个新强权在波罗的海与黑海之间崛起，一个存在数百年的国家从地图上消失，而在东南方，奥斯曼帝国开始从进攻转为防守。

* **1648** 威斯特伐利亚和约
* **1683** 维也纳之围
* **1687** 牛顿《原理》
* **1699** 卡尔洛维茨条约
* **1721** 俄国改称帝国
* **1772 / 1793 / 1795** 波兰被三次瓜分
* **1789** 法国大革命

## 4.1 绝对君主制与“国家理性”

**1648 — 1750**

三十年战争的混乱之后，“强国家”成为时髦的答案。法国**路易十四**把贵族圈养于凡尔赛，建立由中央官僚直接管理的**绝对君主制**（相传曾宣称“朕即国家”，此语或为后人托名，却准确概括了他的执政理念）。他取消南特敕令、压制新教，把宗教也纳入国家管理。

效仿者接踵而至：普鲁士的霍亨索伦家族、奥地利的哈布斯堡、俄国彼得大帝，纷纷建立常备军、统一税制、兴办官僚机构。以国家利益为最高准则的**“国家理性”**，逐渐取代了以宗教为名的战争理由。

这一时期的政治逻辑，是把分散的封建权利收拢到君主手中；而它留下的问题也同样鲜明——教会以外的等级会议、地方法权与议会也可能约束君主。英格兰 1688—1689 年的革命与《权利法案》就是重要路径：议会限制王权，不能把这一时期一概写成绝对君主制走向顶峰。

{% hint style="info" %}
**“绝对”并不等于“全能”。**即便在路易十四的法国，君主仍要面对地方三级会议、高等法院、行省特权与教会的既得利益。所谓绝对君主制，更像是一场持续两百年的**集权努力**，而非已经完成的现实。相比之下，东欧的君主往往面对更弱的城市与更强的贵族——这决定了他们走向集权的方式完全不同。
{% endhint %}

## 4.2 东方的变动：三个新强权与一个消失的国家

**1700 — 1800**

当西欧在殖民地与海权上竞争时，欧洲东部正在重画地图。

**俄国**是变化最大的一家。**彼得大帝（1682—1725 在位）**以近乎粗暴的方式推行西化：迁都圣彼得堡、创办海军、改革行政与军队、强制贵族改换生活方式。1700—1721 年的**大北方战争**击败瑞典，夺得波罗的海出海口；**1721 年俄国正式改称帝国**。此后叶卡捷琳娜二世继续向南、向西扩张，俄国从东欧的一角变成横跨欧亚的庞然大物。

**普鲁士**从一个边缘选侯国成长为军事强国，靠的是腓特烈·威廉一世对军队与财政的严酷经营，以及**腓特烈二世**在 1740 年后发动的西里西亚战争。**奥地利**虽在德意志内部与普鲁士对立，却以哈布斯堡家族统治着包含匈牙利、波希米亚、尼德兰南部与意大利部分领地的**多民族复合体**——它更像一个王朝拼盘，而非民族国家。

代价由**波兰—立陶宛**承担。这个曾容纳多民族、多教派，并在 1791 年通过欧洲较早一部现代成文宪法的国家，因其贵族共和体制下的“自由否决权”而长期瘫痪。1772 年，俄、普、奥**第一次瓜分波兰**；1793 年第二次；**1795 年第三次瓜分后，波兰—立陶宛从地图上消失**，直到 1918 年才复国。

| 政治体   | 集权方式        | 关键特征             |
| ----- | ----------- | ---------------- |
| 俄国    | 沙皇主导的强制西化与军事扩张 | 农奴制长期保留，扩张至黑海与波罗的海 |
| 普鲁士   | 军队与官僚优先，财政高度节制 | 国土不大但组织严密，后成德意志统一核心 |
| 奥地利   | 王朝联姻与行政整合拼接而成 | 多民族、多语言，内部差异极大   |
| 波兰—立陶宛 | 贵族共和，王权受限     | 宗教宽容但决策瘫痪，终被瓜分   |

{% hint style="info" %}
**“东欧”这个说法是什么时候出现的？**很大程度上是这一时期之后被建构出来的。启蒙时代的西欧观察者常用“落后”“专制”“农业”描述东部，以反衬自身的“进步”。实际上，波兰的贵族共和与宗教宽容一度比多数西欧国家更“自由”，而俄国与普鲁士的强国家能力又让西欧君主羡慕。**把它当作一块均质的落后区域，是典型的后见之明。**
{% endhint %}

## 4.3 奥斯曼的退潮

**1683 — 1800**

1683 年夏天，奥斯曼军队第二次围困**维也纳**。这一次，波兰国王扬三世·索别斯基率援军与哈布斯堡、德意志诸侯联手击退围城部队，成为中欧战局的转折。此后十余年的反攻，以**1699 年《卡尔洛维茨条约》**告终：奥斯曼第一次大规模割让欧洲领土，匈牙利与特兰西瓦尼亚转入哈布斯堡之手。

18 世纪，退潮继续。1718 年《帕萨罗维茨条约》再度失地；**1774 年《库楚克—凯纳吉条约》**让俄国获得黑海出海口，并取得对奥斯曼境内东正教徒的“保护”权——这条约埋下了此后一个多世纪“东方问题”的引线；**1783 年，俄国吞并克里米亚汗国**。

| 年份        | 事件与和约       | 变化                |
| --------- | ----------- | ----------------- |
| 1683      | 维也纳之围被击退    | 中欧扩张止步            |
| 1699      | 卡尔洛维茨条约     | 匈牙利、特兰西瓦尼亚归哈布斯堡   |
| 1718      | 帕萨罗维茨条约     | 塞尔维亚北部、瓦拉几亚部分易手   |
| 1774      | 库楚克—凯纳吉条约   | 俄国取得黑海出海口与东正教保护权  |
| 1783      | 俄国吞并克里米亚    | 黑海北岸纳入俄国          |

对巴尔干的基督徒而言，这一时期的处境很矛盾：奥斯曼的秩序在松动，但取而代之的并非本地的独立国家，而是另一个帝国（哈布斯堡）或另一个“保护者”（俄国）。**民族觉醒的种子，就埋在这种失望里。**

## 4.4 科学革命：从哥白尼到牛顿

**1543 — 1687**

与君主集权同时发生的，是世界观的革命。这条线索横跨 16 至 17 世纪，最终改变了人类理解自然的方式。**哥白尼**在 1543 年提出日心说，动摇“地球为中心”的宇宙图景；**伽利略**1610 年用望远镜观察木星卫星；1633 年因支持地动说及与 1616 年禁令有关的争议而受审。

**1687 年，牛顿发表《自然哲学的数学原理》**，用运动定律与万有引力把天与地纳入同一套数学体系。此后，宇宙被理解为一部可以计算、可以预测的机器。

科学革命的深层影响不止于天文学。它确立了一种新的权威来源：**不再是典籍与教义，而是观察、实验与推理**。“自然规律”成为解释世界的通用框架——而这套方法，很快就会被用到社会与政治之上。

{% hint style="info" %}
**科学与宗教并非简单的对立。**哥白尼、开普勒、牛顿本人多持宗教信仰，早期近代科学的许多动力来自“理解造物主的设计”。真正被打破的，是教会对自然解释的垄断权，而非信仰本身。
{% endhint %}

## 4.5 启蒙运动

**1687 — 1789**

如果自然有规律可循，社会是否也可以？18 世纪的启蒙思想家们把科学的方法与信心搬到人事之上。**洛克**谈天赋权利与有限政府，**孟德斯鸠**论三权分立，**伏尔泰**抨击教权与专断，**卢梭**提出人民主权。狄德罗主编的**《百科全书》**把新知识汇编成册，广泛传播。

启蒙的核心诉求是：把判断的依据从传统与权威，转向公开的理性与讨论。它主张普遍的人权与法治，也要求言论与出版的空间。

然而启蒙诞生在一个殖民与奴役扩张的时代。这种矛盾贯穿始终：同样的口号，既能用来要求平等，也能用来为支配辩护。

{% hint style="info" %}
**启蒙如何看东方？**一部分启蒙思想家把奥斯曼或俄国当作“开明专制”的样本，另一部分则把它们当作欧洲的“反面教材”。这里已经埋下 19 世纪“文明—野蛮”话语的种子。**理解欧洲史，也包括理解欧洲如何想象自己之外的欧洲。**
{% endhint %}

## 4.6 全球争霸：重商主义与殖民竞争

**1650 — 1789**

主权国家之间的均势，很快延伸为海外的争夺。17 世纪，荷兰凭借航运与金融称雄；随后英国通过一系列航海法令与战争取而代之。到 18 世纪，英法成为全球竞争的主角。

经济上的指导思想是**重商主义**：把金银与贸易顺差视为国力之本，殖民地则被当作原料来源与市场。这种零和式的思维，使殖民扩张与国家战争紧密捆绑。**1756—1763 年的七年战争**常被称为“第一次世界大战”的预演，战场从欧洲延伸到北美与印度，战后英国确立了海上与殖民的优势。

但代价同样在累积：为分摊战费而加税，最终激化了北美殖民地的反抗。1776 年，**美国宣布独立**——启蒙的政治理念成为建立新国家的重要思想资源。
