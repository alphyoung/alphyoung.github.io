# 05 阶段五·革命、民族与帝国

法国大革命把“主权在民”推向政治中心，拿破仑的战争把这一理念传遍欧洲；维也纳体系试图恢复秩序，却挡不住民族主义与工业化的浪潮。但这一时期欧洲的政治形态远不止一种：向西，是民族国家；向东，是多民族王朝帝国；向东南，是一个正在失去欧洲领土的奥斯曼。**民族主义既是建国的力量，也是拆国的力量。**

* **1789** 法国大革命
* **1815** 维也纳会议
* **1830** 希腊独立
* **1848** 革命之年
* **1861 / 1871** 意大利、德国统一
* **1878** 柏林会议
* **1912—1913** 巴尔干战争
* **1914** 一战爆发

## 5.1 法国大革命与拿破仑

1789 — 1815

财政危机迫使路易十六召开三级会议，却意外打开了闸门。**1789 年**，第三等级自组国民议会，攻占巴士底狱，《人权与公民权宣言》宣告主权在民、法律面前人人平等。此后革命不断激进化：1792 年建立共和国、1793 年处死国王，随后进入**恐怖统治**，再经由热月政变回到保守。

1799 年，**拿破仑·波拿巴**掌权，1804 年称帝。他用一部《拿破仑法典》把革命的部分成果制度化——法律面前平等、私有财产、契约自由——并随军队带到欧洲各地。但他的征服也激起被占领地区的民族反抗，最终在 1815 年**滑铁卢**彻底失败。

| 阶段     | 时间          | 特征               |
| ------ | ----------- | ---------------- |
| 立宪君主   | 1789 — 1792 | 制宪、废除封建特权、《人权宣言》 |
| 共和国与恐怖 | 1792 — 1795 | 处死国王、对外战争、雅各宾专政  |
| 督政府    | 1795 — 1799 | 局势动荡，政局不稳        |
| 拿破仑时代  | 1799 — 1815 | 法典、征服、霸权、最终失败    |

{% hint style="info" %}
**拿破仑也在东方留下痕迹。**1798 年他远征埃及，虽然军事上无果而终，却打断了奥斯曼对埃及的直接控制，让地方势力坐大。欧洲列强由此更清楚地意识到：**奥斯曼的领土是可以被争夺的**——这就是后来所谓“东方问题”的开端。
{% endhint %}

## 5.2 维也纳体系与民族主义

1815 — 1848

1814—1815 年，战胜国在**维也纳会议**上重划欧洲。主导者**梅特涅**追求“均势”与“正统”：恢复被拿破仑打破的王朝，压制革命与民族诉求，战后秩序由列强协商共同维持，不能只归于俄、普、奥的“神圣同盟”；英国和后来重新参与协调的法国同样重要。这套体系维持了近四十年的大体稳定。

但它有一个内在难题：维也纳会议把**民族诉求**当作需要压制的干扰项。波兰再度被瓜分，德意志与意大利仍处于分裂，哈布斯堡帝国内部住着德意志人、匈牙利人、捷克人、波兰人、克罗地亚人、意大利人……**“一族一国”的设想，在这些地方意味着帝国解体。**

1848 年，革命席卷巴黎、维也纳、柏林、米兰、布达佩斯，被称为**“革命之年”**。革命大多被镇压，却把民族与宪政的议题牢牢钉上了欧洲的日程。

{% hint style="info" %}
**1848 年的东欧：另一场革命。**在匈牙利，科苏特领导的运动一度建立起独立的政府与军队，并在 1849 年宣布废黜哈布斯堡王朝；最终被奥地利联合俄国军队镇压。在波希米亚，斯拉夫各族的代表在布拉格召开大会，主张在帝国内部实现民族平等。**这些诉求与西欧的自由主义议会运动并不相同**——它们要解决的是“在一个多民族帝国里，谁算作政治主体”。
{% endhint %}

## 5.3 工业革命与社会变革

1760 — 1900

18 世纪后期，英国的纺织机械化和工厂制度发展，煤、铁与蒸汽动力逐步结合；蒸汽铁路则主要在 19 世纪扩展。工业化从英国扩散到比利时、法国、德国，把欧洲变成“世界工厂”。城市急剧膨胀，人口结构、家庭形态与时间观念都被重塑。

代价同样巨大：工人长时间劳作于恶劣环境，童工普遍，贫富分化加剧。作为回应，出现了工会、合作社与社会主义思潮。**1848 年《共产党宣言》**、此后的第一国际与各国社会民主党，都是这一矛盾的政治产物。工业化也极大增强了国家的军事与经济能力，为此后的总体战埋下伏笔。

{% hint style="info" %}
**工业化的地图很不平均。**19 世纪中叶，英国、比利时、德国西部已是烟囱林立，而俄国、巴尔干、伊比利亚大部仍以农业为主，俄国直到 1861 年才废除农奴制。**这种落差后来直接变成了政治落差**：工业强国能造出机关枪与铁路网，农业帝国只能在人力和粮食上苦撑。
{% endhint %}

## 5.4 民族统一：意大利与德国

1848 — 1871

民族主义从思潮变成现实，最典型的例子是意大利与德国。意大利长期分裂为多个邦国，部分还受奥地利控制。在**加富尔**的外交操作与**加里波第**的军事行动下，1861 年**意大利王国**宣告成立；1870 年收复罗马，1871 年迁都罗马，统一告成。

德国则围绕着“小德意志”（排除奥地利）路线推进。**俾斯麦**以“铁血政策”著称，通过三次战争——对丹麦、对奥地利、对法国——逐步扫清障碍。**1871 年，德意志帝国在凡尔赛宫镜厅宣告成立**，威廉一世称皇帝。一个新的大国出现在欧洲中部，力量格局随之改变。

普鲁士 _→_ 北德意志邦联 _→_ 德意志帝国（1871）

统一的方式也埋下隐患：德国在法国领土上加冕，让法德结下长久的怨怼；新帝国工业与军力增长极快，却缺少与之匹配的国际安排。

## 5.5 帝国的边疆：希腊、巴尔干与“东方问题”

1821 — 1913

当西欧在建国时，东南欧在做另一件事：**从帝国里分离出来**。

**1821 年，希腊爆发起义**，经过近十年战争与列强干预，**1830 年正式独立**——这是第一个成功脱离奥斯曼的欧洲民族国家，也让整个巴尔干的基督徒看到了可能。塞尔维亚在此前后取得自治地位并逐步扩大。

奥斯曼的退却，很快引来列强的争夺。**1853—1856 年的克里米亚战争**中，英法为阻止俄国独吞奥斯曼遗产而参战，战后签订《巴黎和约》——这是“东方问题”最典型的一幕：**主角是奥斯曼的领土，说话的是别人。**1875—1878 年巴尔干再度大起义，俄国出兵击败奥斯曼，最终由**1878 年柏林会议**重划版图：塞尔维亚、黑山、罗马尼亚获得独立，保加利亚成为自治公国，奥匈则取得对波斯尼亚—黑塞哥维那的占领权。

| 时间        | 事件          | 结果                |
| --------- | ----------- | ----------------- |
| 1821—1830 | 希腊独立战争      | 首个脱离奥斯曼的欧洲民族国家    |
| 1853—1856 | 克里米亚战争      | 列强阻止俄国独占，奥斯曼暂获保全  |
| 1878      | 柏林会议        | 塞、黑、罗独立；保加利亚自治；奥匈占波黑 |
| 1908      | 奥匈吞并波黑      | 引发波斯尼亚危机，俄奥对抗加剧   |
| 1912—1913 | 两次巴尔干战争     | 奥斯曼几乎失去全部欧洲领土     |

到 1913 年，奥斯曼在欧洲只剩下伊斯坦布尔周边一小块。**而巴尔干并没有因此安宁**：保加利亚、塞尔维亚、希腊、罗马尼亚立刻为分赃而战，彼此结怨；奥匈与俄国则在这一带正面对撞。**第一次世界大战的火药，大部分就堆在这里。**

{% hint style="info" %}
**“多民族帝国”不是历史遗留物，而是当时的常态。**1830 年的欧洲，领土面积最大的几个政治体——俄国、奥斯曼、哈布斯堡、英国——没有一个是民族国家。民族国家只是当时欧洲的一种形态，而且是最新的一种。
{% endhint %}

## 5.6 帝国争霸与大战前夜

1871 — 1914

19 世纪末，列强在非洲、亚洲展开**殖民争夺**，把世界瓜分殆尽。欧洲形成相互对立的外交结盟格局，但条约性质与参战选择并不完全一致：**三国同盟**（德、奥匈、意大利）与**三国协约**（英、法、俄）。意大利虽属三国同盟，却在 1914 年保持中立，1915 年转而加入协约国一方。军备竞赛、民族矛盾与联盟义务层层叠加，把欧洲推成一只随时可能引爆的火药桶。

1914 年 6 月 28 日，奥匈皇位继承人斐迪南大公在**萨拉热窝**遇刺，看似偶然的事件触发了连锁反应，各国在几周内相继卷入战争。

{% hint style="info" %}
**一战是“意外”还是“必然”？**两种说法各有一半道理。短期看，七月危机中的决策失误的确像一场意外；长期看，联盟体系、军备竞赛、殖民争夺与民族主义早已累积了巨大的结构性压力。更审慎的说法是：**结构提供了火药，决策点燃了引信**——而火药里，有相当一部分来自巴尔干。
{% endhint %}
