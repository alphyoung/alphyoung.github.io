# 03 阶段三·边界的重划

1453 — 1648

这个阶段有两件事同时发生：拉丁基督教世界的信仰统一被打破，以地中海为中心的经济格局被大西洋航线取代；而在东南方，一个以伊斯坦布尔为都的伊斯兰帝国，把巴尔干、匈牙利大部与黑海北岸纳入了自己的版图。欧洲的边界与内部版图，在这两百年里被彻底重划。

* **1453** 君士坦丁堡陷落
* **1492** 哥伦布抵达美洲
* **1517** 宗教改革
* **1526** 莫哈奇战役
* **1555** 奥格斯堡和约
* **1569** 波兰—立陶宛联邦成立
* **1648** 威斯特伐利亚和约

## 3.1 文艺复兴与人文主义

**14 — 16 世纪**

转变更早就已在意大利酝酿。富庶的**意大利城市政权**——包括佛罗伦萨、威尼斯共和国及主要由领主和公爵统治的米兰——赞助艺术家与学者，美第奇家族是最著名的资助者。学者重新搜集、校勘古希腊罗马的文本，形成**人文主义**：把注意力从神学思辨转向人的尊严、修养与公共生活。

技术放大了这场运动。**约 1450 年，古腾堡改良活字印刷**，书籍从此可以大量复制。思想不再依赖手抄与口传，传播速度与范围被彻底改变——这也为随后宗教改革的迅速扩散提供了条件。

达·芬奇、米开朗基罗、拉斐尔、马基雅维利、伊拉斯谟……他们既继承古典，又以新的眼光观察现实。文艺复兴并非与中世纪一刀两断，而是把中世纪的养分用新的方式重新组织。

{% hint style="info" %}
**一场“抢救”的背景。**人文主义者拼命搜集希腊文抄本，恰逢大批拜占庭学者携典籍西迁。这不是巧合：1453 年君士坦丁堡陷落后，许多希腊学者带着手稿前往意大利谋生，把柏拉图与亚里士多德的原文直接带进了拉丁世界。
{% endhint %}

## 3.2 大航海与殖民帝国

**1415 — 1600**

奥斯曼在 1453 年攻陷**君士坦丁堡**，此后长期掌控东地中海与欧亚之间的商路。西欧的商人于是更多转向海洋——不过，把海外扩张完全归因于“商路被堵”是一种简化：葡萄牙的远航早在 1415 年就已开始。葡萄牙沿非洲海岸南下，绕过好望角进入印度洋；西班牙则向西押注——**1492 年，哥伦布抵达美洲**。

此后的百年里，西班牙与葡萄牙率先建立横跨大洋的殖民帝国，荷兰、英国、法国随后加入。美洲的白银大量流入欧洲，颠覆了物价与贸易格局；非洲与美洲之间则被强行串联起**跨大西洋奴隶贸易**，按跨大西洋贸易整个时期（约 16—19 世纪）的估计，约 1250 万人被迫在非洲登船，约 1070 万人生还抵达美洲；途中以及掳掠过程另有大量死亡。

大航海的深层后果是经济重心的转移：地中海不再是欧洲的中心，大西洋沿岸的里斯本、塞维利亚、阿姆斯特丹、伦敦相继崛起。欧洲内部的力量格局，从此开始向西北倾斜。

{% hint style="warning" %}
**关于“地理大发现”这个说法：**它对欧洲人而言是“发现”，对美洲原住民却是灾难的开端——征服、奴役与疫病使当地人口锐减。今天越来越多的教材改用“大航海时代”或“殖民扩张”，以容纳被书写遮蔽的另一侧。
{% endhint %}

## 3.3 1453 的两重含义

**1453 — 1571**

对拉丁西欧，1453 年常常只是一个分期路标：中世纪在此结束，近代在此开始。但同一件事还有另一面。

**君士坦丁堡的陷落，终结了延续近千年的拜占庭帝国。**末代皇帝君士坦丁十一世战死城中，东正教的最高政治庇护者就此消失。此后，莫斯科逐渐接过“第三罗马”的想象，而希腊、塞尔维亚、保加利亚的教会则要在穆斯林君主的治下重新安排自己的位置。

与此同时，**奥斯曼成为一个地跨三洲的欧洲帝国**。它的都城伊斯坦布尔（旧君士坦丁堡）是欧洲最大的城市之一；它直接统治巴尔干与安纳托利亚，把瓦拉几亚、摩尔达维亚、克里米亚汗国作为附庸；它的一省之长官比许多西欧国王更富有。**1526 年的莫哈奇战役**击溃匈牙利军队，此后匈牙利被三分：中部直属于奥斯曼，西北部归哈布斯堡，东部形成特兰西瓦尼亚公国。**1529 年，奥斯曼军队第一次围困维也纳**——中欧的心脏第一次直面来自东南方的兵锋。

直到 **1571 年勒班陀海战**，基督教联合舰队才在地中海上遏制住奥斯曼的海上力量（尽管其陆地优势并未动摇）。此后百余年，中欧与东南欧的政治日程，都绕不开这位邻居。

| 与奥斯曼的关系 | 地区                | 大致形态            |
| ------- | ----------------- | --------------- |
| 直接统治    | 巴尔干大部、安纳托利亚、匈牙利中部 | 设省治理，编入税册与军事体系  |
| 附庸      | 瓦拉几亚、摩尔达维亚、克里米亚汗国 | 纳贡、提供兵源，内部自治程度较高 |
| 年年对峙    | 哈布斯堡、威尼斯、波兰—立陶宛   | 战争与停战交替，边界反复移动  |
| 隔岸观望    | 英、法、北欧等         | 时有贸易与结盟，甚至联合对付哈布斯堡 |

{% hint style="info" %}
**一个常被忽略的事实：法国曾与奥斯曼结盟。**16 世纪，为对抗哈布斯堡的包围，法王弗朗索瓦一世与苏莱曼一世达成合作安排。这说明当时的“基督教世界 vs 伊斯兰世界”并非铁板一块——**国家利益常常压过宗教阵营**。
{% endhint %}

## 3.4 宗教改革：统一信仰的破裂

**1517 — 1555**

**1517 年，马丁·路德发表《九十五条论纲》**，主要质疑赎罪券的效力及相关实践；“因信称义”成为他此后改革思想的核心。《圣经》被译成德语，普通人得以自行阅读。加尔文在日内瓦建立另一套改革传统，英格兰国王亨利八世在婚姻撤销与王权争端中推动英格兰教会脱离罗马管辖，1534 年确立王室最高权威。西欧延续千年的宗教统一就此破裂。

1555 年**《奥格斯堡宗教和约》**确立“教随国定”：谁统治，就信谁的教。但这并没有带来个人信仰自由，也未纳入加尔文宗，矛盾继续积累——半个世纪后，它以一场更大规模战争的形式爆发。

{% hint style="info" %}
**同一时期的东欧，是另一幅地图。**当西欧为信仰开战时，波兰—立陶宛（1569 年正式联合）容纳了天主教、东正教、新教与欧洲最大的犹太社群，并在 1573 年确立宗教宽容；波希米亚的胡斯派早已先行一步；匈牙利部分地区转向新教；而俄国与巴尔干东正教徒，则在莫斯科牧首区与奥斯曼治下的米勒特制度里各自延续。**宗教改革不是全欧洲的故事，它有自己的地形。**
{% endhint %}

## 3.5 三十年战争与威斯特伐利亚体系

**1618 — 1648**

**1618—1648 年的三十年战争**是宗教与王朝矛盾的总爆发：它从波希米亚的一场叛乱开始，逐步卷入西班牙、丹麦、瑞典、法国，几乎把中欧打成废墟，德意志地区人口损失尤为惨重。

1648 年**《威斯特伐利亚和约》**结束了战争。它是帝国宪制和欧洲外交的重要调整，但并未一次创立现代主权平等国家体系；把 1648 年视为这一体系的出生点，是有争议的后世叙事。

| 和约的主要安排 | 含义               | 后世影响          |
| ------- | ---------------- | ------------- |
| 帝国宪制调整 | 确认帝国等级的若干权利，帝国框架仍存 | 不等于现代国家普遍主权平等 |
| 教派归属按领地 | 承认天主教、路德宗、加尔文宗并存 | 宗教多元化在中欧被制度化  |
| 以条约协调冲突 | 通过多边谈判处理宗教和政治争端     | 外交与均势体系的先声    |

值得注意的是，这场“欧洲大战”的参与者里**没有奥斯曼**——此时它正忙于与哈布斯堡在匈牙利方向的对峙、以及与威尼斯的克里特战争。欧洲的政治从来不止一个棋盘。

这一阶段可以概括为：**拉丁基督教世界的制度性统一受到冲击，教派、王朝与不同政治体之间形成新的安排；与此同时，东南欧被纳入另一个帝国的时间表。**国家体系的变化是长期过程，宗教权威也并未从政治中消失。
