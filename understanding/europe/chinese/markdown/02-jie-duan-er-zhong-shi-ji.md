# 02 阶段二·中世纪

中世纪不是“黑暗的空白”，而是欧洲基本结构成型的时代：封建契约、庄园经济、教会权威、大学与城市都在此期生长。但“中世纪欧洲”从来不只有一个中心：当法兰克与教皇在西欧互相加冕时，拜占庭仍以“罗马”自居，斯拉夫诸族正从第聂伯河与波罗的海两个方向进入基督教世界，而安纳托利亚的另一端，一支新的力量正在崛起。

* **962** 奥托一世加冕
* **988** 基辅罗斯受洗
* **1054** 东西教会分裂

* **1204** 君士坦丁堡被十字军攻陷
* **1389** 科索沃战役
* **1347** 黑死病

## 2.1 法兰克与查理曼：西欧的第一次整合

476 — 843

西罗马瓦解后，日耳曼诸部在原帝国土地上建立了一系列王国：西哥特人在伊比利亚、东哥特人在意大利、法兰克人在高卢。其中法兰克王国最具潜力。墨洛温王朝的克洛维皈依天主教，把王权与教会、罗马化的高卢贵族联系起来。

到 8 世纪，加洛林家族取而代之。**800 年，查理曼在罗马由教皇加冕为“罗马人的皇帝”** ——一个意味深长的举动：它既延续了罗马的想象，也让皇权需要教皇的加冕来承认。这是西欧自西罗马灭亡后的第一次大规模整合。

但整合并不牢靠。843 年**《凡尔登条约》**将查理曼的帝国三分，大致奠定了后来法、德、意三国的雏形——不过，这只是若干可能的走向之一，并非命中注定。

{% hint style="info" %}
**注意“罗马人的皇帝”这个头衔的野心与尴尬。**查理曼加冕时，君士坦丁堡还有一位货真价实的罗马皇帝。此后“罗马”在西欧成了一个可以被授予、被争夺的名号——962 年奥托一世加冕，神圣罗马帝国由此而来，而它既非罗马，也未必神圣，更不是个帝国。
{% endhint %}

## 2.2 封建制度、庄园与骑士

9 — 13 世纪

中央权力弱小，秩序便由层层的人际契约来维持。这就是通常所说的**封建制度**：封君把土地（采邑）授予封臣，封臣以军事与忠诚回报，封臣又可以再向下分封。它形成了一个松散的等级网络，而非现代意义上的国家。

土地上的经济单位是**庄园**：领主拥有土地与司法权，农奴或农民耕作并缴纳地租与劳役。绝大多数人口生活在乡村，靠天吃饭。与此并存的是**骑士**阶层——以武力换取土地，逐渐形成一套关于荣誉与忠诚的行为规范。

{% hint style="info" %}
**不要把“封建”想象成整齐的金字塔。**同一块地可能同时存在几重权利主张，封臣对多个封君效忠也属常态。中世纪的政治是拼贴式的，靠习惯法与谈判维系，而非清晰的科层结构。这套安排大体适用于拉丁西欧；拜占庭与东欧走的不是同一条路——那里更重要的是皇权、官僚与村社。
{% endhint %}

## 2.3 教会与皇权的拉锯

1075 — 1250

中世纪欧洲最重要的两条线索，是**教会**与**世俗君主**的关系。教会拥有自己的法律、法庭、税收与广大的地产，它并不仅仅是一个信仰团体，而是一个跨国性的权力机构。

1077 年的**卡诺莎之辱**是这场较量的著名一幕：德意志国王亨利四世（1084 年才加冕皇帝）在与教皇格里高利七世的“叙任权之争”中失势，被迫在雪地里忏悔。1122 年**《沃尔姆斯协定》**达成妥协，皇帝与教会在主教任命上各让一步。

教会内部也不断改革：修道院运动、托钵修会（方济各会、多明我会）兴起，既净化信仰，也扩大影响。到 13 世纪，教皇的权威达到顶峰，却也埋下了与民族君主长期冲突的伏笔。

{% hint style="info" %}
**另一个转折：**1054 年，罗马使节与君士坦丁堡宗主教一方对具体人物作出相互绝罚，后来成为**东西教会分裂**的象征性节点。分离是长期过程，不能据此把全欧洲的宗教版图在这一年整齐一分为二。语言、礼仪、政治归属的差异，早在之前几百年就已累积。
{% endhint %}

## 2.4 十字军、商业复兴与城市

1096 — 1300

1095 年，教皇乌尔班二世在克莱蒙号召“收复圣地”，**第一次十字军（1096 起）**由此发动。此后的两百年间，西欧先后发动多次东征，成果有限，影响却深远：它加剧了与伊斯兰世界及东正教世界的对立，也把东方的商品与知识带回西欧。

**其中对东部欧洲影响最大的一击，发生在 1204 年。**第四次十字军本意指向埃及，最终却攻陷并洗劫了同为基督教世界的**君士坦丁堡**。这座自 330 年以来未曾被外敌攻破的帝都遭到毁灭性破坏，拜占庭帝国被短暂肢解，直到 1261 年才由尼西亚帝国收复都城。这次背刺，是东西教会再难弥合的关键裂痕之一。

与此同时，地中海贸易蓬勃发展。**威尼斯、热那亚、比萨**等意大利城市靠转口贸易积累财富；北方的波罗的海—北海区域则出现**汉萨同盟**。城市自治、行会与银行随之兴起，一个不同于庄园的城市经济逐渐成形。

城市需要识字的人。11—12 世纪，**大学**在博洛尼亚、巴黎、牛津等地逐步成形；博洛尼亚传统建校年为 1088 年，牛津 1096 年已有教学记录。古典著作经由阿拉伯世界的翻译重新进入西欧，为后来的文艺复兴悄悄积蓄了条件。

## 2.5 东部的欧洲：拜占庭、斯拉夫与东正教世界

6 — 14 世纪

当中世纪西欧在封建契约与教权皇权之间拉锯时，欧洲东部运行着另一套逻辑。

**拜占庭**延续着罗马的国家机器：皇帝既是世俗统治者，也是教会事务的主导者；法律、税收与常备官僚一应俱全，城市生活远比同期西欧繁盛。它也有过自己的扩张期——6 世纪查士丁尼一度收复意大利与北非；但此后长期面对波斯、阿拉伯与突厥的压力，疆域逐渐收缩到安纳托利亚与巴尔干。

**斯拉夫诸族则在两个方向上进入了历史。**一支从第聂伯河出发：以基辅为中心的**基辅罗斯**在 9—10 世纪成形（传统纪年常以 862 年为其开端），**988 年，弗拉基米尔一世受洗**，东正教从此成为罗斯的国教。另一支走的是波罗的海南岸与中欧路线：**波兰的梅什科一世约于 966 年受洗**，**匈牙利约在 1000 年由斯蒂芬加冕并皈依**，波希米亚则长期处在德意志与拉丁教会的影响之下。**同样信仰基督，却分属罗马与君士坦丁堡两个世界**——这条界线此后一千年都未曾消失。

{% hint style="info" %}
**三个“边缘王国”的不同命运。**波兰、匈牙利、波希米亚都选择了拉丁基督教。这让它们在文化上属于西欧，却在政治上长期处在神圣罗马帝国与条顿骑士团、蒙古西征、以及后来的奥斯曼扩张的夹缝里。今天所说的“中东欧”，其独特性正源于这种位置：既是西欧的一部分，又持续被来自东方与南方的力量冲击。
{% endhint %}

## 2.6 奥斯曼的登场

13 — 15 世纪

就在拜占庭日益衰弱之际，安纳托利亚西北部出现了新的主角。**奥斯曼人**原是一支塞尔柱之后的突厥部族，13 世纪末在小亚细亚立国，14 世纪迅速向巴尔干推进。

**1361 年占领阿德里安堡（埃迪尔内）**，意味着奥斯曼把政治中心搬到了欧洲一侧；**1389 年的科索沃战役**击溃塞尔维亚力量，塞尔维亚、保加利亚、瓦拉几亚相继臣服。1396 年，西欧骑士组成的十字军又在**尼科波利斯惨败**。到 15 世纪中叶，拜占庭只剩君士坦丁堡一城和伯罗奔尼撒的几块地方。

也就是说，在欧洲历史的这一页上，**奥斯曼不是外来的“亚洲势力”，而是一个欧洲政治体**：它在巴尔干收税、征兵（包括著名的近卫军制度）、册封附庸，其统治持续了四五百年，深刻改变了东南欧的语言、宗教与人口结构。

{% hint style="info" %}
**为什么这一点常被忽略？**因为 19 世纪以来的欧洲史叙事习惯以拉丁西欧为主线，把东南欧放在“帝国边疆”的位置。但对一个塞尔维亚农民或希腊商人的后代来说，1389 年或 1453 年之后的历史，就是与奥斯曼共处的历史——那是欧洲史，只是不是西欧史。
{% endhint %}

## 2.7 黑死病与中世纪的危机

1347 — 1453

**1347 年，黑死病经黑海与西西里登陆欧洲**，此后数年带走约三分之一甚至更多的人口。劳动力锐减，庄园经济动摇，社会矛盾尖锐，宗教权威也遭到质疑。这场瘟疫对欧洲结构的冲击，远超过一场单纯的疾病。

与瘟疫并行的是战争与分裂：**英法百年战争（1337—1453）**持续百年，把两国推向民族意识的觉醒；教会内部出现**大分裂（1378—1417）**，一度同时有两位甚至三位教皇。而在东边，拜占庭的最后一块领土，也正被奥斯曼一点一点削去。

{% hint style="info" %}
**“黑暗的中世纪”这一说法从何而来？**它主要出自文艺复兴时期的人文主义者：为了凸显自己对古典的重光，他们刻意把中间这段贬为“黑暗”。今天的历史学更倾向于把中世纪看作一个有创造力的时代——大学、议会、银行、机械钟都诞生于此。而在东半部，这段时期同样是城市、修道院与商贸繁荣的时代。
{% endhint %}
