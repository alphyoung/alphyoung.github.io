# 00 读懂欧洲

古典、信仰与权力 —— 七大历史阶段

一个伸向大西洋的半岛大陆，如何从希腊城邦与罗马帝国出发，经历基督教世界的分裂、多个帝国的兴亡、民族国家的兴起与两次世界大战，形成今天多种政治形态并存的格局。欧盟只是当代众多安排中的一种——它覆盖不到全欧洲，也不是这段历史的终点。

全篇按七个历史阶段组织，以若干代表性转折作阅读路标。要提醒的是：各地区的变化并不同步，同一时期的不同角落可能处在完全不同的状态——当佛罗伦萨在赞助画家时，巴尔干的农民正被编入奥斯曼的税册；当伦敦开始冒烟时，俄国还在实行农奴制。所以每一个阶段都会同时讲两条线：一条是拉丁西欧，一条是拜占庭与东正教世界、斯拉夫诸族、波兰—立陶宛，以及奥斯曼治下的东南欧。

## 阅读之前，先分清三种“欧洲”

**地理的欧洲**：从大西洋到乌拉尔山的一片陆地。它是自然概念，边界本身就带着人为约定。

**文化的欧洲**：常被等同于“基督教世界”或“拉丁—日耳曼传统”。但基督教本身先分成拉丁与希腊两支，东南欧又长期处在奥斯曼的统治与伊斯兰的深刻影响之下。欧洲从来不是一种文化，而是至少两三种彼此纠缠的传统。

**政治的欧洲**：中世纪的王朝领地、近代的主权国家、多民族帝国、当代的区域组织，都是不同的政治形态，而且长期并存——当西欧走向民族国家时，中东欧还是多民族帝国；当部分西欧国家让渡主权结成联盟时，另一些国家正从联盟中退出。

至于**欧盟**：它成立于 1993 年（《马斯特里赫特条约》），是当代部分欧洲国家之间的一种合作安排。它不等于地理欧洲，不等于文化欧洲，也不代表欧洲各国共同的走向——英国已于 2020 年退出。把它当成欧洲历史的目的地，是理解欧洲最常见的绊脚石。

全篇的分段，依据的是欧洲政治形态的几次根本转折：**古典世界的形成 → 基督教世界的分裂与重组 → 边界的重划 → 君主与帝国的时代 → 革命、民族与帝国 → 在两次大战中崩解 → 分裂、剧变与重新拼合**。

## 一条时间轴看全史

* **前776**：传统纪年中最早有记录的奥林匹亚赛会，希腊城邦时代
* **前509**：罗马共和国建立
* **前27**：奥古斯都，罗马帝国开端
* **313**：米兰敕令，基督教合法化
* **330 / 395**：君士坦丁堡建都／罗马帝国东西分治
* **476**：西罗马灭亡（东部帝国又延续近千年）
* **800**：查理曼加冕
* **862 前后**：基辅罗斯兴起（传统纪年）
* **962**：奥托一世加冕，神圣罗马帝国
* **1054**：东西教会分裂
* **1096**：第一次十字军
* **1204**：第四次十字军攻陷君士坦丁堡
* **1347**：黑死病蔓延
* **1389**：科索沃战役，奥斯曼深入巴尔干
* **1453**：君士坦丁堡陷落，拜占庭终结
* **1492**：哥伦布抵达美洲
* **1517**：路德《九十五条》，宗教改革
* **1526**：莫哈奇战役，匈牙利大部落入奥斯曼之手
* **1648**：威斯特伐利亚和约
* **1683**：维也纳之围，奥斯曼在中欧的扩张止步
* **1687**：牛顿《自然哲学的数学原理》出版
* **1721**：俄国改称帝国
* **1772 / 1793 / 1795**：波兰被三次瓜分
* **1789**：法国大革命
* **1815**：维也纳会议
* **1830**：希腊独立
* **1861 / 1871**：意大利、德国相继统一
* **1878**：柏林会议，巴尔干版图重划
* **1914**：第一次世界大战
* **1918**：德意志、奥匈、俄罗斯、奥斯曼四大帝国崩溃
* **1939**：第二次世界大战
* **1945**：二战结束，欧洲被一分为二
* **1955**：华约成立
* **1968**：布拉格之春
* **1989**：东欧剧变，柏林墙倒塌
* **1991**：苏联解体
* **2004**：部分中东欧国家加入欧盟（不是整个欧洲）
