# 09 附录：概念与资料

把全篇反复出现的关键概念集中解释，并给出可用于继续深入的线索。历史学的价值，一半在于知道事实，一半在于知道这些概念从何而来、边界在哪。

## A.1 七阶段脉络一览

| 阶段 | 跨度 | 一句话主题 |
| --------- | ----------- | -------------------------------- |
| Ⅰ 古典地基    | 前 800 — 476 | 希腊、罗马、基督教在地中海合流；帝国东西分岔，两条线由此开始 |
| Ⅱ 中世纪     | 476 — 1453  | 拉丁西欧、拜占庭与东正教世界并行；奥斯曼登场 |
| Ⅲ 边界的重划   | 1453 — 1648 | 信仰统一破裂、经济重心西移；东南欧被纳入奥斯曼 |
| Ⅳ 君主的世纪   | 1648 — 1789 | 君主集权；俄、普、奥崛起，波兰消失，奥斯曼退潮 |
| Ⅴ 革命、民族与帝国 | 1789 — 1914 | 民族国家与多民族帝国并存，巴尔干持续动荡 |
| Ⅵ 两次大战与帝国的终结 | 1914 — 1945 | 四大帝国崩溃；中东欧的边界与人口被重画 |
| Ⅶ 分裂与重新拼合 | 1945 — 今    | 冷战分裂、1989 剧变、欧洲的再拼接 |

## A.2 关键概念表

| 概念              | 含义                 | 常见误解                |
| --------------- | ------------------ | ------------------- |
| 城邦（polis）       | 以公民共同体为核心的政治单位     | 误当作现代国家；其公民范围其实极为有限 |
| 罗马共和国（此处特指） | 通过元老院、选举与任期等安排组织权力 | 误以为罗马共和国是全民民主       |
| 封建制度            | 以土地封授与效忠关系维系的等级网络  | 误当作整齐的科层金字塔；也误当作适用于全欧洲 |
| 米勒特制度           | 奥斯曼按宗教社群管理非穆斯林臣民的安排 | 误当作现代意义上的宗教宽容       |
| 主权（sovereignty） | 国家在其领土内的最高权力       | 误以为自古就有；它是近代的产物     |
| 民族国家            | 以民族认同为合法性基础的国家     | 误以为“一族一国”是自然状态      |
| 民族自决            | 一个民族有权建立自己的国家      | 误以为它天然适用于帝国境内的每一个族群 |
| 均势              | 以力量平衡防止一方独大、维持秩序   | 误以为平衡必然带来和平         |
| 东方问题            | 列强围绕奥斯曼帝国遗产的长期争夺   | 误当作奥斯曼的内部事务         |
| 一体化             | 国家将部分主权交由共同机构行使    | 误以为等于建立一个“欧洲国”，或等于全欧洲的走向 |

## A.3 主要政治体时序总览

| 政治体         | 大致时间              | 关键线索             |
| ----------- | ----------------- | ---------------- |
| 希腊城邦        | 约前 800 起；前 146 为罗马征服的重要节点 | 公民政治、哲学与戏剧的源头    |
| 罗马共和国 / 帝国  | 前 509 — 公元 476（西） | 法律、行省与地中海统一      |
| 拜占庭帝国       | 约 330／395 — 1453（分期约定） | 东正教、希腊语、延续千年     |
| 基辅罗斯 → 俄罗斯  | 9 世纪起；1721 改称帝国   | 东正教、斯拉夫世界、后成欧亚帝国 |
| 加洛林帝国       | 800 — 843 分割（非加洛林统治终止） | 西欧第一次大规模整合       |
| 神圣罗马帝国      | 962 — 1806        | 多种领地与政治体的复合框架，非单一民族国家 |
| 波兰—立陶宛联邦    | 1569 — 1795       | 贵族共和、宗教宽容，终被三次瓜分 |
| 奥斯曼帝国（欧洲部分） | 14 世纪 — 1922      | 长期统治巴尔干与东南欧      |
| 奥匈帝国        | 1867 — 1918       | 多民族双元帝国，一战中解体    |
| 欧洲联盟        | 1993 — 今          | 部分欧洲国家的主权让渡型区域安排 |

## A.4 继续深入的建议

* **先抓主干：**用七个阶段与总时间轴搭起框架，再往里填细节，比零散记忆事件更有效。
* **再分专题：**宗教、经济、战争、思想四条线索各自可以单独梳理，看清它们如何互相牵引。
* **补上另一半地图：**读完西欧部分后，专门沿拜占庭—东正教—奥斯曼这条线再走一遍，会发现许多“欧洲常识”其实是西欧常识。
* **留意视角：**同一事件在不同立场下叙述迥异。对任何“常识性”结论，都值得问一句：这是谁的说法？
