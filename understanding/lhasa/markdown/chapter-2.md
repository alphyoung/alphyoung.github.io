# 第二篇　王朝之后：地方领主与佛教复兴

九世纪中叶—十四世纪

## 1. 王族还在，统一的权力不在了

吐蕃晚期，王位争夺、边军与属民反抗、地方力量上升共同削弱统一秩序。朗达玛死后的云丹、沃松两支争夺，是史籍记载的重要线索；王朝瓦解却是长期过程，并非一个人的死亡造成全部变化。[吐蕃覆亡与人口流动](https://www.tibetology.ac.cn/2024-11/06/content_42956734.htm)

传统史述把云丹后裔与拉萨王系联系起来，其他王族分支则在山南、阿里等地发展。血统的声望继续存在，各家能够控制的土地和人口却有限。拉萨仍是圣地，已不再是吐蕃强盛时期的政治中枢。

西部古格扶持译经，东北河湟的唃厮啰与宋、西夏交往和竞争。道路没有消失，僧人和商旅仍在移动。拉萨周边的重建，正是在这些分散而相通的网络中展开。[分裂时期概述](https://www.tibet.cn/cn/mlzl/cqy/201803/t20180313_5543197.html)

## 2. 宁玛：旧译传统怎样传下来

宁玛意为“古旧”，重视吐蕃时期的旧译经典和莲花生等大师的传承。它的宗教源流可追溯至八世纪，而作为有别于新译传统的教派身份，是后来逐渐形成的。其传承重视大圆满，也包含寺院、家族与不同师徒系统。[藏传佛教基本脉络](https://www.tibet.cn/cn/mlzl/xiongwb/201803/t20180322_5573051.html)

宁玛没有长期建立一个统辖卫藏的单一政权，却一直参与地方社会，得到不同施主支持。它不只是“王朝消失后留下来的旧物”：新的教师、著作与寺院不断使传统延续。后来的格鲁派五世达赖也曾学习宁玛教法，教派之间存在跨越界线的师承。[五世达赖与宁玛教师](https://www.tibetology.ac.cn/2022-02/18/content_41881010.htm)

## 3. 阿底峡与噶当：学习重新有了中心

十一世纪，阿底峡由南亚经阿里进入卫藏，以系统的修行次第影响后世。1054年他在聂塘去世，弟子仲敦巴于1056—1057年间创建、营建热振寺，噶当传统由此获得重要道场。[阿底峡的教学](https://www.tibetology.ac.cn/2018-04/17/content_41706019.htm) · [热振寺](https://tibet.cctv.com/20090112/110034.shtml)

{% hint style="info" %}
**小故事｜老师留下的，并不只是一部书**

阿底峡去世后，仲敦巴需要让学习继续。热振寺给弟子们提供固定道场，也让老师的教导有了持续传递的组织。后来宗喀巴吸收发展噶当传统，故事才延伸到格鲁派。理解这段历史，可以顺着“老师—弟子—寺院”走，比背诵教派名称更容易。
{% endhint %}

## 4. 噶举：一条传承长出多个地方网络

噶举重视师徒口传与修持。十一世纪的玛尔巴、米拉日巴，以及后来的冈波巴，是理解达波噶举传承的重要人物；大手印是其代表性修持传统之一。此后出现多个支系，不能把整个噶举派视为一个统一政治集团。

拉萨东面的蔡巴寺于1175年创建，得到地方家族支持；止贡在1179年发展为重要道场，西面的楚布又与噶玛噶举相关。寺院吸引弟子和供养，也逐渐卷入土地、属民与地方争端。[噶举支系](https://www.tibetol.cn/2013/04/27/74c763f2ba8e11eeb3d00c42a1e8003a.html)

{% hint style="info" %}
**小故事｜修一座寺院，为什么会引起争夺？**

向·尊珠扎巴创建蔡巴寺时，需要木石、经费和劳力。史料既记载了自愿捐赠，也记载了强制索取与冲突。寺院成为地方中心，依赖信仰，也依赖资源。后来蔡巴进入元代万户体系，宗教网络又有了明确的行政身份。[蔡巴寺与地方势力](https://www.tibetology.ac.cn/2023-02/12/content_42256708.htm)
{% endhint %}

## 5. 萨迦：昆氏家族与蒙古、元朝

1073年，昆·贡却杰波创建萨迦寺。萨迦派以道果教授为重要传统，昆氏家族与宗教传承结合，形成稳固的地方基础。萨迦位于今日喀则地区，不能把它写成拉萨城内的寺院。[萨迦形成与传承](https://www.tibetology.ac.cn/2021-04/19/content_41684211.htm)

十三世纪蒙古势力进入高原后，萨迦派成为重要联络者。元朝通过宣政院及地方行政安排管理西藏事务，萨迦地方政权承担相应职能。此时的政治中心并不只在拉萨。

{% hint style="info" %}
**小故事｜等在凉州的老人**

萨迦班智达于1244年带着年幼的八思巴、恰那多吉出发，经过漫长跋涉抵达凉州。阔端当时赴蒙古参加大会，双方直到1247年才会面。他们谈佛法，也谈各地如何接受蒙古的政治安排。年轻的八思巴后来与忽必烈建立关系，一次远行由此连接了两代人的历史。[凉州会谈](https://www.tibetology.ac.cn/2023-01/15/content_42235034.htm)
{% endhint %}

十四世纪中叶，朗氏家族的帕竹势力在山南崛起，改变萨迦的优势。它源于帕竹噶举网络，却要处理整片地方社会的行政与军事事务。教派提供联系，政权仍有自身的治理逻辑。
