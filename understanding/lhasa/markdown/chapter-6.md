# 第六篇　圣城中的人：修行、诗歌与远行

让人物回到制度与街巷之间

## 1. 米拉日巴：一座反复修筑的塔

在噶举传统的宗教传记里，米拉日巴拜玛尔巴为师，却没有立刻获得教法。他经历搬石、筑塔等磨炼，最终成为以修行与道歌著称的宗教人物。这个故事解释的是传承如何理解悔过、求法与转变，并非拉萨本地的一次建筑工程。

{% hint style="info" %}
**传记故事｜石头与求法**

塔修起来，又被要求拆除；石头搬过去，还要搬回来。后世传记用这样的反复，把抽象的“修行”写成身体的劳作。传记成书晚于人物生活的时代，包含口传和宗教塑造，不能把所有细节当作同时代记录。[转世与传承研究](https://www.tibetology.ac.cn/2022-06/06/content_41992968.htm)
{% endhint %}

## 2. 仓央嘉措：法座之外的诗人

1697年，仓央嘉措被迎立为六世达赖；1706年，他又在拉藏汗介入的权力冲突中被废黜。同一个人，处在宗教身份、个人生活与蒙古汗王的政治安排之间。把他只写成浪漫诗人，会漏掉那个动荡的时代。

他的诗歌以明白、亲切的表达进入广泛传播，又经不同译者呈现出不同面貌。读这些作品，要区分藏文文本、汉译与后人托名；网络上署着他的名字，并不足以证明作者。[相关历史](https://www.tibetology.ac.cn/2022-07/24/content_42046465.htm) · [诗歌研究](https://www.tibetology.ac.cn/2026-01/20/content_43338672.htm)

## 3. 阿尼哥：随教法远行的工匠

十三世纪，来自尼泊尔的工匠阿尼哥随八思巴进入元朝宫廷，以塑像、铸造等技艺获得重用。他还培养了刘元等匠师。传播佛教的不只有经书和僧人，也有模型、工具，以及师徒之间无法只靠文字传授的手艺。[故宫博物院：阿尼哥](https://www.dpm.org.cn/lemmas/244654.html)

这段故事的主要舞台在西藏与元朝宫廷之间，并不能据此断定他曾在拉萨长期工作。它帮助我们理解拉萨所在的更大文化网络：南亚工艺、藏传佛教与汉地匠作，在流动中彼此改变。

## 4. 河坝林：佛教圣城里的清真寺

拉萨的居民并非都信奉同一种宗教。来自克什米尔以及甘、青、川等地的穆斯林，沿商路迁徙，在城市里经营生计、组成家庭。历史称谓“卡契”与“甲卡契”保存着不同来源的记忆，但语言、信仰、出身和今天的民族身份，不能简单画上等号。

{% hint style="info" %}
**民间传说｜一支箭划出的落脚地**

拉萨流传五世达赖为穆斯林射箭赐地的故事。这个传说表达了人们对安居与接纳的记忆；具体赐地经过仍需档案印证。比传说更可见的是，清真寺、商铺和家庭生活长期构成了圣城的一部分。[河坝林的居民与地方记忆](https://www.xzxw.com/lyrw/2015-03/21/content_1264539.html)
{% endhint %}

## 尾声：历史没有停在旧城

1951年以后，拉萨的政治制度与城市生活经历重大变化；1959年的冲突、达赖赴印度与此后的改革，改变了原有地方权力结构。二十世纪后半叶，宗教文化遗产经历严重破坏，随后逐步修复，宗教活动恢复。公路与铁路又扩展了城市的联系。本册把这一时期作为简短收束，将篇幅主要留给塑造古城的漫长历史。[历史沿革](https://www.xizang.gov.cn/rsxz/lsyg/) · [遗产资料](https://whc.unesco.org/en/list/707/)
