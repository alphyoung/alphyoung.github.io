# 专题　四派与地方势力，一次理清

四大传统是入门框架，藏传佛教还有噶当、觉囊等重要传承。俗称“红、白、花、黄”便于记忆，却不足以解释教义，也不能据僧衣颜色判断所有人的所属。

| 教派 | 形成与传承               | 代表特点            | 与地方势力的关系                                   | 相关寺院          |
| -- | ------------------- | --------------- | ------------------------------------------ | ------------- |
| 宁玛 | 源流追溯吐蕃旧译，后来逐渐形成教派身份 | 旧译经典、大圆满，多种传承并存 | 获不同家族和施主支持；没有长期统一卫藏的单一政权；与五世达赖存在师承交流       | 敏珠林、多吉扎等      |
| 噶举 | 十一世纪玛尔巴等传承，后分多支     | 口传与修持，大手印       | 蔡巴、止贡、帕竹分别连接地方家族；仁蚌巴、藏巴支持部分噶玛噶举网络，不能代表所有支系 | 楚布、止贡、蔡巴      |
| 萨迦 | 1073年建寺，昆氏家族延续传承    | 道果教授与系统学修       | 萨迦班智达、八思巴联系蒙古与元廷，形成重要地方政权                  | 萨迦寺           |
| 格鲁 | 十五世纪宗喀巴及弟子发展        | 戒律、道次第与寺院教育     | 先依靠地方供养，后联系土默特、和硕特；1642年后与甘丹颇章政权紧密结合       | 甘丹、哲蚌、色拉与布达拉宫 |

各派特点仅为入门概括，彼此共享大量佛教经典与修行传统。制度与传承依据：[教派形成研究](https://www.tibetology.ac.cn/2022-05/03/content_41958869.htm) · [教义传统研究](https://www.tibetology.ac.cn/2023-06/05/content_42397557.htm)。

## 政治主线与宗教传承，分开看才清楚

| 地方势力        | 大致时期       | 与拉萨有关的变化               |
| ----------- | ---------- | ---------------------- |
| 拉萨王系及各地王族分支 | 九世纪以后      | 保留王族声望，统一帝国权力已瓦解       |
| 萨迦地方政权      | 十三—十四世纪    | 借蒙古、元朝联系承担地方治理，中心在萨迦   |
| 帕竹          | 十四世纪中叶起    | 山南朗氏家族兴起，改变萨迦优势，发展地方行政 |
| 仁蚌巴、藏巴      | 十五—十七世纪前期  | 后藏势力向拉萨扩展，影响寺院与法会      |
| 甘丹颇章与和硕特汗廷  | 1642年以后    | 五世达赖、政务官员与蒙古汗王形成新的权力安排 |
| 准噶尔控制时期     | 1717—1720年 | 拉藏汗被杀，随后准噶尔被清军驱逐       |
| 清代驻藏机构与噶厦等  | 十八世纪以后     | 驻军、官员、地方政务逐次调整，并非一成不变  |

这张表梳理的是主要变化，不表示前一势力在某一天完全消失、后一势力立即控制全部地方。政权更替也不等于相关教派消失。
