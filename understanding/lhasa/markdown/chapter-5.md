# 第五篇　帝国压力下的拉萨：战争与改革

十九世纪末—1950年

## 1. 高山挡不住新的力量

英国在南亚扩张，试图扩大贸易和政治影响；俄国向中亚推进，又引发英国对印度北面的担忧。拉萨方面一度希望通过北方联系获得支持，但外交期待不等于实际援助。英俄竞争和清廷的应对，共同改变拉萨的处境。[近代俄藏关系研究](https://www.tibetology.ac.cn/2020-07/20/content_41700372.htm)

1904年英属印度军队进入拉萨，迫使地方官员签订条约。十三世达赖此前离开拉萨。军队依靠火力优势推进，藏方遭受严重伤亡，这是一场军事侵入，而非普通的探险访问。[英国国家陆军博物馆：1904年远征](https://collection.nam.ac.uk/detail.php?acc=1968-10-65--50)

## 2. 清朝覆亡，旧制度退出

清末进一步介入西藏事务，1910年前后十三世达赖再次离开。辛亥革命后，清代驻藏体系瓦解，地方政府在相当程度上自行处理内部事务。民国政府持续主张主权，并以使团和机构保持联系，1940年在拉萨设置蒙藏委员会驻藏办事处。[历史沿革](https://www.xizang.gov.cn/rsxz/lsyg/)

这一时期，主权主张、实际行政能力与对外承认并不完全一致，需要分别说明。拉萨也在既有寺院、贵族与官僚网络之中尝试应对新的外部环境。

## 3. 改革为什么比购买新器物难

十三世达赖经历战争和流亡后推动练兵等改革。新技术、军队和教育需要稳定经费、人员培养和社会支持，改革因财政与政治阻力而受到限制。[十三世达赖生平与研究书目](https://en.wikipedia.org/wiki/13th_Dalai_Lama)

1947年印度独立，拉萨南向交往面对新的国家。殖民时代的贸易和机构联系没有一夜消失，而是进入此后的国家间交涉。
