# 第一篇　拉萨之前：从史前聚落到吐蕃逻些

史前时代—九世纪中叶

## 1. 在宫殿以前，先有人们的生活

人类进入青藏高原的历史，远早于拉萨建城。高原东北部夏河的丹尼索瓦人化石至少距今十六万年，藏北尼阿底遗址则留下约四万至三万年前的石器。这些发现说明古人类曾在高原不同地区活动，不能直接算作拉萨本地的定居史。[夏河研究](https://itpcas.cas.cn/new_zhxw/202407/t20240704_7210426.html) · [尼阿底研究](https://ivpp.cas.cn/xwdt/zhxw/201812/t20181205_5207276.html)

回到拉萨北郊，曲贡遗址把本地生活的线索带到约四千年前。陶器、石器与墓葬，让我们看到宫殿和佛寺出现以前，人们已经在河谷中制作器物、安排生活。曲贡是拉萨地区的史前聚落证据，并不意味着八廓老城连续存在了四千年。[曲贡遗址](https://www.zgbk.com/ecph/words?ID=32575\&SiteID=1\&SubID=266742\&Type=bkzyb)

河谷适于耕作，山地提供牧草和其他资源；储存、交换与组织能力的积累，为人口集中创造了条件。城市既需要一条河，也需要能把周围资源汇集起来的社会。

{% hint style="info" %}
**科普｜一片陶片，怎样告诉我们年代？**

考古学家把出土层位、器物特征与科学测年结合起来判断。陶片能说明制作和使用的历史，却不会自动告诉我们居民的民族或政权名称。地区有人生活、形成聚落和出现城市，是三个不同的问题。
{% endhint %}

## 2. 松赞干布把逻些带入政治中心

七世纪，松赞干布推动吐蕃政权整合，逻些成为重要政治中心。西面的象雄、北面的苏毗以及东北的吐谷浑，本来都有自己的社会和权力网络；吐蕃的扩张，就是征服、结盟和吸纳这些力量的过程。雅砻王权由此获得更大范围的人力与资源。[高原早期政治整合](https://www.tibetology.ac.cn/2018-04/24/content_41729542.htm)

拉萨的地位也随之上升。红山上的早期宫堡传统，大昭寺和小昭寺的创建，共同进入城市记忆。不过，今天布达拉宫的主体来自十七世纪以后，不能把眼前整座宫殿都算作松赞干布的建筑。

## 3. 公主、寺院与多条文化来路

641年文成公主入藏，是唐蕃交往的重要事件。藏文传统又把尼泊尔赤尊公主与拉萨建寺相联系。两位公主、两尊佛像和两座寺院的故事，解释了人们如何记忆城市起源；但建寺分工、佛像移奉和赤尊公主的生平细节，在不同材料中有差异。[小昭寺源流研究](https://www.tibetology.ac.cn/2022-05/30/content_41986910.htm)

{% hint style="info" %}
**小故事｜一场婚姻，走过的不只是一位公主**

文成公主来到高原时，婚姻首先承担唐蕃外交的任务。随行人员、礼物和宗教物品，又把宫廷关系变成了更长久的文化联系。后人把许多技术与器物的传入都归于公主，历史写作却需要逐项寻找证据。拉萨的文化，由本地创造与中原、尼泊尔、印度等多方交流共同形成。
{% endhint %}

八世纪，佛教僧团与译经事业进一步发展。山南的桑耶寺是重要节点：拉萨早期佛殿的历史，需要同城外的学习、翻译和组织建设一起阅读。

## 4. 会盟碑背后的大世界

唐朝是吐蕃的重要对手和交往对象，但远方还有回纥、南诏、西域诸势力及南亚王国。结盟与战争改变着道路、征发和贡赋，最终影响逻些的王室决策。周边势力影响拉萨，并不都意味着曾占领这座城。

821—822年唐蕃会盟，823年拉萨立碑纪念。大昭寺前的汉藏双语碑刻，把战争之后的和平约定保留至今。它比后世传说更接近当时双方如何表达关系。[唐蕃长庆会盟](https://www.tibetology.ac.cn/2022-12/18/content_42207877.htm)
