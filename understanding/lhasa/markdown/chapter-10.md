# 附录三　历史地名与名称

| 名称          | 怎么理解                    |
| ----------- | ----------------------- |
| 逻些          | 拉萨的历史汉文译名之一             |
| 吉曲          | 拉萨河；雅鲁藏布江支流             |
| 雅砻          | 山南的河谷，与吐蕃早期王权相关         |
| 卫藏          | 历史地理概念，不能直接套今天行政边界      |
| 八廓          | 大昭寺周围转经路及街区；不同于外围林廓     |
| 雪城          | 布达拉宫山下的历史空间，“雪”为音译      |
| 赞普          | 吐蕃统治者称号，与达赖喇嘛不是同一身份     |
| 甘丹颇章        | 从居所名称发展来的政权称呼，不等于甘丹寺    |
| 甘丹赤巴        | 格鲁派重要教职，不等于达赖喇嘛         |
| 噶厦          | 历史上的地方办事机构              |
| 土默特、和硕特、准噶尔 | 不同时期介入藏事的不同蒙古势力         |
| 廓尔喀         | 本册主要指十八世纪起的尼泊尔沙阿王朝势力    |
| 扎仓、康村       | 大寺院内的教学、地域与生活组织，具体制度有差异 |

## 阅读与来源

关键段落附资料链接，供继续查阅。考古年代、教派形成和建筑修复应分别核对；现代史中的综述链接是阅读入口，涉及争议事件时仍需与专著、档案及不同当事材料交叉使用。老照片入口为牛津大学Tibet Album，遗产边界与登记资料参见联合国教科文组织。

沿着拉萨河读历史，最终看到的是一座不断变化的城市：寺院保存知识，宫殿组织权力，商路带来物资，而居民让这些空间一直有着生活。
