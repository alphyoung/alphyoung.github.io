# 第三篇　三大寺与布达拉宫：拉萨重新成为中心

十五世纪—十七世纪末

## 1. 格鲁：从教学与戒律开始

宗喀巴强调戒律、系统研习与循序修行，吸收噶当等传统，格鲁派由其本人和弟子共同发展。1409年，他在拉萨举办大祈愿法会并创建甘丹寺；弟子分别于1416年、1419年创建哲蚌寺和色拉寺。[宗喀巴与三大寺](https://www.tibetology.ac.cn/2024-01/03/content_42660124.htm)

三大寺汇集各地学僧，形成扎仓、康村等教学与生活组织。大昭寺法会则把僧人、施主和城市服务聚在一起。教育带来长期人口，节庆带来周期人流，宗教网络逐渐改变拉萨规模。

{% hint style="info" %}
**科普｜色拉寺的拍掌，不只是热闹**

辩经通过提问、回应和检验推论展开，拍掌与动作属于辩论形式。看懂一个问题怎样被追问，比只拍下动作更接近寺院生活。扎仓可理解为学院性质的组织，康村则与僧人的地域联系和日常生活相关。
{% endhint %}

## 2. 帕竹、仁蚌巴与藏巴：谁能主持法会

帕竹势力衰弱后，后藏仁蚌巴向前藏扩展，并支持与自己关系密切的噶玛噶举网络。其在拉萨的优势，一度限制哲蚌、色拉僧人参与大祈愿法会。1517年前后局势变化，格鲁派重新获得机会。[法会与地方竞争](https://www.tibetology.ac.cn/2024-03/01/content_42712550.htm)

{% hint style="info" %}
**小故事｜一场法会，也有政治门槛**

大昭寺法会看起来是宗教仪式，谁能参加、谁来主持，却与地方势力有关。失去法会地位，既损害声望，也影响供养和联系。后来格鲁派寻求外部保护，不能只从教义出发理解，还要看到寺院所面对的安全压力。
{% endhint %}

十六世纪后期，藏巴势力在后藏崛起，继而向前藏扩张，与格鲁派及其支持者发生冲突。“藏巴汗”是常见汉文称呼，它是后藏地方政权，不能因名称带“汗”就误认为蒙古汗国。仁蚌巴、藏巴与噶玛噶举的关系，也不代表所有噶举支系始终一致行动。[明代地方政治](https://www.tibetology.ac.cn/2023-03/05/content_42281991.htm)

## 3. 两次蒙古联系，带来不同改变

1578年，土默特俺答汗与索南嘉措会晤，形成“达赖喇嘛”尊号。索南嘉措被定为第三世，前两世为追认。这条线索连接《读懂青城》中的召庙和蒙藏往来。[达赖传承与俺答汗](https://www.tibetology.ac.cn/2022-07/04/content_42023725.htm)

十七世纪，和硕特蒙古固始汗介入高原战争，1642年击败藏巴政权，支持五世达赖建立甘丹颇章政权。此后达赖、第司与汗王共同构成权力格局，拉萨再度成为突出政治中心。[固始汗](https://www.dpm.org.cn/lemmas/239970.html)

土默特与和硕特是不同力量：前者推动北向宗教联系，后者以军事实力重组地方政治。明廷的册封往来、清朝兴起及其蒙古政策，又构成更大的背景。

## 4. 宫殿把新秩序建在红山上

1645年，五世达赖开始大规模营建布达拉宫。红山连接早期王权记忆，宫殿的体量则使新权威成为城市最醒目的标志。山上有居住、政务与宗教空间，山下雪城承担相关行政和服务职能。[布达拉宫历史建筑群](https://whc.unesco.org/en/list/707/)

{% hint style="info" %}
**小故事｜一位赞助者，可以向另一派求学**

五世达赖是格鲁派的重要领袖，却学习过宁玛教法。十七世纪政治斗争激烈，宗教传承仍能跨派流动。这一例子提醒我们：四派不是四个始终互相排斥的阵营，个人师承、寺院利益与政权联盟，要分别看待。[五世达赖的宁玛师承](https://www.tibetology.ac.cn/2022-02/18/content_41881010.htm)
{% endhint %}

1652—1653年五世达赖赴京，与顺治皇帝会面，加强与清廷联系。西南方向又有不丹、拉达克等政权；十七世纪后期的拉达克战争牵动克什米尔方向的莫卧尔力量。拉萨的决策，已同时面向多个方向。[赴京之行](https://www.tibetology.ac.cn/2023-12/02/content_42621168.htm) · [拉达克战争研究](https://www.zangx.com/uploads/ueditor/file/20220601/1654067513.pdf)
