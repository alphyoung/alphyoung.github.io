王权、商业、信仰与移民交织的城市历史

从铁器时代的不列颠人、罗马伦蒂尼恩和盎格鲁—撒克逊七国，到诺曼征服、都铎宗教改革、文艺复兴、远洋贸易和现代多元都市——沿着泰晤士河，读懂伦敦，也读懂它与英国及世界的关系。

## 先把地图看明白

伦敦先有河，后有城。泰晤士河向东通海、向西连接内陆；桥梁、码头和道路把城市的商业核心、政治中心与港区串联起来。伦敦的重心也曾移动：罗马城位于今天的伦敦城，盎格鲁—撒克逊贸易聚落一度向西发展，随后又回到旧城墙内。

读伦敦，先认三个范围：伦敦城（City of London）是面积约一平方英里的古老商业核心；威斯敏斯特汇集王宫、修道院、议会与政府；大伦敦（Greater London）则是1965年形成现代体制的都市行政区。三者相互连接，却不能互相替代。

本册以八篇历史专题沿时间展开，从罗马城、七国与中世纪，写到宗教改革、文艺复兴、海洋扩张、工业都市和现代移民社会，另附历史现场、主要事件时间轴与英国王朝表。第三至第五篇年代重叠，分别从宗教、文化和海洋贸易观察同一时期；十八世纪及1901—1939年仅作简要衔接，本册并非连续、穷尽的伦敦通史。人物故事依据史料改写，传说与史实分别说明。
