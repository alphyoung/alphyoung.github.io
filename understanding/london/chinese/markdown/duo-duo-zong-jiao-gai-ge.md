# 第三篇　都铎宗教改革：婚姻、教会与清教徒

### 王室婚姻怎样改变国家与城市

#### 1. 亨利八世的婚姻危机

亨利八世与第一任妻子阿拉贡的凯瑟琳只有女儿玛丽活到成年。担心没有男性继承人，又爱上安妮·博林后，亨利要求教皇宣布婚姻无效。教皇没有同意；凯瑟琳又是神圣罗马帝国皇帝查理五世的姨母，王室婚姻由此成为欧洲政治问题。

1533年，亨利与安妮结婚，坎特伯雷大主教克兰麦宣布亨利与凯瑟琳的婚姻无效。1534年《至尊法案》确认国王是英格兰教会在尘世的最高领袖，英格兰教会与罗马的制度联系被切断。

亨利共有六次婚姻。他的子女后来依次在位：简·西摩之子爱德华六世（1547—1553年）、凯瑟琳之女玛丽一世（1553—1558年）、安妮之女伊丽莎白一世（1558—1603年）。王位继承、宗教政策与个人婚姻因此紧密交织。

{% hint style="warning" %}
**小故事｜同一座堡垒，两种命运**

1533年，安妮·博林在加冕前以王后身份住进伦敦塔；三年后，她又作为囚犯回到这里，并在塔内被处决。伦敦塔既是宫殿，也是监狱，身份转换有时只隔着一次政治审判。
{% endhint %}

#### 2. 宗教改革不只是一场离婚

亨利与罗马决裂后，英格兰并没有立刻成为后来意义上的新教国家。他仍保留主教制和许多传统教义，但教会的最高司法与财政权力转入王室。爱德华六世时期采用英文《公祷书》，教堂图像和祭坛受到更激进的清理；玛丽一世恢复天主教，并在史密斯菲尔德等地处死拒绝改宗的新教徒；伊丽莎白一世则以1559年《至尊法案》和《教会统一法》重建王权主导的国教体制。

这些反复改变的不只是个人信仰。伦敦人必须学习新的礼拜文本、宣誓方式和节庆秩序；服从哪一种教会，也逐渐成为对君主是否忠诚的政治问题。

#### 3. 修道院消失以后

1536—1540年，英格兰修道院陆续解散，财产归王室后，通过出售或授予等方式大量转给贵族、城市精英等私人所有者。修道院原本还承担医疗、施舍和住宿功能，解散因此改变了伦敦的土地与福利网络。Blackfriars、Whitefriars、Charterhouse等地名，至今保存着已经消失的宗教机构。

基层堂区（parish）并未消失。教堂负责洗礼、婚礼和葬礼，堂区会议又逐渐处理济贫、道路、照明和清洁。后来伦敦的行政区划改革，正是从这张细碎的堂区网络上展开。

#### 4. 玛丽、伊丽莎白与伦敦塔

爱德华六世时期继续推行新教改革；玛丽一世即位后恢复与罗马教廷的关系。1554年，反对玛丽与西班牙王子腓力结婚的怀亚特叛乱失败。玛丽怀疑同父异母的妹妹伊丽莎白参与其中，把她送入伦敦塔。

{% hint style="warning" %}
**小故事｜玛丽一世把妹妹伊丽莎白关进伦敦塔**

伊丽莎白乘船从泰晤士河进入伦敦塔。据后来的记述，她担心自己会像母亲安妮·博林一样死在这里。调查没有找到足以定罪的证据，两个月后她被转移软禁。四年后，伊丽莎白继承姐姐的王位；加冕前，她又按传统住进伦敦塔，这一次身份已从囚犯变成女王。
{% endhint %}

#### 5. 清教徒认为改革还不够（兼及斯图亚特时期的尾声）

伊丽莎白一世重新确立王权治下的新教体制。一批改革者认为国教会仍保留太多天主教礼仪，希望简化服饰、装饰和礼拜，更强调讲道与《圣经》。“清教徒”这一称谓在十六世纪六十年代已经出现，常带有贬义；它并不指主张完全一致的单一教派。

1604年，詹姆斯一世在汉普顿宫召集国教主教与清教徒代表。他拒绝取消主教制，却同意编订新的英文《圣经》，后来形成“钦定版圣经”。到查理一世时期，礼仪、主教权威、征税和议会权利纠缠在一起，宗教冲突最终成为内战的重要背景。
