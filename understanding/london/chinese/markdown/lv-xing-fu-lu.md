| --------- | -------- | -------------------- |

{% hint style="info" %}
**阅读遗址的三个问题**

眼前所见是不是原物？它属于哪个时期？结论依据建筑、考古还是后世传说？伦敦常在同一地点叠加罗马、中世纪和近现代遗存，建筑相邻并不代表年代相同。
{% endhint %}

### 三、英国王朝历史表

王朝是君主所属家族，不等于国家名称。1707年前主要是英格兰王朝史；1707年后为大不列颠，1801年后进入联合王国时期。

| 王朝或时期       |                  年代 | 代表统治者或机构                 | 伦敦线索                  |
| ----------- | ------------------: | -------------------- | --------------------- |
| 晚期盎格鲁—撒克逊与丹麦诸王 |  927—1066，期间与丹麦王朝交替 | 埃塞尔斯坦、忏悔者爱德华、克努特     | 英格兰统一，伦敦和威斯敏斯特地位上升    |
| 诺曼王朝        |           1066—1154 | 威廉一世、亨利一世、斯蒂芬        | 伦敦塔兴建，诺曼统治确立          |
| 金雀花王朝主系     |           1154—1399 | 亨利二世、约翰、爱德华一世        | 普通法、议会、《大宪章》与黑死病      |
| 兰开斯特与约克（金雀花分支） |           1399—1485 | 亨利五世、亨利六世、爱德华四世、理查三世 | 玫瑰战争与伦敦政治支持           |
| 都铎王朝        |           1485—1603 | 亨利八世、玛丽一世、伊丽莎白一世     | 宗教改革、修道院解散与剧场文化       |
| 斯图亚特时期（含奥兰治的威廉三世） | 1603—1649、1660—1714 | 詹姆斯一世、查理一世、查理二世、安妮   | 内战、复辟、大火、光荣革命与1707年联合 |
| 共和与护国时期     |           1649—1660 | 国务会议、奥利弗·克伦威尔        | 君主制一度废除               |
| 汉诺威王朝       |           1714—1901 | 乔治一世、乔治三世、维多利亚       | 宪政君主制、工业化与帝国扩张        |
