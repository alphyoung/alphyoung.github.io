# 第二篇　七国与中世纪：从伦登威克到伦敦塔

### 城市曾经向西移动，又回到城墙之内

罗马时代结束后，盎格鲁人、撒克逊人和朱特人等陆续进入不列颠，与当地居民经历迁徙、战争、通婚与融合。几百年后，才形成今天概括所称的“盎格鲁—撒克逊英格兰”。

#### 1. 七国时代与伦敦

后世把七个主要王国称为“七国”：肯特、萨塞克斯、威塞克斯、埃塞克斯、东盎格利亚、麦西亚和诺森布里亚。它们并非长期整齐并立，七国之外也一直存在较小政权。

| 王国    | 大致位置      | 与伦敦的关系                 |
| ----- | --------- | ---------------------- |
| 埃塞克斯  | 东撒克逊地区    | 早期伦敦通常处于其政治范围，圣保罗成为主教座 |
| 麦西亚   | 英格兰中部     | 八世纪前后多次控制伦敦及其港口        |
| 威塞克斯  | 英格兰南部和西南部 | 阿尔弗雷德于886年前后重建城墙内伦敦    |
| 肯特    | 泰晤士河口以南   | 与伦敦隔河相望，较早接受基督教        |
| 萨塞克斯  | 英格兰南部     | 后来进入威塞克斯势力范围           |
| 东盎格利亚 | 英格兰东部     | 与伦敦共享北海贸易和维京活动网络       |
| 诺森布里亚 | 英格兰北部     | 直接联系较少，是早期英格兰宗教文化重镇    |

#### 2. 伦登威克、维京人与阿尔弗雷德

七至九世纪，新的贸易聚落伦登威克（Lundenwic）在罗马城以西兴起，大致位于今天河岸街和考文特花园一带。_wi&#x63;_&#x610F;为贸易聚落。

维京袭击改变了安全条件。886年前后，威塞克斯国王阿尔弗雷德重新利用罗马城墙，把城市活动移回防御更强的城内，形成伦登堡（Lundenburh）。伦敦先后受埃塞克斯、麦西亚和威塞克斯影响，正说明“七国时代”远比七块固定领土复杂。

{% hint style="warning" %}
**小故事｜克努特命令潮水退去**

传说丹麦国王克努特把王座放在海边，命令潮水停止，潮水却照常上涨。这个故事后来常被误解为国王狂妄；较早版本的意思恰好相反：克努特借此告诉奉承者，君王的权力也有边界。故事未必发生在伦敦，却很适合解释这位北海帝国君主的后世形象。
{% endhint %}

#### 3. 诺曼征服与两座权力中心

1066年，诺曼底公爵威廉征服英格兰，并在威斯敏斯特加冕。随后兴建的伦敦塔既防御外敌，也向市民展示新王权。威斯敏斯特逐渐成为王宫与国家政治中心，伦敦城则依靠商业、行会和自治传统发展。

1215年《大宪章》危机中，伦敦支持反对约翰王的贵族。《大宪章》不是现代民主宪法，却确认了伦敦既有自由，说明国王必须认真对待城市的财富与政治力量。
