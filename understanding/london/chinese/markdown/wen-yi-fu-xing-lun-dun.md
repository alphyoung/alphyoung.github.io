# 第四篇　文艺复兴伦敦：印刷、人文主义与剧场

### 新思想如何变成城市生活

#### 1. 文艺复兴先从书页进入伦敦

十五世纪后期，文艺复兴人文主义推动英格兰重新研读古典文本；当地的拉丁学问原已有悠久传统，印刷术又为文本流通开辟了新途径。威廉·卡克斯顿1476年在威斯敏斯特设立印刷所，英文书籍开始更快、更便宜地传播。圣保罗大教堂周围聚集书商、学校和讲道者，伦敦由此成为思想交流中心。

印刷也使宗教争论更难控制。《圣经》译本、布道文和政治小册子可以迅速复制，王室与教会则以许可、查禁和惩罚回应。文艺复兴与宗教改革并非两条互不相干的线索，它们都依赖文字传播。

#### 2. 托马斯·莫尔的矛盾人生

人文主义者托马斯·莫尔曾任伦敦城副司法官（under-sheriff），后来成为亨利八世的大法官。他在《乌托邦》中想象另一种社会秩序，却也参与迫害宗教异见者。因拒绝承认国王的宗教最高权威，他于1535年被处决。

{% hint style="warning" %}
**小故事｜一个名字留下两种记忆**

莫尔既被纪念为学者和良知人物，也因镇压异见受到批评。他的经历提醒人们：文艺复兴并不天然等于宽容，精通古典学问的人同样生活在残酷的宗教政治中。
{% endhint %}

#### 3. 宫廷文化与城市消费

都铎宫廷从欧洲引入绘画、音乐、建筑和礼仪。小汉斯·霍尔拜因等艺术家为王室和伦敦精英画像，服饰、纹章与室内陈设成为展示身份的工具。与此同时，富裕商人也购买书籍、地图、乐器和进口奢侈品，文化趣味不再只属于王宫。

#### 4. 剧场里的伦敦

十六世纪后期，伦敦人口增长，识字率和商业娱乐也不断发展。公共剧场多建在伦敦城市政权管辖较弱的城外：肖尔迪奇有“剧院”，泰晤士河南岸有玫瑰剧院和环球剧院。莎士比亚的戏剧由商业剧团售票演出，观众从学徒、商人到贵族都有。

{% hint style="info" %}
**现场阅读｜为什么环球剧院在河南岸**

伦敦城当局担心剧场带来拥挤、疾病和治安问题。南岸又聚集酒馆、斗熊场等娱乐设施。剧场选址因此也是行政边界的结果：过一座桥，城市规矩就可能不同。
{% endhint %}
