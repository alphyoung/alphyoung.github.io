# 第四篇　辽金元州县与明代边墙

契丹、女真与蒙古相继在这里建立州县：辽置德州宣德县，金改宣宁县，元沿置宣宁县并把它划入中书省腹里；县城北面的官山，是大汗驻夏、处理军政的地方。明朝则把这里推到大同镇的边墙之外，1571 年的隆庆和议又打开了封贡互市的口子。本篇的转折点，是这里从“由首领代管的边地”变成“王朝直接编户的州县”，随后又因边墙的修筑而重新变成一条边界——**墙先是一条现实分界，把两种秩序分开；随后又在互市与日常往来的侵蚀下，慢慢变成一道地景。**

## 一、辽金元：州县三次改名

辽代，今凉城地区的主要建置是**德州宣德县**，属辽朝西京道。辽圣宗开泰八年（1019 年）设置、恢复相关州县建置，宣德县治一般定位在今凉城县东北的淤泥滩一带——**北宋与辽并立时，这里归辽管，并不归北宋管。**

金朝取代辽朝后撤去德州这一层建置。大定八年（1168 年），宣德县改名**宣宁县**，属西京路大同府，隶属关系为“金朝—西京路—大同府—宣宁县”；**南宋存在时，这里主要由金朝治理**，金末再转入蒙古政权统治。元朝继续设置宣宁县，至元二十五年（1288 年）西京改为**大同路**，宣宁县是大同路直接管辖的县之一。大同路属于中书省直接管理的**腹里**，隶属关系为“元朝—中书省腹里—大同路—宣宁县”——**这一地区不隶属岭北行省。**

**辽 · 德州宣德县 → 金 · 大同府宣宁县 → 元 · 大同路宣宁县**

{% hint style="info" %}
**概念辨析｜“宋代”的凉城，为什么属于辽、金？** “宋代”可以表示一个历史时段，**并不意味着当时所有地区都由宋朝治理**。凉城在这一时段主要先属辽、后属金，之后转入蒙古、元朝统治，并未先后接受北宋和南宋的治理。用宋朝年号去推定这里的管辖归属，是最常见的错位。
{% endhint %}

## 二、向北看：官山与大汗的夏营

辽金元时期的凉城并不是一座孤立的县城。西面的**丰州城**（今呼和浩特赛罕区一带，一般追溯到辽神册五年，即 920 年）与今凉城的德州宣德县、金元宣宁县各有其行政沿革，同处一个商贸与交通的网络之中。而与凉城联系更直接的，是县城北面的一片草原湖群——**官山**。

{% hint style="info" %}
**历史小故事｜窝阔台的夏营：避暑时也在处理军政。** 1231 年，窝阔台避暑于九十九泉；1232 年对金作战告一段落后，又出居庸关、到**官山**驻夏。大汗移到凉爽的草原，军政事务也跟着来到营地，金朝使者曾到这里求见。

官山与凉城的联系藏在一个旧县名里：《金史》把官山列在**宣宁县**之下，而宣宁县治一般认为在今凉城东北的淤泥滩一带。石坚军《辽金元时期九十九泉与官山考论》考证，这处官山即今**辉腾锡勒、灰腾梁**一带的九十九泉，位于今日凉城县域以北；不过官山地望另有他说，尚无定论。**古县的管理范围，曾把湖盆和北面的草原联系起来。** 后来元朝侍卫军还曾到官山驻夏、守卫通道——**大汗的避暑地，同时也是处理政务、接待使者和调动军队的地方。**
{% endhint %}

## 三、明代：从卫所到大同边外地

明代凉城一带与**大同边防**紧密相连。地方沿革材料将这里的早明建置与**宣德卫**相联系：明初，这里的主要治理形式由元代县制转为**军事卫所**，处于明朝大同北部防御体系之中。明朝中期以后防线收缩，岱海一带成为**大同边外地**，主要由蒙古诸部控制；今天县域南缘的边墙和军堡，则与明朝**大同镇**防务相连。因此，**明代凉城不能整体、连续地归入明朝某个府县**：明初的卫所控制与中后期的蒙古部落控制，是两个不同阶段。

岱海南侧的长城遗迹，把这种边地经验留在了地表。王墓山坡下遗址的考古报告甚至以附近明代次边长城作为地理参照：**相距不远的史前聚落与明代边墙，属于相隔数千年的两套生活秩序。** 边墙影响人们从哪里经过，也需要烽燧、堡寨、守军和补给配合——**墙内外的实际接触会随军事形势和政策改变，不能想象成几百年从无往来。**

## 四、隆庆和议与封贡互市

明代中后期，蒙古**土默特部**在丰州滩一带发展，**土默川**之名与之相联系。土默特首领阿勒坦汗（汉文史籍常称**俺答汗**）在这里经营牧业、农业和聚落，推动形成新的政治与商业中心；**库库和屯**，即后来归化城、今天呼和浩特旧城的前身，也在这一过程中兴建。凉城一带并不在明朝辖区之内，而是**土默特部**的驻牧地：牧地由各支台吉分别领有，范围东起宣府边外、西抵黄河，岱海周围正在其中。地方沿革材料据此记为：**万历十年（1582 年），今地属蒙古土默特部政权管辖。**

{% hint style="info" %}
**历史小故事｜一个孙子的出走，打开了议和的门。** 1570 年，俺答汗的孙子**把汉那吉**因家庭纠纷投奔明朝。明朝边臣没有将他处死，而是善加接待；俺答汗最初想用兵索回孙子，得知他受到礼遇后转而与明方谈判。双方交换人员，继而讨论封贡与互市。**1571 年，俺答汗受封顺义王**，隆庆和议促成了边境关系的重要转折。和议使大同、宣府等方向的**封贡互市**有了较稳定的制度安排——对长城沿线及边外居民而言，马匹、牲畜、布帛与生活物资的交换直接关系生计。**这种贸易环境的变化，也构成其明清地方社会发展的背景。**
{% endhint %}
