# 第二篇　史前湖畔与边地初开

凉城有人居住的历史，从岱海周边的台地开始。约六千年前，中原先民北上，在背山面水的山坡上定居；约四千年前，村落开始修筑石墙。此后材料有一个明显的空档，等考古材料重新密集起来，这里已经是一个农牧兼营的接触地带。本篇的转折点，是外部政权第一次取代地形与生计，成为决定这里命运的力量。

## 一、山坡上的第一批村落

今天谈环岱海史前遗址，常会遇到**王墓山、老虎山和园子沟**。它们构成**岱海遗址群**的核心，时间跨度约从距今六千七百年到四千三百年，横跨仰韶文化中晚期与龙山文化早期，**打破了“长城以北没有仰韶文化”的旧认识**。要注意的是：所谓“环湖”，**不意味着所有房屋都建在同一条岸线上，也不意味着这些聚落同时繁盛。**

这批遗址与气候有关。距今约六千七百年至六千年前，这里比今天温暖湿润，**岱海湖面约是今天的四倍**，湖滨台地宜耕宜渔。中原先民分两路北上——一支从华北平原沿永定河、桑干河上溯，一支自晋中汾河、关中渭河沿黄河而来，在岱海南岸的丘陵阴坡落脚。考古学家田广金把这次迁徙称为人类历史上最早的**“走西口”**。

落脚点选在**背山面水的山坡**，而不是紧贴湖岸的滩地：山坡排水好，不易受湖水涨落侵袭，又能俯视湖面与河谷，靠近耕地与渔场。发掘所见房址**成排分布**，居住面经过烧烤硬化，说明定居已相当稳定。**今天看到的“距湖多远”，不等于当年的取水距离。**

## 二、陶器与石墙：从生活用品到公共工程

王墓山一带的发掘，是建立岱海地区仰韶时代文化序列的重要工作。陶器首先是生活用品，**从器形的变化里读出的，是做饭、盛水和搬东西的方式在变。** 出土器物里，**火种炉**格外有地方特色：它兼具保存火种、照明与取暖的功能，在岱海地区成批出现——同期的河南孟津、山西芮城也有出土，但数量远不及这里。**在这片湖岸上，火成了需要用专门器物维系的技术。**

仰韶晚期，湖岸上的人群构成更复杂。一支来自太行山东侧、以**小口双耳罐**为水器的文化，与带来**筒形罐和鱼鳞纹**的红山文化因素先后到达岱海—黄旗海一带，与本地使用**小口尖底瓶**的人群相遇、融合，形成具有鲜明地方特征的**海生不浪文化**——陶器上因此同时可见中原彩陶纹样、东来鱼鳞纹与本地创新的网格纹、涡纹。**文化的相遇不等于人群的替换**：学界更倾向把外来因素解释为技术、器物与纹样的传播，而不是大规模的人口迁徙。

进入龙山时代，**老虎山、园子沟**等地出现新的聚落形态。老虎山遗址依山势修筑，面积约十三万平方米，四周环绕石砌围墙，南北长约三百七十米、东西宽约三百三十米，是迄今发现的我国古代最早、最完整的石墙防护体系之一。**修筑围墙意味着劳动需要协调**：石料从哪里来，谁来搬运，墙线怎样安排，损坏以后由谁维修？不过，从“有公共工程”到“已经建立王国”，中间还需要社会分化、权力结构等方面的证据——**墙证明的是协作，不是王权。**

园子沟是目前国内发现的原始社会时期**窑洞式房屋**遗址中规模最大、保存最完好的一处，已发掘房址八十多座。房屋依山成排，多数前有院落；讲究的房址分前后两室——**前室设灶，后室地面与洞壁抹白灰**。四千年后再看这种格局，它正是中国古建筑“前堂后室”的原型。石城为什么会出现？一种解释指向气候：距今五千五百年前后有一次寒冷期，此后干冷加剧，可耕地收缩，聚落之间的资源竞争随之紧张。

{% hint style="info" %}
**概念辨析｜“老虎山文化”不是国号，也不是民族名。** 考古学文化是研究者归纳的一组具有共同特征、分布于一定时空内的遗存。它既不是古人留下的国号，也不是今天某一民族的古称——把考古学文化直接读成“某个古代民族”，是最常见的越界。
{% endhint %}

## 三、材料空档与文献里的鬼方、猃狁

从距今约四千年到公元前五世纪，本地可依据的考古材料明显变少：一般认为，距今四千三百年前后的一次干冷事件使岱海水系萎缩，石城聚落陆续废弃，部分人群沿河谷南迁。**材料少，不能推出“这里一度无人”，也不能反过来凭空补上一段生活。**

但史书没有完全沉默。地方沿革通常把夏、商、周时期这一带记作**鬼方**等北方人群的活动范围，并列出**猃狁、林胡、北狄**等名称。**要分清的是：这些是文献与后世志书留下的记载，不是从岱海边的地层里挖出来的证据。** 相关战事多发生在今陕北、晋北与河套一带，与凉城的方位大致相接，但文献给出的方位并不精确。还有一层要留意：鬼方、猃狁是中原文献从外部给出的称呼，未必是这些人群的自称，也未必始终指同一个群体——**它们提供的是一个方位和一段时间，而不是一份边界清晰的名单。**

## 四、毛庆沟与农牧兼营

等考古材料重新密集出现时，这里已经是一个农牧兼营的接触地带。东周时期的凉城留下了**毛庆沟、饮牛沟**等墓地，出土的装饰品、兵器、马具和陶器显示当地人的物质生活已与史前石城聚落不同。更有意味的是墓葬之间的差别：**朝向、葬具和随葬物组合并不完全一致**，有研究据此讨论不同来源居民的相处。人的生计也未必属于单一类型：有关内蒙古中南部古代居民的研究把这些材料放在**农牧兼营**的背景中讨论——**种植、饲养与狩猎可以共同构成生计，不必把每个人分进“只种地”或“只放牧”的格子。**

## 五、赵武灵王北进与秦汉边城

赵国北进之前，晋北与河套周边已有**林胡、楼烦**等人群活动。《史记》将他们记在赵武灵王北向扩展的历史中。**这些名称代表当时的部落或人群，并不意味着今天的凉城县境曾完整属于一个边界固定的“林胡国”或“楼烦国”。**

战国时期，赵国向北扩展，赵武灵王推行**胡服骑射**——“胡服骑射”常被讲成一次换装；对国家而言，更深的变化是训练人员、取得马匹、适应骑乘作战。《史记》记载他北破林胡、楼烦，设置**云中、雁门、代郡**，并沿北部边地筑长城。**云中郡**与今天呼和浩特周边联系密切，今凉城一带的地方沿革则主要指向**雁门郡**——同属赵国的北方经营，却不是同一个郡。

秦统一后，这一带属秦朝雁门郡。**当时尚无今天的凉城县，郡的辖境跨越了今天内蒙古与山西的省界。** 西汉初年，这一带曾纳入汉朝分封的代国；岱海南岸的**沃阳县**属雁门郡。东汉时雁门郡隶并州，《后汉书》所列辖县包括**疆阴**，已不见沃阳。边城不是孤立的军营：**守城需要粮食，马匹需要草料，器械需要制造维修，人员需要沿道路往来**——一处边城的背后，是一整片地方的生产与运输。

**历史小故事｜白登七日与卫青取河南地。** 公元前 200 年，汉高祖刘邦北征，在平城附近的白登被冒顿单于的骑兵围困七日，最终得以脱身；白登在今天大同一带，位于凉城东南。这场遭遇使汉朝认识到北方战争的困难，随后以和亲等方式缓和汉匈关系。到武帝时期，卫青在公元前 127 年的河南地之战，与随后朔方地区的设郡、筑城和徙民密切相关——**迁入的家庭必须建屋、开田、承担赋役，才能使军事占领转化为较持久的地方经营。** 边地可能发生战争，也可能出现贸易、归附与人员迁居：**政治边界的变化和居民生活的变化，有时并不同步。**
