# 第一篇　湖盆、山口与边墙：地理底座

凉城的全部历史都发生在同一片地形里：一个山地环抱的湖盆。在进入编年之前，先把三件事说清楚——这片湖盆在阴山格局中的位置、“凉城”这个名字的千年旅程，以及岱海本身。

## 一、一座湖盆，几个方向

凉城县位于内蒙古乌兰察布市南部，与山西北部相邻。中央是岱海及周围盆地，外围是山地与沟谷，道路将这里与晋北、呼和浩特和乌兰察布其他地区连接起来。湖盆为聚落提供水土条件；山地影响耕地分布、放牧空间和出行方向；道路则使本地人的生活与更远的市场和政权相连。

凉城的历史地位随周边中心的变化而改变：**大同强盛时，这里与大同腹地的联系突出；归绥和集宁的重要性上升后，凉城与这些城市的联系也更加紧密。** 同一片湖盆，在不同时代被不同方向“拉”进不同的世界。

## 二、山与路：阴山、蛮汉山与山口

凉城的山川属于更大的阴山地理格局。阴山横亘内蒙古中部，由多段山地构成；凉城西北的**蛮汉山**是其支脉，山地西北面向土默特平原，东南面向岱海盆地。县境北部的蛮汉山、南部的**马头山**与中部的**岱海**，构成山地环抱湖盆的地形。

阴山南北的水热条件、植被和生产方式存在差异，山地又有沟谷可供通行，这使它既影响农业与牧业的分布，也影响军队行进、人员迁徙和贸易路线。**湖盆中的种植、山坡上的放牧以及山间道路上的往来，可以同时存在。** 从赵、秦汉的北方经营，到北魏的边防，再到明代大同镇的边墙，山口、水源和能够供给粮草的地方，反复成为争夺与经营的对象——**阴山并没有几千年不变的政治边界。**

{% hint style="info" %}
**疆域 · 别把相邻当成同一** —— “敕勒川，阴山下”所指的原野，通常与今天呼和浩特、土默川及大青山南麓相联系；岱海盆地则在山地另一侧，是一个封闭湖盆。两者相邻而不重合。云中川、敕勒川、白道川、丰州滩、土默川这几个名字，有的来自郡城，有的来自部落，有的来自交通孔道，**范围并不完全重合，也不是一个县依次换了五次名字。**
{% endhint %}

## 三、一个名字的千年旅行

凉城县旧称**宁远**，其名称的历史源头可以追溯到北魏**凉城郡**，古籍中也写作**梁城郡**。“凉城”作为现代县名确立于 1914 年：民国初年的宁远县因与湖南、辽宁等地的宁远县重名，采用北魏旧郡名，更名凉城县。**古老的郡名重新成为地方名称，但北魏郡域与现代县域并不相同。**《水经注》保存的说法是：湖西已有一座俗称凉城的旧城，郡名取自这座城。可以确定的是，**这个名称早于清代，并非始自康熙年间。**

县治的位置也换过。**田家镇**是旧县治所在，与今天的永兴镇相联系；**新堂**则与后来县城的发展相联系——这条线索会在第五篇收尾。

{% hint style="warning" %}
**地方传说与可考史实要分开看。** 岱海一带流传着把湖泊与康熙巡边联系起来的故事：相传皇帝喜爱这里的凉爽与水色，兴建行宫，为湖题名“天池”，又留下“凉城”的名字。但赐名、题字与行宫的具体情节，目前缺少可确证的同时代材料。
{% endhint %}

## 四、岱海：一片湖的名字，与它的水位

岱海所在的湖盆是一个狭长的陷落盆地：北有蛮汉山，南有马头山，水汇在中间的低处。地质研究认为，这一带在较早的地质时期气候湿润，湖面高于现在，湖水曾沿河道外流；后来气候转干、来水减少，岱海便成为一个依靠周围二十多条河流与地下水补给的内陆湖。**这片水从来不是静止的：它的形状与大小，取决于来水与蒸发之间的长期平衡。** 史前大暖期里它曾大幅扩张，距今约六千七百至六千年前的湖面约为今天的四倍。

湖在不同时代留下过不同的名字。《汉书·地理志》雁门郡下已记**“盐泽”**；北魏郦道元《水经注》承《汉志》记**盐池**，并写“沃水又东北流注盐池，池北七里即凉城郡治”——沃水就是今天从西南流入岱海的弓坝河。北魏在这里设县，县名**旋鸿**，据说取自湖上的水鸟。辽金元时期湖名随王朝更迭而变（辽“奄遏下水”、金“昂阿下水”、元“下水”），金代还设了以湖为名的**下水镇**。清代，蒙古语名称进入官方文书，写作**岱噶淖尔**等，光绪初年才固定为今天的**岱海**。**名字换了几次，湖作为这片山地与草原之间最重要水源的身份却没有换。**

湖也是资源。水、草、鱼和湖边的滩地支撑过牧群、渔船与农田；湖一变小，靠它生活的人就得跟着调整。二十世纪后半叶以来，岱海明显萎缩——这一段留到第六篇展开。
