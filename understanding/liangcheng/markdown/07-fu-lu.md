# 附录　常见误解、概念与历代归属

读凉城史最容易踩的坑，大多来自三种习惯：把现代的县界当成古代的边界，把相邻的地方当成同一块地方，把地方传说当成可考的史实。下面三节分别用来澄清误解、解释概念、查对历代归属。

## 一、常见误解

<details>

<summary>凉城自古以来就叫“凉城”？这个名字是康熙赐的？</summary>

不是。这个名字来自北魏凉城郡（亦作梁城郡），此后长期中断；这片地方在清代与民国初年叫宁远。1914 年，宁远县因与湖南、辽宁等地的宁远县重名，才采用北魏旧郡名更名凉城县。地方传说把赐名、题字与兴建行宫都系于康熙巡边，但缺少可确证的同时代材料——名称在北魏已经存在，明显早于清代。

</details>

<details>

<summary>北魏的凉城郡就是今天的凉城县？</summary>

不是。北魏凉城郡隶恒州，郡治在岱海北侧，相关县份有参合、旋鸿等；今县南部还涉及善无郡辖地。古郡是现代县名的来源，不是同一个行政实体。

</details>

<details>

<summary>参合陂之战就发生在岱海边上？</summary>

尚无定论。395 年拓跋珪在参合陂击败后燕军队确有其事，但参合陂的地望存在争议，既有岱海说，也有黄旗海说等解释。这场战役经常进入凉城的地方叙事，但地理对应关系并未确定。

</details>

<details>

<summary>“敕勒川”就是岱海盆地？那几个“川”名是一个地方换了五次名字？</summary>

不是。“敕勒川，阴山下”通常与今天呼和浩特、土默川及大青山南麓联系，而岱海盆地在山地另一侧，两者相邻、由山间道路相连，但各有自己的地形与地方历史。云中川、敕勒川、白道川、丰州滩、土默川这几个名字，有的来自郡城，有的来自部落，有的来自交通孔道，范围并不完全重合，出现时间也各不相同——把它们排成“一个县的历代曾用名”，会遮蔽掉不同区域同时并存的事实。

</details>

<details>

<summary>环岱海的王墓山、老虎山、园子沟是同一时期的一串村落？</summary>

不是。它们分属新石器时代的不同阶段：王墓山属仰韶文化中晚期，距今约六千年；老虎山、园子沟属龙山文化早期，距今约四千五百年至四千三百年。“环湖”并不意味着所有房屋都建在同一条岸线上，也不意味着这些聚落同时繁盛。

</details>

<details>

<summary>老虎山修了城墙，说明当时已经建立了国家？</summary>

不能这样直接推论。修筑石墙说明劳动需要协调，使人看见超出单户家庭的组织能力；苏秉琦曾据石砌城墙、祭祀台、白灰敷壁与规整火塘，判断当时已迈入“古国文明”阶段，这是对这批遗存时代高度的一种评价。但从“有公共工程”到“已经建立王国”，中间还需要社会分化、权力结构等方面的证据。墙证明的是协作，不是王权。

</details>

<details>

<summary>岱海周围的居民不是种地的就是放牧的？</summary>

过于简单。毛庆沟、饮牛沟等墓地的材料显示，种植、饲养与狩猎可以共同构成生计，被放在“农牧兼营”的背景中讨论。这一带的接触早已发生，不必把每个人分进“只种地”或“只放牧”的格子。

</details>

<details>

<summary>林胡、楼烦是边界固定的“国”，凉城曾完整属于其中一个？</summary>

不是。林胡、楼烦是先秦北方人群与部落的名称，与赵国北进有关，但并不意味着今天的凉城县境曾完整属于一个边界固定的“林胡国”或“楼烦国”。类似地，也不能仅凭一把短剑或一副马具，就确定某处墓地居民如何称呼自己。

</details>

<details>

<summary>宋代的凉城由宋朝管辖？</summary>

不是。“宋代”可以表示一个历史时段，并不意味着当时所有地区都由宋朝治理。凉城在这一时段主要先属辽、后属金，之后转入蒙古、元朝统治，并未先后接受北宋和南宋的治理。用宋朝年号推定这里的管辖归属，是最常见的错位。

</details>

<details>

<summary>明代凉城一直属于明朝的某个府县？</summary>

不成立。明初这里由元代县制转为军事卫所，处于大同北部防御体系之中；明中期以后防线收缩，岱海一带成为“大同边外地”，主要由蒙古诸部控制，16 世纪中叶起为俺答汗统领的土默特部的驻牧地。这两个阶段不能整体、连续地归入明朝某一府县。

</details>

<details>

<summary>凉城在清代属于乌兰察布盟吗？</summary>

不属任何盟。清代的蒙古旗分两类：外藩蒙古设世袭扎萨克、编入盟，凉城以北的四子部落旗即属乌兰察布盟；内属蒙古则由朝廷任命总管管理、不设盟，凉城所在的察哈尔八旗正属后者。境内的蒙旗事务归察哈尔都统（1761 年起驻张家口）系统，汉民的钱粮词讼则归山西省宁远厅，即所谓“旗厅并存、蒙汉分治”。今天凉城属乌兰察布市，是 1958 年划归乌兰察布盟、2003 年撤盟设市的结果，与清代盟制没有继承关系。

</details>

<details>

<summary>长城内外几百年从无往来？</summary>

不是。边墙影响人们从哪里经过，也需要烽燧、堡寨、守军和补给配合；但墙内外的实际接触会随军事形势和政策改变。隆庆和议后的封贡互市即为一例——马匹、牲畜、布帛与生活物资的交换，直接关系沿线及边外居民的生计。

</details>

<details>

<summary>田家镇一直是凉城的县城？凉城在民国属于哪个省？</summary>

田家镇（今永兴镇）是宁远厅、宁远县与早期凉城县的治所；据地方沿革记载，1937 年沦陷后县政府驻地迁驻新堂，1948 年新堂解放——县名延续，行政中心的位置却发生过转移。

民国时期凉城先后属于两个省，而且是先察哈尔、后绥远：1914 年 6 月，凉城与丰镇、兴和、陶林四县一起由绥远特别区划归察哈尔特别区（察哈尔省前身），属兴和道；1928 年 9 月特别区改置为省、兴和道裁撤，凉城划归绥远省，直到 1954 年绥远省撤销并入内蒙古自治区。

</details>

<details>

<summary>岱海萎缩只是气候变化造成的自然现象？</summary>

不全是。20 世纪 50 年代以来湖面明显萎缩，是自然气候变化与人为因素共同影响的结果：降水与流域来水提供补给，蒸发消耗水量，而灌溉、工业取用与地下水变化同样参与其中。正因为存在人为的部分，退耕还水、水改旱与工业用水调整才成为可能。

</details>

## 二、关键概念

| 概念        | 含义                                              | 常见误解                           |
| --------- | ----------------------------------------------- | ------------------------------ |
| 岱海遗址群     | 环岱海的新石器时代遗址，以王墓山、老虎山、园子沟为代表，涵盖仰韶中晚期至龙山早期        | 误以为各遗址属于同一时期，或把“老虎山文化”当成某个古代民族 |
| 凉城郡       | 北魏设置的郡，隶恒州，郡治在岱海北侧；古籍亦作梁城郡                      | 误以为就是今天的凉城县，或以为县名自古连续          |
| 宁远        | 清代宁远厅、民国宁远县的名称，1914 年改为凉城县                      | 误与湖南、辽宁等地的宁远混为一谈               |
| 察哈尔特别区    | 1914 年设立的省级建置，1928 年改置为察哈尔省；凉城当时属其下的兴和道         | 误与清代察哈尔八旗混为一谈，或误以为它与绥远省是同一体系   |
| 内属蒙古      | 清代直接由朝廷任命总管管理的蒙古旗，察哈尔八旗属之；不设盟，也不设世袭扎萨克          | 误以为它们与北面的乌兰察布盟同属一套盟旗体系         |
| 旗与厅       | 清代在内蒙古中南部并行的两套管理安排，蒙旗与民政分掌不同人口与事务，俗称“旗厅并存、蒙汉分治” | 误以为两者职权完全分离、互不相干               |
| 卫所        | 明代以军事编制管理地方的形式，隶于都司、镇等体系                        | 误当作普通府县，忽略其军事性质                |
| 羁縻府州      | 唐朝授予地方首领官职、通过其管理部众的间接治理方式                       | 误以为与内地州县同样是直接派官管理              |
| 边外地       | 明中期以后长城以北、由蒙古诸部控制的地带                            | 误以为边墙两侧长期隔绝、从无往来               |
| 考古学文化     | 研究者归纳的一组具有共同特征、分布于一定时空内的遗存                      | 误读成古代国号或现代民族的古称                |
| 农牧兼营      | 种植、饲养与狩猎共同构成生计的经济形态                             | 误用“农耕 vs 游牧”的二分去套每个居民          |
| 敕勒川 · 土默川 | 与今呼和浩特、大青山南麓相联系的历史区域名                           | 误等同于岱海盆地，或误当作一个县的历代曾用名         |

## 三、历代归属总览

今天的凉城县在 1914 年定名，古代各郡县的边界与现代县界不同；同一时期，今县境也可能分属不同单位。本表用于查对，不用于推演。

| 时期          | 管辖政权或实际控制者              | 主要行政隶属与变化                                    |
| ----------- | ----------------------- | -------------------------------------------- |
| 新石器时代       | 本地聚落人群                  | 岱海遗址群（王墓山、老虎山、园子沟等）见证仰韶至龙山时代；尚无王朝行政单位可考      |
| 夏、商、西周至春秋   | 本地人群及其组织                | 尚无足够证据落实到某个王朝直属行政单位                          |
| 战国后期        | 赵国                      | 地方志记为赵国雁门郡地                                  |
| 秦           | 秦朝                      | 雁门郡                                          |
| 西汉          | 汉朝                      | 初年曾属分封的代国；主要涉及雁门郡沃阳等县                        |
| 东汉          | 汉朝，末期控制衰退               | 与并州所辖雁门郡相关；《后汉书》所列郡辖县包括疆阴，已不见沃阳              |
| 三国          | 鲜卑等部落首领                 | 拓跋鲜卑势力逐渐发展，不能确认为曹魏稳定直辖县地                     |
| 西晋          | 地方部族首领，与晋朝存在归附、册封关系     | 拓跋等首领组织部众，出土晋朝官印反映政治联系                       |
| 东晋十六国       | 拓跋代政权，后受前秦支配，再转入北魏      | 376 年前秦灭代；386 年拓跋珪复国并改号魏，不属南方东晋直接管辖         |
| 北魏          | 北魏                      | 恒州—凉城郡相关县地；今县南部还涉及善无郡                        |
| 东魏、北齐、北周    | 北朝边境政权与北方力量交错           | 旧郡县废置调整，相关地区有紫阿镇记载；全县连续、统一的隶属尚不能确定           |
| 隋           | 隋朝                      | 马邑郡；隋末突厥势力介入                                 |
| 唐           | 唐朝羁縻体系，控制范围随时期变化        | 主要隶属线索为单于都护府—桑乾都督府，机构后来有迁治                   |
| 唐末、五代       | 契丹势力逐步扩展                | 逐渐转入辽朝统治，具体交接过程缺少完整地方记录                      |
| 辽（与北宋并立）    | 辽朝                      | 西京道—德州—宣德县，不属北宋                              |
| 金（与南宋并立）    | 金朝，金末转入蒙古统治             | 西京路—大同府—宣宁县；1168 年由宣德县改名                     |
| 元           | 元朝                      | 中书省腹里—大同路—宣宁县，不属岭北行省                         |
| 明初          | 明朝                      | 大同北部军事卫所体系，地方沿革记有宣德卫                         |
| 明中后期        | 岱海一带为蒙古土默特部的驻牧地         | 成为大同边外地，地方沿革记万历十年（1582）属蒙古土默特政权；今县域南缘边墙与明朝大同镇防务相连 |
| 清           | 清朝，蒙旗与民政机构并存（旗厅并存、蒙汉分治） | 蒙旗为察哈尔镶红、镶蓝旗（沿革另记正红旗），属内属蒙古、不设盟，归察哈尔都统系统；民政由宁朔卫、怀远所演变为宁远厅，清末属山西省归绥道 |
| 1912 — 1914 | 中华民国政府                  | 宁远厅改宁远县，属山西归绥道，随后随绥东各县改属绥远特别区                |
| 1914 — 1928 | 中华民国政府                  | 改名凉城县；察哈尔特别区（察哈尔省前身）—兴和道—凉城县                  |
| 1928 — 1937 | 中华民国政府                  | 察哈尔特别区改置为省、兴和道裁撤，划归绥远省—凉城县                   |
| 1937 — 1945 | 日伪占领政权与抗日力量分区控制         | 占领区后来纳入伪蒙疆巴彦塔拉盟体系；山区有抗日根据地                   |
| 1945 — 1948 | 国共双方争夺，控制范围反复变化         | 国民政府区划属绥远省；中共县政权隶绥南专署；1948 年后中共县政权在全县确立       |
| 1949 — 1954 | 中华人民共和国                 | 绥远省—和林专区，1950 年转入集宁专区                        |
| 1954 — 1958 | 中华人民共和国                 | 内蒙古自治区—平地泉行政区—凉城县                            |
| 1958 — 2003 | 中华人民共和国                 | 内蒙古自治区—乌兰察布盟—凉城县                              |
| 2003 年以后    | 中华人民共和国                 | 内蒙古自治区—乌兰察布市—凉城县                              |
