# 第三篇　拓跋、北魏与隋唐边地

中原郡县的北边控制衰退时，草原上的整合已经先行一步。二世纪中叶，鲜卑首领檀石槐把各部编成东、中、西三部，其中的拓跋部向西南移动，落脚在参合陂一带——这正是今天岱海的东北。此后代国建立，北魏设凉城郡、隶恒州，郡治就在岱海北侧，“凉城”这个名字由此出现。本篇的转折点，是本地治理方式的反转：此前是朝廷派官、设县、定籍，此后先由部落首领组织部众，再由一个以草原为根基的王朝重新设郡编户；等隋唐重来时，帝国要的又变成了名义上的臣属与边境的安定。

## 一、檀石槐与三部鲜卑

东汉初年，**乌桓**与**鲜卑**同出被匈奴击破的东胡，长期役属于匈奴；公元 91 年北匈奴西迁之后，鲜卑进据漠北，成为草原上最主要的力量。**“匈奴之后”的草原并没有空下来，只是换了一批组织者。**

二世纪中叶，鲜卑首领**檀石槐**把各部整合起来，立庭于弹汗山，分其地为东、中、西三部，各置大人统领。《后汉书》记他“南抄缘边，北拒丁零，东却夫馀，西击乌孙，尽据匈奴故地”，并特别写到他“网罗山川水泽盐池”。**“盐池”正是岱海在北魏以前的称呼之一：对游牧政权来说，水泽与盐池是必须掌握的资源，而不是风景。** 在这一格局里，鲜卑的西部长驱西南，其中一支——**拓跋部**——越过阴山，落脚到参合陂一带。**换句话说，后来在这里设凉城郡、留下“凉城”之名的那个政权，最初是以草原部众的身份走进这片湖盆的。** 檀石槐死后三部解体；三世纪前期**轲比能**一度再统一漠南鲜卑，235 年被刺杀，联盟随之解散——**草原上的整合与解体反复交替，没有哪一次是永久的。**

西晋时期，拓跋部首领受晋朝册封，拓跋猗卢被封为代公、代王，代国由此建立。**1956 年，凉城县西北的小坝子滩窖藏出土“晋鲜卑归义侯”金印**，正是这类政治关系的实物：朝廷授名号、给印绶，**部众仍由首领自己组织**——这套办法后来被隋唐的羁縻府州沿用。339 年，代王**拓跋什翼犍**在参合陂会集诸部落首领；371 年，**拓跋珪**出生在参合陂以北。**这片湖盆于是成了拓跋部从草原走近平城之前最重要的一处落脚地。**

## 二、北魏设凉城郡：一个郡名进入史册

东汉末至三国，汉朝原有的北边郡县控制衰退，今凉城一带主要由部落首领组织部众，**曹魏稳定的县级直辖关系尚难确证**；地方首领与西晋之间有受封、归附与军事合作，但**部众仍由首领自己统领，并不等同于朝廷派官管理。** 376 年前秦灭代，代国故地一度受前秦支配；386 年**拓跋珪**重建代国，随后改国号为魏，**北魏**兴起。

拓跋鲜卑及北魏的兴起，深刻影响了内蒙古中南部与晋北地区。**盛乐**所在的和林格尔一带与**平城**所在的大同地区，是这一时期的重要政治中心，凉城与岱海处在它们周边的山川和交通网络之中。北魏设**凉城郡**，隶恒州，郡治在岱海北侧，相关县份有**参合、旋鸿**等；今县南部还涉及**善无郡**辖地，说明**今天的凉城县域并不完全等于当年的凉城郡。** 政治中心从草原边缘向平城发展，意味着统治者需要同时处理牧业资源、农业人口和更大规模的行政事务；**鲜卑也不是一个始终由同一君主统率的整体**——拓跋部、慕容部等拥有不同的政治经历。

北魏末年，凉城郡原有建置在动乱中废置。东魏、北齐至北周时期，这一带处在北朝政权与北方力量接触的边境，郡县和军事据点不断调整。《辽史》追述相关地区曾有北齐设置的**紫阿镇**，但对其具体位置和辖境的记载不足，**无法据此确定今天全县在这一时期始终由同一个机构管辖。**

## 三、参合陂之战：一场地望未定的胜仗

**395 年，拓跋珪领导的北魏军队在参合陂击败后燕军队。** 这场战争是北魏崛起的重要事件，因此经常进入凉城的地方历史叙事。

但是，**参合陂的具体位置存在争议**，主要有三说：一说即今岱海（《辞海》《中国历史地图集》采此说）；一说为今黄旗海东岸一带；《大清一统志》则主张在山西阳高。此外《水经注》把战场系于参合陉（今岱海西南一带）。因此，**这场战役与今日岱海之间的地理对应关系尚无定论。** 地方叙事里最响亮的故事，恰恰是地望最不确定的一个。

## 四、敕勒迁徙与《敕勒歌》

**敕勒**与史书中的**高车**诸部关系密切。429 年，北魏太武帝拓跋焘出击柔然，随后又遣军招降、征服东部高车，**将大量部众迁置漠南**。《魏书》描述他们迁居后继续畜牧，逐渐增加谷物食用与农业生活，向北魏贡献牲畜、毡皮等物资。**史籍的迁置范围很广，不能缩成“十余万人同年全部搬到敕勒川”。** 敕勒川的名字与敕勒人群在阴山南麓的活动、居住相联系；这里既有牧群和毡帐，也有战争造成的强制迁徙，以及迁来者重新安排生活的经历。

{% hint style="info" %}
**历史小故事｜斛律金的一曲乡音。** 546 年，东魏权臣高欢进攻西魏玉壁城，久攻不克，损失严重，自己也病倒了。退兵之后，为回应关于他受伤的传言，高欢勉强坐起会见众人，让敕勒出身的将领**斛律金**唱起《敕勒歌》，自己也跟着和唱，感伤落泪。

今天人们常用《敕勒歌》赞美草原。把它放回这段历史，**歌中还有失意者对家园的惦念**：穹庐般的天空、开阔的原野与牛羊，是离乡将士心中熟悉的生活。斛律金的唱歌经历也不等于他独自创作了今天所见的全部诗句；歌谣经过传唱、转译和记录，才成为流传至今的文学作品。
{% endhint %}

## 五、隋唐：马邑郡与羁縻府州

隋朝统一后，今凉城地区属**马邑郡**辖境，治所在今天山西朔州一带。**这是北朝末年郡县废置之后，本地第一次重新被登记进一个统一王朝的行政体系。** 但这段“复位”很短：六世纪中叶**突厥**兴起，击败柔然，建立起从漠北延伸到西域的汗国，此后分裂为东、西两部。隋末天下大乱，东突厥一度控制了阴山南北的许多城塞与部众，地方记录也把这一时期记作**突厥部众的居住地**。**一个由中原王朝设郡的时代，就这样被草原政权的扩张打断。** 这一时期的本地记录并不多——**材料少，不等于当时无人居住或没有管理，只是它留下的文字痕迹比前后的时代更稀薄。**

唐朝击败东突厥、安置归附部众之后，在北方设置了**羁縻府州**。地方志将今凉城地区列入**桑乾都督府**的管辖范围；《新唐书》记载桑乾都督府隶**单于都护府**。羁縻府州由唐朝授予地方首领官职，通过他们管理部众，**和内地普通州县的治理方式不同**——同样是“属于唐朝”，这里并没有像内地那样编户齐民、层层派官。桑乾都督府后来还有迁治，因而这条隶属关系只适用于相应的阶段，**并不代表唐朝近三百年间的实际控制始终不变。**

{% hint style="info" %}
**历史小故事｜会师白道：一条山路改变战局。** 630 年，**李靖**率精骑从马邑出发，夜袭定襄；**李世勣**则在**白道**击败东突厥军，随后两军会合，颉利可汗的统治终于瓦解。白道是呼和浩特北面穿越大青山的重要通道，这场战事并非发生在凉城县城。它说明，**谁控制了山间孔道，谁就更容易截断对手退路，把平原上的胜利推进到山北。**
{% endhint %}

突厥之后草原上又换过几批主人：**薛延陀**一度取代东突厥的位置，八世纪中叶以后**回鹘**兴起并与唐朝长期维持和亲与绢马贸易，九世纪中叶回鹘汗国崩溃后部众四散南下。**对边地居民来说，“草原上换了谁做主”直接影响互市的商品、道路的安全和草场的使用，而不是一个遥远的国号。** 唐末至五代，唐朝北方的统治体系衰退，**沙陀**出身的李克用家族在代北、山西崛起，**契丹**也向西南扩展——周边经历的是交错的政治变化，**不是整片区域在同一天由沙陀统一移交给契丹**。羁縻的时代到此结束。
