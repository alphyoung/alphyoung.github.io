# 05 阶段四·隋唐边地

北朝结束以后，中原帝国重新管到这里，但方式和内地不一样。隋把今凉城一带编入马邑郡，这是郡县体系在北朝末年废置后的第一次复位；唐朝在击败东突厥、安置归附部众之后设置羁縻府州，将这里列入桑乾都督府，隶单于都护府——官职授给地方首领，部众仍由首领组织。

这一阶段的转折点，是帝国要的东西变了：它要的是名义上的臣属与边境的安定，而不是把每家每户编成州县编户。唐末五代契丹西进，这一格局随之结束。

## 4.1 隋的马邑郡：统一王朝的短暂复位

_6 世纪末 — 7 世纪初_

隋朝统一后，今凉城地区属**马邑郡**辖境。马邑郡的治所在今天山西朔州一带，辖境向北延伸，包含今凉城、丰镇等地区。**这是北朝末年郡县废置之后，本地第一次重新被登记进一个统一王朝的行政体系。**

但这段“复位”很短。六世纪中叶，**突厥**兴起，击败柔然，建立起从漠北延伸到西域的汗国；此后突厥分裂为东、西两部，与中原关系最密切的是漠南的**东突厥**。隋末天下大乱，东突厥一度控制了阴山南北的许多城塞与部众，地方记录也把这一时期记作**突厥部众的居住地**。唐朝立国后转入反击，边地的归属随之重新洗牌。**一个由中原王朝设郡的时代，就这样被草原政权的扩张打断。**

还有一点需要说明：这一时期留下的本地记录并不多。我们能确定的是隶属关系的大致框架，至于县一级的治所、辖境和具体运作，材料还不足以落实。\*\*材料少，不等于当时无人居住或没有管理，只是它留下的文字痕迹比前后的时代更稀薄。\*\*这也是本阶段章节较少的原因。

## 4.2 唐朝的羁縻：桑乾都督府与白道之战

_7 — 10 世纪初_

唐朝击败东突厥、安置归附部众之后，在北方设置了**羁縻府州**。地方志将今凉城地区列入**桑乾都督府**的管辖范围；《新唐书》记载桑乾都督府隶**单于都护府**。主要隶属线索为“唐朝—单于都护府—桑乾都督府”。

羁縻府州由唐朝授予地方首领官职，通过他们管理部众，**和内地普通州县的治理方式不同**。这一点对理解凉城很重要：同样是“属于唐朝”，这里并没有像内地那样编户齐民、层层派官。桑乾都督府后来还有迁治，因而这条隶属关系只适用于相应的阶段，**并不代表唐朝近三百年间的实际控制始终不变。**

{% hint style="info" %}
**历史小故事｜会师白道：一条山路改变战局。**

630 年，**李靖**率精骑从马邑出发，夜袭定襄；**李世勣**则在**白道**击败东突厥军。随后两军会合，继续进击，颉利可汗的统治终于瓦解。白道是呼和浩特北面穿越大青山的重要通道，这场战事并非发生在凉城县城。它说明，\*\*谁控制了山间孔道，谁就更容易截断对手退路，把平原上的胜利推进到山北。\*\*白道川、云中与凉城的历史在这一格局中相接，具体上级机构却须分别辨明。
{% endhint %}

突厥之后，草原上又换过几批主人。**薛延陀**一度取代东突厥的位置；八世纪中叶以后**回鹘**兴起，控制漠北，与唐朝长期维持和亲与绢马贸易。九世纪中叶回鹘汗国崩溃，部众四散南下，其中一部分进入漠南与唐朝边地，与当地人群杂处。**对边地居民来说，“草原上换了谁做主”直接影响互市的商品、道路的安全和草场的使用，而不是一个遥远的国号。**

唐末至五代，唐朝北方的统治体系衰退，**沙陀**出身的李克用及其家族在代北、山西崛起，**契丹**也向西南扩展。今天大同、呼和浩特与凉城周边经历的，是交错的政治变化，**不是整片区域在同一天由沙陀统一移交给契丹**；凉城地区也在这个过程中逐步转入辽的统治。羁縻的时代到此结束。
