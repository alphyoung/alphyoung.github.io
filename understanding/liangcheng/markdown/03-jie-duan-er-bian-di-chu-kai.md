# 03 阶段二·边地初开

从距今约四千年到公元前五世纪，本地可依据的材料明显变少。文献在这一带最早留下的，是鬼方、猃狁、北狄这样的名字——它们来自中原的记录，指向一个方位，而不是一份边界清晰的名单。等考古材料重新密集起来，这里已经是一个农牧兼营的接触地带：毛庆沟、饮牛沟的墓地显示，种植、饲养与狩猎可以并存。随后赵国北进、秦汉设郡，中原王朝第一次把郡县与边塞体系推进到湖盆周围。这一阶段的转折点，是外部政权第一次取代地形与生计，成为决定这里命运的力量。

## 2.1 材料空白之后：文献里的鬼方、猃狁与北狄

**商 — 西周**

从距今约四千年到公元前五世纪，本地可依据的考古材料明显变少，但史书并没有完全沉默。地方沿革通常把夏、商、周时期这一带记作**鬼方**等北方人群的活动范围，并列出**猃狁、林胡、北狄**等名称。**要分清的是：这些是文献与后世志书留下的记载，不是从岱海边的地层里挖出来的证据。把它们写进地方沿革，说明的是这一带长期处在中原文献所称的“北方”，而不是一个已经确定的地名。**

商代甲骨与《周易》《诗经》里，鬼方、猃狁都曾作为商、周王朝北面的对手出现。相关战事多发生在今陕北、晋北与河套一带，与凉城所在的方位大致相接。**但文献给出的方位并不精确，因此不能据此说某一年岱海边属于某一个“方国”。**

还有一层需要留意：鬼方、猃狁是中原文献从外部给出的称呼，未必是这些人群的自称，也未必始终指同一个群体。\*\*把它们理解成几千年不变的“民族”，和把它们当成彼此无关的标签，都不符合材料。\*\*它们提供的是一个方位和一段时间，而不是一份边界清晰的名单。

真正让这一带面貌清楚起来的，还是墓葬和遗址。等考古材料重新密集出现时，这里已经是一个农牧兼营的接触地带。

## 2.2 墓地里的居民，生活未必一样

**东周**

东周时期的凉城，留下了**毛庆沟、饮牛沟**等墓地。毛庆沟出土的装饰品、兵器、马具和陶器，显示当地人的物质生活已与史前石城聚落不同。

更有意味的是墓葬之间的差别：\*\*朝向、葬具和随葬物组合并不完全一致。\*\*有研究据此讨论不同来源居民的相处，以及家庭和群体组织的差异。这些是依据墓地提出的解释，仍需与年代、其他墓地和更多材料相互检验。

人的日常生活也未必属于单一类型。有关内蒙古中南部古代居民的研究，将毛庆沟、饮牛沟等材料放在**农牧兼营**的背景中讨论。**种植、饲养与狩猎可以共同构成生计，不必把每个人分进“只种地”或“只放牧”的格子。**

## 2.3 林胡、楼烦与赵国北进

**战国**

赵国北进之前，晋北与河套周边已有**林胡、楼烦**等人群活动。《史记》将他们记在赵武灵王北向扩展的历史中。**这些名称代表当时的部落或人群，并不意味着今天的凉城县境曾完整属于一个边界固定的“林胡国”或“楼烦国”。**

岱海附近墓地呈现的农牧兼营生活，也比“游牧与农耕初次碰撞”更为复杂：这里的接触早已发生，并持续改变着居民的生活。

战国时期，赵国向北扩展，改变了晋北与内蒙古中南部的政治关系。赵武灵王推行**胡服骑射**，与这种扩展紧密相关。长期同北方力量交往和作战，使服装、骑乘与军事组织成为赵国必须处理的问题。

考古研究将毛庆沟、饮牛沟等地所见文化接触，与赵国北进的背景联系起来。不过，**具体墓地居民如何称呼自己，仍不能仅凭一把短剑或一副马具确定。**

{% hint style="info" %}
**人物故事｜赵武灵王改变的，不只是衣服。**“胡服骑射”常被讲成一次换装。对国家而言，更深的变化是训练人员、取得马匹、适应骑乘作战，并向原有秩序解释为什么要改变。赵武灵王的北方经营包含军事改革、设郡与筑长城：《史记》记载他北破林胡、楼烦，设置**云中、雁门、代郡**，并沿北部边地筑长城。**云中郡**与今天呼和浩特周边联系密切，今凉城一带的地方沿革则主要指向**雁门郡**——它们同属赵国的北方经营，却不是同一个郡。
{% endhint %}

## 2.4 秦汉边城，需要一整片地方来养活

**秦 — 东汉**

战国后期，今凉城一带归赵国控制，地方志记为赵国**雁门郡**地。秦统一后，这一带属秦朝雁门郡。**当时尚无今天的凉城县，郡的辖境跨越了今天内蒙古与山西的省界。**

西汉初年，这一带曾纳入汉朝分封的代国；后来仍是汉朝北方郡县体系的一部分。岱海南岸的**沃阳县**属雁门郡。东汉时，雁门郡隶并州，《后汉书》所列辖县包括**疆阴**，已不见沃阳。两汉之间，北边县级建置有所变化，今凉城地区与雁门郡保持着重要的行政联系。

当地保存着古城和长城遗存，左卫夭古城等遗址见于文物保护资料。

边城不是孤立的军营。\*\*守城需要粮食，马匹需要草料，器械需要制造维修，人员需要沿道路往来。\*\*郡县的运作因而会把耕地、村落与军事据点联系起来，城外的生产支撑着城内的驻军和居民。一处边城的背后，是一整片地方的生产与运输。

## 2.5 匈奴与秦汉：长城之外，还有草场、道路和家庭

**秦 — 西汉**

秦统一后，蒙恬率军北击匈奴，夺取河套黄河以南的“河南地”，秦朝在北方修筑、经营城塞。**秦直道**则连接关中的云阳、甘泉一带与九原，北端位于今包头一带。它服务于更广阔的北疆交通，路线并不经过凉城；**凉城的郡县与边城属于这一北方格局的东侧部分。**

西汉武帝时期，卫青、霍去病的多次出征改变了汉匈力量对比。其中，卫青在公元前 127 年的河南地之战，与随后朔方地区的设郡、筑城和徙民密切相关。\*\*迁入的家庭必须建屋、开田、承担赋役，才能使军事占领转化为较持久的地方经营。\*\*这是河套农业发展的一次重要扩展，而岱海的农业生活则早在史前已经存在。

{% hint style="info" %}
**历史小故事｜白登七日：刘邦遇上冒顿单于。公元前 200 年，汉高祖刘邦北征，在平城附近的白登**被冒顿单于的骑兵围困。《史记》记载，汉军前后脱节，围困持续七日，最终才得以脱身。白登在今天大同一带，位于凉城的东南方向。这场遭遇使汉朝认识到北方战争的困难，随后以和亲等方式缓和汉匈关系。
{% endhint %}

冒顿统率的匈奴已有单于、左右贤王等政治与军事组织。\*\*秦汉边塞面对的，是一个能够组织广大部众与牧业资源的政治力量。\*\*沿着晋北到阴山的通道，战争、使节与物资往来相继经过，边地居民也必须在这些变化中维持生计。

阴山岩画留下了另一类记录：动物、骑乘与狩猎的图像。著名的岩刻群主要分布在更西面的巴彦淖尔等地，年代跨度很长，**具体图像也不能都归给匈奴**；它可以与岱海的墓葬、聚落和长城相互参照，展示不同地方、不同人群的生活。

{% hint style="info" %}
**周边格局 · 赵、秦汉与匈奴** —— 这里经历的是前后变化的政治格局。**战国赵国北进与后来汉匈关系并非同一场战争**；匈奴的政治力量也不能概括此前所有北方人群。边地可能发生战争，也可能出现贸易、归附与人员迁居。**政治边界的变化和居民生活的变化，有时并不同步。**
{% endhint %}
