# 简读凉城

凉城县位于内蒙古乌兰察布市南部，与山西北部相邻。县境中央是岱海及其周围的湖盆，北有蛮汉山，南有马头山，湖盆之外是山地与沟谷。它的全部历史，都发生在这片地形里。

这本小册子把凉城的历史收成六个时段：从史前湖岸的房屋与石墙，经过农牧之间的接触地带、北魏的郡城、辽金元的州县、明代的边墙、清代的移民与厅县，走到今天这个必须重新与湖泊协商的凉城。篇幅有限，许多问题只能点到为止。

## 三个“凉城”：地理的、名称的、建置的

**地理的凉城**：一个被山地环抱的湖盆。北有蛮汉山、南有马头山，中部是岱海与其周围的盆地。湖岸线、山口与山道的位置，长期决定了人们在哪里住、往哪里走。

**名称的凉城**：这个名字并非自古如此。它来自北魏的凉城郡（古籍中也写作梁城郡），中间长期中断，直到 1914 年才重新启用为现代县名；在此之前，这片地方叫宁远。

**建置的凉城**：今天的凉城县，与古代的郡、县、厅、卫所辖境并不重合。同一时期，今县境还可能分属不同单位；而同一个行政中心，也曾从田家镇迁往新堂。把“凉城县”当成一条自古连续、边界不变的行政实体，是理解本地历史最常见的绊脚石。
