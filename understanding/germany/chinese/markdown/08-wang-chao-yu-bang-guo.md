# 08 附录：王朝、邦国与跨国王室联系

十七世纪—二十世纪初

这些家族长期并存，并不是依次统治一个德国的王朝表。本表包含1806年神圣罗马帝国结束之后的关系。婚姻能够提供继承主张与外交渠道，其结果仍取决于继承法、政治制度和战争。1714—1837年的英国与汉诺威共戴一君，却不共用一个政府。

## 跨国王室网络

| 王朝与邦国             | 代表性跨国关系                                     | 宗教与政治作用                       |
| ----------------- | ------------------------------------------- | ----------------------------- |
| 霍亨索伦（勃兰登堡—普鲁士）    | 腓特烈·威廉亲王于1858年迎娶维多利亚女王长女维多利亚；他在1861年成为普鲁士王储，1888年即位为腓特烈三世         | 威廉二世是英国女王的外孙；新教王朝领导的普鲁士最终主导统一 |
| 韦尔夫（汉诺威）          | 索菲娅出自斯图亚特母系，其子乔治一世于1714年继承英国王位              | 新教资格和议会立法决定继承；英汉共主关系延续至1837年  |
| 维特尔斯巴赫（巴伐利亚、普法尔茨） | 普法尔茨支系与斯图亚特联姻；巴伐利亚的伊丽莎白“茜茜”嫁给奥地利皇帝弗朗茨·约瑟夫一世 | 不同支系分别信奉天主教、改革宗等，并不总在同一阵营     |
| 韦廷（萨克森）           | 奥古斯特二世、三世兼任波兰国王；三世迎娶哈布斯堡的玛丽娅·约瑟法            | 二世为参选波兰王位改宗天主教，萨克森主体仍保留路德宗    |
| 韦廷支系（萨克森—科堡—哥达）   | 阿尔伯特亲王1840年迎娶英国维多利亚女王，二人之子爱德华七世于1901年即位                       | 后代在英国使用这一王朝名称，1917年改称温莎       |
| 奥尔登堡—格吕克斯堡        | 丹麦克里斯蒂安九世的女儿亚历山德拉嫁给英王爱德华七世，达格玛嫁给俄皇亚历山大三世    | 连接北德—丹麦、英国与俄国的王室网络            |

共主期间，英国与汉诺威保留各自的政府和财政。1837年维多利亚继承英国王位，汉诺威因不同的继承规则由她的叔父继承，两国分开。

资料：[维多利亚的王室亲属](https://www.royal.uk/encyclopedia/victoria-r-1837-1901)[萨克森—科堡—哥达](https://www.royal.uk/saxe-coburg-gotha?page=1)[格吕克斯堡家族](https://www.schloss-gluecksburg.de/en/discover/historical-overview)

## 其他不能忽略的邦国与城市

| 邦国或地区      | 历史位置与作用                                  |
| ---------- | ---------------------------------------- |
| 符腾堡        | 西南德重要邦国，路德宗影响较强；参与统一并保有地方制度传统            |
| 巴登         | 天主教与新教并存，是十九世纪自由主义、宪政与1848年革命的重要地区       |
| 黑森诸邦       | 位于德意志中部，依领地有路德宗、改革宗等传统，在交通、贸易与邦国政治中占重要位置 |
| 汉堡、吕贝克、不来梅 | 与汉萨同盟、北海和波罗的海贸易相连，体现商业城市自治传统             |
| 美因茨、特里尔、科隆 | 三大教会选侯领地，主教兼具宗教与世俗权力                     |

王室亲缘能够建立沟通渠道，却不能保证和平。进入近现代后，议会、军队、民族主义与国家利益的影响逐渐超过君主个人关系。

人物核对：[腓特烈三世生平](https://www.dhm.de/lemo/biografie/friedrich-iii)。这里的1888年德意志皇帝，与1452年加冕的哈布斯堡皇帝腓特烈三世并非同一人；皇帝编号必须结合国家和王朝理解。
