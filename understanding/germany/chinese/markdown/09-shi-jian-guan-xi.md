# 09 附录：时间线与日期关系

本表连接容易被压缩成同一日期的事件，是正文的索引，不表示所有转变瞬间完成。斜线分开的年份对应不同事件，时间范围则可能表示过程或约定俗成的分期。

## 法兰克与中世纪基础

| 年代或顺序 | 事件与对应关系 |
| --- | --- |
| 公元9年 → 14—16年 | 瓦鲁斯军团战败；日耳曼尼库斯后来仍率罗马军出征，说明最初战役没有立即终结莱茵河外军事行动 |
| 751 → 768 → 800 | 加洛林家族取得法兰克王位；查理曼成为法兰克国王；800年12月25日在罗马加冕为皇帝 |
| 814 → 840 → 843 | 查理曼去世；虔诚者路易去世；后者诸子经内战达成凡尔登分割 |
| 855 → 870 → 880 | 中法兰克分裂；墨尔森、里布蒙安排重组洛泰尔林吉亚，而非分配全部原中法兰克领土 |
| 911 → 919 | 东法兰克加洛林王统结束，康拉德一世911年当选，亨利一世919年继位 |
| 936 → 951 → 962 | 奥托一世在亚琛取得王位；取得意大利王位并迎娶阿德莱德；962年2月2日在罗马加冕为皇帝 |
| 955 | 奥托在奥格斯堡附近的莱希费尔德击败马扎尔军，早于其皇帝加冕 |
| 972 | 奥托二世在罗马迎娶狄奥法诺，并未合并西方帝国与拜占庭 |
| 1024 → 1032—1034 | 康拉德二世开创萨利安王统；勃艮第有争议的继承、加冕与巩固发生在后来 |
| 1077 → 1122 | 卡诺莎与沃尔姆斯宗教协定是叙任权斗争的不同节点，不是皇帝或教皇一次取得最终胜利 |
| 1138 → 1186 → 1194 | 霍亨斯陶芬取得王位；亨利六世迎娶康斯坦丝；通过继承主张与征服获得西西里王位 |
| 1198 → 1212 | 奥托卡一世取得波希米亚王号；《西西里金玺诏书》确认其世袭性质 |
| 约1250/1254—1273 | 大空位时期是王位竞争与中央王权衰弱的惯用分期，不是完全没有国王 |
| 1273 → 1278 | 鲁道夫一世当选国王，随后在马尔希费尔德击败奥托卡二世；鲁道夫未加冕为皇帝 |
| 1356 | 《金玺诏书》明确七选侯安排，奥地利不在七席之内 |
| 1438 → 1440 → 1452 | 阿尔布雷希特二世当选国王；腓特烈当选国王；腓特烈三世在罗马加冕为皇帝 |
| 1477 → 1496 | 马克西米连与勃艮第的玛丽结婚；下一代美男子腓力与胡安娜结婚 |
| 1495 | 沃尔姆斯帝国改革使共同法律制度发展，并未以中央集权民族国家取代帝国 |

依据与说明见[法兰克基础](01-jie-duan-yi-qi-yuan-yu-fa-lan-ke-shi-dai.md)、[中世纪与近世帝国](02-jie-duan-er-di-yi-di-guo-shen-sheng-luo-ma-di-guo-de-ba-bai-nian.md)。

## 宗教改革、王朝政治与统一

| 年代或顺序 | 事件与对应关系 |
| --- | --- |
| 1517 | 路德传播《九十五条论纲》；宗教改革持续数十年，也有更早的改革传统与多个中心 |
| 1519 → 1520 → 1530 | 查理五世当选、亚琛国王加冕、博洛尼亚教皇主持的皇帝加冕，是不同事件 |
| 1521—1522 → 1526 | 斐迪南接掌奥地利世袭领地；路易二世死于莫哈奇之后，展开波希米亚与匈牙利王位继承 |
| 1555 → 1556 → 1558 | 奥格斯堡宗教和约与查理移交尼德兰；西班牙王位移交及放弃帝国统治；斐迪南皇帝继承获承认 |
| 1618 → 1619 → 1620 | 波希米亚起义开启三十年战争；腓特烈五世接受波希米亚王位；白山战败终结短暂统治 |
| 1623 → 1648 | 普法尔茨选侯地位转予巴伐利亚；和约另为普法尔茨增设一席 |
| 1648 → 1653 | 威斯特伐利亚安排向勃兰登堡分配波美拉尼亚领土；后续协议落实划分 |
| 1618 → 1657/1660 → 1701 | 勃兰登堡继承普鲁士公国；脱离波兰王冠的主权获取得及确认；1701年1月18日腓特烈加冕为“在普鲁士的国王” |
| 1740—1748 / 1756—1763 | 奥地利王位继承战争／七年战争，是奥普竞争的相关阶段，不是一场连续战争 |
| 1803 → 1804 → 1805 → 1806 | 世俗化及领土重组；奥地利帝号创立；奥斯特利茨战役；莱茵邦联与神圣罗马帝国解体 |
| 1813 → 1814—1815 → 1815年6月8日 | 莱比锡击败拿破仑；维也纳会议；邦联条例建立德意志邦联 |
| 1834年1月1日 | 关税同盟生效，关税整合并不直接创建民族国家 |
| 1848年5月18日 → 1849年3—4月 | 法兰克福国民议会开会；宪法与帝冠提议；腓特烈·威廉四世拒绝方案 |
| 1864 → 1866 → 1867年7月1日 | 对丹麦战争；普奥战争；北德联邦国家宪法生效 |
| 1871年1月1日 → 1月18日 → 5月4日 | 新联邦宪制安排；凡尔赛宣告；修订后的帝国宪法生效 |

依据与说明见[神圣罗马帝国](02-jie-duan-er-di-yi-di-guo-shen-sheng-luo-ma-di-guo-de-ba-bai-nian.md)、[统一进程](03-jie-duan-san-di-er-di-guo-min-zu-guo-jia-de-dan-sheng.md)及[王室联系附录](08-wang-chao-yu-bang-guo.md)。

## 战争、独裁与战后安排

| 年代或顺序 | 事件与对应关系 |
| --- | --- |
| 1914年6—8月 | 萨拉热窝遇刺之后有七月危机、宣战和入侵，政府决策连接各阶段 |
| 1918年11月9日 → 11日 → 28日 | 宣布退位与共和国宣告；停战生效；威廉二世签署正式退位文书 |
| 1919年1月19日 → 7月31日 → 8月11/14日 | 全国选举；通过宪法；签署后公布生效 |
| 1919年6月28日 → 1920年1月10日 | 凡尔赛条约签署、随后生效；各地领土安排另有时间表 |
| 1933年1月30日 → 2月28日 → 3月23/24日 | 希特勒获任命；紧急法令暂停权利；授权法通过并公布 |
| 1938 → 1939年3月 → 1939年9月 | 吞并奥地利和苏台德；摧毁剩余捷克国家并强取梅梅尔；入侵波兰引发欧洲战争 |
| 1941年6月22日 → 1942年1月20日 | 入侵苏联、大规模屠杀扩展；万湖会议协调已经发展的灭绝政策 |
| 1945年5月7日 → 8/9日 → 6月5日 | 兰斯签署投降；投降生效与柏林卡尔斯霍斯特再次签署；盟国接掌最高权力 |
| 1948年6月 → 1949年5月 | 货币改革与柏林封锁；空运维持西柏林后封锁结束 |
| 1949年5月23日／10月7日 | 联邦德国／民主德国成立日期，两国不是同一天建立 |
| 1955 | 西德取得广泛主权并加入北约，东德加入华约；四国对整个德国的保留权力仍存在 |
| 1957年1月1日 → 1959年7月6日 | 萨尔政治加入，随后经济与货币并入 |
| 1961年8月13日 | 开始封闭柏林边境、修墙，区别于1948—1949年封锁 |
| 1970 → 1972 → 1973 | 东方条约；基础条约签署；基础条约生效，两德加入联合国 |
| 1989年10月9日 → 11月9日 | 莱比锡和平示威；柏林口岸开放，两者都不是正式统一日 |
| 1990年3月 → 7月 → 8月 | 东德自由选举；货币联盟；加入表决与统一条约签署 |
| 1990年9月12日 → 10月3日 → 11月14日 | “二加四”签署；国家统一；德波边界条约签署 |
| 1991年3月15日／1992年1月16日 | “二加四”条约／德波边界条约分别生效 |

依据与说明见[战争与独裁](04-jie-duan-si-zhan-zheng-beng-kui-yu-na-cui-tong-zhi.md)、[分裂与统一](05-jie-duan-wu-fen-lie-chong-jian-yu-chong-xin-tong-yi.md)。条约批准、生效日期尤其重要，仅凭签约日不能解释完整制度转变。
