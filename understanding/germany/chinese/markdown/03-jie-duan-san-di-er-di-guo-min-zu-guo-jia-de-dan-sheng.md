# 03 阶段三·第二帝国：民族国家的诞生

维也纳会议后的德意志邦联并未回答“统一德国包括哪里”。普鲁士借关税同盟、三次统一战争与俾斯麦的政治手腕，走“小德意志”路线排除奥地利，于1871年在凡尔赛建立德意志帝国，并迅速成长为工业强国。

**1815** 德意志邦联　**1834** 关税同盟　**1866** 普奥战争　**1871** 帝国宣告成立

## 从1806年到1815年：改革、抵抗与重组

神圣罗马帝国解体后，并未立即出现德意志邦联。1806年10月普鲁士在耶拿、奥尔施泰特战败，暴露军队与行政体系的弱点，随后展开施泰因、哈登贝格及军事改革者推动的改革。其他地区的拿破仑统治既带来法律与行政变化，也伴随军事征发和外来支配。

拿破仑1812年侵俄失败，以及1813年10月联军在莱比锡取胜，动摇了法国优势。1814—1815年的维也纳会议重组欧洲；1815年6月8日《德意志邦联条例》建立的是主权邦国的联盟，既非恢复神圣罗马帝国，也非完成民族国家统一。普鲁士取得莱茵地区、威斯特法伦大片土地及萨克森部分地区，为后来工业实力提供重要基础。

依据：[维也纳会议与复辟时代](https://www.bpb.de/themen/zeit-kulturgeschichte/revolution-1848-1849/519625/der-wiener-kongress-und-die-restaurationszeit/)。

## 3.1 邦联、关税同盟与统一方案

1815 — 1866

1815年建立的**德意志邦联**通常概括为39邦，成员会变化，统计也取决于时点及对共主领地的处理。邦联议会设在法兰克福，由奥地利主持。它包含今天德国大部、奥地利和捷克的广大地区，以及卢森堡、列支敦士登等地，却并未包括奥地利和普鲁士的全部领土。

**疆域 · 邦联与王国的边界并不重合**

匈牙利等哈布斯堡领地不在邦联内，东普鲁士及波森等普鲁士领地最初也在邦联范围之外。“统一德国包括哪里”，因此成为政治难题。

普鲁士主导、奥地利未参加的**德意志关税同盟**于1834年1月1日生效，降低参与邦国之间的关税壁垒。不过，经济整合并不会自动决定政治边界，也不保证必然出现普鲁士领导的统一。

1848年革命将宪政、公民权利与民族统一诉求联系起来。法兰克福国民议会于1848年5月18日在保罗教堂开会，1849年3月通过宪法，并向普鲁士国王腓特烈·威廉四世提出帝冠。国王拒绝是重大挫折，运动内部分歧与君主军事力量的恢复同样重要。革命未能建立所设想的全国制度，但相关宪法与权利讨论并未随失败消失。

依据：[从保罗教堂议会到1871年宪法](https://www.bpb.de/themen/nachkriegszeit/grundgesetz-und-parlamentarischer-rat/39184/von-der-paulskirche-bis-zur-verfassung-von-1871/)。

| 统一方案 | 核心主张         | 主要难题          |
| ---- | ------------ | ------------- |
| 大德意志 | 将奥地利纳入统一安排   | 哈布斯堡多民族领地如何处理 |
| 小德意志 | 排除奥地利，由普鲁士主导 | 以何种制度联合其余邦国   |

### 威廉一世：凡尔赛举行的是皇帝宣告

威廉一世1861年已在柯尼斯堡举行过**普鲁士国王加冕**。1871年1月18日的凡尔赛仪式，则是**德意志皇帝宣告（Kaiserproklamation）**，不是教皇为他戴上帝冠的中世纪加冕礼。

当时普法战争尚未结束，凡尔赛是德军大本营所在地。德国诸侯与军方代表在镜厅出席仪式，俾斯麦宣读告人民书，巴登大公率领欢呼。日期呼应1701年1月18日普鲁士王号的加冕纪念。

新国家的成立是条约与宪法变化的过程，1871年1月1日相关宪制安排已生效；1月18日成为最鲜明的象征性时刻。修订后的帝国宪法签署于1871年4月16日，5月4日生效。皇帝的正式头衔是“德意志皇帝”（Deutscher Kaiser），普鲁士国王兼任这一联邦职位，其他邦国仍保有自身地位。

## 3.3 第二帝国：联邦君主制与工业强国

1871 — 1918

**第二帝国即1871—1918年的德意志帝国。**普鲁士国王兼任皇帝，普鲁士拥有压倒性的领土、人口与军事优势。巴伐利亚、萨克森、符腾堡等保留王室及一定自治权。

**疆域 · 1871年的德国**

包括今天德国大部，以及东普鲁士、西普鲁士大部、波森、西里西亚、波美拉尼亚东部、北石勒苏益格和阿尔萨斯—洛林等地。

**不包括**奥地利、波希米亚、卢森堡和列支敦士登。统一纳入许多非德语人口，也将大量德语人口留在境外。

帝国议会实行原则上平等、直接的25岁以上男性选举权，同时存在法定排除情形；女性没有选举权，现役军人在服役期间不能行使投票权。这与普鲁士邦议会不平等的三级选举制不同。1918年10月宪政改革之前，宰相依赖皇帝信任，而非议会多数；但立法仍需议会参与。工业化使钢铁、化工、电气与科研迅速发展，社会保险制度逐步建立。俾斯麦的**“文化斗争”**限制天主教会影响，却强化了天主教中央党的政治动员。

海外殖民扩张将德国势力延伸至非洲和太平洋。殖民地应与欧洲本土疆域分开理解；海军扩建和世界政策也加剧与其他列强的竞争。


**现代化与排斥同时存在。** 1878—1890年的《反社会党人法》限制社会主义组织及出版物；社会保险立法则分别于1883年、1884年、1889年引入疾病、工伤、养老及失能保障。国家整合也伴随对波兰语人口等少数群体的压力。工业发展不能等同于充分政治平等。

殖民统治从1880年代展开，伴随夺地、强迫劳动与暴力。1904—1908年，德国军队在德属西南非洲、即今天的纳米比亚，对赫雷罗人和纳马人实施种族灭绝。这与经济增长和社会保险一样，属于必须叙述的帝国历史。
