# 02 阶段二·第一帝国：神圣罗马帝国的八百年

从奥托一世962年罗马加冕，到1806年弗朗茨二世放弃帝号，神圣罗马帝国绵延八百余年。这一阶段的核心线索是：皇帝与诸侯的分权、王朝联姻编织的欧洲网络、宗教改革带来的分裂，以及帝国在拿破仑时代的终结。

**962** 奥托一世加冕　**1122** 沃尔姆斯协定　**1356** 金玺诏书　**1517** 宗教改革　**1648** 威斯特伐利亚和约　**1806** 帝国解体

## 2.1 帝国的建立：奥托王朝与萨利安王朝

919 — 1125

**“第一帝国”通常指962—1806年的神圣罗马帝国。**这是后世的概括，帝国的名称和制度本身是在长期发展中形成的。

919年，亨利一世当选东法兰克国王。其子奥托一世于955年赢得**莱希费尔德战役**，962年在罗马加冕。帝国以德意志地区为核心，并将意大利北部及中部部分地区纳入其王权和帝国权利体系。

### 奥托一世的“加冕”，究竟加了哪一顶冠？

{% stepper %}
{% step %}
#### 936 · 亚琛

奥托继承其父亨利一世之后，被选立并加冕为东法兰克国王。这确立了他在王国内的地位，尚不是皇帝加冕。
{% endstep %}

{% step %}
#### 951 · 意大利

奥托介入意大利，取得意大利王位，并迎娶意大利王后遗孀阿德莱德，扩大王朝与政治基础。
{% endstep %}

{% step %}
#### 962.02.02 · 罗马

教皇约翰十二世面对意大利国王贝伦加尔二世的压力，向奥托寻求军事支持。奥托进入罗马，在旧圣彼得大教堂由教皇加冕为皇帝。

这次仪式把奥托的德意志—意大利权力基础与西方罗马皇帝传统、保护教会的使命联系起来。它不是把“德国国王”简单改名为“德国皇帝”，更不是现代德国统一仪式。
{% endstep %}
{% endstepper %}

962年因此常被用作神圣罗马帝国的起点，但它继承了800年查理曼加冕以来的帝国传统。“神圣罗马帝国”这一完整名称尚未在当时定型。教皇与皇帝的合作也很快转为冲突，皇帝并非教皇任意指挥的下属。

### 萨利安王朝与叙任权斗争

萨利安王朝统治于1024—1125年。勃艮第国王鲁道夫三世于1032年去世后，康拉德二世提出继承主张，1033年加冕为勃艮第国王，并至1034年通过斗争巩固地位。这一王国涉及今天法国东南部、瑞士西部等地区，与后来勃艮第公国及其尼德兰领地不能混为一谈。

{% hint style="info" %}
**疆域 · 三个王国的帝国**

帝国通常被概括为以德意志、意大利和勃艮第三个王国为基础。各地制度不同，皇帝的实际控制强弱不一，不能理解为直接管理整个意大利。
{% endhint %}

三个王国的结构逐步形成，不能把1033—1034年勃艮第的加入倒推到“约1000年”的地图上。波希米亚与帝国的关系也经历演变；奥托卡一世于1198年取得王号，1212年《西西里金玺诏书》确认其世袭性质。

皇帝与教皇围绕主教任命发生**叙任权斗争**。1077年的卡诺莎事件与1122年的《沃尔姆斯宗教协定》是关键节点。主教拥有土地与政治资源，因此宗教任命也是权力分配。

末代萨利安皇帝亨利五世迎娶英王亨利一世之女玛蒂尔达，二人没有存活子嗣。玛蒂尔达后来再婚，其子成为英王亨利二世，联姻并未形成英德共同继承体系。

## 2.2 中世纪王朝的欧洲联系

1138—1495

### 霍亨斯陶芬：西西里继承与意大利冲突

霍亨斯陶芬家族于1138年登上德意志王位，此后与其他家族竞争，直至十三世纪中期衰落。“红胡子”腓特烈一世、亨利六世和腓特烈二世试图加强皇权，却受到德意志诸侯、意大利城市和教皇的抵抗。

1186年，**亨利六世迎娶西西里继承人康斯坦丝**。通过继承主张与军事征服，他于1194年取得西西里王位，其子腓特烈二世继承了这一王国。

{% hint style="info" %}
**疆域 · 同一个君主，不同的王国**

西西里王国包括西西里岛和意大利南部大陆地区。它与帝国由同一统治者掌握，却仍是独立的王国体系。教皇担忧自己的领地被南北夹击，冲突因此加剧。
{% endhint %}

腓特烈二世还迎娶英王约翰之女伊莎贝拉，强化与英格兰的联系。

延伸阅读：[普林斯顿大学：康斯坦丝](https://dante.princeton.edu/cgi-bin/dante/DispToynbeeByTitOrId.pl?INP_ID=241859)[英格兰的伊莎贝拉](https://en.wikipedia.org/wiki/Isabella_of_England)

### 韦尔夫：从萨克森到英格兰

韦尔夫家族的“狮子”亨利一度控制萨克森和巴伐利亚，是腓特烈一世的重要竞争者。他迎娶英王亨利二世与阿基坦的埃莉诺之女玛蒂尔达。二人的儿子奥托四世后来成为皇帝，并与英格兰保持密切联系。

韦尔夫的后续支系在不伦瑞克—吕讷堡和汉诺威延续统治，最终于十八世纪登上英国王位。德意志王位竞争因而一直与欧洲政治相连。

### 卢森堡：以波希米亚为中心

1310年，卢森堡的约翰迎娶波希米亚普热米斯尔王朝公主伊丽莎白，取得重要的继承依据，并在当地政治支持下确立统治。其子查理四世成为皇帝，以布拉格为政治和文化中心。

1356年的**《金玺诏书》**明确七位选帝侯的选举地位：美因茨、特里尔和科隆三位大主教，以及波希米亚国王、莱茵行宫伯爵、萨克森公爵和勃兰登堡藩侯。

波希米亚是帝国内的重要王国，包含大量非德语人口，不能简单理解为现代德国的一个省。

延伸阅读：[卢森堡大学：约翰与王朝婚姻](https://publications.uni.lu/handle/10993/1344)

## 2.3 哈布斯堡：婚姻如何改变欧洲地图

1273—1558｜与前后年代重叠的王朝专题

哈布斯堡早期据点位于今天瑞士北部及邻近地区。1273年，鲁道夫一世当选国王；击败波希米亚国王奥托卡二世后，家族于十三世纪末确立对奥地利等地的统治。

十五世纪起，哈布斯堡长期占据皇位，但**皇位与家族领地仍是两回事**。皇帝不能把帝国内其他诸侯的土地都视为自己的私产。

结婚并不等于立即获得领土。继承顺序、贵族认可、谈判与战争都影响结果。斐迪南仍需获得王位选举认可，在匈牙利还面对竞争者和奥斯曼扩张。

### 查理五世：跨欧洲的王朝统治

查理于1506年继承勃艮第尼德兰，1516年与母亲胡安娜共同拥有西班牙诸王国的王号，1519年继承奥地利领地并当选罗马—德意志国王；1520年在亚琛举行国王加冕，1530年在博洛尼亚接受教皇主持的皇帝加冕。这些是不同的继承与职务，不是将全部领土合并成一个国家。1521—1522年的安排使其弟斐迪南接掌奥地利世袭领地，不能把查理整个在位期都写成对奥地利的持续直接统治。

**西班牙与美洲殖民地没有成为德国领土。**匈牙利也没有因为哈布斯堡统治而整体加入神圣罗马帝国。西班牙与奥地利两支的分化自1520年代展开。查理于1555—1556年将尼德兰及西班牙王位交给腓力二世；1556年放弃帝国统治的安排到1558年才获得选帝侯正式接受，并确认斐迪南的皇帝继承。

## 2.4 宗教改革与三十年战争

1517 — 1648

1517年，**马丁·路德提出《九十五条论纲》**，宗教改革逐步扩展。萨克森选帝侯保护路德，信仰与诸侯自主权相互支持。德语《圣经》与印刷传播推动教育和书面德语的发展。

1524—1525年，农民战争将宗教语言与赋役、共同体权利等诉求结合。路德反对起义并支持镇压，表明宗教改革并不等同于社会革命。

1555年，**《奥格斯堡宗教和约》**承认天主教与路德宗，形成通常称为“教随国定”的安排。它没有建立现代个人宗教自由，也未纳入改革宗。不同信仰的天主教或路德宗臣民可以在规定条件下迁出；“教会保留条款”及部分混合信仰帝国城市的安排，又限制了领地主人的选择。常见拉丁语概括形成于后来，并非条约原文中的一句口号。

{% hint style="info" %}
**宗教地理 · 交错的信仰边界**

北部和东北部许多领地以路德宗为主；奥地利、巴伐利亚及许多西部教会领地坚持天主教；普法尔茨等部分领地转向改革宗。实际分布交错，不能画成简单的南北分界。
{% endhint %}

### 普法尔茨与英国王室：“冬王”的失败

1613年，普法尔茨选帝侯腓特烈五世迎娶英王詹姆斯一世之女伊丽莎白·斯图亚特。1619年，他接受波希米亚王位，次年在**白山战役**中战败，因统治短暂被称为“冬王”。英国姻亲关系没有带来足以挽救王位的支持。

### 一条通向英国王位的母系继承线

詹姆斯一世 _→_ 伊丽莎白·斯图亚特 _→_ 汉诺威的索菲娅 _→_ 乔治一世

### 1648年：战争之后的帝国地图

三十年战争始于1618年的波希米亚危机，丹麦、瑞典、法国等国先后介入。天主教法国反对天主教哈布斯堡，说明宗教并不能完全决定国家立场。战争、饥荒与疾病使德意志许多地区遭受严重破坏。

**《威斯特伐利亚和约》**确认并调整诸侯权利，将改革宗纳入宗教和解框架。帝国继续存在，但权力与边界发生变化：

* 帝国和约确认瑞士邦联不受帝国司法管辖的地位；西班牙与荷兰共和国另行缔结《明斯特和约》，由西班牙承认荷兰独立。两项相关安排不能写成同一条款或一次简单的“德国割地”。
* 法国取得或确认在阿尔萨斯部分地区等地的权利，并非一次取得整个现代阿尔萨斯。
* 瑞典取得西波美拉尼亚等帝国领地，以领地主人身份参与帝国政治。
* 勃兰登堡获分后波美拉尼亚大部及其他领地，波美拉尼亚的具体交接至1653年落实。“后波美拉尼亚”是历史地理名称，不等于现代德国海岸以东的一切地区。

和约保留帝国制度，并限制针对皇帝与帝国的结盟，不能说它突然创造了一套现代民族国家的完全主权体系。宗教安排以1624年作为重要基准年，并为得到承认的少数教派提供规定范围内的保护。

依据：[《奥格斯堡宗教和约》](https://germanhistorydocs.org/en/from-the-reformations-to-the-thirty-years-war-1500-1648/the-religious-peace-of-augsburg-september-25-1555) · [《威斯特伐利亚和约》](https://germanhistorydocs.org/en/from-the-reformations-to-the-thirty-years-war-1500-1648/peace-treaties-of-westphalia-october-14-24-1648)。

## 2.5 帝国制度与邦国权力

1356—1806｜制度专题

帝国权力由不同政治主体分享和协商。以下按时期比较制度变化，不把并存的邦国写成先后执政的全国政府。

### 帝国内，究竟谁主导谁？

**皇帝居于帝国最高地位，但不等于直接统治所有邦国。**选帝侯决定国王选举，诸侯经营各自领地；教会领地和自由帝国城市也有自身权利。权力关系随时代变化，不是一张固定的上下级表。

| 政治层次      | 主要权力                           | 需要区分                         |
| --------- | ------------------------------ | ---------------------------- |
| 国王／皇帝     | 代表帝国、授予封地和特权、维护和平与司法，协调诸侯支持    | 中世纪先取得王位，再争取皇帝加冕；不是每位国王都成为皇帝 |
| 选帝侯       | 拥有选举国王的专门权利，同时统治各自领地           | 选侯首先是一种政治资格，并不保证领土最大或军队最强    |
| 其他世俗与教会诸侯 | 在领地内掌握逐渐扩大的司法、财政等权力，参与帝国政治     | 包括公爵、藩侯、主教等；头衔、实力和选举资格并不一致   |
| 自由帝国城市    | 享有直接联系帝国的地位与城市自治，后在帝国议会中形成城市议席 | 不是某个邻近公爵自然拥有的城市              |
| 帝国议会与法院   | 近世逐渐形成共同议事、法律和司法机制             | 皇帝、选侯、诸侯和城市协商治理；不是现代全民议会     |

十三世纪以后，国王越来越依赖家族世袭领地提供财力和人力。哈布斯堡占据皇位的优势来自奥地利等家族资源与选举政治，而不是“奥地利作为国家天然管辖全部德意志”。

### 主要邦国的地位，必须分时代看

| 时期      | 主要力量                                   | 主导关系                                              |
| ------- | -------------------------------------- | ------------------------------------------------- |
| 十—十一世纪  | 萨克森、法兰克尼亚、巴伐利亚、施瓦本、洛林等公国               | 奥托王朝以萨克森为基础，并依靠主教、修道院与贵族合作；不能套用后来的奥普竞争            |
| 十二—十三世纪 | 霍亨斯陶芬的施瓦本基础，韦尔夫的萨克森—巴伐利亚势力，以及奥地利、波希米亚等 | 皇室与强大公爵竞争，旧公国分裂，领地诸侯壮大                            |
| 十四—十五世纪 | 卢森堡—波希米亚、哈布斯堡—奥地利、维特尔斯巴赫—巴伐利亚／普法尔茨     | 几大家族争夺王位；查理四世以波希米亚为重心，1438年后罗马—德意志王位通常由哈布斯堡及相关家族掌握；阿尔布雷希特二世是国王而非皇帝，腓特烈三世于1452年才加冕为皇帝 |
| 十六—十七世纪 | 哈布斯堡皇帝、萨克森、巴伐利亚、普法尔茨、勃兰登堡及教会选侯         | 宗教改革重组联盟；皇帝影响力显著，却无法消除地方自治与教派分歧                   |
| 十八世纪    | 奥地利与勃兰登堡—普鲁士，另有萨克森、巴伐利亚、汉诺威等           | 形成奥普两强竞争。普鲁士取得王号不意味着成为帝国皇室，也没有接管帝国                |

### 三个容易混淆的地方

{% hint style="info" %}
**奥地利不是1356年的七选侯之一。**哈布斯堡后来取得波希米亚王位，才同时掌握相应选票；奥地利自身的公爵或大公称号不自动产生选举权。
{% endhint %}

{% hint style="info" %}
**巴伐利亚与普法尔茨不是同一政治实体。**虽然同属维特尔斯巴赫家族，1356年的选票属于普法尔茨支系。1623年选侯地位转授巴伐利亚；1648年又为普法尔茨增设一席。
{% endhint %}

{% hint style="info" %}
**“萨克森”不是始终同一片土地。**中世纪早期萨克森公国主要位于今天德国北部；后来的萨克森选侯领地重心更偏东，不能直接等同于现代萨克森州。勃兰登堡与帝国外的普鲁士公国也应分开理解。
{% endhint %}

## 2.6 普鲁士崛起与第一帝国终结

1618 — 1806

普鲁士最初不是一块连续的国土，而是继承、战争与外交拼接起来的领地集合。它通过军队、税收和官僚体系壮大，与哈布斯堡的奥地利争夺德意志领导权。

| 时间          | 领土与地位变化                            |
| ----------- | ---------------------------------- |
| 1618        | 勃兰登堡选帝侯继承帝国外的普鲁士公国，后者当时仍受波兰王冠宗主权约束 |
| 1657 / 1660 | 通过条约取得普鲁士公国的主权地位，后获进一步确认           |
| 1701        | 统治者加冕为“在普鲁士的国王”，最初王号与帝国外领地相联系      |
| 1740—1763   | 从奥地利夺取并保住西里西亚大部，七年战争后巩固强国地位        |
| 1772年起      | 参与瓜分波兰，扩张东部领土，加强勃兰登堡与东普鲁士之间的连接     |

普鲁士由新教王朝领导，却包含西里西亚及所获波兰领土等地的天主教人口。1815年进一步向西部扩张的过程放在下一章。

### 哈布斯堡—洛林与法国

1736年，玛丽娅·特蕾西亚与洛林的弗朗茨·斯特凡结婚，形成哈布斯堡—洛林家族。她统治世袭领地，丈夫于1745年成为皇帝；她本人并非以自身权利继承神圣罗马皇位。

女儿玛丽·安托瓦内特于1770年嫁给后来的法国国王路易十六，体现奥法关系调整。这场婚姻与1756年奥法结盟的背景相连，亲缘并未消除国家利益的竞争。

资料：[哈布斯堡—洛林的形成](https://www.habsburger.net/en/chapter/producing-dynasty)[弗朗茨二世的家族婚姻](https://www.habsburger.net/en/chapter/franz-ii-i-upright-citizen-and-his-marriages)

### 1803—1806年：拿破仑重组德意志

拿破仑时代的战争重组德意志政治地图。1803年，帝国代表会议主要决议使大量教会领地世俗化，许多帝国城市失去独立地位。至1806年的进一步重组中，大量骑士领地及小邦被纳入较大邦国，称为“媒介化”（Mediatisierung，即失去直属帝国地位，转而受另一领主统治）。这是分阶段的过程，不能把后续结果全部放在1803年，也不能把1815年的邦国数量当成1803年的即时结果。巴伐利亚、符腾堡扩张，并于1806年成为王国。

1805年12月2日，奥法战争中的奥斯特利茨战役以奥俄联军战败告终。1806年7月，拿破仑保护下的莱茵邦联成立，成员随后退出帝国；8月6日，弗朗茨二世放弃神圣罗马皇帝称号。这些相关事件发生在不同年份与月份。

整合后的领土格局深刻影响后来德国，但现代联邦州还经历1815年、1866年、两次世界大战及1945年以后的重组，不能说今天的州界在拿破仑时代已经一次画定。

奥地利帝国已于1804年另行成立。神圣罗马帝国解体，并不意味着哈布斯堡国家同时消失。

拿破仑通过婚姻巩固影响：巴伐利亚公主奥古斯塔嫁给其继子欧仁·德·博阿尔内，符腾堡公主卡塔琳娜嫁给其弟热罗姆。相关邦国通过与法国合作获得王国地位或领土扩张，又随着战局改变阵营。
