# 01 阶段一·起源与法兰克时代

德国与法国同出法兰克王国。古代日耳曼诸部落并无统一国家，法兰克人建立王国后，843年《凡尔登条约》三分帝国，东法兰克成为德意志国家形成的重要基础。

**9年** 条顿堡森林战役 **800** 查理曼加冕 **843** 凡尔登条约

## 1.1 日耳曼部落与法兰克王国

**古代 — 800**

古代日耳曼人由不断变化的群体组成，并不是统一民族，也不能直接等同于今天的德国人。公元9年，阿尔米尼乌斯率领的联盟在**条顿堡森林战役**中击败瓦鲁斯统率的三个罗马军团。罗马此后仍继续出征，因此这是一场重大挫败，并非罗马势力立即、永久退出莱茵河以东所有地区，更不能视为德国建国。

法兰克人后来在西欧建立王国。墨洛温王朝的克洛维接受尼西亚信经传统的基督教，在这一历史语境中通常称为天主教，使王权与主教及罗马化人口建立更紧密的联系。他的受洗时间存在争论，传统的496年不能当作毫无争议的确切日期。

751年，加洛林家族取代墨洛温家族取得王位。查理曼通过征服扩张，包括774年征服伦巴第王国，以及772—804年漫长的萨克森战争；强制改宗与暴力也是这一过程的一部分。800年12月25日，教皇利奥三世在罗马为其加冕为皇帝。亚琛是重要王室驻地，不能直接理解为现代民族国家的首都。

## 1.2 843年：《凡尔登条约》三分帝国

**843**

| 政治实体 | 大致地理范围                        | 后续影响                 |
| ---- | ----------------------------- | -------------------- |
| 西法兰克 | 以今天法国的大部分地区为中心                | 法国形成的重要基础            |
| 东法兰克 | 以莱茵河以东地区为核心，也包括部分河西领土；以萨克森、法兰克尼亚、巴伐利亚和施瓦本等为骨架 | 德意志国家形成的重要基础         |
| 中法兰克 | 从北海沿岸经洛林、勃艮第一带，延伸至意大利         | 后来分裂，长期成为东西两侧强权争夺的对象 |

条约是在虔诚者路易840年去世、其诸子内战之后达成，并非查理曼814年去世后立即三分。洛泰尔保留皇帝称号，不意味着对两位兄弟的王国拥有实际最高统治权。东法兰克主要位于莱茵河以东，但也包括河西的美因茨、沃尔姆斯、施派尔及相关地区，不能把莱茵河画成严格的民族国界。

## 1.3 从东法兰克到奥托王朝

843—962

洛泰尔于855年去世后，中法兰克继续分裂。870年《墨尔森条约》、880年《里布蒙条约》改变洛泰尔林吉亚的分配，勃艮第与意大利则沿着不同路径发展。843年的地图是起始格局，不是永久疆界。

911年，东法兰克最后一位加洛林国王“孩童”路易去世，主要贵族推举康拉德一世。919年，萨克森柳多尔芬家族的亨利一世继位，起初尤其依靠萨克森与法兰克方面支持，各地承认其王权需要过程。其子奥托一世936年成为国王，962年成为皇帝。“东法兰克”到“德意志”反映渐进转变，不是某一天国家正式更名。

## 联姻、改宗与王权

克洛维的妻子克洛蒂尔德来自勃艮第王族，并信奉天主教。她的婚姻体现了王朝联盟与宗教联系，但克洛维改宗也包含政治和社会因素。

查理曼曾迎娶伦巴第国王德西德里乌斯的女儿，随后解除婚姻，并于774年征服伦巴第王国。联姻能够暂时缓和关系，却不能消除权力冲突。
