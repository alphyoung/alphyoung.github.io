# 03 阶段三·第二帝国：民族国家的诞生

维也纳会议后的德意志邦联并未回答“统一德国包括哪里”。普鲁士借关税同盟、三次王朝战争与俾斯麦的政治手腕，走“小德意志”路线排除奥地利，于1871年在凡尔赛建立德意志帝国，并迅速成长为工业强国。

**1815** 德意志邦联　**1834** 关税同盟　**1866** 普奥战争　**1871** 帝国宣告成立

## 3.1 邦联、关税同盟与统一方案

1815 — 1866

1815年的**德意志邦联**由39个成员组成，包含今天德国大部、奥地利和捷克的广大地区，以及卢森堡、列支敦士登等地，却并未包括奥地利和普鲁士的全部领土。

**疆域 · 邦联与王国的边界并不重合**

匈牙利等哈布斯堡领地不在邦联内，东普鲁士及波森等普鲁士领地最初也在邦联范围之外。“统一德国包括哪里”，因此成为政治难题。

1834年，由普鲁士主导、奥地利未参加的**德意志关税同盟**加强经济联系。1848年法兰克福国民议会尝试宪政统一，但次年普鲁士国王拒绝议会授予的帝冠，方案失败。

| 统一方案 | 核心主张         | 主要难题          |
| ---- | ------------ | ------------- |
| 大德意志 | 将奥地利纳入统一安排   | 哈布斯堡多民族领地如何处理 |
| 小德意志 | 排除奥地利，由普鲁士主导 | 以何种制度联合其余邦国   |

#### 威廉一世：凡尔赛举行的是皇帝宣告

威廉一世1861年已在柯尼斯堡举行过**普鲁士国王加冕**。1871年1月18日的凡尔赛仪式，则是**德意志皇帝宣告（Kaiserproklamation）**，不是教皇为他戴上帝冠的中世纪加冕礼。

当时普法战争尚未结束，凡尔赛是德军大本营所在地。德国诸侯与军方代表在镜厅出席仪式，俾斯麦宣读告人民书，巴登大公率领欢呼。日期呼应1701年1月18日普鲁士王号的加冕纪念。

新国家的成立是条约与宪法变化的过程，1871年1月1日相关宪制安排已生效；1月18日成为最鲜明的象征性时刻。皇帝的正式头衔是“德意志皇帝”（Deutscher Kaiser），普鲁士国王兼任这一联邦职位，其他邦国仍保有自身地位。

## 3.3 第二帝国：联邦君主制与工业强国

1871 — 1918

\*\*第二帝国即1871—1918年的德意志帝国。\*\*普鲁士国王兼任皇帝，普鲁士拥有压倒性的领土、人口与军事优势。巴伐利亚、萨克森、符腾堡等保留王室及一定自治权。

**疆域 · 1871年的德国**

包括今天德国大部，以及东普鲁士、西普鲁士大部、波森、西里西亚、波美拉尼亚东部、北石勒苏益格和阿尔萨斯—洛林等地。

**不包括**奥地利、波希米亚、卢森堡和列支敦士登。统一纳入许多非德语人口，也将大量德语人口留在境外。

帝国议会由成年男性普选产生，但首相主要向皇帝负责。工业化使钢铁、化工、电气与科研迅速发展，社会保险制度逐步建立。俾斯麦的\*\*“文化斗争”\*\*限制天主教会影响，却强化了天主教中央党的政治动员。

海外殖民扩张将德国势力延伸至非洲和太平洋。殖民地应与欧洲本土疆域分开理解；海军扩建和世界政策也加剧与其他列强的竞争。
