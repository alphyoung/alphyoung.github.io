# 07 附录：疆域总览与资料

## 各时代疆域总览

一张表读清边界如何变化

| 时代                 | 政治空间                                | 阅读边界的关键              |
| ------------------ | ----------------------------------- | -------------------- |
| 查理曼时代              | 横跨今法国、德国西南部、低地国家、意大利北部等地            | 尚无现代法德国界             |
| 东法兰克               | 以莱茵河以东诸公国为核心                        | 德意志逐步形成，并非突然建国       |
| 第一帝国中世纪            | 德意志、意大利、勃艮第体系中的广大地区及波希米亚            | 帝国权利与实际统治程度有差异       |
| 第一帝国近世             | 对意大利和西部的联系减弱，内部邦国分立；1648年确认瑞士、尼德兰脱离 | 并非现代中央集权国家           |
| 哈布斯堡扩张             | 家族领地跨越帝国内外                          | 西班牙、匈牙利与海外领地不能全部算作德国 |
| 德意志邦联（1815—1866）   | 含奥地利、波希米亚等地区，未含奥普两国全部领土             | 邦联边界与成员王国边界不同        |
| 德意志第二帝国（1871—1918） | 排除奥地利和波希米亚，纳入普鲁士东部与阿尔萨斯—洛林          | 小德意志统一方案的结果          |
| 魏玛共和国              | 战后收缩，东普鲁士与主体分隔，萨尔和但泽地位特殊            | 条约重组欧洲秩序             |
| 纳粹时期               | 吞并邻国领土并占领欧洲大片地区                     | 正式领土、保护国与占领区必须区分     |
| 战后两个德国             | 形成于战后占领区域，柏林与萨尔存在阶段性特殊安排            | 东部原领土与国家分裂是不同问题      |
| 1990年统一            | 两个战后德国实现统一，确认最终边界                   | 未恢复旧帝国疆域             |

联姻连接宫廷，宗教划分阵营，战争与继承改变地图。现代德国的国家边界与政治合法性，则逐渐由条约、宪法和公民制度来确定。
