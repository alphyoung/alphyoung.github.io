# 10 附录：概念与资料

把反复出现的关键概念集中解释，并给出可以直接查对的阶段脉络与历代归属总览。

## A.1 七阶段脉络一览

| 阶段      | 跨度                   | 一句话主题                                             |
| ------- | -------------------- | ------------------------------------------------- |
| 序 河谷地理  | —                    | 大凌河谷的三个方向，和三种不能混用的时间尺度                            |
| Ⅰ 朝阳之前  | 约 1.3 亿年前 — 前 1000 年 | 化石、聚落与礼仪中心各自留下记录，尚无政权管到这里                         |
| Ⅱ 柳城时代  | 战国 — 238 年           | 燕设五郡、秦开却胡，中原的郡县与长城第一次进入辽西                         |
| Ⅲ 龙城时代  | 294 — 436 年          | 本地政权立都于此，龙城成为中原、草原与辽东的交会点                         |
| Ⅳ 营州时代  | 436 — 10 世纪初         | 降为区域治所，却以帝国东北门户的身份被反复争夺                           |
| Ⅴ 兴中府时代 | 10 世纪 — 14 世纪       | 辽金元的府州体系下，双塔与塔寺群把宗教景观定型                           |
| Ⅵ 边墙内外  | 14 世纪 — 17 世纪初       | 被推出行政体系之外，成为蒙古诸部与辽东军镇之间的通道                        |
| Ⅶ 清代设治  | 17 世纪 — 至今           | 重新被拉回版图，设县建府；1914 年后归热河，1955 年划归辽宁；考古又让地下历史进入公共视野 |

## A.2 关键概念与易混名称

| 概念          | 含义                                                     | 常见误解                          |
| ----------- | ------------------------------------------------------ | ----------------------------- |
| 热河生物群       | 辽西一带以早白垩世陆相生态系统为核心的化石组合                                | 误以为指某一个地点或某一种动物               |
| 红山文化        | 辽西地区新石器时代晚期（约前 4500 — 前 3000）的考古学文化，以玉器与礼仪遗存著称            | 误当成古代族名、国号，或误算作“朝阳建城史”        |
| 考古学文化       | 研究者归纳的一组具有共同特征、分布于一定时空内的遗存                             | 误读成古代国号或现代民族的古称               |
| 辽西走廊        | 沿渤海北岸连接华北与东北的狭长通道                                      | 误当作一条固定的行政边界                  |
| 柳城          | 汉代至唐代文献中反复出现的地名，辽西边郡与交通节点                              | 误以为始终与今天的朝阳市区完全重合             |
| 龙城 / 和龙     | 三燕时期的都城与政治中心，今朝阳城区                                     | 误以为前燕、后燕、北燕三朝都一直以此为都          |
| 营州          | 北朝至隋唐的东北边地军政机构与治所概念                                    | 误以为与内地州县同样直接派官、编户             |
| 羁縻府州        | 唐朝授予当地首领官职、通过其管理部众的间接治理方式                              | 误以为朝廷派流官直接管理                  |
| 互市牙郎        | 边地贸易中熟悉行情与语言的中介人                                       | 误以为是正式官职                      |
| 兴中府         | 辽代 1041 年由霸州升置的府，金代沿置，元代降为兴中州，今朝阳一带                    | 误以为金代就已改州，或误以为元代仍是府            |
| 密檐式砖塔       | 多层屋檐紧密叠置的砖塔，第一层塔身通常较高                                  | 误以为“很多层”就是很多可登临的楼层            |
| 天宫 / 地宫     | 塔内用于安置舍利、经卷、造像的空间，分处塔基之下与塔身之上                          | 误以为是帝王宫殿                      |
| 五世叠压        | 北塔之下依次叠压三燕台基、北魏佛图、隋塔、唐维修层与辽代包砌塔体                       | 误以为同一处地上曾有五座并排的塔              |
| 卫所          | 明代以军事编制管理地方的形式，隶于都司、镇等体系                               | 误当作普通府县，忽略其军事性质               |
| 辽东边墙        | 明代在辽东方向修筑的防务体系，主体在辽河平原边缘                               | 误以为整条大凌河流域都在边墙之内              |
| 外藩蒙古 / 内属蒙古 | 清代蒙古旗的两种安排：前者设世袭扎萨克并编入盟，后者由朝廷任命总管、不设盟                  | 误把两者当成同一套盟旗体系                 |
| 旗地与县治并存     | 清代在同一区域并行运作的两套管理安排，分管不同人口与事务                           | 误以为两者是先后接替的关系                 |
| 三座塔 / 三座塔厅  | 先是民间按城中三座塔对城市的俗称；乾隆三十九年（1774）起又被用作厅名（三座塔厅），1778 年改称朝阳县 | 误以为“三座塔”从未成为正式政区名，或误以为今天仍有三座塔 |

另有一批名称经常被混用。它们字面上部分重合，指向的却不是同一种东西，读文献时最容易在这里出错：

| 名称              | 含义                            | 容易混淆之处                                              |
| --------------- | ----------------------------- | --------------------------------------------------- |
| 大凌河 · 白狼水       | 同一条河流在不同时代的名称                 | 与“白狼山”“白狼县”“白狼城”不是同一种地理实体                           |
| 柳城 · 龙城 · 营州    | 同一片地方在不同时期的名称与建置              | 治所与辖境各有出入，不是边界不变的一个县                                |
| 三燕              | 前燕、后燕、北燕三个政权                  | 不是三个连续接替、始终以龙城为都的王朝                                 |
| 兴中府 · 兴中州       | 辽金两代的府与元代的州                   | 没有“兴中路”这一建置；元代至元七年才降州、隶大宁路                          |
| 大宁都司 · 营州诸卫     | 明初在辽西北部的军事建置                  | 不是府县，不能当作民政单位                                       |
| 辽东边墙            | 明代辽东方向的防务体系                   | 主体在辽河平原边缘，不等于大凌河流域的界线                               |
| 卓索图盟 · 土默特旗     | 清代蒙古的盟旗与旗分                    | 不能与府县系统混为一谈；旗地与县治长期并存                               |
| 喀喇沁 · 土默特 · 科尔沁 | 三支来路不同的蒙古部落                   | 不能因为名字同见于辽西文献就当成一族；朝阳旗地主要来自喀喇沁与土默特，科尔沁的牧地在朝阳东北的哲里木盟 |
| 三座塔             | 旧时对朝阳城市的俗称，1774—1778 年间曾被用作厅名 | 俗称与厅名并存过；东塔毁失后今存两塔                                  |
| 牛河梁             | 红山文化晚期（约前 3500 — 前 3000）礼仪性遗址群    | 位于凌源、建平交界，不等于朝阳市区                                   |

## A.3 朝阳地区历代归属总览

今天的朝阳市在清代才定名，古代各郡、州、府、卫的辖境与现代市界不同；同一时期，今市域也可能分属不同单位。本表用于查对，不用于推演。

| 时期          | 管辖政权或实际控制者             | 主要行政隶属与变化                                                                                 |
| ----------- | ---------------------- | ----------------------------------------------------------------------------------------- |
| 旧石器至新石器时代   | 本地聚落人群                 | 兴隆洼（约前 6200 — 前 5400）、赵宝沟（约前 5000 — 前 4500）、红山（约前 4500 — 前 3000，晚期牛河梁约前 3500 — 前 3000）、小河沿等考古学文化阶段；尚无王朝行政单位可考 |
| 青铜时代        | 本地人群及其组织               | 夏家店下层（约前 2000 — 前 1500）、魏营子（约前 1300 — 前 1000）、夏家店上层（约前 1000 — 前 300）等阶段；农牧并存，与草原方向持续交流 |
| 商、西周至春秋     | 本地人群，与燕国北部接触           | 文献中的“山戎”等称谓指向这一带方位，但尚不能落实到具体行政单位                                                          |
| 战国中晚期       | 燕国                     | 秦开却胡后设上谷、渔阳、右北平、辽西、辽东五郡，修燕北长城；这一带属辽西郡方向                                                   |
| 秦           | 秦朝                     | 沿袭燕制，辽西郡、右北平郡等边郡                                                                          |
| 西汉          | 汉朝                     | 辽西郡等边郡；汉武帝时部分乌桓被安置于边郡地带                                                                   |
| 东汉          | 汉朝，末期控制衰退              | 仍属辽西郡方向；乌桓势力上升，柳城一带成为其政治活动节点                                                              |
| 东汉末 — 238   | 曹操势力、公孙氏辽东政权、三郡乌桓交错    | 207 年白狼山之战后乌桓被削弱并内迁；238 年司马懿灭公孙渊                                                          |
| 3 — 4 世纪初   | 慕容鲜卑等部族首领              | 294 年前后慕容廆经营辽西，吸纳中原人口与制度                                                                  |
| 337 — 370   | 前燕                     | 337 年慕容皝建前燕，341 年营建龙城、342 年迁都；后迁都中原                                                       |
| 384 — 407   | 后燕                     | 慕容垂建后燕；后期以龙城为都城，成为政权根基                                                                    |
| 407 — 436   | 北燕                     | 以龙城为中心；末代君主冯弘东奔高句丽；436 年北魏攻取龙城                                                            |
| 北魏          | 北魏                     | 龙城转为区域治所；485—490 年前后在旧宫基址上营建思燕佛图                                                          |
| 东魏、北齐、北周    | 北朝诸政权                  | 继续控制辽西，建置随政权更替调整；降附人口与军户被安置于此                                                             |
| 隋           | 隋朝                     | 沿用旧城交通条件；602 年前后建舍利塔，延续城市佛教传统                                                             |
| 唐           | 唐朝，军镇与羁縻体系并用           | 以柳城为营州治所；平卢节度使驻营州；松漠都督府（契丹）、饶乐都督府（奚）为羁縻机构                                                 |
| 668 — 698   | 唐朝、契丹、靺鞨等力量交错          | 668 年唐灭高句丽后人口重组；696 年营州事件；698 年前后大祚荣集团建立政权，后号渤海                                           |
| 唐末、五代       | 契丹势力逐步扩展               | 逐渐转入辽朝统治，具体交接过程缺少完整地方记录                                                                   |
| 辽（与北宋并立）    | 辽朝                     | 中京道方向；辽初置霸州，1041 年升兴中府；北塔在重熙年间包砌定型                                                        |
| 金（与南宋并立）    | 金朝                     | 仍置兴中府，属北京路；南塔等建筑留下金代修缮痕迹                                                               |
| 元           | 元朝                     | 至元七年（1270）降兴中府为兴中州，隶大宁路；城市与交通节点继续使用                                                      |
| 明初          | 明朝                     | 设大宁都司及营州左、中、右等卫所，以军事编制管理                                                                  |
| 明中期         | 兀良哈三卫（泰宁、朵颜、福余）势力范围    | 永乐元年（1403）大宁都司徙治保定、营州五屯卫内迁；辽东边墙主体在更东侧的辽河平原边缘，朝阳一带成为长城内外的通道                                |
| 明后期至明末      | 蒙古喀喇沁、土默特等部活动范围        | 喀喇沁、土默特势力相继进入辽西西部与大凌河上游，成为这一带的实际主导力量；同期察哈尔部为蒙古大汗本部，1634 年林丹汗败亡后，诸部先后归附后金                  |
| 清初          | 清朝，蒙旗与民政机构并存           | 主要属土默特左、右翼旗及卓索图盟范围，处柳条边以西北的蒙古旗地环境                                                         |
| 1698 — 1774 | 清朝                     | 1698 年佑顺寺开工，后建成并获赐名；1738 年设塔子沟厅（东境及于这一带）                                                  |
| 1774 — 1904 | 清朝                     | 1774 年析置三座塔厅，治今朝阳市区；1778 年撤厅改设朝阳县，隶直隶省承德府；1904 年升置朝阳府，初领建昌、建平、阜新三县，1909 年增置绥东县，共领四县                      |
| 1913 — 1928 | 中华民国政府；1914 年起为热河特别区   | 1913 年废朝阳府存朝阳县，初隶直隶省；1914 年设热河特别区，脱离直隶省，热河道辖 14 县，朝阳县在列                                   |
| 1928 — 1955 | 热河省（1933 — 1945 为日伪占领） | 1928 年热河特别区改设热河省，朝阳县属之，省会承德；1933 年沦陷，1945 年恢复；1948 年前后中共县政权在全县确立                          |
| 1955 年以后    | 中华人民共和国，辽宁省            | 1949 — 1955 仍属热河省；1955 年 7 月热河省撤销，朝阳、北票、建平、建昌、凌源 5 县及喀喇沁左旗划归辽宁省，由锦州专员公署领导；后设朝阳专区／地区，改设朝阳市 |
