# 08 阶段七·制度路径

前六个阶段讲的是时间线，这一阶段讲的是机制。藏传佛教有两套别的佛教传统少见的制度设计：一是**活佛转世**——用寻访与认定的方式延续一位高僧的法位与寺产；二是**寺院教育**——用扎仓、辩经与格西学位把学修组织成一条可衡量、可考核的路径。理解了这两套机制，再看它的历史，许多事情就顺了。而它们今天如何在法律框架内运作，则是这段历史的当代一章。最后两节还要把前六个阶段放在一起横着看一遍：教权、地方王权与中央皇权这三股力量如何此消彼长，元明清三代的治藏技术又在什么地方不同。

* **13 世纪** 转世制度出现
* **16 — 17 世纪** 格西学位制度成形
* **1793** 金瓶掣签入章程
* **2007** 活佛转世管理办法
* **专题** 三层权力与技术对照

## 7.1 活佛转世：一套怎么运作的制度

**制度**

“活佛”是汉地的习称，藏语称**朱古**（意为“化身”）。这套制度的核心是：一位高僧圆寂之后，通过寻访认定一位幼童作为其“转世化身”，继承其法位与寺产。它同时解决了两个问题——**法统的延续**与**寺产、寺权的继承**。寺院一旦有了大量财产与政治地位，继承问题就变得和法统一样要紧。

认定流程大体包括：圆寂前的预言或遗嘱、护法神的指示、寻访征兆（如遗物、遗言、观湖等）、候选灵童的辨认考验、掣签或认定、报请批准、坐床典礼。**其中“报请批准”这一环，从 1793 年起就是法定程序。**

历史上，藏传佛教的转世系统数以千计，规模大小不一；达赖、班禅、章嘉、哲布尊丹巴等是影响最大的几支。2007 年，国家宗教事务局颁布\*\*《藏传佛教活佛转世管理办法》\*\*，规定活佛转世须遵守宪法法律、遵循宗教仪轨和历史定制，并报政府宗教事务部门批准。

{% hint style="info" %}
**概念辨析｜转世制度不是佛教自古就有的制度。它在 13 世纪才出现（一般认为最早是噶玛噶举的黑帽系），是藏传佛教的一项创造**。把它当成佛教的普遍教义，会误解它的性质：它首先是一套**传承与继承制度**，是为解决“寺院的法位与财产由谁接续”而设计的方案。**“活佛”也不是一个头衔等级，而是指某位高僧的转世化身，各系统之间并无统一的等级序列。**
{% endhint %}

## 7.2 寺院教育：扎仓、辩经与格西

**制度**

大寺院是学校。以拉萨三大寺为例，每座寺下设若干**扎仓**（学院），扎仓下又分**康村**（按籍贯组织的生活与学籍单位）。学僧入学后按班级循序上升，学习**因明、般若、中观、戒律、俱舍**五部大论。

主要方法不是听讲记诵，而是**辩经**。辩经有固定的论式结构：提出“宗”（命题）、给出“因”（理由）、举出“喻”（例证），立论者与问难者就这三者反复攻防，检验逻辑是否严密。**它是一种把义理训练成思维能力的教学法**——也解释了为什么“因明”（逻辑与认识论）在五部大论中排在第一位。

学完一轮后参加**格西**学位考试。格西分不同等级，最高的是**拉然巴格西**（意为“拉萨的博学之人”），此外还有措然巴、林塞、多然巴等。在传召大法会期间举行的辩经考核，是获得高级格西的主要途径。

{% hint style="info" %}
\*\*概念辨析｜格西是“学位”，不是教职，也不是活佛的等级。\*\*考取格西与是否属于转世系统无关；反过来，活佛也要接受教育，但未必都以格西为路径。**把宗教身份（朱古）、学衔（格西）与寺院职务（堪布等）三个体系分开看**，才不会把一个人身上的几种身份混成一件事。这与现代大学里“学位、职称、行政职务”是三条线，道理是一样的。
{% endhint %}

## 7.3 学修的路径：从显宗五部到密宗四续

**教理**

藏传佛教的学修有一条明确的次第，这条传统从阿底峡的《菩提道灯论》一直延续到宗喀巴的《菩提道次第广论》。

{% stepper %}
{% step %}
### 基础

皈依、深信因果、生起出离心与菩提心；依止合格善知识。
{% endstep %}

{% step %}
### 显宗

五部大论——因明（逻辑与认识论）、般若（《现观庄严论》为核心的智慧学）、中观（空性见）、戒律（僧团轨范）、俱舍（《俱舍论》，佛教的宇宙论与心理分类学）。
{% endstep %}

{% step %}
### 密宗

在显宗基础上进入四续部——事续、行续、瑜伽续、无上瑜伽续。正式修持须先受灌顶、依止上师，并有严格的次第与戒律要求。
{% endstep %}
{% endstepper %}

\*\*这条路径的要害是“次第”：它不允许跳级。\*\*显宗未完成，不能进入密法的正式修持。这既是一条教学顺序，也是一种资格制度——它把“能不能修密”的判断权交给了学修的实际进度，而不是身份或地位。

{% hint style="info" %}
\*\*概念辨析｜“先显后密”决定了寺院的形态。\*\*理解了这次第，许多制度才好解释：为什么大寺院要有扎仓（学院）与辩经场，为什么一个显宗的学衔（格西）在寺院体系里分量极重，为什么宗喀巴的改革要从戒律和次第入手。\*\*制度是教理的外壳。\*\*看不懂教理，就只会把寺院当成一个神秘的地方。
{% endhint %}

来源：[中国佛教协会](http://www.chinabuddhism.com.cn/) · [中国大百科全书](https://www.zgbk.com/) · [中国藏学研究中心](http://www.tibetology.ac.cn/)

## 7.4 今天：依法管理与藏传佛教中国化

**当代**

民主改革之后，藏传佛教的宗教活动在法律框架内开展。1980 年代以来，国家投入资金对西藏及其他藏区的寺庙进行维修保护——布达拉宫、大昭寺、扎什伦布寺、萨迦寺等重要文物建筑得到系统修缮；藏文《大藏经》的整理出版、藏传佛教学衔制度的建立（中国藏语系高级佛学院及各地佛学院的学衔授予）、寺院的文物保护与古籍整理，都是这一时期的工作。

与此同时，宗教事务依法管理：宗教活动场所须依法登记，宗教教职人员须备案，活佛转世须按办法报批；国家反对利用宗教从事分裂活动，也反对境外势力借宗教问题干涉中国内政。

\*\*“藏传佛教中国化”的方向，是让宗教在制度、法律与社会环境上与当代中国相适应。\*\*这与它历史上每一次与更大的政治体系相处的经验是一脉相承的：教派的存续离不开所处的社会，而社会也在不断重新安排与宗教的关系。

{% hint style="info" %}
\*\*概念辨析｜依法管理宗教事务，不等于限制宗教信仰自由。\*\*宪法规定公民有宗教信仰自由。**管理针对的是宗教活动的组织与秩序**——场所如何登记、人员如何备案、重大事项如何报批——而不是信仰本身。任何宗教要在现代国家里正常运转，都要有这一层规则；藏传佛教并不例外。
{% endhint %}

## 7.5 三层权力：教权、地方王权与中央皇权

**制度 · 模型**

把前面七个阶段横着叠在一起看，反复出场的力量其实只有三股，而它们各有各的算盘。

**教权（各教派）。它要的是两样东西：生存资源与合法性**。教派之间的教义分歧是真实的，但支撑一个教派站住脚的，是领地、属民、布施与政治庇护——所以它一直在寻找靠山：早先找地方领主，后来找蒙古汗廷，再后来找中原王朝。**谁能给它资源与承认，它就与谁建立关系；这不是投机，而是它赖以生存的条件。**

**地方王权（世俗领主与家族）。它要的是在本地竞争中胜出**。最常用的办法是与教权结合：昆氏家族与萨迦、帕竹（帕木竹巴）与噶举、藏巴汗与噶玛噶举，都是同一个模式——\*\*借宗教的合法性为自己的地方统治背书，同时把寺院的产业纳入势力范围。\*\*教派之争之所以常常比教义更激烈，是因为它同时是领地与人口的争夺。

**中央皇权（元、明、清）。它要的是边界安全与低成本统治**。高原在军事上难以长期驻守、在经济上难以直接产出，因此中原王朝的选择一贯是“以最小成本维持秩序”：能委托就委托，能分势就分势，只有在必要的时候才把制度做实。

三者之间不是固定关系，而是**此消彼长**：中央强，则册封与章程说了算；中央弱，则地方王权与教权的组合说了算。**这条规律，把前面七个阶段串成了一根线。**

## 7.6 元明清治藏：三种治理技术对照

**制度 · 对照**

把元、明、清三代放在一起看，差别不在“管得松还是紧”，而在**把哪一样东西制度化**。

| 历史时期 | 中央核心治理策略                              | 西藏内部权力格局                             | 经济与政体形态             |
| ---- | ------------------------------------- | ------------------------------------ | ------------------- |
| 元朝   | 单点代理：尊奉萨迦一派，通过萨迦本钦间接统治                | 萨迦派一家独大；设宣政院（初名总制院）管理，划分乌思藏十三万户      | 初步形成政教合一的地方政权       |
| 明朝   | 多方制衡：多封众建，三大法王与五大教王并立，互相牵制            | 各教派与世俗家族并起、彼此争斗（帕竹、藏巴汗、噶玛噶举与格鲁派）     | 政教势力割据，庄园经济成熟       |
| 清朝   | 法律规范：册封名号、设驻藏大臣、颁《钦定藏内善后章程二十九条》、立金瓶掣签 | 格鲁派（达赖、班禅两大活佛系统）在中央册封之下执政，噶厦地方政府承办政务 | 制度化的政教合一，噶厦地方政府体制成型 |

三行的差别，说到底是**制度化的对象不同**：元朝制度化的是“谁替中央管事”，明朝制度化的是“谁跟谁互相牵制”，清朝制度化的是“事情按什么程序办”。**到清朝，这套技术已经走到它的极限——它把一个宗教社会的权力关系写成了法规，也因此把宗教与政治绑得比以往任何时候都紧。**

这既是它稳固的理由，也是它在近代面对外部冲击时格外脆弱的原因：\*\*制度一旦固化，要改就必须动整个结构。\*\*1959 年民主改革切断的，正是这条被制度化到极致的捆绑——三股力量之中，教权与地方王权在这一步退出政治领域，只剩中央与地方在一个统一的国家制度里重新安排关系。
