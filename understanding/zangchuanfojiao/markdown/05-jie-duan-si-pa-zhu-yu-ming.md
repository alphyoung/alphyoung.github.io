# 05 阶段四·帕竹与明

明朝没有沿用元朝独尊萨迦的做法，而是把册封分散给多个教派——三大法王、五大教王各自分立、互不统属，同时用朝贡与贸易维系关系。就在这套体系之下，宗喀巴在 15 世纪初创立格鲁派，靠严格的戒律、系统的道次第与新建的三大寺迅速壮大；到 16 世纪后期，“达赖喇嘛”这一名号由蒙古首领赠出、再由清朝正式册封，格鲁派的上升已经有了跨地域的支撑。治理技术上，它的关键词是“因俗分治、分而治之”——把好处摊给多家，让各方互相牵制。这一阶段的转折点，是中央的册封策略从“独尊一派”变成“众建分势”，而教派格局的重心则从噶举转向格鲁。

* **1407** 封大宝法王
* **1409** 甘丹寺 · 大祈愿法会
* **1416—1419** 哲蚌寺 · 色拉寺
* **1578** 俺答汗赠“达赖喇嘛”名号
* **1645** 赠“班禅博克多”之号

## 4.1 明朝的账：为什么不再独尊一派

### 制度

明朝建立后，对高原采取的做法与元朝明显不同。元朝把宗教与地方权力集中授予萨迦一派，结果是一派坐大、内部纷争不断，中央不得不反复介入。

明朝改换了思路：\*\*把封号分散给多个教派与地方首领，使任何一家都无法独大，同时通过朝贡贸易把各方都拉进以明朝为中心的秩序里。\*\*这套做法后世称为“**多封众建**”。

它的成本很低——不需要在高原长期驻军与设省；它的收益也明确——各方为了维持封号与贸易特权，都要与明朝保持往来。同时，明朝在高原东部边缘设有军事与行政机构（都司、卫所），负责通道与联络。

{% hint style="info" %}
**概念辨析｜“多封众建”是一种治理策略，不是“放弃管辖”。**

把封号分给多家，看起来比元朝“松散”，其实目标正好相反：\*\*元朝要靠一家独大来间接管理，结果反被这一家的问题牵制；明朝宁可让各方互相牵制，也不需要一家独大。\*\*这是两种不同的成本—收益计算，而不是治理强度的简单差别。
{% endhint %}

## 4.2 三大法王与五大教王

### 15 世纪

明朝给藏地宗教领袖的封号分两类，两类之间的差别是要害。

**三大法王**——**大宝法王**（1407 年封噶玛噶举黑帽系的得银协巴）、**大乘法王**（1413 年封萨迦派的昆泽思巴）、**大慈法王**（1434 年封格鲁派的释迦也失）。这三位是“法王”，名号最尊，但**没有固定的辖地，称号也不能自行世袭，需要重新请封**。

**五大教王**——**阐化王**（帕竹）、**赞善王**、**护教王**、**阐教王**、**辅教王**。他们是“教王”，与地方权力的结合更紧密，多在明朝的地方军政体系中承担角色。

{% hint style="info" %}
**辨析 · 别把册封读成“任命”或“进贡”**——这些封号不是明朝在西藏“设的官”——受封者不是明朝的流官，也不领明朝的俸禄；但它也绝不是“西藏向明朝自愿送礼”。它是**册封—朝贡体系**的一部分：名号由中央授予，往来按制度进行，双方都在这个体系里获得各自需要的东西。**受封者得到的是合法性与贸易特权，明朝得到的是名义与秩序上的中心地位，以及边疆的稳定。**
{% endhint %}

{% hint style="info" %}
**治理技术｜明朝：因俗分治、分而治之。**

元朝把宝押在一家身上，明朝反过来**把好处摊给多家**：谁来都给封号、都给赏赐、都准朝贡，让各方互相牵制，谁也不足以独大。**它的代价是高原内部长期没有一个稳定的中心**——帕竹、藏巴汗、噶玛噶举与格鲁派之间的争斗一直没有停过，而这些争斗与明朝的分封格局直接相关：\*\*封号给了谁，谁就多了一分压过对手的资本。\*\*换句话说，“分而治之”换来了低成本，也在地方层面留下了长期的动荡。
{% endhint %}

## 4.3 宗喀巴与格鲁派的兴起

### 1357 — 1419

**宗喀巴·洛桑扎巴**（1357—1419）生于安多（今青海湟中，塔尔寺即其诞生地）。他早年广泛学习各派教法，对显宗与密宗都有系统掌握；后来针对当时部分僧人戒律松弛的风气，主张以**严格戒律**为基础重建僧团，并沿着噶当派的路子写下《**菩提道次第广论**》与《**密宗道次第广论**》，把显密修行整理成完整的次第。

1409 年藏历正月，他在拉萨主持**大祈愿法会**（即后来的传召大法会）；同年建成**甘丹寺**——格鲁派（“格鲁”意为“善规”）由此立派。此后，他的弟子陆续建成**哲蚌寺**（1416）与**色拉寺**（1419），与甘丹寺合称**拉萨三大寺**。

三大寺不是三座孤立的寺院：每座寺下设若干**扎仓**（学院），扎仓下又分**康村**（按籍贯组织的生活与学籍单位）。这既是学经机构，也是庞大的寺院经济体。**格鲁派的扩张，靠的是这套“戒律＋学理＋学院”的组合，而不是某一代领袖的个人声望。**

{% hint style="info" %}
**概念辨析｜格鲁派早期被称为“新噶当派”。**

这个称呼说明它的教理来源：宗喀巴继承并系统化了阿底峡与噶当派的道次第传统，只是加上了更严格的戒律要求与更完整的学理组织。\*\*把格鲁派理解成一个突然出现、凭空壮大的新派，会看不出它与前两个阶段的关系。\*\*教派史往往是“继承＋改造”，而不是“从头创造”。
{% endhint %}

## 4.4 “达赖”与“班禅”：两个名号的来历

### 1578 — 1713

今天最知名的两个藏传佛教名号，都不是一开始就有的。

**达赖喇嘛。1578 年，蒙古土默特部首领俺答汗**在青海与格鲁派领袖**索南嘉措**（1543—1588）会面，赠其尊号“圣识一切瓦齐尔达喇**达赖**喇嘛”。此后格鲁派向上追认根敦朱巴为一世、根敦嘉措为二世，索南嘉措即第三世。“达赖”一词来自蒙古语，意为“大海”。

\*\*班禅额尔德尼。\*\*1645 年，蒙古和硕特部首领固始汗赠罗桑却吉坚赞“**班禅博克多**”之号；1713 年，清朝康熙帝正式册封五世班禅罗桑益西为“**班禅额尔德尼**”，并追认前三世。“班”为梵语“班智达”（学者）的略称，“禅”为藏语“钦波”（大）的略称。

**蒙古首领赠号 → 教派内部追认世系 → 中央王朝册封 → 成为定制**

\*\*两个名号的共同点很清楚：都先由蒙古首领赠出，后由中央王朝册封。\*\*这说明格鲁派的上升从一开始就依赖高原之外的政治支持——这是理解此后三百年历史的关键。

{% hint style="info" %}
**概念辨析｜名号是外部授予的，不是自封的。**

“达赖喇嘛”不是自称，也不是格鲁派内部推举的头衔，而是**外部授予、中央确认**的封号。这一点很重要：它意味着这两大活佛系统的合法性，从诞生之初就与中央王朝的承认联系在一起。后来清朝把册封与金瓶掣签制度化，正是沿着这条线往下走。
{% endhint %}
