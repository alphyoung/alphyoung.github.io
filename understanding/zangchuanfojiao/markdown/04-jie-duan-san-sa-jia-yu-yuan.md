# 04 阶段三·萨迦与元

蒙古崛起之后，高原第一次被纳入一个横跨欧亚的政治体系。1247 年，萨迦班智达与蒙古皇子阔端在凉州会面，确立了以归附换取宗教地位与地方权力的安排。此后忽必烈封八思巴为帝师，设总制院（后改宣政院）管理全国佛教与吐蕃事务，在乌思藏划分万户、任命萨迦本钦。治理技术上，它的关键词是“代理人制度”：中央不必亲自下场，只需扶起一家最强的地方宗教势力替它管。这一阶段的转折点，是高原的宗教领袖第一次由中原王朝册封、并凭借这一册封管理地方——政教结合的模型由此确立，但它的合法性来自中央。

* **1260** 八思巴封国师
* **1264** 领总制院
* **1270** 封帝师
* **13 世纪后期** 乌思藏十三万户

## 3.1 凉州会盟：一次改变高原格局的会谈

**1247**

13 世纪，蒙古势力进入河西与河湟，高原的门户被打开。1240 年，蒙古皇子阔端派兵进入吐蕃，随后邀请藏地有影响力的宗教领袖前来会面。1247 年，**萨迦班智达·贡噶坚赞**（1182—1251）带着侄子**八思巴**（1235—1280）抵达凉州（今甘肃武威），与阔端会谈，并发出《萨迦班智达致蕃人书》，说明归附的条件与好处。

这次会面的性质需要说清楚。\*\*它不是一次平等的结盟，而是地方宗教领袖向蒙古汗廷表示归附，并借此获得在藏地宗教与世俗事务上的授权。\*\*但它也不是“征服之后的一纸命令”：蒙古方面需要有人替它管理高原的地方社会，萨迦方面需要更强的外部支持来压过其他教派。双方各有所需，因此谈成了。

这场会谈的长期后果是：\*\*藏地教派之间的竞争，从此多了一个决定性变量——谁能拿到中央王朝的册封。\*\*在此后七百年里，这一变量反复起作用。

{% hint style="info" %}
**概念辨析｜“凉州”在哪里？为什么是凉州？**

凉州即今甘肃武威，处在河西走廊的东段，是从中原进入青藏高原东北缘的要冲。阔端当时受封于河西一带，他的驻地在凉州——\*\*会谈地点的选择本身就是一份地缘说明：蒙古方面是从河西走廊这个方向进入高原的。\*\*这也解释了为什么此后“安多—河西”一线在藏传佛教与中原王朝的往来中长期处于枢纽位置。
{% endhint %}

## 3.2 八思巴与帝师制度

**1260 — 1280**

萨迦班智达于 1251 年去世，八思巴继承其法位。1253 年，八思巴与忽必烈会面，此后长期随侍。元朝建立后，他的地位迅速上升：**1260 年封“国师”，1270 年封“帝师”**，并奉命创制**八思巴文**——一种用于拼写蒙古语、汉语等多种语言的文字。

**帝师制度的实质是：由中央王朝任命一位藏传佛教领袖，作为全国佛教的最高代表，并对吐蕃事务有相当发言权。帝师有极高的宗教地位与丰厚的赏赐，但他没有独立的军政权力**——权力来自皇帝的授予，也随元朝帝位的更替而更换。

{% hint style="info" %}
**辨析 · 三个容易被混为一谈的位置**

* **帝师**：中央册封的宗教最高代表，主持全国佛教事务。
* **萨迦本钦**：“本钦”意为大官，是元朝任命的、负责乌思藏地方行政的官员，多由萨迦系统的人出任。
* **宣政院（初名总制院）**：中央的行政机构，管理全国佛教事务与吐蕃地区军政。

\*\*三者常由同一条人脉网络串联，但职权完全不同：一个是宗教名号，一个是地方行政职务，一个是中央机构。\*\*把它们混成一个“西藏的统治机构”，会看不出元代制度的分层。
{% endhint %}

## 3.3 总制院、宣政院与乌思藏十三万户

**1264 — 13 世纪后期**

元朝管理吐蕃事务的中枢机构是**总制院**（1264 年设立，由八思巴领其事），1288 年改称**宣政院**，兼管全国佛教事务与吐蕃地区的军政。在地方上，元朝在乌思藏划分了**十三万户**，作为基本的行政与户口单位，并在各万户之上设置由中央任命的**萨迦本钦**负责统辖。

这套安排有两个特点。

\*\*第一，把宗教领袖纳入官僚体系。\*\*萨迦派的僧人同时是元朝任命的地方官员，宗教身份与行政职务叠加在同一个体系里。

\*\*第二，不做整齐的郡县化。\*\*元朝没有把高原改造成内地那样的州县，而是保留了大量地方势力与寺院的既有权力，通过万户编制、设置驿站、清查户口、征收赋税来实现控制。

这就是“**因俗而治**”的具体形态：\*\*不改变地方社会的骨架，只把中央的任命与赋税体系架在上面。\*\*明清两代对高原的做法，基本延续了这条思路——只是架设的方式各有不同。

| 层级   | 机构或职位                       | 性质与职权                        |
| ---- | --------------------------- | ---------------------------- |
| 中央   | 皇帝                          | 册封、任命与用兵的最终决定权               |
| 中央   | 总制院（1264 年设）→ 宣政院（1288 年改称） | 管理全国佛教事务与吐蕃地区军政；八思巴曾领其事      |
| 中央册封 | 帝师                          | 全国佛教最高宗教代表，对吐蕃事务有发言权；无独立军政权力 |
| 地方统辖 | 萨迦本钦（“本钦”意为大官）              | 由中央任命，统辖乌思藏地方行政，多由萨迦系统出任     |
| 地方基层 | 乌思藏十三万户                     | 基本的行政与户口单位，负责赋役、驿站与地方事务      |

{% hint style="info" %}
**治理技术｜元朝：代理人制度。**

元朝在高原上不追求整齐的郡县化，而是**挑出最强的一家——萨迦昆氏家族，把地方行政交给它，通过萨迦本钦实行间接统治**。这样做的成本最低：不必长期驻军，不必重编地方社会，只要“一家听命”，就牵住了全局。

风险也同样清楚：\*\*把权柄集中给一家，就等于把自己与这一家的命运绑在一起。\*\*萨迦一衰，元朝在高原上的抓手也就断了——这正是明朝要改换思路的原因。
{% endhint %}

## 3.4 萨迦的衰落与帕竹取而代之

**14 世纪中叶**

萨迦派的权势高度依赖元朝的支持。14 世纪中叶，元朝本身陷入危机，萨迦内部又因家族分裂而争斗不休，实力迅速削弱。1354 年前后，**帕竹噶举**的领袖**绛曲坚赞**（1302—1364）取代萨迦，成为乌思藏最有实力的地方势力，建立**帕竹政权**，首府设在乃东。

帕竹政权的意义在于：\*\*它把政教结合的模型从“家族＋王朝册封”改成了“教派＋地方政权”。\*\*绛曲坚赞推行的一项重要制度是设立“**宗**”——相当于县一级的行政单位，由上级任命“宗本”，任期轮换、不世袭。这项制度后来被明清两代沿用与改造，成为高原基层行政的重要形式。

{% hint style="info" %}
**概念辨析｜元代对吐蕃的管辖，既不是“设省直辖”，也不是“名义宗主权”。**

元朝没有把吐蕃编为行省，但确实设立了专门机构（宣政院）、任命了官员（本钦、万户）、编制了户口、设置了驿站、征收了赋税、还在必要时用兵。\*\*把它说成“元朝直接设省”或说成“只是名义上的宗主权”，都不符合当时的制度设计。\*\*准确的说法是：通过册封与专门机构实现的、保留了地方社会结构的行政管辖。
{% endhint %}
