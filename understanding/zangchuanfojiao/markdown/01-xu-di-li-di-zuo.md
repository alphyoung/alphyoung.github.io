# 01 序·地理底座

藏传佛教的全部历史都发生在同一片高原上。在进入编年之前，先把四件事说清楚——高原内部传统的三大分区，佛教进入高原的几条通道，佛教到来之前的本土宗教，以及藏传佛教的学修结构（显与密）。地理决定它从哪里进来、在哪里扎根；佛教与本土传统的磨合决定它长成什么样子。

## 0.1 三个区，一片高原：卫藏、安多、康区

**地理**

青藏高原平均海拔四千米以上，但它内部并不均质。藏族传统上把高原分为三大区域：**卫藏**、**安多**、**康区**。

**卫藏**以雅鲁藏布江中游的河谷为中心，大体相当于今西藏自治区的中部与西部，包括拉萨、日喀则、山南一带。这里是河谷与农区，也是吐蕃王朝的政治中心、后来各大寺院的集中地——桑耶寺、大昭寺、甘丹寺、哲蚌寺、色拉寺、扎什伦布寺都在这一区。

**安多**大体相当于今青海大部、甘肃南部与四川西北部，是草原、湖泊与牧区。它是高原的东北门户，也是连接河西走廊与中原的通道所在；宗喀巴诞生于安多的湟中（今青海西宁附近），塔尔寺、拉卜楞寺都在这一区。

**康区**横跨今西藏东部、四川西部、云南西北部与青海东南部，是横断山区的高山峡谷与通道地带。它既是贸易走廊，也是教派传播的走廊，历史上德格、昌都等地是重要的印经与学经中心。

{% hint style="info" %}
**疆域 · 别把文化分区当成行政区**——卫藏、安多、康区是**地理与语言文化的分区**，与今天的省界、也不与历史上的郡县或万户边界重合。同一个“康区”今天跨着西藏、四川、云南、青海四个省级单位；而“卫藏”又曾在元代被编成十三万户、在清代分属不同的行政系统。**把传统的三大区直接读成三个行政单元，会看不出人口、语言与教派分布的实际情况。**
{% endhint %}

藏族传统的三大分区。卫藏是雅鲁藏布江中游的河谷农区，吐蕃王廷与后世各大寺院都集中在这里；安多是高原东北的草原与门户；康区是横断山区的高山峡谷与走廊。注意色块边界与虚线所示的今省界并不重合——同一片“康区”今天跨着西藏、四川、云南、青海四个省级单位 · 自制示意图，底图数据：高德行政区划边界

## 0.2 通道：佛教从哪几个方向进入高原

**地理 · 交通**

佛教不是在某一刻从某一个方向整批搬进来的。它进入高原的路线大致有四条，每条带来的东西并不相同。

* \*\*南向——翻越喜马拉雅。\*\*从尼泊尔、印度经吉隆、聂拉木一线的山口进入卫藏。这是与印度佛教联系最直接的一条，也是 11 世纪阿底峡等人进藏的路线。它带来的是戒律、中观学理与密宗的传承。
* \*\*东向——唐蕃古道。\*\*自长安经陇右、河湟入藏。文成公主（641 年）、金城公主（710 年）入藏走的都是这个方向；随行的汉地僧人与工匠，把汉传佛教的制度与技艺带进高原。桑耶寺的建立与早期的译经，有汉僧参与其中。
* \*\*西北向——经河西走廊与西域。\*\*经于阗、敦煌一线进入青藏高原东北缘。这条通道在后来的“后弘期”尤其重要：经河西、安多方向重新传回卫藏的佛教，一般与“下路弘法”相联系。
* \*\*北向——越过大漠进入蒙古。\*\*13 世纪以后才开通。蒙古势力进入高原，藏传佛教随之传入蒙古各部，形成延续数百年的蒙藏宗教联系。这条线的方向与前面三条相反：它把高原来的宗教送出去，而中亚、蒙古的军事与政治力量则送进来。

{% hint style="info" %}
**术语辨析｜“上路”与“下路”不是两条地理通道，而是两个复兴方向。**“后弘期”佛教重新传回卫藏，史料称有“上路弘法”与“下路弘法”：**上路**指从西部的阿里地区重新传入，**下路**指从东北部的安多地区重新传入。“上/下”是以卫藏为参照的方向概念，不是海拔高低的区别，也不是两条具体道路的名称。
{% endhint %}

## 0.3 佛与苯：不是谁取代了谁

**宗教史**

佛教传入之前，高原上已有本土宗教——**苯教**（也写作“本教”）。它有自己的祭司（“辛”）、祭祀仪式、神灵体系与宇宙观，与早期的王室政治关系密切：祭祀、占卜、驱邪、丧葬都由苯教祭司承担。

佛教与苯教相遇之后，历史是长期的**相互影响**，而不是一方把另一方抹掉。佛教吸收了高原原有的神灵与祭祀形式，把它们安置进佛教的护法体系；苯教则在后来大量吸收佛教的教理、戒律与寺院制度，形成今天所说的“雍仲苯教”，其经典体系与寺院组织已带有明显的佛教色彩。

与此同时也有冲突。8 世纪赤松德赞时期，王室主持过佛苯之间的辩论，苯教一度受到压制，部分苯教经典被埋藏或改写成佛教的名义。这场冲突的实质往往不只是教义之争，也是**两种祭司集团对王室地位的争夺**。

{% hint style="info" %}
\*\*概念辨析｜藏传佛教不是“苯教改头换面”，也不是“印度佛教的纯正移植”。\*\*把它说成前者，会抹掉印度、汉地两大佛教传统输入的大量经典与学理；说成后者，则抹掉了它在高原上经历的调适与再造。今天能看到的藏传佛教形态——护法神体系、祭祀仪轨、寺院组织形式——是外来佛教与本地传统长期磨合的产物。
{% endhint %}

## 0.4 显与密：藏传佛教不等于“密宗”

**教理 · 制度**

汉地习惯把藏传佛教叫作“密宗”或“喇嘛教”，这两个称呼都不准确。“喇嘛教”是外部的旧称，藏语本身不使用；而“密宗”只对应它的一部分内容。

藏传佛教的学修有明确的**次第**，大体分两段：

* **显宗阶段**——以“五部大论”为核心：**因明**（逻辑与认识论）、**般若**（以《现观庄严论》为中心的智慧学）、**中观**（空性见）、**戒律**（僧团轨范）、**俱舍**（《俱舍论》，佛教的宇宙论与心理分类学）。这是僧人在寺院里用十几年甚至几十年完成的功课。
* **密宗阶段**——在显宗基础上进入**四续部**：事续、行续、瑜伽续、无上瑜伽续。密法的正式修持须先受灌顶、依止合格上师，并有严格的次第与戒律要求。

这条次第的要害在于：\*\*它不允许跳级。\*\*显宗未完成，不能进入密法的正式修持。也正因如此，藏传佛教的大寺院首先是一所讲逻辑与义理的学校，然后才是密法修持的场所。

{% hint style="info" %}
\*\*概念辨析｜“先显后密、先理后修”是它的结构。\*\*把藏传佛教理解成“直接修法、神秘玄妙”，正好把它的顺序讲反了。理解这一点之后，许多制度才好解释：为什么大寺院要有扎仓（学院）和辩经，为什么格西学位（一个显宗学衔）在寺院体系里分量极重，为什么宗喀巴的改革要从戒律和次第入手。
{% endhint %}
