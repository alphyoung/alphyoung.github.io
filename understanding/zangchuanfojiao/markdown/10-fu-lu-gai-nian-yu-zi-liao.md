# 10 附录：概念与资料

把反复出现的关键概念集中解释，并给出两张可以直接查对的表：一张看教派格局与中央王朝的关系，一张看名称与人物。

## A.1 七阶段脉络一览

| 阶段     | 跨度           | 一句话主题                          | 治藏技术关键词          |
| ------ | ------------ | ------------------------------ | ---------------- |
| 序 地理底座 | —            | 一片高原、三个分区、几条通道，加上显与密的学修结构      | —                |
| Ⅰ 佛教入藏 | 7 — 9 世纪     | 佛教由印度与汉地传入，被立为王朝宗教，又随王朝崩溃而中断   | 王室供养 · 自上而下      |
| Ⅱ 教派林立 | 10 — 12 世纪   | 佛教从阿里与安多两个方向回来，靠领主供养长出多个独立教派   | 领主供养 · 自下而上      |
| Ⅲ 萨迦与元 | 13 — 14 世纪   | 凉州会盟确立归附关系，中央册封一派代管地方，政教结合由此开端 | 代理人制度（独尊萨迦）      |
| Ⅳ 帕竹与明 | 14 — 17 世纪前期 | 明朝多封众建分势，格鲁派在册封体系之下兴起          | 因俗分治 · 多封众建      |
| Ⅴ 格鲁与清 | 17 — 18 世纪   | 政教合一体制定型，中央以驻藏大臣、章程与金瓶掣签直接管辖   | 法规化管辖（章程 · 金瓶掣签） |
| Ⅵ 近代转型 | 19 世纪 — 1959 | 抗英、民国藏事、和平解放与民主改革，政教合一制度终结     | 维护主权 · 制度终结      |
| Ⅶ 制度路径 | 专题           | 转世制度与寺院教育的运作机制，及其当代的法律框架       | 三层权力模型 · 古今对照    |

## A.2 关键概念表

| 概念             | 含义                                                                      | 常见误解                                 |
| -------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| 藏传佛教           | 以藏文为经典语言、显密兼修的佛教传承体系，流传于青藏高原及蒙古等地区                                      | 误等同于“密宗”，或误当作一个统一的组织                 |
| 卫藏 · 安多 · 康区   | 高原传统的地理与语言文化三分区：卫藏为河谷农区，安多为草原牧区，康区为高山峡谷通道                               | 误当作三个行政单元，或等同于今天的省界                  |
| 苯教             | 佛教传入前高原上的本土宗教，后与佛教长期互动，形成佛教化程度较高的雍仲苯教                                   | 误以为被佛教彻底消灭，或误以为藏传佛教只是苯教的改头换面         |
| 前弘期 · 后弘期      | 以 9 世纪中叶朗达玛灭佛为界，佛教在吐蕃的传入期与复兴期                                           | 误以为“灭佛”期间佛教彻底消失——安多、阿里仍有传承存续         |
| 上路弘法 · 下路弘法    | 后弘期佛教传回卫藏的两个方向：上路指从阿里传入，下路指从安多传入                                        | 误当作两条具体道路，或以海拔高低理解“上/下”              |
| 伏藏             | 相传由莲花生等人埋藏、后世由掘藏师取出的经典，是宁玛派经典的重要来源                                      | 误当作普通的“考古发掘”，忽略它是一种宗教传统内的经典传承方式      |
| 活佛转世（朱古）       | 通过寻访认定转世化身以继承高僧法位与寺产的传承制度，13 世纪出现                                       | 误当作佛教自古的普遍教义，或误当作一个统一的头衔等级           |
| 金瓶掣签           | 1793 年确立的转世认定程序：候选灵童名字入瓶当众掣取，并报中央政府批准                                   | 误当作纯粹的宗教仪轨，或误当作“外部干涉”而忽略它针对的是转世舞弊    |
| 政教合一           | 13 世纪以后逐步形成的、宗教权威与地方政权合为一体的治理形态，1959 年终结                                | 误当作藏传佛教的固有属性或自古如此的制度                 |
| 帝师             | 元朝册封的藏传佛教领袖，作为全国佛教最高代表，并对吐蕃事务有发言权                                       | 误当作“西藏的国王”，忽略其权力来自皇帝授予、无独立军政权        |
| 宣政院            | 元朝管理全国佛教事务与吐蕃地区军政的中央机构，初名总制院（1264 年设）                                   | 误当作西藏的地方政府                           |
| 乌思藏十三万户        | 元朝在乌思藏划分的十三个行政与户口单位，本钦由中央任命                                             | 误当作整齐的州县建制，忽略元朝保留了大量地方势力与寺院的既有权力     |
| 多封众建           | 明朝把封号分散授予多个教派与地方首领的策略，避免一家独大                                            | 误当作“放弃管辖”，忽略它是另一种成本更低、更能互相牵制的治理方式    |
| 甘丹颇章           | 1642 年建立的格鲁派掌权的政权，因哲蚌寺的甘丹颇章宫得名                                          | 误当作“教派统治世俗”的单主体结构，忽略蒙古军事力量与地方贵族的同时存在 |
| 驻藏大臣           | 清朝 1727 年起派驻西藏的常设官员，与达赖、班禅共同管理政务                                        | 误当作外国使节或只负责联络的观察员                    |
| 噶厦             | 1751 年正式设立的原西藏地方政府，设噶伦四人（三俗一僧），秉承达赖喇嘛与驻藏大臣指示处理政务                        | 误当作与中央并行的“政府”，忽略其官员任命须经中央核准          |
| 庄园经济           | 寺院与世俗领主占有土地、牧场与依附人口形成的经济形态，是政教合一体制的物质基础                                 | 误以为寺院只靠布施度日，忽略它同时是领地主与债权人            |
| 西姆拉会议 ·“麦克马洪线” | 1913—1914 年英国在西姆拉会议上提出的分裂方案；会议破裂、**所谓“西姆拉条约”无效**，英方私划的“麦克马洪线”中国历届政府从未承认 | 误当作有效的国际条约或已划定的边界                    |
| 扎仓 · 康村        | 大寺院下的学院（扎仓）与按籍贯组织的生活学籍单位（康村）                                            | 误以为寺院只是一个修行场所，忽略它同时也是一所学校与一个经济体      |
| 格西             | 显宗学衔，分拉然巴、措然巴、林塞、多然巴等等级，靠辩经考核取得                                         | 误当作教职或活佛的等级                          |
| 唐卡             | 可卷收携带的宗教绘画（也有刺绣、缂丝），兼具教具、法器与供奉功能                                        | 误当作纯粹的艺术品或装饰画                        |

## A.3 教派格局与政权关系总览

本表用于查对。同一时期常有多个教派并存，表中只列影响最大者；中央政权对高原的管辖方式，随朝代而变。

| 时期                | 中央政权或主导力量      | 教派格局                   | 制度安排                                                                                                      |
| ----------------- | -------------- | ---------------------- | --------------------------------------------------------------------------------------------------------- |
| 7 — 9 世纪          | 吐蕃王朝           | 佛教由印度、汉地传入；佛苯相争后佛教渐占上风 | 王室供养；设译经院、厘定译语；本土僧团出现；无中央王朝介入                                                                             |
| 9 世纪中叶 — 10 世纪    | 吐蕃分裂，无统一政权     | 佛教在卫藏中断，安多、阿里仍有传承存续    | 无统一管辖                                                                                                     |
| 10 — 12 世纪        | 宋朝（中原）与各地方势力并立 | 噶当、萨迦、噶举、宁玛等教派先后形成     | 无统一管辖；教派依附地方领主供养，寺院经济成形                                                                                   |
| 13 — 14 世纪        | 蒙古汗廷 · 元朝      | 萨迦派取得主导                | 1247 凉州会盟；封国师（1260）、帝师（1270）；设总制院（1264，1288 改宣政院）；置乌思藏十三万户、任命萨迦本钦                                         |
| 14 世纪中叶 — 17 世纪前期 | 明朝             | 帕竹噶举当政；噶举各支与格鲁派并起      | 多封众建：三大法王（1407 起）、五大教王；朝贡贸易；设都司、卫所                                                                        |
| 17 — 18 世纪        | 清朝             | 格鲁派掌权（甘丹颇章政权，1642）     | 册封五世达赖（1653）、五世班禅（1713）；设驻藏大臣（1727）；《钦定藏内善后章程二十九条》（1793）；金瓶掣签                                             |
| 19 世纪末 — 1911     | 清朝             | 格鲁派主导                  | 1888、1904 两次抗英；清末新政整顿藏事（1906 起）；驻藏大臣制度延续                                                                  |
| 1912 — 1949       | 中华民国           | 格鲁派主导                  | 设蒙藏事务机构（后称蒙藏委员会）；按历史定制处理册封、致祭与联络（1919 年派员入藏联络，1940 年批准并派员主持十四世达赖坐床典礼）；1913—1914 年西姆拉会议，英国私划“麦克马洪线”，中国从未承认 |
| 1951 — 1959       | 中华人民共和国        | 格鲁派主导                  | 1951 和平解放，签订“十七条协议”；1959 平叛后实行民主改革                                                                        |
| 1959 — 1965       | 中华人民共和国        | 政教合一制度废除               | 民主改革：废除政教合一与寺院封建特权、废除封建农奴制（1961 年基本完成）                                                                    |
| 1965 年 — 至今       | 中华人民共和国        | 各教派依法开展宗教活动            | 1965 年西藏自治区成立，实行民族区域自治；宗教事务依法管理；2007 年《藏传佛教活佛转世管理办法》                                                      |

## A.4 教派与人物速查

| 名称     | 要点                                     | 容易混淆之处                            |
| ------ | -------------------------------------- | --------------------------------- |
| 宁玛派    | “古旧派”，奉莲花生为祖师，以旧译密法与伏藏为特色，跨越前弘期与后弘期    | 并非“最古老的原始佛教”，其组织也是后弘期才成形的         |
| 噶当派    | 阿底峡传《菩提道灯论》，仲敦巴建寺立派，以“道次第”为核心          | 后来不再作为独立大派传续，但教理被格鲁派继承，分量不可低估     |
| 萨迦派    | 1073 年昆·贡却杰布建寺；道果法；昆氏家族世袭寺主            | “花教”是俗称；其寺主世袭不代表整个教派都是家族组织        |
| 噶举派    | 玛尔巴—米拉日巴—塔波拉杰一系；大手印、那若六法；分出“四大八小”      | “四大八小”是后世归纳的谱系，不是当时就有的名录          |
| 格鲁派    | 宗喀巴 1409 年立派；严格戒律、道次第、三大寺；俗称“黄教”       | 早期被称为“新噶当派”，并非凭空出现的新派             |
| 莲花生    | 8 世纪受邀入藏，处理佛苯冲突，建立密法传入通道；宁玛派奉为祖师       | 宗教传统中的祖师传记与史书中的参与者，是两套不同性质的材料     |
| 阿底峡    | 1042 年入藏，著《菩提道灯论》，确立“由显入密”的次第          | 他并非格鲁派祖师，而是格鲁派教理的上游来源             |
| 萨迦班智达  | 1247 年与阔端凉州会盟，发出《致蕃人书》                 | 他不是“向蒙古投降”，而是代表地方与蒙古汗廷确立归附与授权关系   |
| 八思巴    | 萨迦班智达之侄；1260 封国师、1270 封帝师；创制八思巴文       | 帝师是宗教封号，不等于地方行政长官                 |
| 宗喀巴    | 1357 年生于安多；1409 年主持大祈愿法会、建甘丹寺          | 他不是“改革掉了其他教派”，而是以戒律与次第重整僧团        |
| 达赖喇嘛   | 1578 年俺答汗赠号，格鲁派向上追认世系，1653 年清朝正式册封五世达赖 | 不是自称的头衔，是外部授予、中央确认的封号             |
| 班禅额尔德尼 | 1645 年固始汗赠“班禅博克多”，1713 年康熙帝正式册封五世班禅    | 与达赖并列为格鲁派两大活佛系统，不是同一系统的两个等级       |
| 绛曲坚赞   | 帕竹噶举领袖，14 世纪中叶取代萨迦，建立帕竹政权；创立“宗”制       | “宗”是行政单位，与今天作为行政区划名称的“县”层级相近而来源不同 |
| 固始汗    | 和硕特部首领，1642 年攻灭第悉藏巴，扶助格鲁派建立甘丹颇章政权      | 他的角色是外部军事支持者，不是“西藏地方政府的官员”        |
