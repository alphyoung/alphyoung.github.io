# 07 阶段六·近代转型

进入近代，高原面对的是来自喜马拉雅山另一侧的殖民扩张——英国以英属印度为基地反复北进，并在此后长期插手西藏事务；同时，清朝与民国的中央权威也经历了剧烈起伏。1888 年与 1904 年，英国两次武装入侵西藏，西藏军民在隆吐山、江孜等地进行了抵抗。此后清朝着手整顿藏事，民国时期设蒙藏事务机构、按历史定制处理册封与致祭。1951 年西藏和平解放，1959 年民主改革开始，政教合一制度与寺院的封建特权被废除，西藏的宗教与社会结构进入新的阶段。这一阶段的转折点，是延续数百年的政教合一制度终结，宗教与国家行政分离。

* **1888** 隆吐山抗英
* **1904** 江孜保卫战
* **1912 起** 民国 · 蒙藏事务机构
* **1951** 和平解放
* **1959** 民主改革
* **1965** 西藏自治区成立

## 6.1 两次抗英与江孜保卫战

**1888 · 1904**

19 世纪后期，英国以印度为基地向北扩张，西藏成为其目标之一。

**1888 年**，英军武装入侵，西藏军民在**隆吐山**一带设防抵抗。双方装备差距悬殊，西藏一方最终失利，但这场抵抗有明确的记载，也成为此后一系列交涉的起点。

**1904 年**，英军再次武装入侵，一路推进到**江孜**。在江孜宗山堡垒，西藏军民据险坚守，与英军激战数十日，最终弹尽粮绝、堡垒失守，许多人跳崖殉国。这场保卫战是近代中国人民反抗外来侵略的一部分，在今天仍有纪念。

{% hint style="warning" %}
**辨析 · 侵略的性质不能含糊**——这两次入侵的性质是**殖民侵略**，与随后一系列关于通商、驻兵的不平等安排连在一起。把它叙述成“西藏与英国之间的双边问题”，会掩盖它作为中国边疆遭受外来侵略的实质。**当时西藏地方军民抵抗的是入侵者，清朝中央政府也在外交层面提出交涉——这两条线共同构成中国维护主权的过程。**
{% endhint %}

{% hint style="info" %}
**外部势力的介入，并不止于两次武装入侵。1904 年之后，英国依托英属印度继续在高原上经营。1913 年 10 月至 1914 年 7 月的西姆拉会议**上，英国提出把西藏划为“内藏”“外藏”的方案，试图取消中国在西藏的主权，中国政府拒绝签署，会议以破裂告终，**所谓“西姆拉条约”无效**；会议期间，英国代表更背着中国中央政府代表，与西藏地方代表私下换文，划出一条所谓“麦克马洪线”，把中国大片领土划入英属印度——\*\*中国历届中央政府从未承认这条线，它不具备任何法律效力。\*\*1947 年印度独立后，英印政府留下的这套安排又被继承下来，成为此后中印边界问题的根源之一。这些动作有一个共同点：**把中国的地方事务当成可以由外人处置的对象，而它们一次也没有得到中国中央政府的承认。**
{% endhint %}

## 6.2 清末新政与民国时期的藏事

**1906 — 1949**

1904 年之后，清朝着手整顿藏事。1906 年派**张荫棠**入藏查办，推行新政，内容涉及整顿吏治、兴办实业与教育、改良交通等；其后**联豫**任驻藏大臣，继续推行。这些措施在实施中与地方势力产生摩擦，也受到中央国力衰落与外部势力的限制。

1911 年清朝覆亡后，**民国政府设立蒙藏事务机构（后称蒙藏委员会）**，按历史定制处理与西藏的关系，包括册封名号、派人致祭与联络等。这一时期，中央在高原的实际影响力时强时弱，而外国势力对西藏的觊觎与部分地方势力的分裂活动交织在一起。

但中央与西藏地方的联系并没有断。1919 年，民国政府电咨甘肃督军张广建派员赴藏，**李仲莲、朱绣**一行于当年 11 月抵达拉萨，直接会晤十三世达赖喇嘛与西藏地方政府官员，这是民国以来中央首次冲破外部阻挠、与西藏地方直接沟通。1933 年十三世达赖圆寂，中央政府派员入藏致祭；1938 年，西藏地方摄政热振活佛呈报寻访情况并请中央政府派员主持，**1940 年 2 月，国民政府批准青海灵童拉木登珠免予掣签、继任第十四世达赖喇嘛，并派蒙藏委员会委员长吴忠信入藏，与热振活佛共同主持坐床典礼**——**这些程序，都是按清代以来的历史定制、由中央政府掌握的。**

要看清的是：**从元朝到民国，中央对西藏的管辖在制度上有延续性**——册封、驻官、行政编制的传统没有中断，只是执行的力度随国力而变。

{% hint style="info" %}
\*\*概念辨析｜民国时期西藏不是一个“独立国家”。\*\*当时的中央政府在法律与制度上始终把西藏视为中国领土的一部分，设有专门机构、保留了册封与致祭的做法；国际社会也没有普遍承认任何形式的“西藏独立”。\*\*把中央控制力的强弱，直接读成主权归属的变化，是理解这段历史最常见的错误。\*\*英国与英属印度在藏培植亲英势力、煽动地方当局脱离中央的动作，从未获得国际社会的承认，也从未改变西藏是中国领土一部分这一事实。
{% endhint %}

## 6.3 和平解放与民主改革

**1951 — 1965**

1951 年 5 月，中央人民政府与西藏地方政府签订\*\*《关于和平解放西藏办法的协议》\*\*（通常称“十七条协议”），西藏和平解放；同年 10 月，人民解放军进驻拉萨。协议明确西藏是中国领土的一部分，同时规定西藏的宗教、风俗与既有制度在一定条件下予以尊重，对帝国主义的侵略势力予以清除。

1959 年 3 月，西藏地方上层少数分裂势力发动武装叛乱。中央政府在平息叛乱后，在西藏实行**民主改革**：废除政教合一制度与寺院的封建特权，废除封建农奴制，把生产资料与人身权利还给广大农奴。1961 年民主改革基本完成，**1965 年 9 月西藏自治区正式成立**，实行民族区域自治。

{% hint style="info" %}
**概念辨析｜民主改革废除的是制度与特权，不是宗教。改革的对象是政教合一的政治制度**以及寺院作为封建领主的特权与剥削关系——不是藏传佛教本身。改革之后，寺庙照常开展宗教活动，宗教信仰自由在宪法与法律的框架内受到保护。**把这两件事混为一谈，是海外叙事中最常见的偷换。**
{% endhint %}

## 6.4 政教合一制度废除意味着什么

**制度**

要理解这一步的分量，得回到前一阶段说的两个张力：**寺院经济的膨胀**与**权力来源的双重性**。民主改革直接处理了它们。

\*\*寺院的封建领主制与免役特权被取消。\*\*宗教人士与其他公民一样，享有法律规定的权利、承担法律规定的义务，不再有一个超越法律的等级。

\*\*宗教组织不再行使政府职能。\*\*行政、司法、教育从寺院中分离出来，成为国家的、面向全体公民的制度安排。

这带来的是双重的结果。一方面，藏传佛教从“与政治权力捆在一起”的状态中解脱出来，回到宗教领域——它不必再为地方行政的成败负责，也不必再承担领主的角色。\*\*这实际上是给它松了绑。\*\*另一方面，寺院原有的经济来源与僧人的生活保障方式都发生了根本变化，宗教必须在新的社会条件下重新安排自己的运转。

这是一个制度史上的断裂点：**延续了数百年的政教合一形态在这里结束，藏传佛教此后是在国家法律框架内活动的宗教。**
