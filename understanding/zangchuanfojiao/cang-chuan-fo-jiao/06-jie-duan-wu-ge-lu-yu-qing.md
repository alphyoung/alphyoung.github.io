# 06 阶段五·格鲁与清

1642 年，格鲁派在蒙古和硕特部的军事支持下建立甘丹颇章政权，成为高原上最有实力的政治—宗教力量。此后清朝一步步把管辖制度化：1653 年册封五世达赖，1713 年册封五世班禅，1727 年起设立驻藏大臣，1793 年颁布《钦定藏内善后章程二十九条》，并把金瓶掣签写入其中。治理技术上，它的关键词是“制度化”：清朝一面尊奉其教，一面把外交、军事、财政、人事与转世认定的权力逐项写进章程。这一阶段的转折点，是“政教合一”从格鲁派的一家之政，变成在中央监督下运作的地方制度——宗教领袖的认定权、地方官的任命权、军队与对外交涉权，都收归中央掌握。

* **1713** 册封五世班禅
* **1727** 设驻藏大臣

## 5.1 甘丹颇章：格鲁派怎样掌权

**1642**

1642 年，和硕特部首领**固始汗**攻灭第悉藏巴政权，把乌思藏的地方权力交给**五世达赖喇嘛阿旺洛桑嘉措**（1617—1682），建立**甘丹颇章**政权（因哲蚌寺的甘丹颇章宫得名）。这是格鲁派第一次成为掌权的教派。

要注意的是，这里的关系并不是“教派统治世俗”这么简单，而是**三方并存**：蒙古军事力量提供保护，格鲁派的宗教权威提供合法性，原有的世俗贵族与地方势力继续承担基层治理。所谓“政教合一”的“合一”，是**权力在不同主体之间的一种组合方式**，而不是一个人同时当国王和教主。

这种组合方式也留下了长期的内部分歧：蒙古势力与格鲁派之间、以及格鲁派内部不同系统之间，对权力如何分配始终存在张力。18 世纪前期高原政局的多次动荡，都与这些张力有关。

## 5.2 五世达赖进京与“达赖喇嘛”的正式册封

**1652 — 1713**

1652 年，五世达赖应顺治帝之邀启程赴京，次年（1653 年）抵达北京，受到高规格接待。同年，清朝正式册封其为“西天大善自在佛所领天下释教普通瓦赤喇但喇达赖喇嘛”，并赐金册、金印。

这次册封确立了三件事：

* **第一，达赖喇嘛这一封号由中央政府正式确认**，从此是一个需要中央册封的名号；
* **第二，清朝借此确立了自己在藏传佛教事务中的最高地位**；
* **第三，格鲁派获得了来自中原王朝的背书**，在与蒙古各部及其他教派的竞争中占据了主动。

1713 年，康熙帝册封五世班禅罗桑益西为“班禅额尔德尼”，同样赐金册、金印。**达赖、班禅两大活佛系统的册封权，自此都在中央。**

## 5.3 驻藏大臣与《钦定藏内善后章程二十九条》

**1727 — 1793**

18 世纪前期，高原政局屡生动荡。1720 年清朝派兵入藏，驱逐准噶尔势力；**1727 年（雍正五年）正式设立驻藏大臣**，作为中央派驻西藏的常设官员。1751 年，清朝在平定动乱之后颁布善后章程，确立驻藏大臣与达赖、班禅共同管理政务的格局，并改组了地方政府机构。

1793 年（乾隆五十八年），清朝在击退廓尔喀入侵之后颁布\*\*《钦定藏内善后章程二十九条》\*\*。这份章程把中央对西藏的管辖具体化，涉及的内容包括：驻藏大臣的地位与职权，达赖、班禅及各大活佛的转世认定程序，地方政府官员的任免，军队的编制与训练，财政与赋税，对外交涉与边境管理。

{% hint style="info" %}
\*\*它的性质要看清：这是中央政府对西藏地方事务作出系统规定的行政法规，是“管辖制度化”的标志。\*\*此后的近两百年里，它一直是中央管理西藏事务的基本依据。
{% endhint %}

{% hint style="info" %}
**治理技术｜清朝：明尊其教，暗抑其势。**

清朝面对的局面与元明都不同：格鲁派已经通过俺答汗赠号（1578）与固始汗入藏（1642）完成“蒙藏结盟”，背后站着蒙古军事力量——既不能像元朝那样只扶一家，也不能像明朝那样只撒封号。**清朝的做法是一面抬高其宗教地位，一面把实权拆开来收进制度**：册封名号（1653、1713）、设驻藏大臣（1727）、1751 年颁《酌定西藏善后章程》十三条并正式设立噶厦、1793 年以《钦定藏内善后章程二十九条》把外交、军事、财政、人事与活佛转世认定逐项写成条文。**元朝靠“代理人”，明朝靠“分而治之”，清朝靠“写成法规”——治藏的重心，从此落在常设官员与成文法规上。这是三个阶段里技术跨度最大的一步。**
{% endhint %}

{% hint style="info" %}
**辨析 · 驻藏大臣不是“外国使节”**

驻藏大臣是**清朝派驻地方的官员**，代表中央在西藏行使职权，与达赖、班禅是共同管理的关系，重大事项须报中央批准。他既不是“外国的代表”，也不是“只负责联络的观察员”——\*\*章程把外交、军事、财政与人事等实际权力都写在他的职权范围内。\*\*理解这个位置，才理解清代西藏制度的实际运作方式。
{% endhint %}

## 5.4 金瓶掣签：转世认定权归谁

**1793**

活佛转世是藏传佛教特有的传承方式。到 18 世纪，围绕转世的寻访与认定出现了不少争执——涉及哪个家族、哪股势力、哪一派的利益，甚至影响到地方政局的稳定。

1793 年的善后章程对此作出明确规定：**达赖、班禅及各大活佛的转世灵童认定，须经金瓶掣签确定，并报中央政府批准。**

具体做法是：将寻访到的候选灵童的名字写在签上，放入金瓶，在朝廷派员或驻藏大臣的监督下当众掣取一签，掣中者认定为转世灵童；若只有一名候选灵童，仍须掣签确认，或按程序申请免予掣签并报请批准。清朝为此制作了两个金瓶，一置于**拉萨大昭寺**，一置于**北京雍和宫**。

\*\*这一制度的实质，是把转世的最终认定权从地方转移到了中央。\*\*此后两百多年，金瓶掣签成为历史定制。

{% hint style="info" %}
**概念辨析｜“金瓶掣签”是程序，也是管辖权的行使形式。**

把它单说成“中央干涉宗教”，会漏掉它要解决的问题——**它是为制止转世中的舞弊与势力争夺而设计的程序**（当时的转世认定常常被某些家族或势力左右）。把它单说成“纯粹的技术程序”，又会漏掉它的政治含义。两者是同一件事的两面：一个为纠正乱象而设的公认程序，同时也是中央行使管辖权的具体方式。
{% endhint %}

## 5.5 政教合一：这套制度究竟怎么运转

**制度**

“政教合一”常被说成一个抽象原则，其实它有很具体的机构与运作方式。以甘丹颇章政权为例：

* \*\*它的地方政府就是噶厦。\*\*噶厦设噶伦四人（三俗一僧）、地位平等，秉承达赖喇嘛与驻藏大臣的指示共同处理地方政务——这是 1751 年清朝颁行《酌定西藏善后章程》十三条时正式确立下来的，也是“政教合一”体制成型的具体形态。**读近代西藏政局，“噶厦”是一个绕不开的名字。**
* \*\*宗教权威与世俗官职并置。\*\*达赖喇嘛及三大寺的堪布、僧官，与噶厦的噶伦、代本等世俗官职，同处一套政府之中。
* \*\*地方政府同时管寺院。\*\*行政机构既处理民政，也管理寺院与寺属庄园。
* \*\*大寺院本身是领地主与债权人。\*\*它们占有土地与依附人口，享有免役等特权，参与贸易与放贷。
* **僧官与俗官由不同渠道产生**，却都在同一个体系里任职、共同议政。

这套结构里有两个内在张力，理解它们是理解后面两阶段的关键。

* \*\*一是寺院经济的膨胀。\*\*大量土地、人口与财富集中在寺院手里，而世俗生产者的负担不断加重。
* \*\*二是权力来源的双重性。\*\*宗教权威来自教派内部的传承与声望，行政权力来自中央的册封与任命——一旦中央控制力下降，就容易被外部势力与内部分裂力量利用。

这两点张力，决定了它在近代必须面对的问题，也是 1959 年民主改革要处理的核心内容。
