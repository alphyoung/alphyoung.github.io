# 2.3 专家系统范式（1974—1993）

## 2.3.1 从通用推理转向领域知识

新一轮热潮源于一次务实的路线修正：既然通用推理难以实现，则将领域专家的知识直接编码进系统。1965 年起，斯坦福大学费根鲍姆（Edward Feigenbaum）团队开始研发 DENDRAL（用于质谱分析）\[16]；1972 年推出 MYCIN，用于诊断血液感染并推荐抗生素，其准确率一度超过普通医师\[17]。这一路线的实质，是以**知识的显式编码**替代**通用推理机制**作为系统能力的来源。

## 2.3.2 商业化与产业规模

商业化的标志性事件是 1980 年卡内基梅隆大学为 DEC 公司开发的 XCON（R1），该系统负责为 VAX 计算机配置硬件组件，DEC 声称其每年节省数千万美元\[18]。专家系统由此成为企业信息化的热门方向，人工智能产业一度达到数十亿美元规模。

1982 年，日本启动第五代计算机计划，目标是以十年时间造出以逻辑推理为核心的并行计算机\[19]。该计划刺激了美国与欧洲的竞争性投入，客观上推动了人工智能在日本之外的复苏。同期，联结主义路线亦出现回暖迹象：1982 年霍普菲尔德（John Hopfield）提出霍普菲尔德网络\[20]；1986 年鲁梅尔哈特、辛顿与威廉姆斯在《自然》发表反向传播算法用于多层网络的论文\[21]。

## 2.3.3 结构性缺陷与第二次寒冬

专家系统的缺陷随即暴露，且属结构性而非工程性：

1. \*\*知识获取瓶颈。\*\*将专家知识手工编码为规则成本极高，复杂系统的规则数常达上万条，维护代价随规模非线性增长。
2. \*\*脆弱性。\*\*规则覆盖范围之外的情形一概无法处理，系统不具备"举一反三"的泛化能力。
3. \*\*无法学习。\*\*系统不会从运行经验中自动改进，知识更新完全依赖人工介入。

1987 年，随着通用工作站性能超越专用 LISP 机，专为人工智能设计的 LISP 机器市场骤然崩塌；日本第五代计算机计划于 1992 年结束，未达成核心目标。1987 至 1993 年，**第二次人工智能寒冬**降临。

{% hint style="info" %}
**范式教训**

第二次寒冬的教训可概括为一句：**手工编码的知识不可规模化**。这与第一次寒冬形成对照——第一次是承诺超出硬件能力，第二次是知识表示方式本身不具备扩展性。二者共同指向同一约束：范式的存续取决于其能否随资源投入持续变强。
{% endhint %}

从事后视角看，第二次寒冬期间实际埋下了随后爆发的技术种子。反向传播算法、卷积网络的雏形、循环网络与 LSTM——这些当时被主流忽视的成果，将在二十年后的算力与数据洪流中真正发挥作用。这一现象提示：**寒冬淘汰的是范式与资助结构，而非全部技术积累。**
