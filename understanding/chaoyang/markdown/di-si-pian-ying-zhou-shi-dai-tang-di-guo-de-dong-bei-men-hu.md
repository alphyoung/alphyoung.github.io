# 第四篇　营州时代：唐帝国的东北门户

**时间定位**｜北魏—东魏北齐—北周—隋—唐（全书与中原关系最紧密的一章）。

### 营州门户：唐代东北的交通与碰撞

龙城不再是都城，却以营州柳城的身份继续连接中原、草原与东北。

北魏取得龙城后，朝阳地区进入北朝至隋唐的行政与交通体系。隋唐时期，营州柳城连接幽州、辽东、契丹诸部及更远的东北地区，是帝国东北边地的军政节点。

{% hint style="info" %}
**提示｜本篇涉及的族名**

靺鞨、契丹、奚、突厥等名称，以及肃慎—挹娄—勿吉—靺鞨的称谓演变、秽貊与扶余和高句丽的渊源关系，已在第二篇「0. 先辨古代族名：东北诸族的称谓与谱系」一节讲清，本篇不再重复辨析。
{% endhint %}

#### 1. 北魏至隋：从都城到营州

436年北魏攻取龙城，三燕的都城时代结束，这片土地却没有变成废墟。北魏太延二年（436年）先在此设和龙镇；太平真君五年（444年），正式设置**营州**，治所就落在龙城。此后近一千年，"营州"成为今朝阳一带最稳定的行政名称——本篇的标题正由此而来。北朝时期的营州领有昌黎、建德、辽东、乐良、冀阳、营丘等郡（不同材料所列郡县略有出入），昌黎郡与州同治龙城，建德郡则治白狼城。

政权在变，城市的角色也在变。北魏在龙城旧宫殿基址上营建思燕佛图（约485—490年），把三燕的宫殿区改造成佛教空间；同时，战争中的降附人口、军户，以及来自鲜卑、高句丽等不同背景的人群被安置到营州及周边。这里既是军事前沿，也是人口重新编组、文化重新磨合的集散地。

北魏在此设镇置州，也不只是为了安置旧地人口。和龙镇与营州正处在中原通往东北的走廊上：向北可控扼契丹、库莫奚，向东应对高句丽，是北魏经营东北、维系东部边境的据点；镇与州同治一城，说明它同时是军镇与政区。不过建置的架子撑起来了，人口却没有跟上——《魏书·地形志》记营州领六郡十四县，登记户口只有一千余户、四千余口（该志户口数字多反映东魏武定年间情况）。一座名义上辖六郡的州，实际更接近边地军镇，与三燕都城时期已不可同日而语。

534年北魏分裂后，辽西先后归东魏、北齐。建置随政局不断收缩：北齐只保留建德、冀阳二郡和龙城等县，其余并废。对朝阳来说，这意味着一座曾统辖六郡的军政中心，退成了区域治所。但它积累下来的道路、城址和人口并未散去——后来者仍然沿着同一条轴线修城、建塔。

581年隋朝建立，辽西进入统一王朝版图。隋初废郡、行州县两级，只留建德一郡与龙城一县；开皇十八年（598年）废郡，**改龙城县为柳城县**。汉代的柳城见于两汉文献之后，这一带更常用"龙城""和龙"来称呼；到隋代，那个汉代的旧名重新成为城市的通行称谓——唐代营州治所"柳城"，用的正是这一支。

隋代对这里的经营，比北朝任何时期都更用力。隋在此设**营州总管府**，治柳城，西隔燕长城与突厥相望，东隔辽河与高句丽相对，是隋朝在东北最重要的战略中心。开皇十八年（598年），高句丽联合靺鞨万余骑进犯辽西，被营州总管韦冲击退；此后韦冲又能怀抚靺鞨、契丹，奚、霫等部朝贡相继。

真正的转折来自隋炀帝的三次亲征。大业八年至十年（612—614年），隋朝连续发动对高句丽的战争，陆路大军自涿郡集结出发，出今山海关一线后北行经柳城，再折向辽东——柳城由此成为大军、粮运与民夫的必经咽喉。隋炀帝改州为郡，这里先后设柳城郡与辽西郡（具体年代不同材料有出入）。战争最终没有打赢，但柳城作为"进出东北之门"的位置被彻底确立：唐太宗、唐高宗征高句丽，陆路仍以营州为前进基地。**"营州时代"的门户逻辑，起点其实在隋代，而不在唐代。**

{% hint style="info" %}
**科普｜"营州"是行政区名，不是一座城**

从《尚书·舜典》的十二州之一，到北魏在此置州，再到隋唐的营州总管府、营州都督府与平卢节度使治所，"营州"这个名字断续沿用近千年。但每一朝的辖境、层级和治所都不完全相同，有时州与军镇同治一城，有时治所寄籍他处。读史料时，把它当作一个被反复重新定义的区域概念，比当作某一座固定的城更稳妥。
{% endhint %}

#### 2. 唐代营州：军镇、互市与羁縻中心

唐代以柳城为营州治所，使其成为经营东北的军事和交通重镇。唐玄宗时期平卢节度使驻营州，统辖边军并应对契丹、奚等力量；松漠都督府、饶乐都督府等羁縻机构，则分别联系契丹、奚首领。羁縻并非现代意义上的直接县级行政，而是借助当地首领、册封和贡赐维持关系。

营州汇集汉人、契丹、奚、高句丽遗民、靺鞨、突厥及来自中亚的商旅。

互市既交换马匹、牲畜、布帛和金属器，也让语言、服饰与信仰彼此影响。

安禄山早年活动于营州边地市场，史籍称其善多种语言、曾任互市牙郎；关于其具体族属与家世，史料解释并不完全一致。

{% hint style="info" %}
**科普｜什么是“互市牙郎”**

“互市”是边地官方或半官方贸易，“牙郎”相当于熟悉行情、语言和交易规则的中介人。他们帮助买卖双方议价、翻译并撮合交易。营州多族群并居，能掌握多种语言的人既可能成为商贸中介，也容易进入军政网络。
{% endhint %}

#### 3. 高句丽灭亡后的东北重组

668年唐与新罗联军灭高句丽后，大量人口迁徙，东北政治空间重新组合。营州成为安置、管理和调动人口的重要节点。高句丽遗民并非单一行动整体，不同首领与集团会在唐朝、契丹、新罗及新兴地方力量之间作出不同选择。

#### 4. 696年营州事件：边疆体系的震荡

696年，契丹首领李尽忠、孙万荣在营州起兵。传统叙事把导火索与营州都督赵文翙对契丹首领的轻慢、灾荒处置失当联系起来；更深层原因则包括羁縻关系失衡、地方治理矛盾和契丹力量成长。李尽忠称“无上可汗”，孙万荣继续扩大战事，局势波及河北与东北交通。

武周多次调兵，并利用突厥等周边力量夹击契丹。事件最终被平定，却改变了地区力量配置：营州人口离散、道路受阻，部分高句丽遗民和靺鞨集团东迁。大祚荣在复杂迁徙与战争中逐渐整合力量，于698年前后建立政权，后来发展为渤海国。

{% hint style="warning" %}
**小故事｜一对姻亲掀起边疆风暴**

李尽忠与孙万荣不仅是契丹首领，也是姻亲。李尽忠起兵后不久去世，孙万荣接续统军，使冲突从营州迅速扩大。个人关系并非事件的根本原因，却解释了权力为何能在危急时刻迅速交接。
{% endhint %}

{% hint style="info" %}
**提示｜不能把营州事件归为单一原因**

营州事件与渤海国建立之间存在重要历史联系，但不能简化为一条单因果链。战乱、迁徙、唐朝东北政策、契丹变化以及遗民集团自身组织共同作用，才形成新的政治格局。
{% endhint %}

{% hint style="info" %}
**小结｜营州为何重要**

营州的重要性来自“门”的位置：向西可联系幽州和中原，向东通辽东，向北连接契丹、奚等活动区域。门户既能聚集贸易、人口和信息，也最容易在帝国控制减弱时成为冲突中心。696年的震荡，正说明交通枢纽与政治风险往往是一体两面。

营州的遗产并没有随王朝更替消失：旧城轴线、佛寺传统与交通条件被后续政权继续沿用。契丹接手辽西之后，正是在这片基础上营建兴中府，并留下下一篇要看的“辽塔圣地”。
{% endhint %}

{% hint style="info" %}
**专题｜安禄山与李光弼的两条道路**

唐代东北边军为不同出身者提供了上升通道。安禄山从营州互市与边军环境进入帝国权力中心，后来发动安史之乱；李光弼则出身营州柳城的契丹家庭，成为平定安史之乱的重要将领。同一座边城能够产生走向完全不同的人生，也说明营州不是文化边缘，而是唐帝国军事与人才网络的一部分。

阅读这类人物时，应把个人族属、家庭背景与政治选择分开。多族群出身并不预先决定忠诚或叛乱；真正塑造行动的，还有边军制度、权力竞争与个人处境。
{% endhint %}
