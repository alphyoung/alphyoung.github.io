# 第四篇　营州时代：唐帝国的东北门户

### 营州门户：唐代东北的交通与碰撞

龙城不再是都城，却以营州柳城的身份继续连接中原、草原与东北。

北魏取得龙城后，朝阳地区进入北朝至隋唐的行政与交通体系。隋唐时期，营州柳城连接幽州、辽东、契丹诸部及更远的东北地区，是帝国东北边地的军政节点。

#### 0. 先辨古代族名：肃慎、秽貊与后世诸部

“肃慎”是先秦以来中原文献对东北东部人群的重要称谓之一，活动地域通常指向长白山以北、松花江下游、黑龙江和乌苏里江流域。汉魏时期文献更多使用“挹娄”，南北朝有“勿吉”，隋唐则见“靺鞨”。把这些名称视为长期演变的族群序列有助于理解文献，但不应想象成一个名称和血缘完全不变的单一民族。

“秽貊”（也写作濊貊）是古代文献对东北中东部及朝鲜半岛北部若干相关人群的概括性称呼。扶余、高句丽的形成与这些人群存在渊源联系，但二者后来各自发展为政治共同体，彼此还有长期竞争。因而“秽貊等于扶余”或“秽貊等于高句丽”都过于简单。

朝阳位于这些核心区域以西。肃慎、挹娄或秽貊人群并非朝阳地方史的直接主角，却通过朝贡道路、人口移动、辽东战争以及靺鞨参与渤海建国，与营州这一东北门户发生联系。

{% hint style="info" %}
**科普｜族名不是生物学标签**

古代族名可能来自自称、他称、政权名称或生活地域，同一人群在不同时代可能使用不同名称，同一名称下也可能包含多个来源。研究族群关系要结合语言、考古、文献和政治组织，不能画成一棵血统绝对纯粹的“家谱树”。
{% endhint %}

{% hint style="warning" %}
**小故事｜楛矢石砮：一件贡物的长久记忆**

古书反复以“楛矢石砮”描述肃慎贡物：用楛木作箭杆、石材作箭镞。它首先是一种文献记忆，说明中原作者很早便用特定物产识别遥远东北人群；但不能仅凭这四个字，把不同时代、不同地区的考古遗存都直接定为肃慎。
{% endhint %}

#### 1. 北朝管辖：都城之后的人口集散地

北魏取得龙城后，在旧宫殿基址上营建思燕佛图。此后北齐、北周相继控制辽西，区域建置随政权更替而调整。龙城由王朝首都转为区域治所，却继续利用旧有道路、城址和人口基础。

北朝时期，战争中的降附人口、军户和来自鲜卑、高句丽等不同背景的人群被安置于营州及周边。这里既是军事前沿，也是人口重新编组、文化重新磨合的集散地。隋代舍利塔建设，又把城市佛教传统延续到统一王朝。

#### 2. 唐代营州：军镇、互市与羁縻中心

唐代以柳城为营州治所，使其成为经营东北的军事和交通重镇。唐玄宗时期平卢节度使驻营州，统辖边军并应对契丹、奚等力量；松漠都督府、饶乐都督府等羁縻机构，则分别联系契丹、奚首领。羁縻并非现代意义上的直接县级行政，而是借助当地首领、册封和贡赐维持关系。

营州汇集汉人、契丹、奚、高句丽遗民、靺鞨、突厥及来自中亚的商旅。

互市既交换马匹、牲畜、布帛和金属器，也让语言、服饰与信仰彼此影响。

安禄山早年活动于营州边地市场，史籍称其善多种语言、曾任互市牙郎；关于其具体族属与家世，史料解释并不完全一致。

{% hint style="info" %}
**科普｜什么是“互市牙郎”**

“互市”是边地官方或半官方贸易，“牙郎”相当于熟悉行情、语言和交易规则的中介人。他们帮助买卖双方议价、翻译并撮合交易。营州多族群并居，能掌握多种语言的人既可能成为商贸中介，也容易进入军政网络。
{% endhint %}

#### 3. 高句丽灭亡后的东北重组

668年唐与新罗联军灭高句丽后，大量人口迁徙，东北政治空间重新组合。营州成为安置、管理和调动人口的重要节点。高句丽遗民并非单一行动整体，不同首领与集团会在唐朝、契丹、新罗及新兴地方力量之间作出不同选择。

#### 4. 696年营州事件：边疆体系的震荡

696年，契丹首领李尽忠、孙万荣在营州起兵。传统叙事把导火索与营州都督赵文翙对契丹首领的轻慢、灾荒处置失当联系起来；更深层原因则包括羁縻关系失衡、地方治理矛盾和契丹力量成长。李尽忠称“无上可汗”，孙万荣继续扩大战事，局势波及河北与东北交通。

武周多次调兵，并利用突厥等周边力量夹击契丹。事件最终被平定，却改变了地区力量配置：营州人口离散、道路受阻，部分高句丽遗民和靺鞨集团东迁。大祚荣在复杂迁徙与战争中逐渐整合力量，于698年前后建立政权，后来发展为渤海国。

{% hint style="warning" %}
**小故事｜一对姻亲掀起边疆风暴**

李尽忠与孙万荣不仅是契丹首领，也是姻亲。李尽忠起兵后不久去世，孙万荣接续统军，使冲突从营州迅速扩大。个人关系并非事件的根本原因，却解释了权力为何能在危急时刻迅速交接。
{% endhint %}

{% hint style="info" %}
**提示｜不能把营州事件归为单一原因**

营州事件与渤海国建立之间存在重要历史联系，但不能简化为一条单因果链。战乱、迁徙、唐朝东北政策、契丹变化以及遗民集团自身组织共同作用，才形成新的政治格局。
{% endhint %}

{% hint style="info" %}
**小结｜营州为何重要**

营州的重要性来自“门”的位置：向西可联系幽州和中原，向东通辽东，向北连接契丹、奚等活动区域。门户既能聚集贸易、人口和信息，也最容易在帝国控制减弱时成为冲突中心。696年的震荡，正说明交通枢纽与政治风险往往是一体两面。
{% endhint %}

{% hint style="info" %}
**专题｜安禄山与李光弼的两条道路**

唐代东北边军为不同出身者提供了上升通道。安禄山从营州互市与边军环境进入帝国权力中心，后来发动安史之乱；李光弼则出身营州柳城的契丹家庭，成为平定安史之乱的重要将领。同一座边城能够产生走向完全不同的人生，也说明营州不是文化边缘，而是唐帝国军事与人才网络的一部分。

阅读这类人物时，应把个人族属、家庭背景与政治选择分开。多族群出身并不预先决定忠诚或叛乱；真正塑造行动的，还有边军制度、权力竞争与个人处境。
{% endhint %}
