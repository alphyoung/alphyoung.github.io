# 第六篇　从古城到今天

**时间与城名**｜金、元、明、清 → 民国以来（明代卫所内移后，不宜简单说成在明治下）；上承兴中府。金仍为兴中府，元至元七年（1270）降为兴中州，明清建置屡变，乾隆四十三年（1778）设朝阳县，“朝阳”之名沿用至今。

### 本篇导读｜古城新生：从金元明清到今天

王朝更替、寺院营建与近现代考古，让古城记忆不断被重新发现。

金元时期继续利用辽西旧城与交通节点，古塔亦有修缮。明代辽西处在防御、交通和农牧交错的边疆格局中。清代随着治理结构稳定、寺院营建和县治设置，今天“朝阳”的城市名称与空间逐步定型。这中间的节点是 1778 年设朝阳县：本册写了六篇的这片土地，到这里才终于有了一个沿用至今的名字。

#### 1. 金元承接：兴中府与兴中州

金朝继承辽地，朝阳地区属**北京路**，仍设**兴中府**（并未改州）；南塔等建筑留下金代修缮痕迹。元代至元七年（1270）降兴中府为**兴中州**，改隶**大宁路**，城市和交通节点继续使用，女真、蒙古、汉人及其他人群在辽西往来。

这里宜区分“府、州、路”：它们是不同王朝的行政层级和名称。金代仍是府（兴中府），元代才降为州（兴中州）——所以金代既不能写成“兴中州”，更不能写成“兴中路”，元代也不是继续以兴中府为最高层级；名称的升降反映的正是统治体系的重组。

#### 2. 明代：大宁诸卫与汉蒙交界

明初在辽西北部设置大宁都司及相关卫所，朝阳一带曾有营州左、中、右等卫所。永乐元年（1403）大宁都司及诸卫内撤，边地屏障随之消失，南下的**兀良哈三卫**——泰宁、朵颜、福余——逐渐进入这一带驻牧，其中朵颜卫的活动范围东到今喀左一线。

明代中后期，东进的**察哈尔**等部又瓜分了三卫的牧地，部众陆续融入后来活跃于这一带的**喀喇沁**、**土默特**诸部。对朝阳地区来说，这一时期的主线是蒙古诸部的进驻与重组，而不是州县治理。

明代辽东边墙的主体位于更东侧的辽河平原边缘，不能笼统说整条大凌河流域都在边墙之内。朝阳更适合被理解为长城内外、蒙古诸部与辽东军镇之间的战略通道。

#### 3. 1631年大凌河之战：同一流域的下游战场

崇祯四年（1631），后金军围攻明军据守的大凌河城。该城位于今天锦州凌海一带的大凌河下游，并不在朝阳市区；它与朝阳共享一条河流，却属于关宁锦防线的另一段历史空间。此役以明军出降、后金获胜告终，明朝在辽西的防线被明显削弱，但锦州等地的统治并非由此立即崩溃。

战役之后，辽西的归属还要看蒙古力量的走向。当时这一带的蒙古强部是**察哈尔**，林丹汗力图整合东蒙古诸部，成为后金的主要对手；1634年林丹汗病故，次年其子率部归降后金，辽西的蒙古诸部随之纳入后金体系。

{% hint style="info" %}
**科普｜为什么“大凌河之战”不等于“朝阳之战”**

河流名称常被用作城名、堡名或战役名。1631年的大凌河城在今天凌海附近，距朝阳市区较远；把它收入本册，是为了展示大凌河从上游朝阳到下游辽东湾的整体战略意义，而不是把战场位置移到朝阳。
{% endhint %}

#### 4. 清代旗地、垦殖与朝阳府

清初朝阳地区主要属卓索图盟的土默特左、右翼旗与喀喇沁左翼旗等地。它位于柳条边以西北的蒙古旗地环境，人口流动和土地开垦受到制度约束；随着十八、十九世纪人口压力和边地开发，获准垦殖、租佃及越边迁入并行，汉人数量增加，形成更大规模的汉蒙交往。

除了汉、蒙两方，**满族**因八旗征战与分封进入辽西，**回族**则随商贸与屯戍陆续迁来。清乾隆年间建于今凌源的清真寺，是辽西现存规模最大的伊斯兰教建筑群，寺内碑记还记载了喀喇沁左翼旗王公施地建寺的缘由。今天朝阳的民族构成——蒙古族最多，满族、回族次之——正来自这一长期累积。

佑顺寺于康熙三十七年（1698）开工，康熙四十六年（1707）竣工并由康熙帝赐名，是辽西重要的藏传佛教寺院。其建筑群位于南塔附近，却与辽代双塔相隔六百余年。乾隆四十三年（1778）设置朝阳县，光绪三十年（1904）又升置朝阳府，近现代行政地名和治理中心逐步稳定。这个地点历代城名的分期，见**首页**的城名沿革图；各代地名承担的功能与阅读提示，见**附录二**的地名对照。

{% hint style="warning" %}
**小故事｜“三座塔”为什么只剩两座**

后世地名记忆中，朝阳城曾以“三座塔”著称。东塔于清乾隆七年（1742）倾塌，今日城市中心最醒目的是北塔与南塔。消失的东塔虽然不再可见，却仍通过地名和地方叙事参与塑造城市身份。

它并没有从地面上彻底消失。东塔的塔基至今仍留在城内的关帝庙院里——乾隆九年（1744），人们紧挨塔基建起关帝庙，时人的说法是借此“补”上倾塌的那一座，重凑三塔鼎峙之形。清代李调元路过朝阳时记下这一景：“今只存二座，其一于乾隆七年倾塌，市人建关帝庙补之，基阜尚存。”
{% endhint %}

#### 5. 从发现到保护：近现代考古改变城市记忆

近现代调查、发掘和古建筑维修，使三燕龙城、北塔地宫天宫、南塔石宫、牛河梁和热河生物群等材料进入公共视野。朝阳的城市身份也由“古塔可见”扩展为“地下城址、史前文明与生命化石共同可读”。

保护并不是把遗址冻结。考古研究会修正旧认识，展示方式也会更新。

旅行者最重要的阅读方法，是区分原址、原物、复建与叙事，并尊重遗址的脆弱性。

{% hint style="info" %}
**小结｜朝阳何以成为朝阳**

在朝阳，亿万年的生命史、五千余年的文明史与两千余年的城市史叠在同一片土地上。这里既不是单线发展的“古都传奇”，也不是若干景点的拼盘。它的独特性正来自反复的连接：农耕与草原、中原与东北、王朝政治与宗教信仰、地上古塔与地下城址。

如果要给这份独特性挑两个最直观的入口，那就是**三燕古都**与**辽塔圣地**：一个在地下，一个在地上；一个讲政权与族群，一个讲信仰与工艺。
{% endhint %}
