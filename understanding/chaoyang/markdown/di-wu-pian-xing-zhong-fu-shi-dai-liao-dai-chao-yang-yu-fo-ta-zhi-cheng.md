# 第五篇　兴中府时代：辽代朝阳与佛塔之城

### 兴中府与古塔：辽代朝阳的佛教盛景

今天最醒目的朝阳古迹，大多在辽代兴中府时期定型。

辽代在多京制、府州体系和交通网络中经营辽西。兴中府既承接旧城传统，也通过寺院、佛塔和舍利崇拜塑造新的城市景观。北塔、南塔与凤凰山塔寺群，展示的不是孤立建筑，而是辽代区域政治、宗教和工艺的共同成果。

#### 1. 从霸州到兴中府：辽代区域重镇

契丹建立辽朝后，朝阳地区进入其中京道体系。辽初在旧营州地区置霸州，1041年升为兴中府。它利用旧城基础，连接中京、辽东与燕云地区；

汉人、契丹人与渤海遗民等在府州、村落和寺院周边长期杂居。

辽代崇佛风气浓厚，佛塔兼具供奉舍利、展示功德与标志城市空间的作用。朝阳双塔南北相望，凤凰山亦分布塔寺，形成今日理解“佛塔之城”的历史基础。辽代朝阳的重要性，不只是接近契丹早期活动区域，更在于它位于农耕城镇、草原通道和中京交通之间。

{% hint style="info" %}
**科普｜什么是密檐式砖塔**

密檐式塔把多层屋檐紧密叠置，塔身第一层通常较高，上部各层距离很短。

远看层数很多，但多数层并不是可供人登临的楼层。砖砌斗拱、门窗、佛像和飞天常兼具结构模拟与宗教装饰作用。
{% endhint %}

#### 2. 北塔：五世叠压，全国罕见

北塔位于今慕容街北端。考古与维修揭示，其下叠压三燕宫殿台基、北魏思燕佛图、隋代舍利塔、唐代维修层与辽代包砌塔体。所谓“五世同堂”，指同一建筑地点跨越多个时代的连续使用与改造。

辽重熙年间的大规模包砌和维修，形成今天所见密檐式砖塔主体。天宫、地宫出土舍利容器和大量佛教文物，使北塔不仅是地面建筑，也是研究辽代佛教、工艺和舍利制度的重要考古现场。

{% hint style="info" %}
**科普｜塔的“天宫”和“地宫”在哪里**

地宫通常设在塔基之下，天宫则位于塔身较高处或刹座附近。两者都可安置舍利、经卷、造像和供养器。名称中的“宫”是宗教建筑术语，并非帝王居住的宫殿；它们像被封存的时间胶囊，为断代和理解信仰仪式提供证据。
{% endhint %}

{% hint style="warning" %}
**小故事｜五十六万余块砖包住旧塔**

辽代大修并不是简单补缝，而是以五十六万余块砖进行大规模包砌。工匠把前代塔体纳入新结构，才形成今天所见外观。北塔因此像一部没有拆掉旧页、而是在旧页外继续装订的建筑史。
{% endhint %}

**表05｜朝阳北塔“五世叠压”**

| 时期       | 年代           | 遗存与事件             |
| -------- | ------------ | ----------------- |
| 第五世 · 辽  | 1044年前后（重熙十三年） | 延昌寺塔大修包砌；形成现存主体。  |
| 第四世 · 唐  | 天宝年间         | 维修隋塔，开元寺传统。       |
| 第三世 · 隋  | 602年前后       | 舍利塔建设；寺名资料存在不同口径。 |
| 第二世 · 北魏 | 485—490年前后   | 旧宫基上建思燕佛图，后毁于火。   |
| 第一世 · 三燕 | 4—5世纪        | 和龙宫大型宫殿夯土台基。      |

从上往下读，是今天看到的塔向地下追溯；从下往上读，则是一处宫殿台基不断被后世宗教建筑继承的过程。

#### 3. 南塔：辽代原塔与锭光佛舍利

南塔位于慕容街南端，与北塔南北呼应。塔为方形密檐式砖塔，现存主体体现辽代建筑特征。塔基石宫题记关联辽统和二年（984）的锭光佛舍利供奉，现存塔身通常联系到辽大康二年（1076）前后的营建，金代又有维修。

2004年前后施工发现塔基石宫及成套舍利器物。关于舍利数量，通俗资料曾出现不同说法，阅读时宜以正式发掘记录和铭文释读为准。与北塔复杂包叠不同，南塔更适合观察一座辽代密檐砖塔的整体形制。

#### 4. 凤凰山：龙山佛寺传统与辽塔群

凤凰山古名龙山。前燕龙翔佛寺遗址把山地佛教史追溯到三燕时期；辽代又在山中大规模营建。摩云塔位于云接寺一带，为方形密檐砖塔；现存寺院建筑多属后世重建。北沟大宝塔则呈现山野孤塔的风貌。

延寿寺等寺院经历多次兴废和重修。今天游览凤凰山，应把“古代遗址”“现存辽塔”“清代或现代重建寺院”区分开来，才能准确理解所见建筑的年代层次。

{% hint style="info" %}
**专题｜双塔如何构成城市轴线**

北塔和南塔今天隔街相望，容易让人以为它们原本属于同一座对称寺院。

实际上，两塔的营建过程、地下遗存和附属寺院并不相同。北塔最突出的是跨越三燕至辽代的五世叠压；南塔则更集中体现辽代塔体与石宫舍利发现。

古代城市借塔标识佛寺、街道和天际线，后世寺院消失后，孤塔仍会成为城市方向感的核心。“三座塔”的地方称谓，正说明古塔不仅是宗教建筑，也长期参与居民对城市空间的记忆。

沿慕容街由北塔走向南塔，再转往佑顺寺，短距离内可以依次读到三燕宫城遗存、辽代佛塔和清代寺院。空间很近，年代却相隔数百年；这正是朝阳历史最具辨识度的“垂直叠压”与“水平并置”。
{% endhint %}
