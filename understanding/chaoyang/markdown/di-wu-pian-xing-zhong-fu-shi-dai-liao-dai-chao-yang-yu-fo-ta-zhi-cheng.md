# 第五篇　兴中府时代：辽塔圣地与佛教盛景

**时间与城名**｜五代十国至北宋（辽代约 916—1125 年；朝阳属辽，不在五代、北宋版图内）；上承营州。辽初置霸州，1041 年升为兴中府。

### 本篇导读｜辽塔圣地：辽代兴中府与十四座古塔

今天最醒目的朝阳古迹，大多在辽代兴中府时期定型。

辽代在多京制、府州体系和交通网络中经营辽西。兴中府既承接旧城传统，也通过寺院、佛塔和舍利崇拜塑造新的城市景观。北塔、南塔与凤凰山塔寺群，展示的不是孤立建筑，而是辽代区域政治、宗教和工艺的共同成果——正是这一片密集留存至今的塔，让朝阳有了“辽塔圣地”之名。上一篇的“营州”落幕之后，这座城以“兴中府”之名重新成为区域中心——名字换了，塔留下了，这就是本篇的线索。

#### 1. 为什么朝阳被称为“辽塔圣地”

契丹立国后，皇室对佛教的推崇持续了近两个世纪，广施寺田、度僧无数，在关键州府与交通要道兴建佛塔。塔的功能并不单一：供奉舍利、累积功德、标识州县与城市空间，还可以“一塔定乾坤”地昭示政权气象。辽代佛教兴盛，后世梳理出若干区域佛教中心，**兴中府**（今朝阳）即居其一——这也解释了这里的塔为何如此密集。

数量与分布能说明问题：**朝阳地区现存辽塔约十四座**，绝大多数是方形或八角形的密檐式砖塔，塔身常见砖雕佛像、胁侍菩萨、飞天与八大灵塔。它们不集中在城内，而是散布于城区、山谷、河岸与郊野——这正是“圣地”与“一座名塔”的区别。为便于直观，也常有人以比值来描述：“全国每两座幸存辽代古塔就有一座在辽宁，每五座就有一座在朝阳。”这类比值来自通俗梳理，可作印象参考，正式统计仍宜以文物部门口径为准。

在城市内部，两座塔锁定了空间骨架：北塔与南塔沿慕容街南北相望，相距约一千二百米，形成一条肉眼可见的辽代都城中轴线。

{% hint style="info" %}
**科普｜为什么辽塔这么多，而且大多长得很像**

辽代实行多京制，州府与要道成网，建塔又被视为积累功德、安定地方的有效方式，于是同一套信仰需求在广阔区域内反复落地。形制上也确实趋同：以密檐式砖塔为主，方形或八角、十三级居多。趋同不等于简单复制——层数、砖雕题材、塔身空心或实心、天宫与地宫的设置各有差别，正是这些差别构成断代与辨寺的线索。
{% endhint %}

#### 2. 从霸州到兴中府：辽代区域重镇

营州失守后至契丹立国的这一百五十余年里，辽西没有稳定的州县建制，奚与契丹诸部往来其间（见**附录一**“朝阳历史总时间轴”）。契丹建立辽朝后，朝阳地区进入其中京道体系。辽初在旧营州地区置霸州，1041年升为兴中府。它利用旧城基础，连接中京、辽东与燕云地区；

汉人、契丹人与渤海遗民等在府州、村落和寺院周边长期杂居。

辽代朝阳的重要性，不只是接近契丹早期活动区域，更在于它位于农耕城镇、草原通道和中京交通之间。

{% hint style="info" %}
**科普｜什么是密檐式砖塔**

密檐式塔把多层屋檐紧密叠置，塔身第一层通常较高，上部各层距离很短。

远看层数很多，但多数层并不是可供人登临的楼层。砖砌斗拱、门窗、佛像和飞天常兼具结构模拟与宗教装饰作用。
{% endhint %}

#### 3. 北塔：五世叠压，全国罕见

北塔位于今慕容街北端。考古与维修揭示，其下叠压三燕宫殿台基、北魏思燕佛图、隋代舍利塔、唐代维修层与辽代包砌塔体。所谓“五世同堂”，指同一建筑地点跨越多个时代的连续使用与改造。

辽重熙年间的大规模包砌和维修，形成今天所见密檐式砖塔主体。天宫、地宫出土舍利容器和大量佛教文物，使北塔不仅是地面建筑，也是研究辽代佛教、工艺和舍利制度的重要考古现场。

{% hint style="info" %}
**科普｜塔的“天宫”和“地宫”在哪里**

地宫通常设在塔基之下，天宫则位于塔身较高处或刹座附近。两者都可安置舍利、经卷、造像和供养器。名称中的“宫”是宗教建筑术语，并非帝王居住的宫殿；它们像被封存的时间胶囊，为断代和理解信仰仪式提供证据。
{% endhint %}

{% hint style="warning" %}
**小故事｜五十六万二千余块砖包住旧塔**

辽代大修并不是简单补缝，而是以五十六万二千余块砖进行大规模包砌。工匠把前代塔体纳入新结构，才形成今天所见外观。北塔因此像一部没有拆掉旧页、而是在旧页外继续装订的建筑史。
{% endhint %}

**表05｜朝阳北塔“五世叠压”**

| 时期       | 年代           | 遗存与事件             |
| -------- | ------------ | ----------------- |
| 第五世 · 辽  | 1043—1044年（重熙十二—十三年） | 延昌寺塔大修包砌；形成现存主体。  |

| 第三世 · 隋  | 602年前后       | 舍利塔建设；寺名资料存在不同口径。 |

从上往下读，是今天看到的塔向地下追溯；从下往上读，则是一处宫殿台基不断被后世宗教建筑继承的过程。

#### 4. 南塔：辽代原塔与锭光佛舍利

南塔位于慕容街南端，与北塔南北呼应。塔为方形密檐式砖塔，现存主体体现辽代建筑特征。塔基石宫题记关联辽统和二年（984）的锭光佛舍利供奉，现存塔身通常联系到辽大康二年（1076）前后的营建，金代又有维修。

2004年前后施工发现塔基石宫及成套舍利器物。关于舍利数量，通俗资料曾出现不同说法，阅读时宜以正式发掘记录和铭文释读为准。与北塔复杂包叠不同，南塔更适合观察一座辽代密檐砖塔的整体形制。

{% hint style="info" %}
**专题｜双塔如何构成城市轴线**

北塔和南塔今天沿街南北相望，容易让人以为它们原本属于同一座对称寺院。

实际上，两塔的营建过程、地下遗存和附属寺院并不相同。北塔最突出的是跨越三燕至辽代的五世叠压；南塔则更集中体现辽代塔体与石宫舍利发现。

古代城市借塔标识佛寺、街道和天际线，后世寺院消失后，孤塔仍会成为城市方向感的核心。古塔不仅是宗教建筑，也长期参与居民对城市空间的记忆。

沿慕容街由北塔走向南塔，再转往佑顺寺，短距离内可以依次读到三燕宫城遗存、辽代佛塔和清代寺院。空间很近，年代却相隔数百年；这正是朝阳历史最具辨识度的“垂直叠压”与“水平并置”。
{% endhint %}

#### 5. 凤凰山：龙山佛寺传统与辽塔群

凤凰山古名龙山，山中的佛寺传统可以上溯到三燕时期的龙翔佛寺（见第三篇第 6 节）；辽代又在山中大规模营建。摩云塔位于云接寺一带，为方形密檐砖塔；现存寺院建筑多属后世重建。北沟大宝塔则呈现山野孤塔的风貌。

延寿寺等寺院经历多次兴废和重修。今天游览凤凰山，应把“古代遗址”“现存辽塔”“清代或现代重建寺院”区分开来，才能准确理解所见建筑的年代层次。

#### 6. 郊野塔群：大平房镇三塔与悬崖双塔

辽塔并不都在城里。龙城区大平房镇不足数公里的范围内，八棱观塔、黄花滩塔、东平房塔成品字排列——它们与辽代的建州城址、交通线相互配套：塔既供奉舍利，也充当行旅与聚落的方向标。

再往南，朝阳县木头城子镇的峡谷峭壁上并列着双塔寺双塔。把塔修在几乎无处立足的崖壁上，选址本身就传达了“以塔镇护”的意图。这类郊野塔提醒我们：辽代的塔不是城市的专利，而是在广大区域内铺开的一张信仰网络上的节点。

{% hint style="info" %}
**小结｜从兴中府到朝阳**

辽代在旧营州的基础上置霸州、升兴中府，佛塔与寺院随之铺满城区与郊野，“辽塔圣地”的名字由此而来。此后金仍为兴中府，元代降为兴中州，明清之间州县建置长期不定——城市的名字反复更换，而那些塔一直立着，成了这片土地上最稳定的地标。

下一篇要看的，正是这些塔如何在金元明清的更替中被继续沿用，又如何在近现代考古中被重新读出来。
{% endhint %}
