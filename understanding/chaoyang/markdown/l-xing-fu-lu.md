# 旅行附录

### 一、遗址图鉴

### 带着历史看遗址

先辨年代，再看空间；先找原址，再看展陈。

**表09｜朝阳主要遗址现场阅读索引**

| 地点                              | 时代           | 现场阅读重点                    | 对应看点          |
| ------------------------------- | ------------ | ------------------------- | ------------- |
| <p>牛河梁遗址<br>凌源、建平交界一带</p>       | 红山文化晚期       | 祭坛、积石冢、女神庙遗址；关注礼仪中心与区域社会。 | 前史铺垫          |
| <p>朝阳鸟化石国家地质公园<br>化石及相关展馆</p>   | 早白垩世         | 理解热河生物群；区分原产地、标本与复原展示。    | 前史铺垫          |
| <p>朝阳地区三燕龙城遗址<br>朝阳市区</p>       | 4—5世纪及后续沿用   | 城市叠压与宫城考古；遗址可见度受保护展示条件影响。 | **三燕古都**      |
| <p>朝阳北塔与北塔博物馆<br>慕容街北端</p>      | 三燕至辽         | 重点看五世叠压、天宫地宫出土文物与辽塔外观。    | **三燕古都**／**辽塔圣地** |
| <p>朝阳南塔<br>慕容街南端</p>            | 辽代，金代维修      | 看方形密檐砖塔、石宫发现及与北塔的城市轴线。    | **辽塔圣地**      |
| <p>佑顺寺<br>南塔附近</p>              | 清代           | 看藏传佛教建筑群；牢记它与辽塔年代相隔甚远。    | **辽塔圣地**周边（清代寺院） |
| <p>凤凰山摩云塔、寺院遗址<br>朝阳市区东部凤凰山</p> | 三燕传统、辽塔及后世重建 | 适合用“遗址—古塔—重建寺院”三层方法阅读。    | **辽塔圣地**（兼三燕佛寺传统） |
| <p>大平房镇三塔<br>龙城区大平房镇</p>        | 辽代           | 八棱观塔、黄花滩塔、东平房塔数公里内成品字排列；郊野塔群。 | **辽塔圣地**（郊野）  |

{% hint style="info" %}
**提示｜阅读遗址的三个问题**

一问“眼前所见是否原物”：北塔塔身、考古出土文物、保护棚中的遗迹和复建寺院，真实性层次不同。二问“它属于哪个时期”：同一地点往往叠压多代遗存，空间相邻不代表年代相同。三问“结论依据什么”：优先看发掘报告、正式展签与可识别的碑刻题记，对传奇故事保留求证意识。

参观时若只记住一条原则，可以是：先读年代说明，再看建筑与遗物，最后把现场放回本册的总时间轴。
{% endhint %}

### 二、朝阳历史总时间轴

### 一页看懂朝阳时间线

从一亿年前到近现代：生命、文明与城市三条线并读。

**表10｜朝阳历史总时间轴**

| 时间           | 事件                             | 时间        | 事件                        |
| ------------ | ------------------------------ | --------- | ------------------------- |
| 约1.3亿—1.2亿年前 | 热河生物群繁盛；羽毛恐龙、早期鸟类与早期被子植物被保存。   | 436—618   | 北魏取龙城、置营州；思燕佛图与隋代舍利塔；隋改龙城为柳城。 |
| 约前6200—前5400 | 兴隆洼等早期新石器文化。                | 唐代—696    | 营州连接契丹、靺鞨等部；696年事件改变地区格局。 |
| 约前5000—前3000 | 赵宝沟、红山文化发展（富河文化分布更北）；红山晚期牛河梁礼仪中心形成。      | 698前后     | 大祚荣集团以粟末靺鞨等为基础建立政权，后号渤海。  |
| 约前3000—前300 | 小河沿、夏家店下层、魏营子、夏家店上层等阶段，进入青铜时代。 | 10—12世纪初  | 辽代兴中府；北塔、南塔及凤凰山塔寺群定型。     |
| 战国—秦汉        | 燕将秦开却胡（约前300年）、设五郡；肃慎、秽貊等东北族名见于古代文献。 | 金—元—明     | 旧城和古塔继续使用；1403年大宁都司内迁，辽西渐入蒙古诸部牧地。 |
| 东汉末—238      | 公孙氏据辽东并联络扶余；曹操白狼山取胜；238年辽东平定。  | 1698—1707 | 佑顺寺营建并赐名。                 |
| 294—342      | 慕容鲜卑经营辽西；337年前燕建立，342年迁都龙城。    | 1774—1904 | 置三座塔厅，1778年改设朝阳县，1904年升置朝阳府。 |
| 4—5世纪        | 三燕龙城兴衰，与高句丽、扶余发生战和关系。          | 近现代       | 考古发掘、古塔维修、遗址保护与博物馆展示不断推进。 |

{% hint style="info" %}
**提示｜生命、文明与城市怎样汇合**

左列由生命史走向史前文明，再进入柳城与龙城；右列从北魏、隋唐接续到辽金明清和近现代保护。分栏不是把历史切断，而是让跨越一亿多年的尺度在一页中保持可读。朝阳真正的连续性，不在于同一王朝或同一城名从未改变，而在于这片土地长期充当生态保存地、文化交汇区和东北交通节点。
{% endhint %}

### 三、历史地名表

### 古地名怎样对照今天

同一地区在不同时期承担不同功能；地名相近，也不必然意味着城址边界完全重合。

**表11｜朝阳历史地名对照**

| 地名      | 主要时期         | 历史功能                   | 阅读提示                             |
| ------- | ------------ | ---------------------- | -------------------------------- |
| 柳城      | 汉代与隋唐两度出现 | 汉柳城是辽西边郡所在；隋开皇十八年（598年）改龙城县为柳城，唐沿为营州治所。 | **同名的两座城**：汉柳城与隋唐柳城未必同址，207年白狼山之战中的“柳城”指前者。 |
| 龙城 / 和龙 | 三燕时期         | 前燕、后燕、北燕重要都城或政治中心。     | 三燕龙城遗址是认识城市布局的核心；也是“三燕古都”一名的由来。  |
| 营州      | 北魏隋唐，唐代尤重要   | 东北边地军政机构与多族群交通枢纽。      | “营州”是行政区与治所概念，范围随时期变化。           |
| 兴中府 / 兴中州 | 辽金元时期        | 辽金为府，元代降为州；连接中京、辽东与燕云交通。 | 辽代佛塔和寺院景观的制度背景；金代仍是府，元代才改州。      |
| 三座塔     | 清代（1774—1778年曾作厅名） | 源自城市古塔景观记忆；东塔乾隆七年（1742）倾塌后仅存两塔。 | 帮助理解双塔之外曾有第三座塔的城市传说与地名。          |
| 朝阳      | 清代以来         | 1778设置朝阳县，名称逐渐稳定。      | 今日市、县等行政范围与古代城址不可直接等同。           |

{% hint style="info" %}
**提示｜按两个看点安排路线**

**看三燕古都，半天**：北塔博物馆（看塔下的三燕宫殿台基）→ 慕容街与龙城宫城南门遗址 → 南塔。先看地层，再看轴线，最后回到文物。

**看辽塔圣地，一天**：上午在北塔、南塔之间辨形制与年代层次，下午上凤凰山看摩云塔与山寺群；若自驾，可另加龙城区大平房镇的八棱观塔、黄花滩塔、东平房塔。

**若安排两天**：第一天交给两个看点，第二天向牛河梁与化石产地相关场馆延伸，把“辽塔”放回亿万年的时间轴。

开放状态、预约规则和交通条件可能变化，出行前应以场馆与文保部门当日公告为准。
{% endhint %}
