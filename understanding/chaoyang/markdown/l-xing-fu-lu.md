### 一、遗址图鉴

### 带着历史看遗址

先辨年代，再看空间；先找原址，再看展陈。

**表06｜朝阳主要遗址现场阅读索引**

| 地点                              | 时代           | 现场阅读重点                    |
| ------------------------------- | ------------ | ------------------------- |
| <p>牛河梁遗址<br>凌源、建平交界一带</p>       | 红山文化晚期       | 祭坛、积石冢、女神庙遗址；关注礼仪中心与区域社会。 |

{% hint style="info" %}
**提示｜阅读遗址的三个问题**

一问“眼前所见是否原物”：北塔塔身、考古出土文物、保护棚中的遗迹和复建寺院，真实性层次不同。二问“它属于哪个时期”：同一地点往往叠压多代遗存，空间相邻不代表年代相同。三问“结论依据什么”：优先看发掘报告、正式展签与可识别的碑刻题记，对传奇故事保留求证意识。

参观时若只记住一条原则，可以是：先读年代说明，再看建筑与遗物，最后把现场放回本册的总时间轴。
{% endhint %}

### 一页看懂朝阳时间线

从一亿年前到近现代：生命、文明与城市三条线并读。

{% hint style="info" %}
**提示｜生命、文明与城市怎样汇合**

左列由生命史走向史前文明，再进入柳城与龙城；右列从北魏、隋唐接续到辽金明清和近现代保护。分栏不是把历史切断，而是让跨越一亿多年的尺度在一页中保持可读。朝阳真正的连续性，不在于同一王朝或同一城名从未改变，而在于这片土地长期充当生态保存地、文化交汇区和东北交通节点。
{% endhint %}

### 三、历史地名表

### 古地名怎样对照今天

同一地区在不同时期承担不同功能；地名相近，也不必然意味着城址边界完全重合。

**表08｜朝阳历史地名对照**

| 地名      | 主要时期         | 历史功能                   | 阅读提示                             |
| ------- | ------------ | ---------------------- | -------------------------------- |
| 柳城      | 汉代—唐代文献中反复出现 | 辽西边郡与交通节点；唐时与营州治所关系密切。 | 与今天朝阳市区及周边历史地理关系密切，具体定位须结合考古与文献。 |
| 龙城 / 和龙 | 三燕时期         | 前燕、后燕、北燕重要都城或政治中心。     | 三燕龙城遗址是认识城市布局的核心。                |
| 营州      | 北魏隋唐，唐代尤重要   | 东北边地军政机构与多族群交通枢纽。      | “营州”是行政区与治所概念，范围随时期变化。           |
| 兴中府 / 兴中州 | 辽金元时期        | 辽金为府，元代降为州；连接中京、辽东与燕云交通。 | 辽代佛塔和寺院景观的制度背景；金代仍是府，元代才改州。      |
| 三座塔     | 后世地方称谓       | 源自城市古塔景观记忆，东塔后来毁失。     | 帮助理解双塔之外曾有第三座塔的城市传说与地名。          |
| 朝阳      | 清代以来         | 1778设置朝阳县，名称逐渐稳定。      | 今日市、县等行政范围与古代城址不可直接等同。           |

{% hint style="info" %}
**提示｜按时间安排阅读路线**

若只有半天，可从北塔博物馆—慕容街—南塔—佑顺寺建立城市历史轴线；若有一天，再加入三燕龙城遗址展示点与凤凰山；若安排两天以上，可向牛河梁及化石产地相关场馆延伸。开放状态、预约规则和交通条件可能变化，出行前应以场馆当日公告为准。
{% endhint %}
