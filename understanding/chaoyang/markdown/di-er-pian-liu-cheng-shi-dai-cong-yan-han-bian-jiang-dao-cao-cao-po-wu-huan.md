# 第二篇　柳城时代：从燕汉边疆到曹操破乌桓

**时间与城名**｜战国燕、秦、西汉、东汉、三国·曹魏、西晋 → 西晋末（316 年）；柳城之名沿用至东晋咸康七年（341 年）慕容皝改筑龙城之前。

### 本篇导读｜白狼水与柳城：燕汉边疆和曹操北征

走进文字记载中的辽西，沿着古称“白狼水”的大凌河认识柳城。

战国燕向东北经略后，辽西被纳入更大规模的郡县与交通网络。秦汉沿用并调整相关建置；与此同时，东胡、乌桓和鲜卑等北方族群活跃于这一广阔区域。边疆不是一道静止的线，而是人口迁徙、军事行动、互市与结盟反复发生的地带。

大凌河历代的河名变化，以及“白狼水、白狼山、白狼县、白狼城”这几个同源名称的分辨，见**附录五**。

{% hint style="info" %}
**科普｜“柳城”有两座**

本篇讲的柳城，是汉魏时期的辽西边城，207年白狼山之战前后的“柳城”都指它。隋开皇十八年（598年）把龙城县改名为柳城，唐代营州治所的“柳城”用的是后一个名字。两个“柳城”相隔约四百年，城址是否重合，要靠考古与文献分别判断，不能因为同名就当作同一座城。
{% endhint %}

这个地点从柳城到龙城、营州、兴中府再到朝阳的完整城名分期，见**首页**的城名沿革图；每一个名字各承担什么功能，见**附录二**。

#### 0. 先辨古代族名：东北诸族的称谓与谱系

地名理清了，接着看人群。进入文字时代以后，东北方向出现了一批今天听来陌生的族名。需要先说明：这一节按族别而不是年代编排，其中不少称谓的沿用时间会超出本篇的时间范围。

更东北的方向还有一组称谓：先秦称“肃慎”，汉魏多作“挹娄”，南北朝有“勿吉”，隋唐则见“靺鞨”，地域大致在长白山以北、松花江下游至黑龙江流域。这是一串长期演变的称谓，不宜想象成血缘始终不变的单一民族；古书常以“楛矢石砮”识别其贡物，同样只是文献记忆。

“秽貊”（也写作濊貊）则是对东北中东部及朝鲜半岛北部若干相关人群的概括性称呼，扶余、高句丽的形成与它有渊源，但不能据此把二者直接等同。

第三组是草原方向的东胡、乌桓与鲜卑。它们与辽西的关系最直接。传统叙述常把东胡被匈奴击破、乌桓衰落和鲜卑兴起写成整齐的先后接替；现实则更复杂，其中伴随迁徙、分化与重新结盟，称谓变化既包含历史渊源，也反映政治组织重新形成。

鲜卑在魏晋时期分成多部，与辽西关系最深的是东部的三支：**慕容部**、**段部**、**宇文部**。此外还有后来建立北魏的**拓跋部**，其核心在更西的阴山、代北一带。同一个“鲜卑”名下，是若干各自为政的部落集团，彼此联姻、结盟，也彼此吞并。三支在东部的具体分布、以及它们之间如何角力，第三篇「2. 三燕之前」会接着讲。再往北，漠北草原先后是柔然、突厥等游牧政权的舞台；它们并不以辽西为家，却常通过草原诸部牵动这一带的局势。

东胡谱系还有两条向下的支流值得先记住。一是**乌桓**：内迁后进入郡县编户（其过程见本章第 3、5 节）。二是**宇文部的残部**：它在344年被慕容部击破后窜匿“松漠之间”，后来分化出**契丹**与**库莫奚**（隋唐以后简称“奚”）。第四篇讲隋唐营州时反复出现的契丹、奚，源头就在这里。

朝阳位于这些核心区域以西。肃慎、挹娄或秽貊人群并非朝阳地方史的直接主角，却通过朝贡道路、人口移动、辽东战争以及靺鞨参与渤海建国，与这片土地持续发生联系。

{% hint style="info" %}
**科普｜族名不是生物学标签**

古代族名可能来自自称、他称、政权名称或生活地域，同一人群在不同时代可能使用不同名称，同一名称下也可能包含多个来源。研究族群关系要结合语言、考古、文献和政治组织，不能画成一棵血统绝对纯粹的“家谱树”。
{% endhint %}

#### 1. 山戎、东胡与燕国的东北边界

商周至春秋时期，燕国北部与山戎等群体长期接触。春秋时齐桓公应燕国之请北伐山戎，是华北北缘格局变化的重要事件；但其具体行军范围与大凌河流域的直接关系，不能仅凭后世传说确定。到了战国，东胡成为燕国东北方向更重要的力量。

“山戎”和“东胡”都是古代文献中的概括性称谓，不能直接套用现代民族边界。辽西的位置也很特别：南接中原农耕区，东北连山林的渔猎地带，西北通蒙古高原的游牧草原，三种生产方式在此交汇。因此辽西考古显示农耕、畜牧与青铜文化长期并存——这一地带并非只有单一生活方式，而是燕地居民与北方人群反复交往、竞争和融合的接触区。

#### 2. 秦开却胡与燕秦汉的辽西格局

战国中晚期，燕将秦开曾在东胡为质，归燕后率军击退东胡。燕国随后在北方、东北方向设置上谷、渔阳、右北平、辽西、辽东五郡，并修筑自造阳至襄平的燕北长城。大、小凌河流域由此更深入地纳入郡县、障塞和交通体系。

长城在这里不仅是一堵墙，还包括城障、烽燧、驻军点和道路网络。它既承担防御功能，也保护新设郡县及人口迁入。建平等地保存的燕秦长城遗迹，是大凌河上游由青铜时代文化区转向帝国边郡的地面证据。

秦汉沿袭并调整燕的制度。辽西郡、右北平郡等建置成为东北交通与军事治理的支点。今天讨论“朝阳在汉代的位置”，应理解为朝阳地区处在这一边郡网络中，而不宜把后世城市边界机械套回古代。

{% hint style="info" %}
**科普｜燕长城不是今天熟悉的明长城**

战国燕长城多以夯土、石砌墙体及障塞构成，保存形态和明代砖石长城很不一样。经过两千多年侵蚀，一些遗迹看起来只是山脊上的土垄或石线，必须结合考古调查判断，不能把所有“老墙”都认作长城。
{% endhint %}

#### 3. 汉朝经略与乌桓内迁

东胡联盟被匈奴击破后，文献中的乌桓、鲜卑逐渐活跃。汉武帝时期，朝廷把部分乌桓安置在上谷、渔阳、右北平、辽西、辽东等塞外或边郡地带，希望其侦察匈奴动向并协助守边。

此后数百年，乌桓或居塞外，或入塞内附。西汉设护乌桓校尉监领塞外乌桓；到东汉安帝永初年间（107、109年，两说），朝廷又从辽西郡划出昌黎、宾徒、徒河三县，从辽东郡划出无虑、房、险渎三县，合置**辽东属国**，治所在昌黎（今义县一带），长官为都尉，官级与郡守相当。属国不是独立政权，而是与郡平行、专为安置内附乌桓而设的政区，辖境大体在今大凌河、小凌河下游至辽河以西。曹魏正始五年（244），因鲜卑内附又复置一次，不久改置昌黎郡。

乌桓与汉朝的关系并非始终稳定：首领受封、互市贸易、随军作战与反叛冲突交替出现。到东汉末年，辽西柳城附近成为三郡乌桓政治活动的重要节点，也成为袁氏残余与曹操争夺的战略空间。

{% hint style="info" %}
**科普｜“三郡乌桓”是哪三郡**

“三郡乌桓”不是族名，而是东汉末年三支乌桓势力的合称，《三国志》写作“三郡乌丸”。通常指辽西、辽东属国、右北平三部——袁绍所封的“三王”（辽西蹋顿、辽东属国苏仆延、右北平乌延）正对应这三部，上谷乌桓不在其中。

这里的“辽东”指治所在昌黎（今义县一带）的辽东属国，与辽东郡不是同一个政区。蹋顿代立后“总摄三王部”，三部号令归一；207年曹操在白狼山面对的正是这支力量。
{% endhint %}

#### 4. 柳城、三郡乌桓与公孙氏辽东

东汉末年中央权威衰落，辽西、辽东一带的地方力量重新组合。袁绍集团曾与乌桓结盟；袁绍死后，袁尚、袁熙在河北失势，向乌桓寻求支持。对曹操而言，北征既要消除袁氏残余，也要重塑北方边疆秩序。

与此同时，公孙度及其后继者以辽东为根据地扩张。这个政权的核心在辽河以东，却直接影响柳城的战略位置。公孙氏经营郡县、向朝鲜半岛北部发展，并借婚姻和军事手段在扶余、高句丽、鲜卑之间维持平衡。

238年司马懿攻灭公孙渊后，曹魏更直接面对东北诸力量。柳城由此成为观察中原政权、草原部落与辽东割据三方关系的窗口。

{% hint style="warning" %}
**小故事｜公孙康为什么杀掉袁氏兄弟**

207年袁尚、袁熙逃入辽东，企图依靠公孙康东山再起。公孙康既担心二袁夺权，也判断曹操不会立即越境强攻，于是杀死二人并送首级。曹操没有追入辽东，正是利用了公孙康与袁氏之间无法互信的矛盾。
{% endhint %}

#### 5. 207年白狼山之战与鲜卑崛起

建安十二年（207），曹操采纳郭嘉等人的战略意见北征乌桓。大军经险道出塞，在白狼山附近与以蹋顿为核心的乌桓力量决战。战后蹋顿被斩，袁尚、袁熙继续逃往辽东，最终被公孙康所杀。

这场战争削弱了三郡乌桓的独立政治力量。大批乌桓人口被迁徙、整编并逐渐融入中原社会，其骑兵被编入曹军，史称“由是三郡乌丸为天下名骑”；乌桓衰落后，同样源出东胡历史谱系的鲜卑诸部在辽西及其北部更趋活跃，为三世纪以后慕容鲜卑的崛起创造了条件。

{% hint style="info" %}
**科普｜为什么古战场很难精确到一点**

古代史书常以山、水、城或行军日程定位战事，但河道会改迁，地名会移动，同名地点也可能并存。考证白狼山之战，需要把文献里程、河谷走向、古城遗址与地形通道综合起来；“大致区域可信”不等于“某块石头就是交战中心”。
{% endhint %}

{% hint style="warning" %}
**小故事｜郭嘉没有看到凯旋**

郭嘉主张趁乌桓尚未充分戒备迅速远征，并支持轻装疾进。他在归途中病逝，未能回到邺城。后世常把这场胜利称为“遗计定辽东”，但更准确的理解是：他的判断、曹操的执行以及辽东公孙康的选择共同促成结局。
{% endhint %}

#### 6. 曹魏与西晋：柳城时代的尾声

238 年公孙氏政权被攻灭，辽西、辽东直接归入曹魏。但中原王朝在东北的最高军政代表——**东夷校尉**（其后又有护东夷校尉）——驻在辽河以东的襄平（今辽阳），大凌河中游的柳城，军事分量随之下降。建置也在这时重新洗牌：大凌河中下游改由**昌黎郡**管理，它由正始五年（244）复置的辽东属国改置而来，治所在昌黎（今义县，过程见本章第 3 节）。今天朝阳一带自此进入以“昌黎”为名的行政体系，“辽西”这个名字反倒留在了更西边的郡上——两个“昌黎”的来龙去脉，见**附录二**的辨析。

柳城自身的处境更特别。西汉曾在这一带设柳城县，此县后来废置，年代有东汉初与曹魏黄初元年两说；无论取哪一说，**曹魏与西晋的正史建置记录里都没有柳城**——西晋的辽西郡只领阳乐、肥如、海阳三县，昌黎郡只领昌黎、宾徒二县。这一时期的“柳城”，是一座**有城名、无县级建制**的城，照旧出现在行军路线与地理叙述中，行政上却已不再独立，正接得上**首页**那幅城名沿革图。西晋大体沿袭曹魏，但把幽州五郡分出置平州，昌黎郡改属，州治仍在襄平；按《晋书·地理志》，昌黎郡全郡只有九百户——郡县的架子还在，人口与实土都已相当单薄。

西晋后期，中原自顾不暇：八王之乱、永嘉之乱相继，幽州逐步失控，辽西落入地方势力与部族首领之手。建兴四年（316）西晋灭亡，中原王朝在这片土地上的直接治理就此中断。“柳城”这个名字，比它所依托的王朝多活了二十多年——直到东晋咸康七年（341），慕容皝在柳城之北、龙山之西营建新都，才把它改称龙城县（见第三篇第 3 节）。柳城时代的句号，画在那里。


{% hint style="info" %}
**小结｜从柳城时代走向龙城时代**

曹操把部分乌桓人口迁入内地并编入军事体系，辽西的力量结构随之变化；到西晋末年，中原王朝在这一带的直接治理已难维持。此后鲜卑诸部逐步兴起，成为三世纪至四世纪北方政治的重要力量。由柳城时代走向龙城时代，并不是一次突然换幕，而是边疆人口、军事资源和地方首领长期重组的结果。正是这段重组腾出了空间，为慕容鲜卑进入辽西、建立三燕政权准备了政治条件，也有了下一篇的“三燕古都”。
{% endhint %}
