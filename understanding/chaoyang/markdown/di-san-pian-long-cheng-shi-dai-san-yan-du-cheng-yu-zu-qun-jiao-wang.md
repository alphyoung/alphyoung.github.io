# 第三篇　龙城时代：三燕古都与族群交往

**时间定位**｜东晋十六国 → 南北朝之初（三燕与东晋并立，朝阳不在东晋治下）。

### 三燕古都：四至五世纪辽西的都城时代

四至五世纪，今天的朝阳一带成为都城，历史舞台由边郡转向龙城。

魏晋时期，鲜卑诸部在北方兴起。慕容鲜卑进入辽西后，逐步建立政权与城市中心。前燕、后燕、北燕的政治变动，使龙城在东北亚交通、军事和文化交流中取得罕见地位——同一座城先后被三个政权当作都城，这正是“三燕古都”这一称谓的来历。

#### 1. 为什么朝阳被称为“三燕古都”

“三燕”不是某一个王朝的别称，而是史学界对东晋十六国时期、以今朝阳（古龙城）为中心先后建立的前燕、后燕、北燕三个地方政权的统称。前燕与后燕由慕容鲜卑建立，北燕由汉人冯氏执掌，三者国号都取“燕”。地方表述说得很直接：“三燕王朝均以龙城（今辽宁朝阳）为都城或陪都，因此龙城又被称为‘三燕古都’。”

换句话说，“三燕古都”不是修辞，而是一个可以核查的历史结论：**同一座城，被三个以“燕”为国号的政权先后选作都城或陪都。** 中国古代做过都城的城市不少，但一地先后为三个政权之都的并不多；三次选择又都落在同一座城、彼此相隔不过几十年，就更为罕见。

还有一层独特性：龙城是中国古代唯一一座以“龙”命名的都城。341 年慕容皝在柳城以北、龙山以西营建新城（营建详情见本章第 4 节），新城因此得名“龙城”。据史书记载，新宫落成后龙山之上出现“黑龙、白龙各一”，慕容皝亲率群僚前往观看、祭以太牢，遂号新宫为“和龙”，并在山上立龙翔佛寺。宫名、城名与寺名，就此连成一串。

**提示｜“立都龙城多少年”：几种口径**

三燕合计历时 **99 年**（337—436，不计中断）。至于以龙城为都城或陪都的时间，常见说法有“**立都龙城 69 载**”与“**前后约 80 年**”。数字的差别来自统计方式：是否扣除前秦占据的十五年、是否把迁都中原后的陪都期计入、以哪一年为起点。阅读时先问一句“这个数字算的是哪一段”，比记住某一个数字更有用。
{% endhint %}

#### 2. 三燕之前：段部、宇文部与“辽西国”

慕容部并非最早立足辽西的鲜卑。魏晋时期东部鲜卑分为三支：慕容部在辽水东西两侧往返迁徙，**段部**集居辽西，**宇文部**在辽东塞外偏北。晋初，段氏与宇文氏都强于慕容，《资治通鉴》记晋武帝太康十年（289年）：“时鲜卑宇文氏、段氏方强，数侵掠廆，廆卑辞厚币以事之。”慕容廆正是在这种压力下把部众迁到徒河之青山（学者多比定在今义县、北票一带的群山），回到辽西立足。

段部是这一阶段辽西最强的一方。西晋末年，幽州都督王浚为求外援而与段部结盟；晋惠帝太安二年（303年），段部首领段务勿尘受封**辽西公**，得到辽西郡封地，后世据此把这段割据称为“**辽西国**”（303—338）。段部以令支（今河北迁安西）为都城，最盛时西接渔阳、东界辽水，有部众三万余家、控弦四五万骑。

段部与慕容部之间，争夺与联姻同时进行。《资治通鉴》接着记：“段国单于阶以女妻廆，生皝、仁、昭。”慕容廆的正妻出自段部，她所生的慕容皝，正是后来建立前燕的那个人；此后段氏之女又多次成为慕容政权的后妃。两个部族互为敌手，也互为姻亲。

辽西的格局在十几年间翻转：338年，段部被前燕与后赵联军攻破，令支失守，辽西国随之解体；344年，慕容部北攻宇文部，宇文部单于逸豆归走死漠北，部众五千余落被俘，残部窜匿松漠之间——这批残部，正是第二篇所记契丹、库莫奚的来源（族名谱系见第二篇「0. 先辨古代族名」）。三部角力之后，慕容部独占辽西——接下来出现的龙城，正是这场角力的产物。

{% hint style="info" %}
**提示｜“辽西国”是后世的称法**

段部首领受封的是“辽西公”（辽西郡公），其政权性质是晋朝册封下的割据势力，并非独立王朝——“辽西国”只是后世与地方表述对这段割据时段的概括，这个政权的中心并不在朝阳境内。但它说明了一件事：在慕容部建都龙城之前，辽西早已是各部族反复争夺的舞台。
{% endhint %}

#### 3. 慕容鲜卑与“三燕”龙城

294年前后，慕容廆在辽西一带经营势力。337年慕容皝建立前燕，341年在柳城以北、龙山以西营建龙城，342年迁都于此。宫殿、官署、道路、市场和宗教空间共同形成，龙城由区域中心跃升为王朝政治核心。

前燕后来迁都中原，但龙城仍是慕容政权的重要根基。慕容垂建立后燕后，龙城在政权后期再次成为都城；冯跋建立北燕，也以龙城为中心。436年北魏攻取龙城，三燕都城时代结束。

#### 4. 龙城的形制：一座仿邺城而建的新都

营建一座什么样的都城，在十六国时代是有范本可循的。慕容皝把这件事交给了汉人官员阳裕——史书称“皝所制城池宫阙，皆裕之规模”。据《资治通鉴》与《前燕录》一类记载，341年慕容皝“筑城于柳城之北、龙山之西，立宗庙宫阙，命曰龙城”，同时把柳城改称龙城县。

龙城就埋在今天朝阳的老城区之下，考古工作把这座城一点点“挖”了回来：

* **宫城。** 2003—2004年，考古人员在老城区北部发掘出一处坐北朝南的城门遗址，现存部分由大型夯土城门墩台、石砌门道、南北向石子路面、砖路和城墙构成。前燕时期的门址开三个门道，后燕门址在其基础上扩建。古代建筑等级制度规定，只有都城城门才允许开设三门道，因此这处门址被判定为三燕都城宫城——和龙宫的南门。
* **城圈。** 2005年又发现龙城北门：外城与宫城共用北门，为单门道，宽7.5米、进深22米。宫城与和龙宫位于城的北部，与外城共用北墙。根据已发掘的北、东、西面城墙北半部以及宫城东墙、南墙，龙城平面呈北宽南窄的梯形，南北长约1300米、北部宽约820米（西门压在近现代建筑之下，尚未发掘）。
* **园林。** 城北有皇家园林龙腾苑，遗址在今双塔区他拉皋镇木营子村附近，以东团山子、西团山子两座大型人工土台为中心，面积约1平方公里，被认为是东北地区最早的皇家园林。

为什么值得专门看它？魏晋至隋唐是中国古代都城格局的转型期。此前西周确立的“营国”制度以王宫居中、棋盘格道路为特征；把它改造成“宫城偏北、以南北中轴统摄全城”的，是曹操营建的曹魏邺城。龙城正是按邺城的营造模式建造的，恰好位于这条链条的中间：**曹魏邺城 → 三燕龙城 → 北魏洛阳城 → 唐长安城 → 明清北京。** 所以龙城的价值不只在“做过都城”，还在于它是一座都城规划变革期的珍贵样本。

{% hint style="info" %}
**考古｜两道“国字号”记录**

龙城宫城南门遗址于2004年被评为“全国十大考古新发现”；2019年10月，“三燕龙城遗址”被国务院公布为第八批全国重点文物保护单位。遗址位于朝阳老城区北部，可见度受原址保护与展示条件影响，具体开放情况以现场为准。
{% endhint %}

#### 5. 移民与制度：辽西文化圈的形成

西晋末年以来中原战乱，大量人口进入辽西。慕容政权吸纳汉族士人、沿用中原官制与礼法，同时保留鲜卑军事组织和政治传统。所谓“汉化”并非单向替代，“鲜卑化”也不是文化倒退；不同人群在军役、婚姻、语言、服饰和制度中相互影响。

三燕龙城因此形成兼具草原、辽东和中原因素的区域文化圈。朝阳出土的墓葬、壁画、陶器与建筑遗存，既可见中原制度和审美，也保留北方族群的生活与军事传统。

这段交融的影响比三燕政权本身更长久。留在辽西的汉人在乱世中大量依附鲜卑贵族，形成胡汉杂糅的复合群体。十六国到北魏的连年整合，正是靠这样一批兼通两种传统的人完成的——他们也是后来北魏统一北方、乃至隋唐重建大一统所依靠的精英来源之一。

{% hint style="warning" %}
**看点｜四件常被提起的三燕文物**

地方文物梳理中，最常被点名的三燕代表是：**马镫**（三燕马具与甲骑具装技术对后世影响深远）、**金步摇**（鲜卑贵族的冠饰）、**鸭形玻璃注**（来自域外的玻璃器，说明草原丝路上的贸易网络）、以及**冯素弗墓壁画**（冯素弗是北燕宗室重臣）。四者合起来说明：龙城不只是政治中心，也是技术、奢侈品与图像的汇聚点。它们多可在朝阳与沈阳的博物馆中看到，具体展陈以馆方当日安排为准。
{% endhint %}

#### 6. 从宫殿到佛寺：城市空间的再解释

三燕宫殿台基后来成为北魏佛塔、隋唐塔院和辽塔的基础，这种层层利用浓缩在今天的朝阳北塔之下。旧王朝的权力中心被改造为佛教纪念空间，既是城市遗产的延续，也体现新政权对历史记忆的重新解释。

凤凰山古称龙山。前燕时期修建龙翔佛寺，被地方历史叙事视为东北较早见于记载的佛寺之一。

{% hint style="info" %}
**科普｜大凌河为何也是一条文化通道**

大凌河穿行于辽西山地和盆地，沿岸阶地适合聚落，河谷又把凌源、喀左、朝阳、北票、义县一线连接起来。人群、军队、使者和物资未必乘船远航，却会沿着河谷较平缓的地形移动，因此“河流通道”既包括水运，也包括沿河陆路。
{% endhint %}

{% hint style="warning" %}
**小故事｜从北燕公主后裔到北魏太后**

冯太后是北燕末代君主冯弘的孙女、冯朗之女。北燕灭亡后，冯氏家族进入北魏；她后来成为北魏文成帝皇后，又以皇太后、太皇太后身份两度临朝。

约485至490年间，她在龙城旧宫基址兴建“思燕佛图”。塔名中的“思燕”，把她的北燕血缘、对父祖的追念与北魏皇家的佛教功德联系在了一起。
{% endhint %}

{% hint style="warning" %}
**小故事｜比玄奘更早的求法者**

北燕僧人昙无竭又名法勇，相传从龙城一带出发，经西域前往印度求法，时代早于玄奘二百余年。他的旅程提醒我们：三燕龙城既接近东北边地，也连接着横跨欧亚的佛教传播路线。
{% endhint %}

#### 7. 龙城、高句丽与扶余关系

三燕与高句丽之间既有战争，也有外交、婚姻、人口流动和文化接触。

辽东局势的每一次变化，都会影响龙城的安全与资源。北燕末年，冯弘东奔高句丽，更显示两地政治命运彼此牵动。

扶余的中心大体位于今吉林中部松花江流域。魏晋时期，它既要应对高句丽扩张，也与辽东郡、公孙氏、曹魏和后来的前燕保持朝贡、结盟或依附关系。前燕慕容皝曾东击高句丽，后又进攻扶余并掳其王；这些行动说明龙城政权要取得辽东优势，就必须同时处理辽河以东与松花江流域的力量。

从更大尺度看，龙城位于中原、草原、辽东与朝鲜半岛之间。扶余和高句丽并不以朝阳为中心，却会通过战争、使节、人口迁移和贸易改变龙城的外部环境。朝阳的兴盛来自交通交汇，危机也来自多方向力量同时进入。

**小结｜龙城的历史坐标**

都城史的核心不是连续存在一个固定王朝，而是同一片城市空间被不同政权反复占据、焚毁、重建与赋义。北塔之下的地层，是这段历史最直观的剖面。
{% endhint %}

{% hint style="info" %}
**提示｜都城遗址四问**

第一，城墙与宫城如何布局；第二，宫殿、道路和佛寺如何分区；第三，火烧、废弃和重建留下什么地层；第四，后世为何继续选择同一地点。带着这四个问题看三燕龙城和北塔，零散遗迹便会重新组成一座城市。
{% endhint %}

{% hint style="info" %}
**小结｜从龙城都城到营州门户**

436年北魏攻取龙城后，部分官民被迁往平城等地，部分人口留在辽西，另一些则进入辽东或高句丽控制区。古都衰落并不意味着居民全部消失，而是政治中心、人口和技术发生再分配。

北魏、北齐、北周和隋唐继续利用旧城交通条件，并在宫殿基址上营建佛塔。三燕时期汇聚的工匠传统、佛教信仰和多族群社会，因此以新的制度形式延续。下一篇的“营州”，正是都城遗产向区域门户转型的结果。

从考古角度看，判断城市是否“延续”，不能只看名称是否相同，还要观察道路、建筑方向、墓地、陶器和生活垃圾是否连续。朝阳北塔及三燕龙城遗址提供的，正是多时期城市叠压的证据。
{% endhint %}
