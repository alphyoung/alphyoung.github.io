# 简读朝阳

![朝阳与周边地点示意图：以朝阳市区为中心，北接内蒙古赤峰，西邻宁城、平泉与河北承德，东连阜新、义县、北票，南经锦州、葫芦岛、山海关临渤海；大凌河自西南向东北流经朝阳后折向东南入海；图下为同一个地点的五个名字——柳城、龙城·和龙、营州、兴中府、朝阳](.gitbook/assets/map-region.png)

*图中朝阳市区即历代柳城、龙城（和龙）、营州、兴中府所在；周边城市仅作方位参照。*

朝阳最硬的两张名片，是**三燕古都**和**辽塔圣地**。

在中国古代，一座城市做过都城并不稀奇；但同一座城被三个以“燕”为国号的政权先后选作都城或陪都，全国罕见。四至五世纪，前燕、后燕、北燕先后以龙城（今朝阳）为都城或陪都，龙城也是中国古代唯一以“龙”命名的都城。今天慕容街下面的宫城南门遗址、北塔地下的和龙宫夯土台基，都是那个时代的实物。

辽代又给了朝阳第二重身份。辽国七大佛教中心之一就是兴中府（今朝阳），境内现存辽塔约十四座：北塔与南塔沿慕容街南北相望、相距约一千二百米，锁定了一条肉眼可见的辽代城市轴线；凤凰山的摩云塔、大平房镇的郊野塔群，则把“辽塔圣地”写进山野与天际线。

## 这本书怎么读

全书以时间为序，六篇串起一亿三千万年的生命史、五千余年的文明史和两千余年的城市史。其中**第三篇（三燕古都）与第五篇（辽塔圣地）是两个核心篇**，其余各篇是它们的来路与余响：

| 篇目 | 内容 | 与两个看点的关系 |
| --- | --- | --- |
| 第一篇 | 朝阳之前：一亿年的生命与五千年的文明 | 远景铺垫 |
| 第二篇 | 柳城时代：燕汉边疆与曹操破乌桓 | 通往三燕古都的前奏 |
| **第三篇** | **龙城时代：三燕古都** | **核心看点一** |
| 第四篇 | 营州时代：唐帝国的东北门户 | 通往辽塔圣地的前奏 |
| **第五篇** | **兴中府时代：辽塔圣地** | **核心看点二** |
| 第六篇 | 从古城到今天 | 余韵：塔与城如何被重新发现 |

这本小册子写给历史爱好者和旅行者，愿它成为一次认识朝阳的起点。
