朝阳最硬的两张名片，是**三燕古都**和**辽塔圣地**。

四至五世纪，前燕、后燕、北燕先后以龙城（今朝阳）为都城或陪都——因三者国号都取“燕”，后世合称“三燕”；龙城也是中国古代唯一以“龙”命名的都城。

辽代又给了朝阳第二重身份：辽国七大佛教中心之一就是兴中府（今朝阳），境内现存辽塔约十四座，是名副其实的“辽塔圣地”。

## 这本书怎么读

全书以时间为序，六篇串起一亿三千万年的生命史、五千余年的文明史和两千余年的城市史。其中**第三篇（三燕古都）与第五篇（辽塔圣地）是两个核心篇**，其余各篇是它们的来路与余响：

| 篇目 | 内容 | 与两个看点的关系 |
| --- | --- | --- |
| 第一篇 | 朝阳之前：一亿年的生命与五千年的文明 | 远景铺垫 |
| 第二篇 | 柳城时代：从燕汉边疆到曹操破乌桓 | 通往三燕古都的前奏 |
| **第三篇** | **龙城时代：三燕古都与族群交往** | **核心看点一** |
| 第四篇 | 营州时代：唐帝国的东北门户 | 通往辽塔圣地的前奏 |
| **第五篇** | **兴中府时代：辽塔圣地与佛教盛景** | **核心看点二** |
| 第六篇 | 从古城到今天 | 余韵：塔与城如何被重新发现 |

这本小册子写给历史爱好者和旅行者，愿它成为一次认识朝阳的起点。
