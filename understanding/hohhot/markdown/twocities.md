# 第五篇｜双城岁月：驻防、寺院与商路

> 清代

归化城之外，一座新的驻防城改变了城市格局。

## 1. 归化与绥远

1739年，清廷在归化城东北建成绥远城。旧城以召庙、商贸和居民生活见长，新城以驻防军政为突出职能，两城逐渐由道路和商业联系起来。将军衙署保存了新城的制度痕迹，“归绥”则合取两城之名。

双城相距约五里，驻防制度使它们在管理与人口构成上有所区别。但旧城也有蒙古居民和政治功能，新城也有商业生活。随着城间道路上的店铺、住宅增加，两城逐渐相连；“军城”“商城”概括的是重心，并非截然隔绝的两种世界。

## 2. 公主府与宗教建筑

公主府与康熙帝之女固伦恪靖公主有关，呈现清代皇室与蒙古贵族的婚姻关系。五塔寺的塔与蒙文天文图、清真大寺的历次重修，则记录着不同的知识传统与社区生活。清代青城由这些各具来历的空间共同组成。

同时，蒙古和硕特部固始汗进入青藏地区，支持格鲁派，形成和硕特汗国的统治；准噶尔汗国则在西部草原崛起，并与清廷长期交战。前者有助于理解青城召庙所联系的藏传佛教世界，后者直接影响归化城防务与清代驻防政策。

## 3. 驼队连接的商业城市

大盛魁等商号把归化城的采购、仓储与结算，连接到草原运输和销售。茶叶等货物依靠驼队、伙计与信用远行，旅蒙贸易与人口迁徙共同塑造了旧城的商业生活。

**小故事｜走西口：一首离别歌背后的生计**

离乡者走向口外，有人做伙计，有人务农、经营手艺或贩运货物。清代以来，晋陕等地人口进入土默川、归化城及周边地区，“走西口”成为这段迁徙谋生史的概括。它不是一次统一出发，也并非每个人最终定居。

杀虎口是晋北通向口外的重要通道，但“西口”在迁徙、贸易与地方称谓中的含义有所不同，不能把所有人的路线都画成同一条。民歌《走西口》传唱离别与牵挂，留下的正是宏大移民史中家庭的感受。

这些往来给归化城带来劳动力、商业联系与生活习惯。走西口发生在已经形成的城市与区域网络中，不能用它替代俺答汗营建归化城的历史。
{% endhint %}

{% hint style="success" %}
**小故事｜寺院里的四种文字**

康熙时期，清廷与准噶尔的战争影响归化城。1694年，席力图呼图克图组织僧人和民众参与加筑城垣，寺院随后得到支持并扩建。

召内西征记功碑使用满、汉、蒙、藏四种文字。它们说明，寺院既属于信仰世界，也参与地方防务，并与清代跨地区的政治和宗教关系相连。
{% endhint %}

{% hint style="info" %}
**科普｜不出本钱，也能“顶身股”？**

晋商经营中的“身股”，是依据任职、资历或贡献取得分红份额的安排。大盛魁也发展出自己的身股制度，用利润分配把掌柜、伙计与商号的长期经营联系起来。它与出资形成的资本份额不同，也不等于今天可以自由买卖的股票。

商号的赊销、债务与异地结算，同货物运输一样重要。不过，贸易网络、信用业务与专业票号并非一回事；“清代华尔街”不足以准确说明大盛魁的经营制度。
{% endhint %}
