# 第三篇｜丰州与白塔：区域中心的再次兴起

> 隋唐至辽金元

丰州是辽金元时期的城市中心，不能视为明代归化城在同一地点的延续。

## 1. 突厥、回鹘与唐朝的北方

552年，突厥击败柔然，逐渐成为草原强权，后来分为东、西突厥。中原此时经历西魏、北周到隋唐的更替。630年，唐太宗时期唐军击败颉利可汗，东突厥政权覆亡，阴山南麓进入新的军政格局。

七世纪后期，后突厥汗国兴起；八世纪中叶，回纥汗国取而代之，后来改称回鹘。它与唐朝既有军事合作，也有马绢贸易。840年汗国瓦解后，部分人群迁往其他地区。阴山南北的历史因此包含政权更替，也包含人群、技术和信仰的流动。

唐代盛乐地区与单于大都护府相联系，显示这里在北方军政管理中的地位。都护府并非普通郡县，其设置与对周边人群、地域的统辖有关。有关机构曾有调整，因此不能将整个唐代都概括为同一种地方建制。

## 2. 辽金元的丰州

辽代丰州属于西京道，位于今呼和浩特东部，后来历经金、蒙古与元朝统治。行政、驻军、生产和贸易共同支撑城市，榷场为区域交换提供受管理的渠道。

丰州与托克托的云中、和林格尔的盛乐分处不同地点。白塔留下宗教景观，城址与题记则记录它曾经的区域中心地位。

## 3. 城消隐，塔留下

辽代兴建的万部华严经塔，俗称白塔，八角七层。砖雕与佛教图像保存了当年的宗教艺术，塔内金、元、明等时期的多种文字题记，则留下后来者的踪迹。丰州的大部分面貌已经消隐，白塔仍记录着城市曾经的繁盛。

## 4. 蒙古帝国、元朝与四大汗国

蒙古高原的人群史，并不是匈奴、鲜卑、柔然、突厥、回鹘依次消失的接力。政权瓦解以后，居民仍可能留居、迁徙，或加入新的联盟。汗国的名称、语言群体与民族身份，不能简单画上等号。

1206年，铁木真被拥立为成吉思汗，蒙古帝国兴起。西夏在1227年灭亡，金朝在1234年灭亡，丰州进入蒙古统治。1271年忽必烈定国号为元，1279年南宋灭亡，阴山南麓与中原进入同一王朝的统治格局。

蒙古部的早期历史通常与额尔古纳河流域及史籍中的“蒙兀室韦”相联系。此后相关人群向高原腹地迁徙，与不同部落交往。十三世纪初的政治整合，推动“蒙古”从部落名称发展为更广泛的共同身份。蒙古高原作为地理名称，其历史远早于蒙古族共同体的形成。

**小故事｜辽亡以后，耶律大石去了哪里？**

1125年辽朝灭亡前后，契丹贵族耶律大石率部向西发展，最终在中亚建立西辽。辽的政治传统因此有了两种不同去向：丰州进入金朝统治，西迁者则在遥远的中亚延续了新的政权。

西辽使用汉文年号，也治理中亚不同语言和信仰的人群。它与青城的联系在于辽朝历史的分流，而不是西辽曾接替金朝统治丰州。
{% endhint %}

**科普｜白塔上的中世纪“朋友圈”**

白塔题记保存了汉文、契丹文、女真文、蒙古文、西夏文及叙利亚文等文字，也有八思巴字的使用。叙利亚文题记联系着东方基督教传统：一座佛塔，也留下了不同信仰者往来的痕迹。

文字、语言和族属并非一一对应，有人会用一种文字记录另一种语言。题记见证了多样人群的活动，却不能仅凭文字就判定每位题记者都是外国商人。
{% endhint %}
