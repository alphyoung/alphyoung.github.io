## 从地域往事到双城与首府

> 给历史爱好者与旅行者的地方历史科普小册。沿阴山与黄河，从云中、盛乐、丰州读到归化、绥远和现代首府。

## 先有地域，后有青城

1572年，俺答汗与三娘子营建库库和屯；1575年明廷赐名“归化”。此前，这片地域已有漫长历史和多座古城，却没有后来这座青城。另有资料以1581年为建城节点，本书将其理解为十六世纪后期营建过程的不同记年口径。

阴山南麓连接蒙古高原与黄河流域。这里的历史，既有政权竞争，也有迁徙、贸易、宗教和共同生活。云中、盛乐、丰州分处不同地点，并非同一座城市连续改名。
