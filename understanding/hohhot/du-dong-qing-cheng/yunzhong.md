# 第二篇｜云中与盛乐：地域统治中心的转移

> 战国至北朝

阴山的历史由许多不同人群共同书写：这里有赵国的骑兵、汉朝的边郡、匈奴的外交，也有拓跋鲜卑建立的都城。

## 1. 赵武灵王的改革与云中

公元前307年，赵武灵王推行胡服骑射，学习北方人群的骑乘装束与作战方式。赵国随后经营云中，今托克托县古城村一带由此成为重要治理中心。云中郡是辖区，云中城是与郡治相联系的城市，都不同于今天的呼和浩特城区。

秦汉时期，云中承担行政、驻军与粮食供应职能。汉武帝经略匈奴时，它是军事支点；汉宣帝、汉元帝时期，外交与粮食援助又成为汉匈关系的重要内容。

## 2. 秦始皇、蒙恬与北方道路

公元前221年，秦始皇统一六国，云中进入秦帝国的郡县体系。此后蒙恬北击匈奴，长城、驻军与交通共同组成北方防务。长城背后，需要持续运输粮食、调动军队，也需要道路把边郡与关中连接起来。

前212年，秦始皇下令营建连接云阳与九原的秦直道，使关中与北疆的联系更加紧密。长城背后的道路与粮食供应，同样支撑着帝国的边防。

对秦汉王朝而言，河套不仅是边防空间，也是粮食、牧草和马匹的来源。控制河岸、渡口和道路，可以支撑驻军与运输；争夺这些资源又可能引发战争。因此，黄河有时是军事屏障，有时是运输通道，其作用随政治局势和河道条件而变化。

## 3. 盛乐与拓跋鲜卑

今和林格尔县土城子一带的盛乐，是拓跋鲜卑早期政治中心。386年，拓跋珪在此重建政权，随后改称魏；398年迁都平城，即今大同。当时南方为东晋，北方诸政权竞争。

盛乐曾承担都城职能，与云中郡治性质不同，也并非由云中迁址改名而来。迁都以后，此地仍继续使用，多期城址保存了政治地位改变后的历史。

## 4. 武川军人走向关中

四世纪末至六世纪中叶，柔然在蒙古高原崛起，社仑于402年称可汗。它与北魏长期竞争，阴山一带成为双方军事往来的重要地带。北魏太武帝拓跋焘多次北征，军镇的设置正与这种持续的压力有关。

北魏为防御柔然设置北方军镇，武川是六镇之一。六世纪二十年代的动乱，使许多军人离开故乡。出身武川的宇文泰后来掌握西魏政权，奠定北周基础，其军事政治集团继续影响隋唐。地方军镇由此与中国中古政治史相连。

武川与盛乐承担不同职能：盛乐曾是统治者所在的政治中心，武川则属于北边防御体系中的军镇。都城、郡治和军镇可以同时存在于更大的国家空间中，彼此配合，而非依次取代。

**小故事｜昭君出塞之前，云中的粮食已经北行**

呼韩邪单于与郅支单于争立时，转而寻求汉朝支持。汉元帝初年，汉廷命云中、五原运粮，救济其困乏的部众。前36年郅支被汉军击败并杀死，三年后呼韩邪再到长安，请求婚姻关系，王昭君由此出塞。

昭君的远行巩固了已有的政治联系。汉代匈奴首领称“单于”；后世诗文中的琵琶、离愁和青冢，则为这段外交史增添了深厚的文化记忆。呼市南郊青冢的纪念传统悠久，但墓主人身份尚未经考古确证。
{% endhint %}

{% hint style="success" %}
**小故事｜战败之后，一首歌留下阴山**

546年，东魏高欢进攻西魏玉壁失败。据文献流传的故事，他让斛律金唱《敕勒歌》，自己随之应和。歌中没有战场，只有“敕勒川，阴山下”与“风吹草低见牛羊”。

敕勒川常被联系到土默川及阴山南麓。经过语言转换和文献传承，这首歌把北方人群的故乡记忆留了下来，也把青城与北朝的战争、迁徙连接在一起。
{% endhint %}

{% hint style="success" %}
**小故事｜木兰的军书，为什么写着“可汗”？**

《木兰诗》写“可汗大点兵”，又写“归来见天子”。两种称呼并存，使这首诗带有北朝政治与文化交汇的色彩。木兰替父从军、渡河远行的故事，也让人联想到北方军户家庭与长期征战的生活。

有研究将诗的背景联系到北魏与柔然的战争，但其成篇年代和地名解释仍有不同意见。后来广为流传的“花木兰”姓氏也不见于诗中。木兰在本书中属于文学记忆，不能据此认定她是呼和浩特人，或把某一处遗址确定为她的战场。
{% endhint %}

{% hint style="success" %}
**小故事｜阴山没有留住所有出发的人**

从盛乐迁往平城的拓跋政权，从武川走向关中的宇文泰，以及后来跨越关口谋生的人们，都把这片土地的经验带向远方。草原往事不仅是英雄在故乡建功，也包括离开故乡以后改变更广阔的历史。

他们属于不同年代和政治世界，不能排成单一民族的英雄谱。共同的线索是：阴山南北的骑乘经验、军镇生活、语言与人际联系，在迁徙中进入新的社会。
{% endhint %}
