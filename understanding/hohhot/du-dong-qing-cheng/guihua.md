# 第四篇｜归化召城：俺答汗与藏传佛教

> 元明之际至明末

十六世纪后期，库库和屯兴起。“呼和浩特”及“青城”作为这座城市的名称，从这一阶段进入地方史。

## 1. 北元：元朝退出大都以后

1368年，明朝建立，元顺帝退出大都，元朝统治集团退向北方，其延续政权通常称为北元。中原王朝已经更替，蒙古草原的政治历史却继续展开。此后明朝文献中常见的“鞑靼”“瓦剌”，记录着蒙古各部之间及其与明朝的复杂关系；“北元”一词的具体时间范围，在不同著述中也不完全一致。

十五世纪末至十六世纪初，达延汗巴图孟克重整蒙古诸部，土默特属于蒙古右翼的重要组成部分。他的孙子俺答汗后来经营土默川，发展生产与贸易。由北元、达延汗到俺答汗，归化城的兴起才有了完整的草原政治背景。

明代围绕河套的竞争，也影响土默特的发展。俺答汗经营的社会兼有畜牧、农业与贸易，迁入人口带来耕作和手工业，互市又把当地与明朝边镇联系起来。“草原政权”之中同样有农田、村落和城市。

## 2. 从封贡到建城

1570年，把汉那吉投奔明朝，促成祖父俺答汗与明廷交涉。1571年，明穆宗封俺答为顺义王，封贡互市确立，为土默特的生产、贸易和建城创造了较稳定的条件。

1572年（明隆庆六年），俺答汗与三娘子营建库库和屯，现代呼和浩特的城市史由此开启。库库和屯与“呼和浩特”是同一蒙古语地名的不同音写，意为“青色的城”。1575年明廷赐名“归化”；另有资料以1581年为建城节点。

先有俺答汗营建的新城，后有“归化城”这一赐名。在此之前，云中、盛乐、丰州已各有历史，但没有这座青城，也不存在早已建成的归化城。

## 3. 大召与城市生活

大召始建于1579年。银佛、龙雕与壁画体现宗教艺术，僧众、工匠与供养者则将寺院连接到城市生活。大召、席力图召周边逐渐形成街巷与商业，塑造了归化城的召城面貌。

## 4. 林丹汗与后金：归化城的又一次转折

十七世纪，察哈尔部林丹汗试图重振蒙古大汗权威，归化城也被卷入争夺。1627年，他占领归化城；1632年，皇太极率后金军西进，林丹汗撤离。1635年其子额哲归降后金，次年皇太极改国号为清。青城由此进入新的统治格局。

**小故事｜1578年，青海湖畔的一次会面**

俺答汗与格鲁派高僧索南嘉措在青海会面，互赠尊号，建立施主与宗教导师的联系。俺答提供支持，索南嘉措带来宗教影响；随后的寺院营建、僧人往来与经典传播，使土默特和西藏更加紧密地相连。

索南嘉措最先获得“达赖喇嘛”尊号，却称三世，因为前两世属于追认的传承。“达赖”意为大海，这个蒙古语参与构成的称号，本身就保存着蒙藏交往史。
{% endhint %}

{% hint style="success" %}
**小故事｜从土默特出发的少年**

1589年，俺答汗的曾孙云丹嘉措出生，后来被认定为索南嘉措的转世，成为四世达赖。席力图召第一世主持希迪图噶布齐担任他的启蒙老师，连接起蒙古贵族家庭与藏文经典的学习世界。在历世达赖喇嘛中，他是唯一的蒙古族成员，这一出身使土默特家族与西藏宗教传承形成了格外鲜明的联系。

1602年，云丹嘉措入藏。扯力克汗和三娘子派人护送，寺史也记述了老师同行的经历。归化城既接待远来的高僧，也由此成为重要宗教人物成长和出发的地方。
{% endhint %}

{% hint style="success" %}
**小故事｜三娘子守住的，不只是一座城**

俺答汗去世以后，土默特面临权力承继与内部关系调整。三娘子仍参与政治交涉，维护同明朝的互市关系，明廷封她为忠顺夫人。

“三娘子城”的地方记忆，既与营建有关，也与她在此后维持秩序和通商中的作用有关。归化城的生活需要稳定的交换，政治人物的选择最终影响着商人、牧民和耕作者的生计。
{% endhint %}

{% hint style="info" %}
**科普｜“召”是什么？**

“召”在蒙古语语境中常用于称佛教寺庙。大召、席力图召等各有自己的师承和营建历史，今天的建筑往往包含多次重修与扩建的成果。
{% endhint %}
