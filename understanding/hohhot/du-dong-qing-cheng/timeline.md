# 附录二｜历史简表

### 表11｜地方事件与时代背景

| 年代           | 事件                            |
| ------------ | ----------------------------- |
| 旧石器时代        | 大窑一带留下石器制造与人类活动的遗存。           |
| 新石器时代        | 海生不浪等聚落发展；龙山时代出现后城咀设防聚落。      |
| 商周时期         | 阴山南麓及周边进入青铜时代，与中原和其他北方地区发生联系。 |
| 战国秦汉         | 云中成为北方重要边郡和城市。                |
| 公元前221—前212年 | 秦统一六国，经略北疆，营建连接云阳与九原的秦直道。     |
| 公元前33年       | 王昭君出塞，嫁给呼韩邪单于。                |
| 386—398年     | 盛乐为拓跋珪政权的早期政治中心，后迁都平城。        |
| 隋唐           | 盛乐地区进入新的北方军政与交通格局。            |
| 辽金元          | 丰州发展，辽代兴建万部华严经塔。              |
| 1368年以后      | 元朝统治集团北退，北元及此后蒙古各部的历史展开。      |
| 十五世纪末至十六世纪初  | 达延汗重整蒙古诸部，为后来土默特的发展提供政治背景。    |
| 1571年        | 俺答封贡，明蒙关系出现重要转折。              |
| 十六世纪后期       | 归化城兴起；大召于1579年始建。             |
| 1739年        | 绥远城建成，双城格局确立。                 |
| 1921年        | 铁路通达归绥。                       |
| 1937—1949年   | 归绥沦陷、地方抗日斗争与绥远起义。             |
| 1952年        | 内蒙古自治区党政机关迁驻归绥。               |
| 1954年        | 蒙绥合并，归绥市改名呼和浩特。               |
| 1957年        | 内蒙古大学成立。                      |
