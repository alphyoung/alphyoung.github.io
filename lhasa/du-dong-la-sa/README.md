宗教、族群与人物交织的城市历史

从曲贡的史前聚落，到吐蕃赞普的逻些；从佛教各派与地方领主，到和硕特、准噶尔和清廷的角逐；从跨越山口的商队，到八廓街巷里的不同信仰——沿着拉萨河，读懂圣城，也读懂它与周边世界的关系。

## 先把地图看明白

拉萨老城位于拉萨河、也就是吉曲的北岸。河谷相对开阔，周围高山环绕，农业、牧业与远途交通共同支撑城市。雅鲁藏布江是拉萨河汇入的干流，并不直接穿过老城。

读拉萨，先认三个中心：大昭寺与八廓街汇集朝圣和街市，布达拉宫与雪城承载历史上的宗教与政务，罗布林卡展现夏季驻地和园林生活。再向城外看，寺院、村落、牧场和商路把它们连接起来。

本册以五篇通史串起年代，以一篇人物故事走进日常，另附四派与地方势力速览、文物札记、时间轴和地名表。故事依据史料改写，不虚构对白；宗教传说与历史证据分别说明。
