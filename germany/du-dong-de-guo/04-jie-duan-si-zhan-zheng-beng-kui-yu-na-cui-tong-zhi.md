# 04 阶段四·战争、崩溃与纳粹统治

一战战败终结了帝制与王朝政治，凡尔赛条约重划边界，魏玛民主在危机中艰难维系，最终被纳粹政权摧毁。1933—1945年的"第三帝国"带来吞并、占领与大屠杀，1945年德国无条件投降。

**1918** 十一月革命\
**1919** 凡尔赛条约 · 魏玛宪法\
**1933** 希特勒上台\
**1945** 无条件投降

## 4.1 一战、帝制终结与魏玛共和国

1914 — 1933

1914年第一次世界大战爆发。德国对奥匈帝国的支持和自身战略选择是危机扩大的重要因素，欧洲王室亲缘未能阻止战争。

1918年的基尔水兵起义和**十一月革命**推动帝制崩溃，威廉二世退位，各邦君主制相继结束。此后王室联姻不再具有决定德国国家继承的制度作用。

#### 《凡尔赛条约》之后

| 地区        | 战后安排                    |
| --------- | ----------------------- |
| 阿尔萨斯—洛林   | 归还法国                    |
| 波森、西普鲁士大部 | 划入重建的波兰，东普鲁士与德国主体被分隔    |
| 但泽        | 成为国际联盟保护下的自由市，与波兰存在特殊安排 |
| 北石勒苏益格    | 公投后划入丹麦                 |
| 欧本—马尔梅迪   | 划入比利时                   |
| 上西里西亚     | 公投、冲突与国际处理后分割，部分划入波兰    |
| 萨尔        | 由国际联盟管理15年，1935年公投后回归德国 |
| 海外殖民地     | 德国失去全部殖民地               |

德国失去约13%的战前欧洲领土。领土与赔款问题成为民族主义动员的重要议题，但共和国的失败还与国内反民主力量和经济危机相连。

资料：[德国联邦政治教育中心：凡尔赛与魏玛](https://www.bpb.de/shop/zeitschriften/apuz/30789/versailles-und-weimar/)

1919年的魏玛宪法实行民主制度和包括女性在内的普选。文化与科学一度繁荣，但政治暴力、1923年恶性通货膨胀和1929年后的大萧条不断侵蚀民主。纳粹利用失业、民族主义和反犹主义扩大影响，保守精英误以为能够控制希特勒。

## 4.2 纳粹统治：吞并、占领与毁灭

1933 — 1945

{% hint style="info" %}
\*\*"第三帝国"是纳粹的宣传性称呼。\*\*这一政权并未恢复皇帝或王朝统治。
{% endhint %}

1933年希特勒出任总理，随后利用紧急措施与《授权法》摧毁民主、镇压反对派，并削弱邦国自治。

纳粹对教会同时采取拉拢、控制与打压。部分人士迎合政权，也有人抵抗或保护受迫害者，教会整体未能有效阻止迫害。纳粹反犹主义以种族论为核心，同时利用欧洲长期存在的反犹偏见。

#### 不同性质的扩张

| 时间       | 行动                   | 性质                       |
| -------- | -------------------- | ------------------------ |
| 1935     | 萨尔回归                 | 依既定国际安排公投后重归德国           |
| 1936     | 莱茵兰重新军事化             | 改变军事限制，国界并未扩大            |
| 1938年3月  | 吞并奥地利                | 将邻国并入德国                  |
| 1938年秋   | 吞并苏台德地区              | 在《慕尼黑协定》背景下夺取捷克斯洛伐克领土    |
| 1939年3月  | 设立波希米亚和摩拉维亚保护国，夺取梅梅尔 | 进一步摧毁捷克斯洛伐克，并向立陶宛强取领土    |
| 1939年9月后 | 入侵波兰并扩大战争            | 部分土地直接吞并，其他地区实行不同形式的占领统治 |

地图：[德国领土变化至1939年](https://www.bpb.de/system/files/dokument_pdf/01_deutsches_reich_0.pdf)

军事占领范围远大于正式吞并范围。占领法国、挪威或苏联部分地区，不等于这些地区都成为德国本土。

1935年的《纽伦堡法》剥夺犹太人权利，1938年"水晶之夜"标志反犹暴力进一步升级。1941年入侵苏联后，战争与大规模屠杀持续扩大；1942年万湖会议协调已经推进的欧洲犹太人灭绝政策。

纳粹及其协作者杀害约**六百万犹太人**，并大规模迫害和杀害罗姆人、辛提人、残疾人、波兰平民、苏联战俘及其他群体。1945年德国无条件投降，纳粹统治与吞并秩序瓦解。
