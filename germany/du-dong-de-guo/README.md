## 阅读之前，先区分三种“版图”

**文化与语言分布区**：德语人口生活的地区，不总在同一个国家之内。

**帝国政治疆域**：神圣罗马帝国包含德意志地区，也包括波希米亚及意大利部分地区。

**王朝领地**：一个家族可以统治多个国家。哈布斯堡统治西班牙，不意味着西班牙成为德国领土。

{% hint style="info" %}
联姻也不等于国家合并。“共主关系”指两个政治实体拥有同一位君主，却保留各自的法律与制度。
{% endhint %}
