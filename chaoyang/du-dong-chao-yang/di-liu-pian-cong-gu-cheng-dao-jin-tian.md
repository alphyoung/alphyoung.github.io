# 第六篇　从古城到今天

### 古城新生：从金元明清到今天

王朝更替、寺院营建与近现代考古，让古城记忆不断被重新发现。

金元时期继续利用辽西旧城与交通节点，古塔亦有修缮。明代辽西处在防御、交通和农牧交错的边疆格局中。清代随着治理结构稳定、寺院营建和县治设置，今天“朝阳”的城市名称与空间逐步定型。

#### 1. 金元承接：兴中州与大宁路

金朝继承辽地，朝阳地区属北京路大定府体系，设兴中州等建置；南塔等建筑留下金代修缮痕迹。元代兴中州隶属大宁路，城市和交通节点继续使用，女真、蒙古、汉人及其他人群在辽西往来。

这里宜区分“府、州、路”：它们是不同王朝的行政层级和名称。金代不能简单写成“兴中路”，元代也不是继续以兴中府为最高层级；名称变化正反映统治体系的重组。

#### 2. 明代：大宁诸卫与汉蒙交界

明初在辽西北部设置大宁都司及相关卫所，朝阳一带曾有营州左、中、右等卫所。靖难之役前后明军防线和卫所内移，朝阳地区逐渐更多处于蒙古诸部活动范围，喀喇沁、土默特等力量在辽西西部和大凌河上游产生长期影响。

明代辽东边墙的主体位于更东侧的辽河平原边缘，不能笼统说整条大凌河流域都在边墙之内。朝阳更适合被理解为长城内外、蒙古诸部与辽东军镇之间的战略通道。

#### 3. 1631年大凌河之战：同一流域的下游战场

崇祯四年（1631），皇太极率后金军围困祖大寿驻守的大凌河城。该城位于今天锦州凌海一带的大凌河下游，并不在朝阳市区；它与朝阳共享一条河流，却属于关宁锦防线的另一段历史空间。

后金围城并连续打击明军援军，祖大寿最终出城议降，后又返回锦州。

此役显示后金军已能把围城、炮兵、招降和打援结合起来，严重削弱明朝辽西防线，但明朝在锦州等地的统治并非由此立即全部崩溃。

{% hint style="info" %}
**科普｜为什么“大凌河之战”不等于“朝阳之战”**

河流名称常被用作城名、堡名或战役名。1631年的大凌河城在今天凌海附近，距朝阳市区较远；把它收入本册，是为了展示大凌河从上游朝阳到下游辽东湾的整体战略意义，而不是把战场位置移到朝阳。
{% endhint %}

#### 4. 清代旗地、垦殖与朝阳府

清初朝阳地区主要属土默特左、右翼旗及卓索图盟范围。它位于柳条边以西北的蒙古旗地环境，人口流动和土地开垦受到制度约束；随着十八、十九世纪人口压力和边地开发，获准垦殖、租佃及越边迁入并行，汉人数量增加，形成更大规模的汉蒙交往。

佑顺寺于康熙三十七年（1698）开工，后建成并获赐名，是辽西重要的藏传佛教寺院。其建筑群位于南塔附近，却与辽代双塔相隔六百余年。乾隆四十三年（1778）设置朝阳县，光绪三十年（1904）又升置朝阳府，近现代行政地名和治理中心逐步稳定。

{% hint style="warning" %}
**小故事｜“三座塔”为什么只剩两座**

后世地名记忆中，朝阳城曾以“三座塔”著称。随着东塔毁失，今日城市中心最醒目的是北塔与南塔。消失的东塔虽然不再可见，却仍通过地名和地方叙事参与塑造城市身份。
{% endhint %}

#### 3. 从发现到保护：近现代考古改变城市记忆

近现代调查、发掘和古建筑维修，使三燕龙城、北塔地宫天宫、南塔石宫、牛河梁和热河生物群等材料进入公共视野。朝阳的城市身份也由“古塔可见”扩展为“地下城址、史前文明与生命化石共同可读”。

保护并不是把遗址冻结。考古研究会修正旧认识，展示方式也会更新。

旅行者最重要的阅读方法，是区分原址、原物、复建与叙事，并尊重遗址的脆弱性。

{% hint style="info" %}
**小结｜朝阳何以成为朝阳**

在朝阳，亿万年的生命史、五千余年的文明史与两千余年的城市史叠在同一片土地上。这里既不是单线发展的“古都传奇”，也不是若干景点的拼盘。它的独特性正来自反复的连接：农耕与草原、中原与东北、王朝政治与宗教信仰、地上古塔与地下城址。
{% endhint %}

{% hint style="info" %}
**提示｜阅读朝阳的四把钥匙**

用“叠压”理解北塔下的宫殿、木塔、砖塔与包砌层；用“通道”理解柳城、龙城、营州和兴中府为何反复成为区域中心。前者说明后世如何继承旧址，后者说明交通为何同时带来繁荣、战争和迁徙。

再用“尺度”区分亿年的化石史、千年的史前文化与数十年的王朝事件；

用“证据”让地层、器物、碑刻、文献和现存建筑彼此校验。带着这四把钥匙重访朝阳，零散景点便会重新连接成一册可以带到现场的历史地图。
{% endhint %}
