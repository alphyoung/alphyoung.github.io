# 第三篇　龙城时代：三燕都城与族群交往

### 龙城风云：三燕都城与族群交往

四至五世纪，今天的朝阳一带成为都城，历史舞台由边郡转向龙城。

魏晋时期，鲜卑诸部在北方兴起。慕容鲜卑进入辽西后，逐步建立政权与城市中心。前燕、后燕、北燕的政治变动，使龙城在东北亚交通、军事和文化交流中取得罕见地位。

#### 1. 慕容鲜卑与“三燕”龙城

294年前后，慕容廆在辽西一带经营势力。337年慕容皝建立前燕，341年在柳城以北、龙山以西营建龙城，342年迁都于此。宫殿、官署、道路、市场和宗教空间共同形成，龙城由区域中心跃升为王朝政治核心。

前燕后来迁都中原，但龙城仍是慕容政权的重要根基。慕容垂建立后燕后，龙城在政权后期再次成为都城；冯跋建立北燕，也以龙城为中心。436年北魏攻取龙城，三燕都城时代结束。

#### 2. 移民与制度：辽西文化圈的形成

西晋末年以来中原战乱，大量人口进入辽西。慕容政权吸纳汉族士人、沿用中原官制与礼法，同时保留鲜卑军事组织和政治传统。所谓“汉化”并非单向替代，“鲜卑化”也不是文化倒退；不同人群在军役、婚姻、语言、服饰和制度中相互影响。

三燕龙城因此形成兼具草原、辽东和中原因素的区域文化圈。朝阳出土的墓葬、壁画、陶器与建筑遗存，既可见中原制度和审美，也保留北方族群的生活与军事传统。

#### 3. 从宫殿到佛寺：城市空间的再解释

三燕宫殿台基后来成为北魏佛塔、隋唐塔院和辽塔的基础，这种层层利用浓缩在今天的朝阳北塔之下。旧王朝的权力中心被改造为佛教纪念空间，既是城市遗产的延续，也体现新政权对历史记忆的重新解释。

凤凰山古称龙山。前燕时期修建龙翔佛寺，被地方历史叙事视为东北较早见于记载的佛寺之一。北燕僧人昙无竭（法勇）由此一带出发西行求法，说明龙城并非封闭边都，而与更广的佛教交通网络相连。

{% hint style="info" %}
**科普｜大凌河为何也是一条文化通道**

大凌河穿行于辽西山地和盆地，沿岸阶地适合聚落，河谷又把凌源、喀左、朝阳、北票、义县一线连接起来。人群、军队、使者和物资未必乘船远航，却会沿着河谷较平缓的地形移动，因此“河流通道”既包括水运，也包括沿河陆路。
{% endhint %}

{% hint style="warning" %}
**小故事｜从北燕公主后裔到北魏太后**

冯太后是北燕末代君主冯弘的孙女、冯朗之女。北燕灭亡后，冯氏家族进入北魏；她后来成为北魏文成帝皇后，又以皇太后、太皇太后身份两度临朝。

约485至490年间，她在龙城旧宫基址兴建“思燕佛图”。塔名中的“思燕”，把她的北燕血缘、对父祖的追念与北魏皇家的佛教功德联系在了一起。
{% endhint %}

{% hint style="warning" %}
**小故事｜比玄奘更早的求法者**

北燕僧人昙无竭又名法勇，相传从龙城一带出发，经西域前往印度求法，时代早于玄奘二百余年。他的旅程提醒我们：三燕龙城既接近东北边地，也连接着横跨欧亚的佛教传播路线。
{% endhint %}

#### 4. 龙城、高句丽与扶余关系

三燕与高句丽之间既有战争，也有外交、婚姻、人口流动和文化接触。

辽东局势的每一次变化，都会影响龙城的安全与资源。北燕末年，冯弘东奔高句丽，更显示两地政治命运彼此牵动。

扶余的中心大体位于今吉林中部松花江流域。魏晋时期，它既要应对高句丽扩张，也与辽东郡、公孙氏、曹魏和后来的前燕保持朝贡、结盟或依附关系。前燕慕容皝曾东击高句丽，后又进攻扶余并掳其王；这些行动说明龙城政权要取得辽东优势，就必须同时处理辽河以东与松花江流域的力量。

从更大尺度看，龙城位于中原、草原、辽东与朝鲜半岛之间。扶余和高句丽并不以朝阳为中心，却会通过战争、使节、人口迁移和贸易改变龙城的外部环境。朝阳的兴盛来自交通交汇，危机也来自多方向力量同时进入。

**小结｜龙城的历史坐标**

都城史的核心不是连续存在一个固定王朝，而是同一片城市空间被不同政权反复占据、焚毁、重建与赋义。北塔之下的地层，是这段历史最直观的剖面。
{% endhint %}

{% hint style="info" %}
**提示｜都城遗址四问**

第一，城墙与宫城如何布局；第二，宫殿、道路和佛寺如何分区；第三，火烧、废弃和重建留下什么地层；第四，后世为何继续选择同一地点。带着这四个问题看三燕龙城和北塔，零散遗迹便会重新组成一座城市。
{% endhint %}

{% hint style="info" %}
**小结｜从龙城都城到营州门户**

436年北魏攻取龙城后，部分官民被迁往平城等地，部分人口留在辽西，另一些则进入辽东或高句丽控制区。古都衰落并不意味着居民全部消失，而是政治中心、人口和技术发生再分配。

北魏、北齐、北周和隋唐继续利用旧城交通条件，并在宫殿基址上营建佛塔。三燕时期汇聚的工匠传统、佛教信仰和多族群社会，因此以新的制度形式延续。下一篇的“营州”，正是都城遗产向区域门户转型的结果。

从考古角度看，判断城市是否“延续”，不能只看名称是否相同，还要观察道路、建筑方向、墓地、陶器和生活垃圾是否连续。朝阳北塔及三燕龙城遗址提供的，正是多时期城市叠压的证据。
{% endhint %}
