# 第一篇　河流与罗马：伦敦从哪里开始

### 泰晤士河与伦蒂尼恩

伦敦先有河，后有城。泰晤士河向东通海、向西连接内陆，适合航运，也需要稳定的渡口和桥梁。罗马人公元43年征服不列颠后不久，在河北岸建立伦蒂尼恩（Londinium）。桥、码头和道路使它迅速成为商业与行政中心。

#### 1. “凯尔特人”不是一个统一民族

罗马征服前，不列颠由许多地方共同体组成。今天常用“凯尔特人”统称他们，但卡图维劳尼人、特里诺文特人、爱西尼人等各有自己的首领与活动区域。伦敦附近的铁器时代居民没有建立一座可与罗马伦蒂尼恩直接对应的城市。

{% hint style="warning" %}
**小故事｜布狄卡烧毁了年轻的伦敦**

公元60或61年，爱西尼女王布狄卡起兵反抗罗马。罗马总督判断兵力不足，放弃守卫伦蒂尼恩；许多来不及撤走的居民被杀，城市被焚毁。考古层中的烧毁痕迹，至今仍是这场战争的证据。布狄卡来自东盎格利亚，并不是“伦敦女王”。
{% endhint %}

#### 2. 一座帝国城市

重建后的伦蒂尼恩拥有总督府、公共浴场、神庙、市场和繁忙港口。居民来自帝国各地，其中有商人、军人、工匠，也有被奴役者。约公元200年前后修建的陆侧城墙，后来长期影响伦敦城的边界。

五世纪初罗马统治结束后，依赖帝国行政与贸易的城市生活明显衰落。今天在地铁站、办公楼和街道下看到罗马遗迹，并不意味着伦敦两千年来始终保持同一规模和中心。

{% hint style="info" %}
**现场阅读｜罗马城为什么在地下**

房屋倒塌、道路垫高和反复重建会抬升地面。观看伦敦城墙遗存时，还要分辨罗马砌体与中世纪增修；眼前的一整面墙，往往不属于同一个年代。
{% endhint %}
