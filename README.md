# Understanding Series

Repository: https://github.com/alphyoung/alphyoung.github.io

All maintained documentation is stored under `understanding/`.

- GitHub Pages root: https://alphyoung.github.io/
- Europe: https://alphyoung.github.io/understanding/europe/
- Germany (English): https://alphyoung.github.io/understanding/germany/
- London: https://alphyoung.github.io/understanding/london/

The repository root is intentionally minimal:

- `.nojekyll` keeps GitHub Pages from applying Jekyll processing.
- `index.html` redirects the root address to the Understanding Europe landing page.
- `understanding/` contains all published projects and their Markdown sources.

Edit project files only under `understanding/`, commit them to `main`, and let GitHub Pages publish from that branch.
