# 第一篇｜山河与先民：青城诞生以前

> 地质往事至新石器时代

这里讲述的是今呼和浩特地区的自然与人类历史。此时尚无明代兴起的库库和屯，也不能把不同古城合成一座连续存在的“青城”。

## 1. 山地、河流与平原

大青山属于阴山山脉，呼和浩特城区位于其南麓的土默川平原。古老岩石经历多期构造变化，山地抬升、盆地沉降，流水不断搬运砂砾，逐渐形成今天山川相依的地貌。大黑河等水系连接黄河，也滋养了后来的聚落。

黄河在北方绕出巨大的“几”字弯，河套由此得名。广义河套与较狭义的河套平原，范围并不完全相同。青城处于土默川东部，山口联系南北，河谷联系东西。

阴山是蒙古高原南缘的重要山系，山口把草原与黄河流域连接起来。它既曾是军事防线，也是迁徙、贸易和日常往来的通道。山南山北的人群通过征战、婚姻、耕牧与交换不断接触，形成了漫长的多民族交往历史。

## 2. 大窑：石器制造留下的现场

1973年发现的大窑遗址，保存了远古人类利用燧石制造工具的痕迹。石核、石片和加工废料，使一次次敲击重新进入历史。遗址跨越多个时期，年代上限有约50万年、约70万年等不同表述；伴出的披毛犀、野马等化石，则留下了古代环境的线索。

## 3. 从村落到设防聚落

新石器时代，海生不浪等遗址呈现出陶器、石器与定居生活。距今约四千三百年前后的后城咀，已有城墙、壕沟和地下通道。此时黄河流域多个地区都出现了大型聚落，阴山南麓也进入了社会组织日益复杂的时代。

后城咀的防御并非只有一道墙。城门、瓮城、壕沟与地下通道组成多层设施，使进出路径受到控制。其城防形制与石峁、碧村等遗址有可比较之处，呈现黄河中游史前石城之间的联系。形制相近，并不等于已能确认它们属于同一个政权。

## 4. 商周时代：青铜器与北方人群

当中原进入商朝、西周和春秋时期，阴山南麓及周边也进入青铜时代。农业、畜牧与远距离交换共同塑造北方社会，这段历史连接着史前聚落与后来有郡县记载的云中。

商周文献中的鬼方、猃狁等名称，反映中原对北方人群的认识，但其活动范围与考古文化的对应仍有争议，不能直接当作呼和浩特的居民名册。到战国时期，林胡、楼烦等才更清楚地进入赵国北向扩张的记载。

{% hint style="info" %}
**科普｜大窑“石器工厂”怎样生产？**

古人先选取适合敲击的燧石，再从石核上剥下石片，部分石片经过修整成为工具。成品之外，废片与石核也能显示加工步骤。“工厂”是现代比喻，这里并没有已经证实的流水线、经理或固定职业分工。
{% endhint %}
